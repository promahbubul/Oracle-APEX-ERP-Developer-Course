# ক্লাস ৮: Data Type: DATE, TIMESTAMP, CLOB, BLOB

**তারিখ:** ১৬ নভেম্বর ২০২৬, সোমবার
**সময়:** সন্ধ্যা ৭:০০ থেকে রাত ১০:০০
**সপ্তাহ:** ২ | **ধাপ:** ১ (কম্পিউটার ও ডাটাবেসের বেসিক)

---

## আজকে কী শিখব

- `DATE`: তারিখ আর সময় রাখা
- তারিখ কীভাবে লিখতে হয়: `DATE '...'` আর `TO_DATE`
- তারিখ দেখানোর ফরম্যাট
- তারিখ দিয়ে যোগ-বিয়োগ
- `TIMESTAMP`
- `CLOB`: বড় লেখা
- `BLOB`: ছবি, PDF, ফাইল

---

## ১. DATE (৪০ মিনিট)

Oracle-এর `DATE`-এ থাকে: **বছর, মাস, দিন, ঘণ্টা, মিনিট, সেকেন্ড।**

> নামে DATE হলেও এতে সময়ও থাকে। এটা অনেকে ভুলে যায়, আর তাতে রিপোর্টে ভুল হয়।

### তারিখ লেখার উপায়

**উপায় ১: DATE লিটারেল (সবচেয়ে নিরাপদ)**
```sql
DATE '2026-11-16'          -- ফরম্যাট সবসময় YYYY-MM-DD
```

**উপায় ২: TO_DATE (যেকোনো ফরম্যাট থেকে)**
```sql
TO_DATE('16-11-2026', 'DD-MM-YYYY')
TO_DATE('16/11/2026 14:30', 'DD/MM/YYYY HH24:MI')
```

**বর্তমান তারিখ-সময়:**
```sql
SELECT SYSDATE FROM dual;
```

### প্র্যাকটিস

```sql
CREATE TABLE order_dates (
    order_no      VARCHAR2(20),
    order_date    DATE,
    ship_date     DATE,
    created_on    DATE
);

INSERT INTO order_dates VALUES ('ORD-001', DATE '2026-11-01', DATE '2027-01-15', SYSDATE);
INSERT INTO order_dates VALUES ('ORD-002', TO_DATE('05-11-2026', 'DD-MM-YYYY'),
                                           TO_DATE('20-02-2027', 'DD-MM-YYYY'), SYSDATE);
COMMIT;

SELECT * FROM order_dates;
```

## ২. তারিখ দেখানোর ফরম্যাট (৩০ মিনিট)

ফলাফলে তারিখ হয়তো `16-NOV-26` এর মতো দেখাচ্ছে, সময় দেখাচ্ছে না। এটা শুধু **দেখানোর** ফরম্যাট। ভেতরে সময়ও সেভ আছে।

### TO_CHAR দিয়ে নিজের ফরম্যাটে দেখাও

```sql
SELECT order_no,
       TO_CHAR(order_date, 'DD-MM-YYYY')            AS order_dt,
       TO_CHAR(created_on, 'DD-MON-YYYY HH24:MI:SS') AS created
FROM   order_dates;
```

### ফরম্যাট কোড

| কোড | মানে | উদাহরণ |
|---|---|---|
| `YYYY` | ৪ অঙ্কের বছর | 2026 |
| `MM` | মাস সংখ্যায় | 11 |
| `MON` | মাসের ছোট নাম | NOV |
| `MONTH` | মাসের পুরো নাম | NOVEMBER |
| `DD` | দিন | 16 |
| `DY` / `DAY` | বারের নাম | MON / MONDAY |
| `HH24` | ঘণ্টা (০–২৩) | 14 |
| `HH` বা `HH12` | ঘণ্টা (১–১২) | 02 |
| `MI` | মিনিট | 30 |
| `SS` | সেকেন্ড | 45 |
| `AM` / `PM` | সকাল/বিকাল | PM |

> সতর্ক: `MM` = মাস, `MI` = মিনিট। অনেকে ভুল করে মিনিটের জন্য `MM` লেখে।

### পুরো সেশনের ফরম্যাট বদলানো

```sql
ALTER SESSION SET NLS_DATE_FORMAT = 'DD-MM-YYYY HH24:MI:SS';
SELECT * FROM order_dates;
```

এখন সব DATE কলাম সময়সহ দেখাবে। SQL Developer বন্ধ করলে এটা আবার আগের মতো হয়ে যাবে।

> **স্থায়ীভাবে বদলাতে:** SQL Developer-এ **Tools → Preferences → Database → NLS → Date Format**-এ `DD-MM-YYYY HH24:MI:SS` দাও।

## ৩. তারিখ দিয়ে হিসাব (৩০ মিনিট)

Oracle-এ তারিখের সাথে সংখ্যা যোগ করলে **দিন** যোগ হয়।

```sql
SELECT SYSDATE           AS today,
       SYSDATE + 1       AS tomorrow,
       SYSDATE - 7       AS last_week,
       SYSDATE + 1/24    AS one_hour_later
FROM   dual;
```

### দুই তারিখের পার্থক্য = দিনের সংখ্যা

```sql
SELECT order_no,
       ship_date - order_date AS lead_days
FROM   order_dates;
```

ফলাফল: অর্ডার থেকে শিপমেন্ট পর্যন্ত কত দিন (**Lead Time**)। গার্মেন্টসে এটা খুব জরুরি রিপোর্ট।

### শিপমেন্টের আর কত দিন বাকি

```sql
SELECT order_no,
       TRUNC(ship_date - SYSDATE) AS days_left
FROM   order_dates;
```

### TRUNC: সময় বাদ দিয়ে শুধু তারিখ

```sql
SELECT SYSDATE, TRUNC(SYSDATE) FROM dual;
```

`TRUNC(SYSDATE)` মানে আজকের তারিখ, রাত ১২:০০:০০।

**কেন জরুরি?** আজকের সব প্রোডাকশন খুঁজতে:
```sql
-- ভুল: সময় না মিললে কিছুই আসবে না
WHERE entry_date = DATE '2026-11-16'

-- সঠিক
WHERE TRUNC(entry_date) = DATE '2026-11-16'
```

## ৪. TIMESTAMP (১৫ মিনিট)

`TIMESTAMP` হলো DATE-এর মতো, কিন্তু সেকেন্ডের ভগ্নাংশও রাখে।

```sql
SELECT SYSDATE, SYSTIMESTAMP FROM dual;
```

```
SYSDATE               SYSTIMESTAMP
16-11-2026 19:45:12   16-11-26 07.45.12.345678000 PM +06:00
```

| Data Type | কী রাখে | কখন ব্যবহার |
|---|---|---|
| `DATE` | সেকেন্ড পর্যন্ত | প্রায় সব কাজে: অর্ডার, শিপমেন্ট, এন্ট্রির তারিখ |
| `TIMESTAMP` | সেকেন্ডের ভগ্নাংশ পর্যন্ত | খুব সূক্ষ্ম সময়: লগ, অডিট |
| `TIMESTAMP WITH TIME ZONE` | সাথে টাইমজোন (+06:00) | বিভিন্ন দেশের অফিস থাকলে |

**ERP-তে বেশিরভাগ জায়গায় DATE-ই যথেষ্ট।**

## ৫. CLOB (১৫ মিনিট)

**CLOB = Character Large Object।** খুব বড় লেখা রাখার জন্য, যেখানে VARCHAR2-এর ৪০০০ byte যথেষ্ট না।

উদাহরণ: অর্ডারের বিস্তারিত নির্দেশনা, Buyer-এর লম্বা কমপ্লায়েন্স নোট, ইমেইলের বডি।

```sql
CREATE TABLE style_instruction (
    style_no     VARCHAR2(30),
    instruction  CLOB
);

INSERT INTO style_instruction VALUES ('ST-001',
  'Wash: Enzyme wash. Packing: 12 pcs per carton, solid size solid color. ' ||
  'Label: Main label center back, care label left side seam...');
COMMIT;

SELECT * FROM style_instruction;
```

> নিয়ম: লেখা ৪০০০ byte-এর মধ্যে থাকলে `VARCHAR2`, তার বেশি হলে `CLOB`।

---

## ৬. BLOB (২০ মিনিট)

**BLOB = Binary Large Object।** ফাইল রাখার জন্য: ছবি, PDF, Excel, Word।

উদাহরণ: স্টাইলের ছবি, Buyer-এর Tech Pack (PDF), PI-এর স্ক্যান কপি।

```sql
CREATE TABLE style_image (
    style_no    VARCHAR2(30),
    image_file  BLOB,
    file_name   VARCHAR2(200),
    mime_type   VARCHAR2(100),
    uploaded_on DATE
);
```

- `file_name`: আসল ফাইলের নাম, যেমন `tshirt_front.jpg`
- `mime_type`: ফাইলের ধরন, যেমন `image/jpeg`, `application/pdf`
- BLOB-এ সরাসরি `INSERT` দিয়ে ছবি ঢোকানো যায় না। **APEX-এ File Upload দিয়ে খুব সহজে করা যায়** (সপ্তাহ ৩১-এ শিখব)।

> APEX-এ ফাইল আপলোড করলে সাধারণত BLOB, ফাইলের নাম আর MIME Type, এই তিনটা একসাথে রাখা হয়। তাই টেবিলটা এভাবে ডিজাইন করেছি।

## ৭. সব Data Type একসাথে (১০ মিনিট)

| Data Type | কী রাখে | উদাহরণ কলাম |
|---|---|---|
| `VARCHAR2(n)` | লেখা | buyer_name, style_no |
| `VARCHAR2(n CHAR)` | বাংলা লেখা | name_bn |
| `CHAR(n)` | ফিক্সড লেখা | is_active |
| `NUMBER(p,s)` | সংখ্যা | qty, price |
| `DATE` | তারিখ ও সময় | order_date |
| `TIMESTAMP` | সূক্ষ্ম সময় | log_time |
| `CLOB` | বড় লেখা | instruction |
| `BLOB` | ফাইল | style_image |

## ৮. হাতে-কলমে প্র্যাকটিস (৩০ মিনিট)

**কাজ ১:** `production_entry` টেবিল বানাও: entry_id, line_name, entry_date (DATE), produced_qty, remarks। ৪টা এন্ট্রি দাও, আজকের দুইটা আর গতকালের দুইটা, ভিন্ন ভিন্ন সময়ে।

**কাজ ২:** শুধু আজকের এন্ট্রিগুলো দেখাও।

**কাজ ৩:** নিচেরগুলো বের করো:
1. আজ থেকে ৯০ দিন পরের তারিখ
2. তোমার জন্মদিন থেকে আজ পর্যন্ত কত দিন
3. আজকের তারিখ এই ফরম্যাটে: `Monday, 16 November 2026`

<details>
<summary>কাজ ১ ও ২-এর সমাধান</summary>

```sql
CREATE TABLE production_entry (
    entry_id      NUMBER,
    line_name     VARCHAR2(50),
    entry_date    DATE,
    produced_qty  NUMBER(6),
    remarks       VARCHAR2(200)
);

INSERT INTO production_entry VALUES (1, 'Line-01', SYSDATE, 120, NULL);
INSERT INTO production_entry VALUES (2, 'Line-02', SYSDATE - 2/24, 95, 'Machine problem');
INSERT INTO production_entry VALUES (3, 'Line-01', SYSDATE - 1, 130, NULL);
INSERT INTO production_entry VALUES (4, 'Line-02', SYSDATE - 1 - 3/24, 110, NULL);
COMMIT;

-- শুধু আজকের
SELECT * FROM production_entry
WHERE  TRUNC(entry_date) = TRUNC(SYSDATE);
```

</details>

<details>
<summary>কাজ ৩-এর সমাধান</summary>

```sql
SELECT SYSDATE + 90 FROM dual;

SELECT TRUNC(SYSDATE - DATE '2000-05-20') AS days_alive FROM dual;   -- নিজের জন্মতারিখ দাও

SELECT TO_CHAR(SYSDATE, 'fmDay, DD Month YYYY') FROM dual;
```

> `fm` দিলে নামের পরের বাড়তি স্পেস বাদ যায়।

</details>

## সারাংশ

- DATE-এ সময়ও থাকে, শুধু তারিখ তুলনা করতে `TRUNC` লাগে
- তারিখ লেখা: `DATE 'YYYY-MM-DD'` বা `TO_DATE`; দেখানো: `TO_CHAR`
- তারিখ + সংখ্যা = দিন যোগ; তারিখ − তারিখ = দিনের সংখ্যা
- বড় লেখা `CLOB`, ফাইল `BLOB`
