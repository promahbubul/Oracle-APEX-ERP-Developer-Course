## ১. টেবিলের অংশ (৩০ মিনিট)

**FABRIC_STOCK টেবিল**

| FABRIC_ID | FABRIC_NAME | COLOR | GSM | STOCK_KG |
|---|---|---|---|---|
| 1 | Single Jersey | Black | 160 | 1200 |
| 2 | Single Jersey | White | 160 | 850 |
| 3 | Pique | Navy | 220 | 430 |
| 4 | Fleece | Grey | 280 | 0 |

| শব্দ | মানে | উদাহরণ |
|---|---|---|
| **টেবিল (Table)** | একই ধরনের জিনিসের ডাটার সংগ্রহ | পুরো `FABRIC_STOCK` |
| **কলাম (Column)** | একটা নির্দিষ্ট বৈশিষ্ট্য, উপর থেকে নিচে | `COLOR` কলাম |
| **রো (Row)** | একটা জিনিসের পুরো তথ্য, বাম থেকে ডানে | ৩ নম্বর রো: Pique, Navy... |
| **রেকর্ড (Record)** | রো-এর আরেক নাম | |
| **ফিল্ড (Field)** | কলামের আরেক নাম (কখনো একটা সেলকেও বলা হয়) | |
| **সেল (Cell) / Value** | একটা রো আর একটা কলামের মিলনস্থল | `430` |

**মনে রাখো:**
- একটা টেবিল = একটা বিষয় (যেমন: শুধু কাপড়, শুধু Buyer)
- একটা রো = সেই বিষয়ের একটা জিনিস (যেমন: একটা কাপড়)
- একটা কলাম = সেই জিনিসের একটা তথ্য (যেমন: রং)

> GSM = Gram per Square Meter, মানে কাপড় কতটা ভারী। গার্মেন্টসে খুব ব্যবহার হয়।

## ২. ভালো টেবিলের বৈশিষ্ট্য (৩০ মিনিট)

| নিয়ম | ভুল | সঠিক |
|---|---|---|
| এক টেবিলে এক বিষয় | Buyer আর Supplier একই টেবিলে | `BUYER` আর `SUPPLIER` আলাদা টেবিল |
| এক সেলে এক মান | `COLOR = 'Black, White, Navy'` | প্রতিটা রঙের জন্য আলাদা রো |
| প্রতিটা রো আলাদাভাবে চেনা যাবে | দুইটা রো পুরো একই রকম | প্রতিটা রো-এ ইউনিক `ID` |
| একই তথ্য বারবার নয় | প্রতিটা অর্ডারে Buyer-এর ঠিকানা | ঠিকানা শুধু `BUYER` টেবিলে |
| হিসাব করা যায় এমন মান রাখবে না | `TOTAL_PRICE` কলাম (qty × rate) | দরকার হলে কোয়েরিতে হিসাব করবে |

> শেষ নিয়মের কিছু ব্যতিক্রম আছে (যেমন রিপোর্ট দ্রুত করার জন্য)। পরে Normalization ক্লাসে বিস্তারিত।

## ৩. নাম রাখার নিয়ম (Naming Rules) (৩০ মিনিট)

### Oracle-এর বাধ্যতামূলক নিয়ম

1. নাম অক্ষর (A–Z) দিয়ে শুরু হতে হবে
2. শুধু অক্ষর, সংখ্যা, `_`, `$`, `#` ব্যবহার করা যাবে (`$` আর `#` এড়িয়ে চলো)
3. সর্বোচ্চ ১২৮ অক্ষর (পুরনো ভার্সনে ৩০)
4. Oracle-এর সংরক্ষিত শব্দ (Reserved Word) নাম হিসেবে দেওয়া যাবে না। যেমন: `ORDER`, `DATE`, `TABLE`, `SELECT`, `USER`, `LEVEL`
5. একই ইউজারের দুইটা অবজেক্টের একই নাম হতে পারবে না
6. নাম ছোট বা বড় হাতের যেভাবেই লেখো, Oracle বড় হাতের অক্ষরে (UPPERCASE) রাখে

### ভালো অভ্যাস (Convention)

| নিয়ম | উদাহরণ |
|---|---|
| শব্দের মাঝে `_` দাও | `fabric_name`, `shipment_date` |
| টেবিলের নাম একবচন বা বহুবচন, যেটাই নাও সব জায়গায় একরকম রাখো | `buyer`, `style`, `fabric` |
| ID কলামের নাম `টেবিল_id` | `buyer_id`, `style_id` |
| তারিখের কলামে `_date` | `order_date`, `ship_date` |
| হ্যাঁ/না কলামে `is_` | `is_active` |
| বোঝা যায় এমন নাম | `qty` চলবে, কিন্তু `q` না |

### ঠিক না ভুল?

| নাম | ঠিক/ভুল | কারণ |
|---|---|---|
| `buyer_info` | ✅ | |
| `2nd_buyer` | ❌ | সংখ্যা দিয়ে শুরু |
| `buyer name` | ❌ | স্পেস আছে |
| `order` | ❌ | Reserved word |
| `orders` | ✅ | |
| `shipment-date` | ❌ | `-` ব্যবহার করা যায় না |

> **Double Quote নাম:** `"Buyer Name"` এভাবে দিলে স্পেস রাখা যায়, কিন্তু তখন প্রতিবার হুবহু একই রকম লিখতে হয়। **কখনো এটা ব্যবহার করবে না।**

## ৪. CREATE TABLE-এর গঠন (৪০ মিনিট)

```sql
CREATE TABLE টেবিলের_নাম (
    কলাম১  DataType,
    কলাম২  DataType,
    কলাম৩  DataType
);
```

- প্রতিটা কলামের পরে কমা `,`, কিন্তু শেষ কলামের পরে কমা **না**
- শেষে `);` আর সেমিকোলন

### প্র্যাকটিস: `learn_freepdb1` কানেকশনে চালাও

```sql
CREATE TABLE fabric_stock (
    fabric_id    NUMBER,
    fabric_name  VARCHAR2(100),
    color        VARCHAR2(50),
    gsm          NUMBER,
    stock_kg     NUMBER
);
```

এখন ডাটা ঢোকাও:

```sql
INSERT INTO fabric_stock VALUES (1, 'Single Jersey', 'Black', 160, 1200);
INSERT INTO fabric_stock VALUES (2, 'Single Jersey', 'White', 160, 850);
INSERT INTO fabric_stock VALUES (3, 'Pique', 'Navy', 220, 430);
INSERT INTO fabric_stock VALUES (4, 'Fleece', 'Grey', 280, 0);
COMMIT;

SELECT * FROM fabric_stock;
```

### কলামের নাম দিয়ে INSERT (ভালো অভ্যাস)

```sql
INSERT INTO fabric_stock (fabric_id, fabric_name, color, gsm, stock_kg)
VALUES (5, 'Rib', 'Black', 200, 150);
COMMIT;
```

কলামের নাম লিখলে কোন মান কোন কলামে যাচ্ছে পরিষ্কার বোঝা যায়, আর টেবিলে পরে নতুন কলাম যোগ হলেও কোড ভাঙে না।

### টেবিলের গঠন দেখা: DESC

```sql
DESC fabric_stock
```

ফলাফল:
```
Name         Null?    Type
------------ -------- -------------
FABRIC_ID             NUMBER
FABRIC_NAME           VARCHAR2(100)
COLOR                 VARCHAR2(50)
GSM                   NUMBER
STOCK_KG              NUMBER
```

### নিজের সব টেবিলের তালিকা

```sql
SELECT table_name FROM user_tables;
```

### একটা টেবিলের সব কলাম

```sql
SELECT column_name, data_type, data_length
FROM   user_tab_columns
WHERE  table_name = 'FABRIC_STOCK';
```

> `user_tables`, `user_tab_columns` এগুলোকে বলে **Data Dictionary**: Oracle নিজের সম্পর্কে তথ্য যেখানে রাখে। খেয়াল করো, `'FABRIC_STOCK'` বড় হাতের অক্ষরে লিখতে হয়েছে।

### টেবিল মুছে ফেলা

```sql
DROP TABLE fabric_stock;
```

> সাবধান: এতে টেবিল আর সব ডাটা মুছে যায়। প্র্যাকটিসের জন্য আবার `CREATE` আর `INSERT` চালিয়ে টেবিলটা ফিরিয়ে আনো।

## ৫. সাধারণ এরর (১০ মিনিট)

| এরর | কারণ |
|---|---|
| `ORA-00955: name is already used by an existing object` | এই নামে আগেই টেবিল আছে |
| `ORA-00942: table or view does not exist` | টেবিলের নাম ভুল, অথবা টেবিল নেই |
| `ORA-00904: invalid identifier` | কলামের নাম ভুল, অথবা Reserved word ব্যবহার করেছ |
| `ORA-00947: not enough values` | কলাম যতগুলো, তার চেয়ে কম মান দিয়েছ |
| `ORA-00913: too many values` | কলামের চেয়ে বেশি মান দিয়েছ |
| `ORA-00907: missing right parenthesis` | ব্র্যাকেট বা কমা ভুল |

**নিজে এরর বানিয়ে দেখো:**
```sql
CREATE TABLE order (id NUMBER);                       -- Reserved word
INSERT INTO fabric_stock VALUES (6, 'Rib', 'Red');    -- কম মান
```

## সারাংশ

- টেবিল = এক বিষয়, রো = একটা জিনিস, কলাম = একটা বৈশিষ্ট্য

- `CREATE TABLE`, `INSERT`, `DESC`, `user_tables` ব্যবহার করেছি

**পরের ক্লাস:** Data Type: VARCHAR2, CHAR, NUMBER।
