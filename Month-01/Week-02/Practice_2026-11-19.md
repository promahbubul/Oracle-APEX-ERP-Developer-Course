## ১. রিভিশন (৩০ মিনিট)

খাতা না দেখে উত্তর দাও। না পারলে সেই ক্লাসের ফাইল আবার পড়ো।

**ক্লাস ৬:** টেবিল, রো, কলাম কী? ভালো টেবিলের ৩টা নিয়ম কী? নাম রাখার ৪টা নিয়ম কী?

**ক্লাস ৭:** VARCHAR2 আর CHAR-এর পার্থক্য কী? বাংলা লেখার কলাম কীভাবে বানাবে? `NUMBER(8,2)`-এ সর্বোচ্চ কত রাখা যায়?

**ক্লাস ৮:** DATE-এ কী কী থাকে? `TRUNC(SYSDATE)` কী দেয়? দুই তারিখের পার্থক্য কীভাবে বের করবে? CLOB আর BLOB কখন লাগে?

**ক্লাস ৯:** User আর Schema-র পার্থক্য কী? `GRANT` আর `REVOKE` কী করে?

**ক্লাস ১০:** Live SQL কখন ব্যবহার করবে?

## ২. মূল কাজ: ৫টা টেবিলের ডিজাইন (১০৫ মিনিট)

একটা ছোট গার্মেন্টস ফ্যাক্টরির **Store (Inventory)** বিভাগের জন্য ৫টা টেবিল ডিজাইন করবে।

### ধাপ ১: খাতায় ডিজাইন (৩০ মিনিট)

প্রতিটা টেবিলের জন্য খাতায় লেখো: কলামের নাম, Data Type, সাইজ, আর কেন এই Data Type।

| # | টেবিল | কী রাখবে |
|---|---|---|
| ১ | `item_category` | আইটেমের ধরন: Fabric, Yarn, Accessories, Chemical |
| ২ | `item` | প্রতিটা আইটেম: নাম, ধরন, ইউনিট, সর্বনিম্ন স্টক |
| ৩ | `supplier` | সাপ্লায়ার: নাম, ঠিকানা, মোবাইল, ইমেইল, সক্রিয় কি না |
| ৪ | `goods_receive` | মাল গ্রহণ: কোন আইটেম, কোন সাপ্লায়ার, কত পরিমাণ, দাম, তারিখ, মন্তব্য |
| ৫ | `goods_issue` | মাল প্রদান: কোন আইটেম, কোন বিভাগে, কত পরিমাণ, তারিখ, কে নিল |

**শর্ত:**
- প্রতিটা টেবিলে একটা ID কলাম থাকবে
- একটা টেবিলের সাথে আরেকটা টেবিল ID দিয়ে যুক্ত থাকবে (নাম না লিখে)
- সাপ্লায়ারের নাম বাংলায়ও রাখার ব্যবস্থা থাকবে
- পরিমাণে দশমিক ৩ ঘর পর্যন্ত লাগবে (কেজি আর গ্রাম)
- দাম দশমিক ২ ঘর পর্যন্ত
- কোন টেবিল কোনটার সাথে যুক্ত, তীর দিয়ে ডায়াগ্রাম আঁকো

### ধাপ ২: SQL Developer-এ বানানো (৪৫ মিনিট)

`learn_freepdb1`-এ ৫টা টেবিল বানাও, আর প্রতিটায় ডাটা দাও:
- `item_category`: ৪টা
- `item`: ৮টা (প্রতিটা ধরনে ২টা)
- `supplier`: ৪টা (অন্তত একটার নাম বাংলায়)
- `goods_receive`: ৬টা (ভিন্ন ভিন্ন তারিখে)
- `goods_issue`: ৫টা

### ধাপ ৩: যাচাই (৩০ মিনিট)

নিচের কোয়েরিগুলো চালাও:
```sql
-- আমার সব টেবিল
SELECT table_name FROM user_tables ORDER BY table_name;

-- প্রতিটা টেবিলের গঠন
DESC item_category
DESC item
DESC supplier
DESC goods_receive
DESC goods_issue

-- গত ৭ দিনের Receive
SELECT * FROM goods_receive
WHERE  receive_date >= TRUNC(SYSDATE) - 7;

-- প্রতিটা Receive-এর মোট টাকা
SELECT receive_id, qty, unit_price, qty * unit_price AS total_amount
FROM   goods_receive;
```
