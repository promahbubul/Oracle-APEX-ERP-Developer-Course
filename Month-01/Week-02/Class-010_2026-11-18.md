## ১. Oracle Live SQL কী (১৫ মিনিট)

**Oracle Live SQL** হলো ব্রাউজারে চলা ফ্রি Oracle ডাটাবেস। কিছু ইনস্টল করতে হয় না।

**ঠিকানা:** https://livesql.oracle.com

### কখন কাজে লাগে
- অফিসের বা অন্যের কম্পিউটারে, যেখানে Oracle ইনস্টল নেই
- নিজের কম্পিউটারে Oracle কাজ না করলে
- কাউকে কোড শেয়ার করতে হলে (লিংক দিয়ে)
- Oracle-এর তৈরি টিউটোরিয়াল চালাতে

### সীমাবদ্ধতা
- ইন্টারনেট লাগে
- অনেক বড় ডাটা নিয়ে কাজ করা যায় না
- কিছু অ্যাডমিন কমান্ড (যেমন `CREATE USER`) চলে না

---

## ২. লগইন আর স্ক্রিন চেনা (৩০ মিনিট)

1. যাও: **https://livesql.oracle.com**
2. **Sign In** দাও, সপ্তাহ ১-এ যে Oracle অ্যাকাউন্ট খুলেছিলে সেটা দিয়ে
3. প্রথমবার শর্ত মেনে নিতে বললে মেনে নাও

### প্রধান অংশ

| অংশ | কাজ |
|---|---|
| **SQL Worksheet** | SQL লিখে চালানো |
| **My Scripts / Sessions** | সেভ করা স্ক্রিপ্ট |
| **Library / Tutorials** | Oracle-এর তৈরি টিউটোরিয়াল আর উদাহরণ |
| **Schema / Navigator** | তোমার টেবিল দেখা |

> Oracle মাঝে মাঝে Live SQL-এর ডিজাইন বদলায়। মেনুর নাম বা জায়গা একটু আলাদা হতে পারে, কিন্তু এই অংশগুলো থাকে।

### প্রথম কোয়েরি

Worksheet-এ লেখো:
```sql
SELECT 'Hello Live SQL' AS msg FROM dual;
```
**Run** বাটন চাপো (বা `Ctrl + Enter`)।

## ৩. Live SQL-এ টেবিল বানানো (৪০ মিনিট)

ক্লাস ৬–৮-এ যা শিখেছি, Live SQL-এ আবার করো। এটা রিভিশনও হবে।

```sql
CREATE TABLE buyer (
    buyer_id     NUMBER,
    buyer_name   VARCHAR2(100),
    country      VARCHAR2(50),
    contact_no   VARCHAR2(20),
    created_on   DATE
);

INSERT INTO buyer VALUES (1, 'H&M', 'Sweden', '+46-8-0000000', SYSDATE);
INSERT INTO buyer VALUES (2, 'Zara', 'Spain', '+34-9-0000000', SYSDATE);
INSERT INTO buyer VALUES (3, 'Walmart', 'USA', '+1-479-0000000', SYSDATE);
INSERT INTO buyer VALUES (4, 'Primark', 'Ireland', '+353-1-0000000', SYSDATE);
COMMIT;

SELECT * FROM buyer;
```

> Live SQL-এ `&` চিহ্ন নিয়ে সাধারণত সমস্যা হয় না। সমস্যা হলে শুরুতে `SET DEFINE OFF` চালাও।

```sql
CREATE TABLE style (
    style_id    NUMBER,
    style_no    VARCHAR2(30),
    style_name  VARCHAR2(100),
    buyer_id    NUMBER,
    fob_price   NUMBER(10,4)
);

INSERT INTO style VALUES (1, 'HM-TS-001', 'Basic Crew Neck T-Shirt', 1, 2.3500);
INSERT INTO style VALUES (2, 'HM-PL-002', 'Pique Polo', 1, 4.1000);
INSERT INTO style VALUES (3, 'ZR-HD-001', 'Fleece Hoodie', 2, 7.8500);
INSERT INTO style VALUES (4, 'WM-JN-001', 'Denim Jeans', 3, 6.2000);
COMMIT;

SELECT * FROM style;
DESC style
```

**সতর্কতা:** Live SQL-এ সেশন বন্ধ হলে বা কিছু সময় পর টেবিল মুছে যেতে পারে। জরুরি কোড সবসময় **স্ক্রিপ্ট হিসেবে সেভ** করবে, অথবা নিজের কম্পিউটারে `.sql` ফাইলে রাখবে।

## ৪. স্যাম্পল স্কিমা (HR) ব্যবহার (২৫ মিনিট)

Live SQL-এ HR স্কিমা আগে থেকেই আছে। শুধু দেখা যায় (Read-only)।

```sql
SELECT * FROM hr.employees;

SELECT * FROM hr.departments;

SELECT first_name, last_name, salary
FROM   hr.employees
WHERE  department_id = 90;
```

> HR ছাড়াও আরো স্যাম্পল স্কিমা থাকে, যেমন `SH` (Sales History), `OE` (Order Entry)। পরে বড় ডাটা নিয়ে প্র্যাকটিসে কাজে লাগবে।

## ৫. স্ক্রিপ্ট সেভ ও শেয়ার করা (২০ মিনিট)

## ৬. টিউটোরিয়াল ব্যবহার (২০ মিনিট)

Live SQL-এর **Library** বা **Tutorials** অংশে Oracle-এর তৈরি অনেক ফ্রি টিউটোরিয়াল আছে। প্রতিটা ধাপে কোড আর ব্যাখ্যা থাকে, **Run** দিলেই চলে।

আজ একটা খুঁজে চালাও:
- সার্চ করো: **"Databases for Developers: Foundations"**
- প্রথম অধ্যায় (Introduction বা Tables) চালাও

> এটা Oracle-এর খুব ভালো একটা ফ্রি কোর্স। সামনের সপ্তাহগুলোর SQL ক্লাসের সাথে মিলিয়ে এর অধ্যায়গুলো করতে পারো।

## ৭. কোন কাজ কোথায় করব (১০ মিনিট)

| কাজ | কোথায় |
|---|---|
| প্রতিদিনের SQL, PL/SQL প্র্যাকটিস | নিজের কম্পিউটার (SQL Developer + Oracle Free) |
| বাইরে থাকলে বা অন্যের কম্পিউটারে | Live SQL |
| কাউকে কোড দেখানো | Live SQL (শেয়ার লিংক) |
| Oracle-এর টিউটোরিয়াল | Live SQL |
| APEX অ্যাপ বানানো | apex.oracle.com |

> নিজের কম্পিউটারেও APEX ইনস্টল করা যায় (ORDS সহ)। এটা একটু জটিল, তাই আপাতত apex.oracle.com ব্যবহার করব।

## ৮. হাতে-কলমে প্র্যাকটিস (২০ মিনিট)

**কাজ ১:** Live SQL-এ `fabric` টেবিল বানাও: fabric_id, fabric_name, composition (যেমন `100% Cotton`), gsm, width_inch, price_per_kg। ৫টা কাপড়ের ডাটা দাও। স্ক্রিপ্ট সেভ করো।

**কাজ ২:** `hr.employees` থেকে শুধু `first_name`, `last_name`, `hire_date` দেখাও।

**কাজ ৩:** কাজ ১-এর স্ক্রিপ্ট শেয়ার লিংক বানাও, আর একই কোড নিজের কম্পিউটারে `week02.sql` ফাইলে সেভ করো।
