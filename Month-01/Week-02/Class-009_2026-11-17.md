## ১. User আর Schema (৩০ মিনিট)

- **User:** যে ডাটাবেসে লগইন করে। যেমন: `system`, `learn`
- **Schema:** একজন User-এর মালিকানায় থাকা সব জিনিসের (টেবিল, ভিউ, প্রসিডিওর) সংগ্রহ

Oracle-এ প্রতিটা User-এর একটা Schema থাকে, **একই নামে।** `learn` ইউজার যা বানায়, সব যায় `LEARN` স্কিমায়।

উদাহরণ: অফিস বিল্ডিংয়ে প্রতিটা কর্মীর নিজের আলমারি আছে।
- কর্মী = User
- তার আলমারি আর ভেতরের সব ফাইল = Schema

### বাস্তব ERP-তে Schema

বড় কোম্পানিতে প্রায়ই এরকম আলাদা Schema থাকে:

| Schema | কী থাকে |
|---|---|
| `ERP_MERCH` | Merchandising-এর টেবিল |
| `ERP_STORE` | Inventory-র টেবিল |
| `ERP_PROD` | Production-এর টেবিল |
| `ERP_ACC` | Accounts-এর টেবিল |

ছোট বা মাঝারি ERP-তে সাধারণত একটা Schema-তেই সব থাকে।

**APEX-এ:** প্রতিটা Workspace এক বা একাধিক Schema-র সাথে যুক্ত থাকে। তোমার অ্যাপ সেই Schema-র টেবিল ব্যবহার করে।

## ২. অন্য Schema-র টেবিল ব্যবহার (৪০ মিনিট)

অন্য Schema-র টেবিল লিখতে হয় এভাবে: `schema_নাম.টেবিল_নাম`

```sql
SELECT * FROM learn.fabric_stock;
```

কিন্তু অনুমতি (Privilege) না থাকলে দেখা যাবে না।

### প্র্যাকটিস: দ্বিতীয় একটা User বানাও

**ধাপ ১:** `system_freepdb1` কানেকশনে:
```sql
CREATE USER store_user IDENTIFIED BY Store123;
GRANT CREATE SESSION TO store_user;
```

**ধাপ ২:** SQL Developer-এ `store_user` দিয়ে নতুন কানেকশন বানাও (Host `localhost`, Port `1521`, Service name `FREEPDB1`)। তারপর চালাও:
```sql
SELECT * FROM learn.fabric_stock;
```
এরর আসবে:
```
ORA-00942: table or view does not exist
```
টেবিল আছে, কিন্তু অনুমতি নেই, তাই Oracle বলে "নেই"। (নিরাপত্তার জন্য Oracle এভাবে লুকায়।)

**ধাপ ৩:** `learn_freepdb1` কানেকশনে অনুমতি দাও:
```sql
GRANT SELECT ON fabric_stock TO store_user;
```

**ধাপ ৪:** `store_user`-এ আবার চালাও:
```sql
SELECT * FROM learn.fabric_stock;     -- এবার চলবে

DELETE FROM learn.fabric_stock;       -- এরর: ORA-01031 insufficient privileges
```
শুধু দেখার (`SELECT`) অনুমতি আছে, মোছার (`DELETE`) অনুমতি নেই।

**ধাপ ৫:** অনুমতি ফেরত নেওয়া (`learn`-এ):
```sql
REVOKE SELECT ON fabric_stock FROM store_user;
```

### অনুমতির ধরন

| ধরন | উদাহরণ | কে দেয় |
|---|---|---|
| **System Privilege** | `CREATE SESSION`, `CREATE TABLE` | সাধারণত অ্যাডমিন (SYSTEM) |
| **Object Privilege** | `SELECT`, `INSERT`, `UPDATE`, `DELETE` একটা নির্দিষ্ট টেবিলে | টেবিলের মালিক |

> এটাই ERP-র ডাটাবেস লেভেলের নিরাপত্তার ভিত্তি। পরে APEX-এ Role-based access শিখব, সেটা অ্যাপ্লিকেশন লেভেলের নিরাপত্তা।

## ৩. Data Dictionary (২০ মিনিট)

Oracle নিজের সব তথ্য কিছু বিশেষ ভিউতে রাখে।

| প্রিফিক্স | কী দেখায় | কে দেখতে পারে |
|---|---|---|
| `USER_` | শুধু আমার নিজের জিনিস | সবাই |
| `ALL_` | আমার নিজের আর যেগুলো দেখার অনুমতি আছে | সবাই |
| `DBA_` | পুরো ডাটাবেসের সব জিনিস | শুধু অ্যাডমিন |

```sql
-- আমার টেবিলগুলো
SELECT table_name FROM user_tables;

-- আমার সব অবজেক্ট (টেবিল, ভিউ ইত্যাদি)
SELECT object_name, object_type, created FROM user_objects;

-- যেসব টেবিল আমি দেখতে পারি, কার মালিকানায়
SELECT owner, table_name FROM all_tables WHERE owner IN ('LEARN', 'HR');

-- আমার কী কী System Privilege আছে
SELECT * FROM user_sys_privs;
```

## ৪. HR স্যাম্পল স্কিমা ইনস্টল (৪০ মিনিট)

**HR স্কিমা** হলো Oracle-এর তৈরি একটা নমুনা ডাটাবেস: একটা কোম্পানির কর্মী, বিভাগ, চাকরি, অফিসের ঠিকানা। সারা পৃথিবীতে SQL শেখার জন্য এটা ব্যবহার হয়। **সপ্তাহ ৫ থেকে বেশিরভাগ SQL প্র্যাকটিস এর উপর করব।**

> Oracle Database Free-তে HR স্কিমা আগে থেকে থাকে না, নিজে ইনস্টল করতে হয়।

### ধাপ

1. যাও: **https://github.com/oracle-samples/db-sample-schemas**
2. ডান পাশে **Releases**-এ গিয়ে সর্বশেষ রিলিজের **Source code (zip)** ডাউনলোড করো
3. Extract করো, যেমন: `D:\sample-schemas\`
4. ভেতরে **`human_resources`** ফোল্ডারে যাও। এখানে `hr_install.sql` ফাইল আছে
5. cmd খোলো, ওই ফোল্ডারে যাও:
   ```
   cd /d D:\sample-schemas\db-sample-schemas-XXX\human_resources
   ```
   (`XXX` এর জায়গায় তোমার ফোল্ডারের আসল নাম)
6. SYSTEM দিয়ে কানেক্ট করো:
   ```
   sqlplus system/Oracle123@localhost:1521/FREEPDB1
   ```
7. ইনস্টল স্ক্রিপ্ট চালাও:
   ```
   @hr_install.sql
   ```
8. কিছু প্রশ্ন করবে:
   - **HR password:** একটা পাসওয়ার্ড দাও, যেমন `Hr123456` (খাতায় লেখো)
   - **Tablespace:** Enter চাপো (ডিফল্ট `USERS`)
   - **Overwrite schema:** `YES` বা Enter
9. শেষে `Installation ... verification` এর মতো একটা সারাংশ দেখাবে, যেখানে প্রতিটা টেবিলে কয়টা রো আছে তা থাকে

> রিপোজিটরির ফোল্ডার বা ফাইলের নাম ভবিষ্যতে একটু বদলাতে পারে। সেক্ষেত্রে `human_resources` ফোল্ডারের `README.md` ফাইলে ইনস্টলের নিয়ম লেখা থাকে।

### HR দিয়ে কানেকশন

SQL Developer-এ নতুন কানেকশন: Name `hr_freepdb1`, Username `hr`, Password তোমার দেওয়াটা, বাকি আগের মতো।

## ৫. HR স্কিমা চেনা (৩০ মিনিট)

`hr_freepdb1`-এ:

```sql
SELECT table_name FROM user_tables ORDER BY table_name;
```

| টেবিল | কী আছে | রো সংখ্যা |
|---|---|---|
| `REGIONS` | মহাদেশ/অঞ্চল | ৪–৫ |
| `COUNTRIES` | দেশ | ২৫ |
| `LOCATIONS` | অফিসের ঠিকানা | ২৩ |
| `DEPARTMENTS` | বিভাগ | ২৭ |
| `JOBS` | পদবি, বেতনের সীমা | ১৯ |
| `EMPLOYEES` | কর্মী | ১০৭ |
| `JOB_HISTORY` | কর্মীর আগের পদ | ১০ |

> রো সংখ্যা ভার্সনভেদে সামান্য আলাদা হতে পারে।

### টেবিলগুলোর সম্পর্ক

```
REGIONS ──< COUNTRIES ──< LOCATIONS ──< DEPARTMENTS ──< EMPLOYEES >── JOBS
                                                            │
                                                       JOB_HISTORY
```
`──<` মানে "একটার সাথে অনেকগুলো"। যেমন: একটা বিভাগে অনেক কর্মী।

### দেখে নাও

```sql
DESC employees

SELECT * FROM departments;

SELECT employee_id, first_name, last_name, salary, department_id
FROM   employees;
```

**SQL Developer-এ ডায়াগ্রাম দেখো:** বাম পাশে `hr_freepdb1` → **Tables**। সব টেবিল সিলেক্ট করে (Shift চেপে) রাইট-ক্লিক দাও, তারপর **Data Modeler → Reverse Engineer**। (মেনুর নাম ভার্সনভেদে একটু আলাদা হতে পারে।)

## ৬. হাতে-কলমে প্র্যাকটিস (২০ মিনিট)

1. `hr` ইউজার থেকে `learn` ইউজারকে `employees` আর `departments` টেবিলে `SELECT` অনুমতি দাও।
2. `learn_freepdb1`-এ `hr.employees` থেকে ডাটা দেখো।
3. `EMPLOYEES` টেবিলের প্রতিটা কলামের Data Type লেখো। কোনটা কেন এই Data Type, নিজে ব্যাখ্যা করো।

<details>
<summary>সমাধান</summary>

```sql
-- hr_freepdb1-এ
GRANT SELECT ON employees TO learn;
GRANT SELECT ON departments TO learn;

-- learn_freepdb1-এ
SELECT * FROM hr.employees;
SELECT * FROM hr.departments;
```

`EMPLOYEES` টেবিলের কলামের Data Type দেখতে `DESC hr.employees` চালাও।

</details>
