# ক্লাস ৭: Data Type: VARCHAR2, CHAR, NUMBER

**তারিখ:** ১৫ নভেম্বর ২০২৬, রবিবার
**সময়:** সন্ধ্যা ৭:০০ থেকে রাত ১০:০০
**সপ্তাহ:** ২ | **ধাপ:** ১ (কম্পিউটার ও ডাটাবেসের বেসিক)

---

## আজকে কী শিখব

- Data Type কী, কেন লাগে
- লেখা রাখার জন্য: `VARCHAR2`, `CHAR`
- BYTE আর CHAR (বাংলা লেখার জন্য জরুরি)
- সংখ্যা রাখার জন্য: `NUMBER`, `NUMBER(p,s)`
- কোন কলামে কোন Data Type দেবে

## ১. Data Type কী (১৫ মিনিট)

**Data Type** বলে দেয় একটা কলামে কী ধরনের ডাটা রাখা যাবে।

কেন লাগে:
- ভুল ডাটা ঢোকা আটকায় (যেমন: পরিমাণের কলামে "অনেক" লেখা যাবে না)
- জায়গা কম লাগে
- হিসাব (যোগ, গড়) করা যায়
- সঠিকভাবে সাজানো (Sort) যায়

Oracle-এর প্রধান Data Type:

| ধরন | Data Type |
|---|---|
| লেখা | `VARCHAR2`, `CHAR` |
| সংখ্যা | `NUMBER` |
| তারিখ ও সময় | `DATE`, `TIMESTAMP` (কাল শিখব) |
| বড় লেখা ও ফাইল | `CLOB`, `BLOB` (কাল শিখব) |

---

## ২. VARCHAR2 (৪০ মিনিট)

**VARCHAR2(n):** পরিবর্তনশীল দৈর্ঘ্যের লেখা। সর্বোচ্চ `n` সাইজ পর্যন্ত রাখা যায়।

```sql
buyer_name VARCHAR2(100)
```

- `'H&M'` রাখলে শুধু ৩ অক্ষরের জায়গা নেয়, ১০০ না
- সর্বোচ্চ সাইজ সাধারণত **৪০০০ byte** (ডাটাবেসের সেটিং বদলালে ৩২৭৬৭)
- **লেখার জন্য প্রায় সবসময় VARCHAR2 ব্যবহার করবে**

### লেখা সবসময় Single Quote-এ

```sql
'H&M'        -- ঠিক
"H&M"        -- ভুল (Double quote কলামের নামের জন্য)
'Men''s Wear'   -- লেখার ভেতরে ' দিতে হলে দুইবার '' লিখতে হয়
```

### BYTE বনাম CHAR: বাংলা লেখার জন্য জরুরি

`VARCHAR2(10)` মানে ডিফল্টভাবে **১০ byte**, ১০ অক্ষর না।
- ইংরেজি অক্ষর = ১ byte
- বাংলা অক্ষর = সাধারণত **৩ byte**

তাই `VARCHAR2(10)` কলামে মাত্র ৩টা বাংলা অক্ষর আঁটবে।

সমাধান: সাইজের সাথে `CHAR` লিখে দাও।

```sql
name_bn VARCHAR2(50 CHAR)   -- ৫০টা অক্ষর, বাংলা হলেও
```

**প্র্যাকটিস:**

```sql
CREATE TABLE test_text (
    name_byte  VARCHAR2(10),
    name_char  VARCHAR2(10 CHAR)
);

INSERT INTO test_text (name_char) VALUES ('গার্মেন্টস');   -- চলবে
INSERT INTO test_text (name_byte) VALUES ('গার্মেন্টস');   -- এরর দেবে
```

দ্বিতীয়টায় এরর আসবে:
```
ORA-12899: value too large for column "LEARN"."TEST_TEXT"."NAME_BYTE" (actual: 30, maximum: 10)
```

`LENGTH` আর `LENGTHB` দিয়ে দেখো:
```sql
SELECT LENGTH('গার্মেন্টস') AS chars, LENGTHB('গার্মেন্টস') AS bytes FROM dual;
SELECT LENGTH('Garments') AS chars, LENGTHB('Garments') AS bytes FROM dual;
```

## ৩. CHAR (২০ মিনিট)

**CHAR(n):** নির্দিষ্ট দৈর্ঘ্যের লেখা। ছোট লেখা দিলে বাকি জায়গা **স্পেস দিয়ে ভরে দেয়**।

```sql
CREATE TABLE test_char (
    code_char     CHAR(5),
    code_varchar  VARCHAR2(5)
);

INSERT INTO test_char VALUES ('AB', 'AB');
COMMIT;

SELECT '[' || code_char || ']'    AS c,
       '[' || code_varchar || ']' AS v
FROM   test_char;
```

ফলাফল:
```
C         V
--------- ----
[AB   ]   [AB]
```

> `||` দিয়ে দুইটা লেখা জোড়া লাগানো হয়।

### কখন CHAR?
শুধু যখন মান সবসময় একই দৈর্ঘ্যের। যেমন: `'Y'`/`'N'` (CHAR(1)), দেশের কোড `'BD'`, `'US'` (CHAR(2))।

**বাকি সব ক্ষেত্রে VARCHAR2।**

| | VARCHAR2 | CHAR |
|---|---|---|
| দৈর্ঘ্য | পরিবর্তনশীল | নির্দিষ্ট |
| ফাঁকা জায়গা | রাখে না | স্পেস দিয়ে ভরে |
| সর্বোচ্চ সাইজ | ৪০০০ byte | ২০০০ byte |
| ব্যবহার | প্রায় সব লেখা | Y/N, ফিক্সড কোড |

## ৪. NUMBER (৫০ মিনিট)

### NUMBER (সাইজ ছাড়া)
যেকোনো সংখ্যা, দশমিকসহ বা ছাড়া।
```sql
stock_kg NUMBER
```

### NUMBER(p, s)
- **p (Precision):** মোট কয়টা অঙ্ক (সর্বোচ্চ ৩৮)
- **s (Scale):** দশমিকের পরে কয়টা অঙ্ক

| Data Type | মানে | সর্বোচ্চ মান | উদাহরণ |
|---|---|---|---|
| `NUMBER(5)` | ৫ অঙ্ক, দশমিক নেই | 99999 | পিস সংখ্যা |
| `NUMBER(5,2)` | মোট ৫ অঙ্ক, দশমিকের পরে ২ | 999.99 | Efficiency % |
| `NUMBER(10,2)` | মোট ১০, দশমিকের পরে ২ | 99999999.99 | টাকা, দাম |
| `NUMBER(8,3)` | মোট ৮, দশমিকের পরে ৩ | 99999.999 | কেজি (গ্রামসহ) |

### প্র্যাকটিস

```sql
CREATE TABLE test_number (
    qty         NUMBER(5),
    efficiency  NUMBER(5,2),
    price       NUMBER(10,2)
);

INSERT INTO test_number VALUES (1200, 87.5, 4.25);
INSERT INTO test_number VALUES (500, 92.456, 3.999);   -- দশমিক রাউন্ড হবে
COMMIT;

SELECT * FROM test_number;
```

ফলাফল:
```
QTY   EFFICIENCY   PRICE
----  ----------   -----
1200  87.5         4.25
500   92.46        4
```

খেয়াল করো: `92.456` হয়ে গেছে `92.46`, আর `3.999` হয়ে গেছে `4` (মানে 4.00)। Oracle নিজে থেকে রাউন্ড করে।

**এবার এরর দেখো:**
```sql
INSERT INTO test_number (qty) VALUES (123456);         -- ৬ অঙ্ক, অনুমতি ৫
INSERT INTO test_number (efficiency) VALUES (1000);    -- 999.99-এর বেশি
```
এরর:
```
ORA-01438: value larger than specified precision allowed for this column
```

### সংখ্যা লেখার নিয়ম
```sql
1200       -- ঠিক
1,200      -- ভুল (কমা দেওয়া যাবে না)
'1200'     -- এটা লেখা, সংখ্যা না (Oracle মাঝে মাঝে নিজে বদলে নেয়, কিন্তু এভাবে লিখবে না)
-50        -- ঋণাত্মক সংখ্যা ঠিক আছে
```

### অন্যান্য সংখ্যার Data Type (শুধু নাম জেনে রাখো)
- `INTEGER`, `INT`: আসলে `NUMBER(38)`
- `BINARY_FLOAT`, `BINARY_DOUBLE`: বৈজ্ঞানিক হিসাবের জন্য

### ফোন নম্বর কি NUMBER?
**না।** ফোন নম্বর `VARCHAR2`-এ রাখবে, কারণ:
- শুরুর `0` হারিয়ে যায় (`01711...` হয়ে যায় `1711...`)
- `+880` লেখা যায় না
- ফোন নম্বর দিয়ে যোগ-বিয়োগ করা হয় না

**নিয়ম:** যে সংখ্যা দিয়ে হিসাব করা হয় না (ফোন, NID, পোস্ট কোড, স্টাইল নম্বর), সেটা `VARCHAR2`।

## ৫. কোন কলামে কোন Data Type? (১৫ মিনিট)

| কলাম | Data Type | কারণ |
|---|---|---|
| buyer_name | `VARCHAR2(100)` | লেখা |
| buyer_name_bn | `VARCHAR2(100 CHAR)` | বাংলা লেখা |
| style_no | `VARCHAR2(30)` | `ST-2026-001` এর মতো |
| order_qty | `NUMBER(10)` | পিস, দশমিক নেই |
| unit_price | `NUMBER(10,4)` | ডলারে দাম, যেমন 2.3550 |
| fabric_kg | `NUMBER(12,3)` | কেজি আর গ্রাম |
| efficiency_pct | `NUMBER(5,2)` | ৮৭.৫০% |
| is_active | `CHAR(1)` | `'Y'` বা `'N'` |
| mobile_no | `VARCHAR2(20)` | ফোন নম্বর |

> Oracle-এর নতুন ভার্সনে (23ai থেকে) `BOOLEAN` Data Type-ও আছে। কিন্তু অনেক কোম্পানি এখনো পুরনো ভার্সন চালায়, তাই `CHAR(1)` দিয়ে Y/N রাখার পদ্ধতিও জানতে হবে।

## ৬. হাতে-কলমে প্র্যাকটিস (৪০ মিনিট)

**কাজ ১:** `employee_info` টেবিল বানাও, সঠিক Data Type দিয়ে:
- কর্মীর আইডি (যেমন `EMP-0001`)
- নাম (ইংরেজি)
- নাম (বাংলা)
- মোবাইল নম্বর
- মাসিক বেতন (পয়সাসহ)
- সক্রিয় কি না (Y/N)

৩ জন কর্মীর ডাটা ঢোকাও, একজনের নাম বাংলায়।

**কাজ ২:** নিচের INSERT-গুলো চালানোর আগে আন্দাজ করো কোনটা চলবে আর কোনটা এরর দেবে। তারপর চালিয়ে মিলাও।

```sql
CREATE TABLE test_guess (
    a VARCHAR2(5),
    b NUMBER(4,1),
    c CHAR(3)
);

INSERT INTO test_guess (a) VALUES ('Hello');
INSERT INTO test_guess (a) VALUES ('Hello!');
INSERT INTO test_guess (b) VALUES (999.9);
INSERT INTO test_guess (b) VALUES (999.96);
INSERT INTO test_guess (b) VALUES (12.34);
INSERT INTO test_guess (c) VALUES ('AB');
```

<summary>কাজ ১-এর সমাধান</summary>

CREATE TABLE employee_info (
    emp_code    VARCHAR2(20),
    emp_name    VARCHAR2(100),
    emp_name_bn VARCHAR2(100 CHAR),

INSERT INTO employee_info VALUES ('EMP-0002', 'Karima Begum', 'করিমা বেগম', '01811000002', 15200.50, 'Y');

## ৮. কুইজ

1. VARCHAR2 আর CHAR-এর মূল পার্থক্য কী?
2. বাংলা নাম রাখার কলাম কীভাবে ডিফাইন করবে?
3. `NUMBER(6,2)`-এ সর্বোচ্চ কত রাখা যায়?
4. মোবাইল নম্বর কোন Data Type-এ রাখবে, কেন?
5. `ORA-01438` এরর কখন আসে?

<details>
<summary>উত্তর দেখো</summary>

1. VARCHAR2 যতটুকু লেখা ততটুকু জায়গা নেয়, CHAR বাকি জায়গা স্পেস দিয়ে ভরে
2. `VARCHAR2(100 CHAR)`
3. 9999.99
4. VARCHAR2, কারণ শুরুর 0 আর + চিহ্ন রাখতে হয়, আর এটা দিয়ে হিসাব হয় না
5. NUMBER কলামের অনুমতির চেয়ে বড় সংখ্যা দিলে

</details>

## সারাংশ

- লেখার জন্য `VARCHAR2`, বাংলা হলে সাইজের সাথে `CHAR`
- `CHAR` শুধু ফিক্সড দৈর্ঘ্যের জন্য (Y/N)
- `NUMBER(p,s)`: p মোট অঙ্ক, s দশমিকের পরের অঙ্ক
- হিসাব হয় না এমন সংখ্যা (ফোন, NID) `VARCHAR2`-এ

**পরের ক্লাস:** Data Type: DATE, TIMESTAMP, CLOB, BLOB।
