## ১. ডাটা আর ইনফরমেশন (২০ মিনিট)

- **ডাটা (Data):** কাঁচা তথ্য, আলাদাভাবে যার তেমন মানে নেই।
  উদাহরণ: `500`, `Blue`, `H&M`, `2026-11-09`
- **ইনফরমেশন (Information):** ডাটা সাজিয়ে যখন অর্থপূর্ণ হয়।
  উদাহরণ: "H&M-এর জন্য 500 পিস Blue টি-শার্ট 2026-11-09 তারিখে শিপমেন্ট হবে।"

**ডাটা → প্রসেস → ইনফরমেশন → সিদ্ধান্ত**

ERP-র কাজই হলো ডাটা জমা করে ম্যানেজমেন্টকে ইনফরমেশন (রিপোর্ট) দেওয়া, যাতে তারা সিদ্ধান্ত নিতে পারে।

## ২. ডাটাবেস কী (৩০ মিনিট)

**ডাটাবেস (Database):** সাজানো-গোছানো ডাটার সংগ্রহ, যেখান থেকে দ্রুত ডাটা খোঁজা, যোগ করা, বদলানো আর মোছা যায়।

### খাতা বা Excel-এ রাখলে সমস্যা কী?

| সমস্যা | উদাহরণ |
|---|---|
| একই ডাটা বারবার লেখা | প্রতিটা অর্ডারে Buyer-এর ঠিকানা আবার লেখা |
| ভুল ডাটা | এক জায়গায় "H&M", আরেক জায়গায় "HM" |
| একসাথে অনেকে কাজ করতে পারে না | Excel ফাইল একজন খুললে আরেকজন সেভ করতে পারে না |
| নিরাপত্তা নেই | যে কেউ ফাইল কপি বা ডিলিট করতে পারে |
| বেশি ডাটা হলে ধীর | ১০ লাখ রো Excel-এ চালানো কঠিন |
| ব্যাকআপ ও রিকভারি কঠিন | কম্পিউটার নষ্ট হলে সব হারায় |

ডাটাবেস এই সব সমস্যার সমাধান করে।

## ৩. DBMS আর RDBMS (৪০ মিনিট)

### DBMS
**DBMS = Database Management System**
যে সফটওয়্যার দিয়ে ডাটাবেস তৈরি, চালানো আর ম্যানেজ করা হয়।

DBMS-এর কাজ:
- ডাটা জমা রাখা আর খুঁজে দেওয়া
- কে কোন ডাটা দেখতে পারবে, তা ঠিক করা (Security)
- একসাথে অনেক ইউজারকে সামলানো
- ব্যাকআপ আর রিকভারি
- ভুল ডাটা ঢুকতে না দেওয়া

### RDBMS
**RDBMS = Relational Database Management System**
যে DBMS ডাটাকে **টেবিল** আকারে রাখে, আর টেবিলগুলোর মধ্যে **সম্পর্ক (Relation)** তৈরি করা যায়।

### টেবিলের উদাহরণ

**BUYER টেবিল**

| BUYER_ID | BUYER_NAME | COUNTRY |
|---|---|---|
| 1 | H&M | Sweden |
| 2 | Zara | Spain |
| 3 | Walmart | USA |

**ORDERS টেবিল**

| ORDER_ID | BUYER_ID | STYLE | QUANTITY |
|---|---|---|---|
| 101 | 1 | T-Shirt | 5000 |
| 102 | 1 | Polo Shirt | 3000 |
| 103 | 3 | Jeans | 8000 |

খেয়াল করো: ORDERS টেবিলে Buyer-এর পুরো নাম আর দেশ লেখা হয়নি, শুধু `BUYER_ID` লেখা হয়েছে। `BUYER_ID = 1` দেখে BUYER টেবিল থেকে জানা যায় এটা H&M। **এটাই Relation (সম্পর্ক)।**

সুবিধা: H&M-এর নাম বদলাতে হলে শুধু BUYER টেবিলে একবার বদলালেই হবে।

### জনপ্রিয় RDBMS

| RDBMS | কোম্পানি |
|---|---|
| **Oracle Database** | Oracle |
| MySQL | Oracle (ফ্রি, ওপেন সোর্স) |
| SQL Server | Microsoft |
| PostgreSQL | ওপেন সোর্স |

### NoSQL (শুধু নাম জেনে রাখো)
কিছু ডাটাবেস টেবিল ব্যবহার করে না। যেমন: MongoDB। এগুলোকে NoSQL বলে। ERP-তে সাধারণত RDBMS ব্যবহার হয়।

## ৪. SQL কী (২০ মিনিট)

**SQL = Structured Query Language**
ডাটাবেসের সাথে কথা বলার ভাষা।

```sql
-- সব Buyer দেখাও
SELECT * FROM buyer;

-- শুধু Sweden-এর Buyer দেখাও
SELECT buyer_name FROM buyer WHERE country = 'Sweden';
```

এগুলো এখনই চালাতে হবে না। সপ্তাহ ৫ থেকে SQL বিস্তারিত শিখব। শুধু দেখো, SQL প্রায় ইংরেজির মতো পড়া যায়।

**SQL আর PL/SQL:**
- **SQL:** ডাটা আনা, রাখা, বদলানো
- **PL/SQL:** Oracle-এর প্রোগ্রামিং ভাষা। SQL-এর সাথে if-else, loop ইত্যাদি যোগ করে বড় লজিক লেখা যায়

## ৫. Oracle Database-এর পরিচিতি (৩০ মিনিট)

- **Oracle Corporation** একটা আমেরিকান কোম্পানি। ১৯৭৭ সালে Larry Ellison প্রতিষ্ঠা করেন।
- **Oracle Database** পৃথিবীর সবচেয়ে বেশি ব্যবহৃত বড় এন্টারপ্রাইজ ডাটাবেসগুলোর একটা।
- ব্যাংক, টেলিকম, বড় গার্মেন্টস গ্রুপ, সরকারি প্রতিষ্ঠান Oracle ব্যবহার করে।

### Oracle Database-এর সংস্করণ (Edition)

| সংস্করণ | কার জন্য | দাম |
|---|---|---|
| Enterprise Edition | বড় কোম্পানি | অনেক দামি |
| Standard Edition | মাঝারি কোম্পানি | দামি |
| **Oracle Database Free** | শেখা আর ছোট প্রজেক্ট | **ফ্রি** |

**আমরা শেখার জন্য Oracle Database Free ব্যবহার করব।** কাল এটা ইনস্টল করব।

### Oracle-এর কিছু গুরুত্বপূর্ণ টুল

| টুল | কাজ |
|---|---|
| SQL Developer | SQL আর PL/SQL লেখা ও চালানো |
| SQL*Plus | কমান্ড লাইন থেকে SQL চালানো |
| Oracle APEX | ওয়েব অ্যাপ্লিকেশন বানানো |
| ORDS | ডাটাবেসকে ওয়েবে যুক্ত করা |
| Oracle Live SQL | ব্রাউজারে ফ্রি SQL প্র্যাকটিস |
