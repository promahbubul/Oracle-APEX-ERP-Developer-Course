## ১. Client আর Server (৩০ মিনিট)

রেস্টুরেন্টের উদাহরণ দিয়ে বুঝি:

| রেস্টুরেন্ট | কম্পিউটার |
|---|---|
| তুমি (কাস্টমার), খাবার চাও | **Client**: যে সেবা চায় |
| ওয়েটার, অর্ডার নিয়ে যায়, খাবার এনে দেয় | **Web Server / Application Server** |
| রান্নাঘর আর স্টোর, যেখানে খাবার আর উপকরণ থাকে | **Database Server** |

- **Client:** যে কম্পিউটার বা প্রোগ্রাম সেবা চায়। যেমন: তোমার ল্যাপটপের Chrome ব্রাউজার।
- **Server:** যে কম্পিউটার বা প্রোগ্রাম সেবা দেয়। সাধারণত ২৪ ঘণ্টা চালু থাকে।

একটা সার্ভার একসাথে হাজার হাজার Client-কে সেবা দিতে পারে।

## ২. ইন্টারনেটের কিছু বেসিক শব্দ (৩০ মিনিট)

| শব্দ | মানে | উদাহরণ |
|---|---|---|
| **নেটওয়ার্ক** | একাধিক কম্পিউটার একসাথে যুক্ত | অফিসের LAN |
| **ইন্টারনেট** | সারা পৃথিবীর নেটওয়ার্কগুলোর নেটওয়ার্ক | |
| **IP Address** | নেটওয়ার্কে প্রতিটা কম্পিউটারের ঠিকানা | `192.168.1.10` |
| **localhost** | নিজের কম্পিউটারের ঠিকানা | `127.0.0.1` |
| **Port** | একটা কম্পিউটারের ভেতরে নির্দিষ্ট প্রোগ্রামের দরজা | Oracle ডাটাবেস: `1521`, ওয়েব: `80`/`443` |
| **Domain** | IP Address-এর সহজ নাম | `oracle.com` |
| **URL** | একটা পেজের পুরো ঠিকানা | `https://apex.oracle.com/pls/apex/` |
| **HTTP / HTTPS** | ব্রাউজার আর সার্ভারের কথা বলার নিয়ম। HTTPS হলো নিরাপদ (এনক্রিপ্টেড) | |

### URL-এর অংশ

```
https://apex.oracle.com:443/pls/apex/r/myapp/home
  │          │           │        │
  │          │           │        └── Path (কোন পেজ)
  │          │           └── Port
  │          └── Domain
  └── Protocol
```

**গুরুত্বপূর্ণ:** পরে ডাটাবেস ইনস্টল করার সময় `localhost` আর `1521` বারবার দেখবে। মানে হলো: "আমার নিজের কম্পিউটারে, ১৫২১ নম্বর দরজায় Oracle ডাটাবেস চলছে।"

## ৩. Request আর Response (৩০ মিনিট)

যখন তুমি ব্রাউজারে একটা পেজ খোলো:

```
[তোমার ব্রাউজার]  ──── Request (আমাকে Home পেজ দাও) ────►  [সার্ভার]
[তোমার ব্রাউজার]  ◄─── Response (এই নাও HTML পেজ) ─────  [সার্ভার]
```

- **Request:** Client সার্ভারের কাছে কিছু চায়
- **Response:** সার্ভার উত্তর পাঠায়

### HTTP Status Code (পরিচিত হয়ে রাখো)

| কোড | মানে |
|---|---|
| 200 | সব ঠিক আছে (OK) |
| 404 | পেজ পাওয়া যায়নি (Not Found) |
| 401 / 403 | অনুমতি নেই |
| 500 | সার্ভারে সমস্যা হয়েছে |

## ৪. ৩-স্তরের আর্কিটেকচার (৪০ মিনিট)

বেশিরভাগ ওয়েব অ্যাপ্লিকেশন তিন ভাগে কাজ করে:

```
┌──────────────────┐      ┌───────────────────────┐      ┌──────────────────┐
│  ১. Client       │      │  ২. Application/Web   │      │  ৩. Database     │
│  (ব্রাউজার)       │ ───► │     Server            │ ───► │     Server       │
│                  │ ◄─── │  (লজিক চালায়)          │ ◄─── │  (ডাটা রাখে)      │
│  HTML, CSS, JS   │      │                       │      │  Oracle Database │
└──────────────────┘      └───────────────────────┘      └──────────────────┘
   যা দেখা যায়                  মাঝখানের কাজ                   ডাটা জমা থাকে
```

### একটা উদাহরণ: Store Keeper কাপড়ের স্টক দেখবেন

1. Store Keeper ব্রাউজারে ERP খুলে "Fabric Stock Report"-এ ক্লিক করলেন (**Client**)
2. ব্রাউজার Request পাঠাল **Application Server**-এ
3. Application Server ডাটাবেসকে বলল: "সব কাপড়ের স্টক দাও" (এটা বলা হয় **SQL** দিয়ে)
4. **Database Server** ডাটা খুঁজে ফেরত দিল
5. Application Server ডাটাকে সুন্দর টেবিল (HTML) বানিয়ে ব্রাউজারে পাঠাল
6. Store Keeper স্ক্রিনে রিপোর্ট দেখলেন

## ৫. Oracle APEX-এর আর্কিটেকচার (৩০ মিনিট)

Oracle APEX একটু আলাদা। এর সব কিছু **ডাটাবেসের ভেতরেই** থাকে।

```
[ব্রাউজার]  ◄──►  [ORDS]  ◄──►  [Oracle Database]
                                    ├── APEX (অ্যাপের সব পেজ, সেটিং)
                                    ├── তোমার টেবিল আর ডাটা
                                    └── তোমার PL/SQL কোড
```

- **ORDS (Oracle REST Data Services):** ব্রাউজার আর ডাটাবেসের মাঝে সংযোগকারী (ওয়েটারের মতো)। এটা Java দিয়ে বানানো, কিন্তু তোমাকে Java শিখতে হবে না।
- **Oracle Database:** এখানেই APEX, তোমার টেবিল আর তোমার কোড, সব থাকে।

**এজন্যই APEX ডেভেলপারের জন্য SQL আর PL/SQL সবচেয়ে জরুরি।** Node.js বা Java লাগে না।

## ৬. হাতে-কলমে প্র্যাকটিস (৪০ মিনিট)

1. **নিজের IP Address দেখো:**
   - `Windows + R` চাপো, লেখো `cmd`, Enter দাও
   - লেখো `ipconfig`, Enter দাও
   - `IPv4 Address` লাইনটা খুঁজে খাতায় লেখো

2. **একটা ওয়েবসাইটের IP Address বের করো:**
   - cmd-তে লেখো `ping google.com`
   - যে IP Address দেখায়, সেটা খাতায় লেখো

3. **Request/Response নিজের চোখে দেখো:**
   - Chrome-এ যেকোনো ওয়েবসাইট খোলো
   - `F12` চাপো, তারপর **Network** ট্যাবে যাও
   - পেজ রিফ্রেশ করো (`F5`)
   - দেখো কতগুলো Request গেল, আর প্রতিটার Status কোড (200, 304 ইত্যাদি) কী

4. **৪০৪ দেখো:** ব্রাউজারে `https://www.google.com/abcxyz123` খোলো। কী দেখায়?

## সারাংশ

- Client চায়, Server দেয়
- ব্রাউজার Request পাঠায়, সার্ভার Response দেয়
- সাধারণ ওয়েব অ্যাপের ৩টা স্তর: Client → Application Server → Database
- APEX-এ ব্রাউজার → ORDS → Oracle Database, আর অ্যাপের সবকিছু ডাটাবেসের ভেতরে

**পরের ক্লাস:** ডাটা, ইনফরমেশন, ডাটাবেস, DBMS, RDBMS কী, আর Oracle-এর পরিচিতি।
