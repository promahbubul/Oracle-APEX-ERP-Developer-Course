## ১. SQL Developer কী (১০ মিনিট)

**SQL Developer** হলো Oracle-এর ফ্রি টুল, যেখানে:
- SQL আর PL/SQL লিখে চালানো যায়
- টেবিল, ডাটা মাউস দিয়ে দেখা যায়
- এরর সহজে বোঝা যায়

SQL*Plus (কালো cmd স্ক্রিন) থেকে এটা অনেক সহজ। এখন থেকে বেশিরভাগ কাজ এখানে করব।

> **বিকল্প:** VS Code ব্যবহার করলে **"Oracle SQL Developer Extension for VS Code"** নামে একটা এক্সটেনশনও আছে। তবে শুরুতে আসল SQL Developer ব্যবহার করাই সহজ।

## ২. SQL Developer ডাউনলোড ও চালানো (২৫ মিনিট)

1. যাও: **https://www.oracle.com/database/sqldeveloper/**
2. **Download** পেজে **Windows 64-bit with JDK included** ভার্সনটা নাও (এতে Java আলাদা ইনস্টল করতে হয় না)
3. Oracle অ্যাকাউন্ট দিয়ে লগইন করতে বললে কাল যে অ্যাকাউন্ট খুলেছিলে সেটা দাও
4. zip ফাইল ডাউনলোড হলে Extract করো। যেমন: `D:\sqldeveloper\`
5. ফোল্ডারের ভেতর **`sqldeveloper.exe`** চালাও
6. প্রথমবার পুরনো সেটিং Import করতে চাইলে **No** দাও
7. সহজে খোলার জন্য `sqldeveloper.exe`-তে রাইট-ক্লিক করে **Send to → Desktop (create shortcut)** দাও

> SQL Developer ইনস্টল করতে হয় না, শুধু Extract করে চালাতে হয়।

## ৩. SYSTEM ইউজার দিয়ে কানেক্ট করা (২০ মিনিট)

1. বাম পাশে **Connections** প্যানেলে সবুজ **+** চিহ্নে ক্লিক করো
2. নিচের মতো পূরণ করো:

| ঘর | কী দেবে |
|---|---|
| Name | `system_freepdb1` |
| Username | `system` |
| Password | তোমার পাসওয়ার্ড (যেমন `Oracle123`) |
| Save Password | টিক দাও |
| Hostname | `localhost` |
| Port | `1521` |
| **Service name** (SID না) | `FREEPDB1` |

3. **Test** চাপো। নিচে **Status: Success** দেখালে সব ঠিক আছে
4. **Save**, তারপর **Connect**

## ৪. নিজের জন্য আলাদা ইউজার বানানো (৩০ মিনিট)

**কেন?** `SYSTEM` হলো অ্যাডমিন ইউজার। এটা দিয়ে প্রতিদিনের কাজ করলে ভুল করে ডাটাবেসের জরুরি কিছু নষ্ট হতে পারে। তাই প্র্যাকটিসের জন্য আলাদা ইউজার বানাব।

`system_freepdb1` কানেকশনের Worksheet-এ লেখো:

```sql
-- নতুন ইউজার তৈরি
CREATE USER learn IDENTIFIED BY Learn123;

-- কানেক্ট করা আর টেবিল, ভিউ, প্রসিডিওর ইত্যাদি বানানোর অনুমতি
GRANT CREATE SESSION, CREATE TABLE, CREATE VIEW, CREATE SEQUENCE,
      CREATE PROCEDURE, CREATE TRIGGER, CREATE SYNONYM TO learn;

-- ডাটা রাখার জায়গা
ALTER USER learn QUOTA UNLIMITED ON users;
```

**কীভাবে চালাবে:** পুরোটা সিলেক্ট করে **Run Script** (`F5`) চাপো। নিচে প্রতিটার জন্য `User LEARN created.` বা `Grant succeeded.` দেখাবে।

> **Run Statement (`Ctrl + Enter`):** কার্সার যে লাইনে আছে, শুধু সেই কোয়েরি চালায়।
> **Run Script (`F5`):** পুরো Worksheet-এর সব কোয়েরি একসাথে চালায়।

### নতুন ইউজার দিয়ে কানেকশন

আবার সবুজ **+** চাপো:

| ঘর | কী দেবে |
|---|---|
| Name | `learn_freepdb1` |
| Username | `learn` |
| Password | `Learn123` |
| Hostname | `localhost` |
| Port | `1521` |
| Service name | `FREEPDB1` |

**Test → Save → Connect**

**এখন থেকে সব প্র্যাকটিস `learn_freepdb1` কানেকশনে করবে।**

## ৫. SQL Developer-এর স্ক্রিন চেনা (২৫ মিনিট)

```
┌───────────────┬──────────────────────────────────────────┐
│ Connections   │  Worksheet (এখানে SQL লিখবে)              │
│  └ learn_...  │                                          │
│    ├ Tables   │                                          │
│    ├ Views    ├──────────────────────────────────────────┤
│    ├ ...      │  Query Result / Script Output            │
│               │  (ফলাফল এখানে দেখাবে)                     │
└───────────────┴──────────────────────────────────────────┘
```

`learn_freepdb1` Worksheet-এ এগুলো একটা একটা করে `Ctrl + Enter` দিয়ে চালাও:

```sql
SELECT USER FROM dual;

SELECT SYSDATE FROM dual;

SELECT 'আমি Oracle শিখছি' AS message FROM dual;

SELECT 5000 * 12 AS yearly_salary FROM dual;
```

### একটা ছোট পরীক্ষামূলক টেবিল

এখনই পুরোটা বুঝতে হবে না, শুধু চালিয়ে দেখো (সপ্তাহ ৫-এ বিস্তারিত শিখব):

```sql
CREATE TABLE test_buyer (
    buyer_id   NUMBER,
    buyer_name VARCHAR2(100),
    country    VARCHAR2(50)
);

INSERT INTO test_buyer VALUES (1, 'H&M', 'Sweden');
INSERT INTO test_buyer VALUES (2, 'Zara', 'Spain');
INSERT INTO test_buyer VALUES (3, 'Walmart', 'USA');
COMMIT;

SELECT * FROM test_buyer;
```

এখন বাম পাশে **Tables**-এ রাইট-ক্লিক করে **Refresh** দাও। `TEST_BUYER` টেবিল দেখাবে। এতে ক্লিক করে **Data** ট্যাবে ডাটাগুলো দেখো।

> `H&M` লেখার সময় SQL Developer একটা বক্স খুলে কিছু চাইতে পারে, কারণ `&` চিহ্নের বিশেষ মানে আছে। এরকম হলে আগে এই লাইনটা চালাও: `SET DEFINE OFF`

### দরকারি শর্টকাট

| শর্টকাট | কাজ |
|---|---|
| `Ctrl + Enter` | একটা কোয়েরি চালানো |
| `F5` | পুরো স্ক্রিপ্ট চালানো |
| `Ctrl + S` | Worksheet সেভ করা |
| `Ctrl + F7` | কোড সুন্দর করে সাজানো (Format) |
| `Ctrl + /` | লাইন কমেন্ট করা |

## ৬. apex.oracle.com-এ ফ্রি Workspace খোলা (৩০ মিনিট)

**Workspace** হলো APEX-এ তোমার নিজের জায়গা, যেখানে তোমার অ্যাপ আর টেবিল থাকবে।

1. যাও: **https://apex.oracle.com**
2. **Get Started for Free** বা **Request a Free Workspace**-এ ক্লিক করো
3. ফর্ম পূরণ করো:
   - **First Name, Last Name, Email:** তোমার তথ্য
   - **Workspace Name:** ছোট আর ইউনিক নাম, যেমন `mahbub_erp` (না পেলে অন্য নাম দাও)
4. পরের পেজগুলোতে কিছু প্রশ্ন (কেন ব্যবহার করবে, অভিজ্ঞতা কতটুকু) থাকবে, সঠিকভাবে উত্তর দাও
5. শর্ত মেনে নিয়ে **Submit Request**
6. ইমেইলে একটা লিংক আসবে। সেই লিংকে ক্লিক করে workspace চালু করো আর পাসওয়ার্ড সেট করো
7. লগইনের জন্য ৩টা জিনিস লাগবে, খাতায় লিখে রাখো:
   ```
   Workspace: (তোমার workspace নাম)
   Username:  (সাধারণত তোমার ইমেইল)
   Password:  (তোমার পাসওয়ার্ড)
   ```

### লগইন করে ঘুরে দেখো

লগইন করলে ৪টা বড় অংশ দেখবে:

| অংশ | কাজ |
|---|---|
| **App Builder** | অ্যাপ বানানো |
| **SQL Workshop** | SQL চালানো, টেবিল দেখা |
| **Team Development** | টিমের কাজ ট্র্যাক করা |
| **Gallery** | রেডিমেড স্যাম্পল অ্যাপ |

**SQL Workshop → SQL Commands**-এ গিয়ে লেখো আর **Run** চাপো:
```sql
SELECT 'Hello APEX' FROM dual;
```

> apex.oracle.com শুধু **শেখার জন্য**। এখানে আসল কোম্পানির ডাটা রাখা যাবে না।
