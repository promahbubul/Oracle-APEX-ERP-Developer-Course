# ক্লাস ৪: Oracle Database Free ইনস্টল করা

**তারিখ:** ১০ নভেম্বর ২০২৬, মঙ্গলবার
**সময়:** সন্ধ্যা ৭:০০ থেকে রাত ১০:০০
**সপ্তাহ:** ১ | **ধাপ:** ১ (কম্পিউটার ও ডাটাবেসের বেসিক)

---

## আজকে কী শিখব

- Oracle Database Free ইনস্টলের আগে কী কী লাগবে
- Oracle অ্যাকাউন্ট খোলা
- Windows-এ Oracle Database Free ইনস্টল করা
- ডাটাবেস চলছে কি না চেক করা
- SQL*Plus দিয়ে প্রথমবার ডাটাবেসে ঢোকা
- CDB, PDB আর Service Name কী

---

## ১. ইনস্টলের আগে চেকলিস্ট (১৫ মিনিট)

| জিনিস | লাগবে |
|---|---|
| অপারেটিং সিস্টেম | Windows 10 বা 11, **64-bit** |
| RAM | কমপক্ষে ৮ GB হলে ভালো (৪ GB-তে চলবে, কিন্তু ধীর হবে) |
| খালি জায়গা | কমপক্ষে ১৫ GB |
| ইন্টারনেট | ডাউনলোডের জন্য (ফাইল প্রায় ১–২ GB) |
| অ্যাকাউন্ট | Windows-এর Administrator অ্যাকাউন্ট |

> **কম্পিউটার দুর্বল হলে:** ইনস্টল না করেও শেখা যাবে। SQL প্র্যাকটিসের জন্য **livesql.oracle.com** আর APEX-এর জন্য **apex.oracle.com** ব্রাউজারে ফ্রি চলে। তবে নিজের কম্পিউটারে ইনস্টল থাকলে শেখা সহজ হয়, তাই সম্ভব হলে ইনস্টল করো।

---

## ২. কিছু নতুন শব্দ (২০ মিনিট)

| শব্দ | মানে |
|---|---|
| **Instance** | চালু থাকা ডাটাবেস প্রোগ্রাম (মেমোরিতে চলে) |
| **CDB (Container Database)** | বড় ডাটাবেস, যার ভেতরে ছোট ছোট ডাটাবেস থাকে। নাম: `FREE` |
| **PDB (Pluggable Database)** | CDB-এর ভেতরের ছোট ডাটাবেস। **আমরা এখানেই কাজ করব।** নাম: `FREEPDB1` |
| **Service Name** | কোন ডাটাবেসে কানেক্ট করব তার নাম। আমাদের: `FREEPDB1` |
| **Listener** | Port `1521`-এ বসে থেকে কানেকশন গ্রহণ করে |
| **SYS, SYSTEM** | ডাটাবেসের সবচেয়ে বড় অ্যাডমিন ইউজার |

উদাহরণ: CDB একটা অ্যাপার্টমেন্ট বিল্ডিং, আর PDB তার একটা ফ্ল্যাট। আমরা নিজেদের ফ্ল্যাটে (`FREEPDB1`) কাজ করব।

---

## ৩. Oracle অ্যাকাউন্ট খোলা (১৫ মিনিট)

1. ব্রাউজারে যাও: **https://www.oracle.com**
2. উপরে ডানে **Account** বা **Sign In**-এ ক্লিক করো
3. **Create an Account** বেছে নাও
4. ইমেইল, নাম, দেশ (Bangladesh), পাসওয়ার্ড দাও
5. ইমেইলে যে ভেরিফিকেশন লিংক আসবে, সেটায় ক্লিক করো

> এই অ্যাকাউন্ট পরে SQL Developer ডাউনলোড আর Oracle Live SQL-এও লাগবে।

---

## ৪. Oracle Database Free ডাউনলোড (২০ মিনিট)

1. যাও: **https://www.oracle.com/database/free/**
2. **Download** বাটনে ক্লিক করো
3. **Windows** অংশ থেকে Windows-এর জন্য `.zip` ফাইল ডাউনলোড করো
4. ডাউনলোড শেষ হলে zip ফাইলে রাইট-ক্লিক করে **Extract All** দাও। যেমন: `D:\OracleSetup\` ফোল্ডারে

> Oracle মাঝে মাঝে ভার্সনের নাম বদলায় (যেমন 23ai, 26ai)। সাইটে যে **সর্বশেষ ফ্রি ভার্সন** আছে, সেটাই নাও। ইনস্টলের ধাপ প্রায় একই থাকে।

---

## ৫. ইনস্টল করা (৬০ মিনিট)

1. Extract করা ফোল্ডারে **`setup.exe`** খুঁজে বের করো
2. রাইট-ক্লিক করে **Run as administrator** দাও
3. স্বাগত পেজে **Next**
4. লাইসেন্স অ্যাগ্রিমেন্ট মেনে নিয়ে **Next**
5. **Destination Folder:** ডিফল্ট রাখতে পারো, অথবা অন্য ড্রাইভ দাও। **ফোল্ডারের নামে স্পেস রাখবে না।**
6. **Database Password:** একটা পাসওয়ার্ড দাও। এটা `SYS`, `SYSTEM` আর `PDBADMIN` তিনটা ইউজারের পাসওয়ার্ড হবে।
   - উদাহরণ: `Oracle123`
   - **এই পাসওয়ার্ড অবশ্যই খাতায় লিখে রাখো।** ভুলে গেলে সমস্যা হবে।
7. **Install** বাটনে ক্লিক করো
8. অপেক্ষা করো। ১০–৩০ মিনিট লাগতে পারে। মাঝে Windows Firewall অনুমতি চাইলে **Allow** দাও।
9. শেষ হলে একটা পেজ দেখাবে, যেখানে কানেকশনের তথ্য থাকে। **এটার স্ক্রিনশট নিয়ে রাখো।** সাধারণত এরকম দেখায়:
   ```
   Multitenant container database: localhost:1521
   Pluggable database: localhost:1521/FREEPDB1
   ```
10. **Finish**

---

## ৬. ডাটাবেস চলছে কি না চেক (১৫ মিনিট)

1. `Windows + R` চাপো, লেখো `services.msc`, Enter দাও
2. লিস্টে খুঁজো:
   - **OracleServiceFREE** → Status: **Running** থাকতে হবে
   - **OracleOraDB...TNSListener** (নাম একটু আলাদা হতে পারে) → Status: **Running**
3. কোনোটা বন্ধ থাকলে রাইট-ক্লিক করে **Start** দাও

> **টিপস:** Oracle সবসময় চালু থাকলে কম্পিউটার একটু ধীর হতে পারে। চাইলে এই সার্ভিসগুলোর **Startup type** বদলে **Manual** করে রাখো, আর পড়ার সময় হাতে **Start** দিও।

---

## ৭. SQL*Plus দিয়ে প্রথম কানেকশন (২৫ মিনিট)

1. `Windows + R` চাপো, লেখো `cmd`, Enter দাও
2. লেখো (পাসওয়ার্ডের জায়গায় নিজেরটা দাও):
   ```
   sqlplus system/Oracle123@localhost:1521/FREEPDB1
   ```
3. এরকম দেখালে কানেকশন সফল:
   ```
   Connected to:
   Oracle Database ... Free Release ...
   SQL>
   ```
4. তোমার প্রথম SQL চালাও:
   ```sql
   SELECT 'আমি Oracle শিখছি' AS message FROM dual;
   ```
5. আজকের তারিখ দেখো:
   ```sql
   SELECT SYSDATE FROM dual;
   ```
6. কোন ডাটাবেসে আছ দেখো:
   ```sql
   SHOW CON_NAME
   ```
   উত্তর আসবে: `FREEPDB1`
7. বের হতে লেখো:
   ```
   exit
   ```

> `DUAL` হলো Oracle-এর একটা ছোট ডামি টেবিল। কোনো টেবিল ছাড়া কিছু হিসাব বা দেখার দরকার হলে এটা ব্যবহার হয়।

> বাংলা লেখা cmd-তে `???` দেখাতে পারে। এটা শুধু দেখানোর সমস্যা, ডাটাবেসের না। কাল SQL Developer-এ ঠিকমতো দেখাবে।

## ৮. সাধারণ সমস্যা ও সমাধান

| সমস্যা | সমাধান |
|---|---|
| `'sqlplus' is not recognized` | কম্পিউটার রিস্টার্ট দাও। তারপরও না হলে Oracle ইনস্টল ফোল্ডারের `bin` ফোল্ডার থেকে চালাও |
| `ORA-12541: TNS:no listener` | `services.msc`-এ Listener সার্ভিস Start করো |
| `ORA-01017: invalid username/password` | পাসওয়ার্ড ঠিকমতো দিয়েছ কি না দেখো |
| `ORA-12514: listener does not currently know of service` | ডাটাবেস সার্ভিস (`OracleServiceFREE`) চালু হতে কয়েক মিনিট লাগে, একটু অপেক্ষা করে আবার চেষ্টা করো |
| ইনস্টল মাঝপথে বন্ধ হয়ে যায় | Antivirus সাময়িক বন্ধ করে, Run as administrator দিয়ে আবার চেষ্টা করো |

## ৯. হোমওয়ার্ক

1. খাতায় এই তথ্যগুলো একটা পেজে লিখে রাখো (পরে বারবার লাগবে):
   ```
   Host: localhost
   Port: 1521
   Service Name: FREEPDB1
   Username: system
   Password: (তোমার পাসওয়ার্ড)
   ```
2. SQL*Plus-এ ঢুকে নিচের কোয়েরিগুলো চালাও, ফলাফল খাতায় লেখো:
   ```sql
   SELECT 10 + 20 FROM dual;
   SELECT 500 * 12 FROM dual;
   SELECT USER FROM dual;
   ```
3. Oracle সার্ভিস বন্ধ করে আবার চালু করার প্র্যাকটিস করো।

## সারাংশ

- Oracle Database Free ফ্রিতে ডাউনলোড করে Windows-এ ইনস্টল করা যায়
- CDB হলো বড় কন্টেইনার, আমরা কাজ করব PDB `FREEPDB1`-এ
- কানেকশনের তথ্য: `localhost`, `1521`, `FREEPDB1`
- SQL*Plus দিয়ে প্রথম কোয়েরি চালিয়েছি

**পরের ক্লাস:** SQL Developer ইনস্টল আর কানেক্ট করা, আর apex.oracle.com-এ ফ্রি workspace খোলা।
