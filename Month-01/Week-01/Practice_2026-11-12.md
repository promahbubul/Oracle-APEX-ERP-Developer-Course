## ১. পুরো সপ্তাহের রিভিশন (৪০ মিনিট)

নিচের প্রতিটা প্রশ্নের উত্তর খাতা না দেখে মুখে বলো বা লেখো। না পারলে সেই ক্লাসের ফাইল আবার পড়ো।

**ক্লাস ১**
- সফটওয়্যারের ধরন কয়টা?
- ওয়েব অ্যাপ্লিকেশনের ৩টা সুবিধা
- ERP কী, গার্মেন্টসে কেন লাগে?

**ক্লাস ২**
- Client আর Server-এর পার্থক্য
- Request আর Response কী?
- ৩-স্তরের আর্কিটেকচার আঁকো
- APEX-এ ORDS-এর কাজ কী?

**ক্লাস ৩**
- ডাটা আর ইনফরমেশনের পার্থক্য
- DBMS আর RDBMS কী?
- টেবিলের মধ্যে Relation কীভাবে তৈরি হয়?

**ক্লাস ৪**
- CDB আর PDB কী?
- আমাদের কানেকশনের তথ্য (Host, Port, Service Name) কী?

**ক্লাস ৫**
- SQL Developer-এ কীভাবে নতুন কানেকশন বানায়?
- কেন আলাদা `learn` ইউজার বানিয়েছি?

## ৩. প্র্যাকটিসের কাজ (৭৫ মিনিট)

### কাজ ১: আর্কিটেকচার ব্যাখ্যা (১৫ মিনিট)
"Merchandiser ERP-তে একটা নতুন অর্ডার এন্ট্রি দিলেন।" এই ঘটনায় ব্রাউজার, ORDS আর Oracle Database কে কী কাজ করছে, ধাপে ধাপে লেখো আর ছবি আঁকো।

### কাজ ২: টেবিল ডিজাইন খাতায় (২০ মিনিট)
একটা গার্মেন্টস ফ্যাক্টরির জন্য ৩টা টেবিল খাতায় বানাও:
- **BUYER:** buyer_id, buyer_name, country
- **STYLE:** style_id, style_name, buyer_id
- **ORDERS:** order_id, style_id, quantity, shipment_date

প্রতিটায় ৩–৪টা ডাটা দাও। কোন টেবিল কোনটার সাথে যুক্ত, তীর দিয়ে দেখাও।

### কাজ ৩: SQL Developer-এ টেবিল বানানো (৩০ মিনিট)
`learn_freepdb1` কানেকশনে কাজ ২-এর `test_style` টেবিল বানাও আর ডাটা ঢোকাও। ক্লাস ৫-এর `test_buyer` টেবিলের উদাহরণ দেখে নিজে লেখার চেষ্টা করো, তারপর সমাধান মিলিয়ে দেখো।

<details>
<summary>কাজ ৩-এর সমাধান</summary>

```sql
CREATE TABLE test_style (
    style_id   NUMBER,
    style_name VARCHAR2(100),
    buyer_id   NUMBER
);

INSERT INTO test_style VALUES (1, 'Basic T-Shirt', 1);
INSERT INTO test_style VALUES (2, 'Polo Shirt', 1);
INSERT INTO test_style VALUES (3, 'Denim Jeans', 3);
INSERT INTO test_style VALUES (4, 'Hoodie', 2);
COMMIT;

SELECT * FROM test_style;
```

</details>

### কাজ ৪: APEX-এ একই কাজ (১০ মিনিট)
apex.oracle.com-এ **SQL Workshop → SQL Commands**-এ গিয়ে কাজ ৩-এর টেবিল আর ডাটা আবার বানাও। তারপর **SQL Workshop → Object Browser**-এ গিয়ে টেবিলটা খুঁজে দেখো।
