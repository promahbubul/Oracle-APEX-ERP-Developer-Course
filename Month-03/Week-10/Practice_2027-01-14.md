## ১. রিভিশন (২০ মিনিট)

খাতা না দেখে উত্তর দাও। না পারলে সেই ক্লাসের ফাইল আবার পড়ো।

**ক্লাস ৪৬:** Single Row Subquery-তে কোন তুলনা চলে? `ORA-01427` কখন আসে? Inline View কী?

**ক্লাস ৪৭:** `NOT IN (SELECT ...)`-এর ফাঁদ কী? `> ANY` আর `> ALL`-এর পার্থক্য কী?

**ক্লাস ৪৮:** Correlated Subquery কতবার চলে? `EXISTS` কী দেখে? "নেই" খোঁজার সবচেয়ে নিরাপদ উপায় কী?

**ক্লাস ৪৯:** `UNION` আর `UNION ALL`-এর পার্থক্য কী? টাকার হিসাবে কোনটা? `ORDER BY` কোথায়?

**ক্লাস ৫০:** `MINUS`-এর ক্রম কেন জরুরি? দুই টেবিল মিলেছে কি না কীভাবে প্রমাণ করবে?

## ২. মূল কাজ: ২০টা কোয়েরি (১১৫ মিনিট)

`hr_freepdb1`-এ করো। প্রতিটা কোয়েরি `week10.sql`-এ কমেন্টে নম্বর দিয়ে রাখো।

**নিয়ম:**
- আগে ভেতরের কোয়েরি আলাদা চালিয়ে দেখো, ঠিক হলে বাইরে বসাও
- শর্তে অন্য টেবিল লাগলে যে উপায়ই নাও, ফল মিলিয়ে দেখো
- `NOT IN` লিখলে ভেতরের NULL ভেবে নাও

> `(n)` মানে প্রত্যাশিত রো সংখ্যা। HR-এর ভার্সনভেদে সামান্য আলাদা হতে পারে।

### অংশ ক: Single Row (৬টা)

1. Abel-এর চেয়ে বেশি বেতন। (১০)
2. কোম্পানির গড়ের চেয়ে বেশি বেতন। (৫১)
3. `Ernst`-এর পদের সবাই, `Ernst`-সহ। (৫)
4. সবচেয়ে কম বেতনের কর্মী। (১: Olson)
5. দ্বিতীয় সর্বোচ্চ বেতনের মান। (১৭০০০)
6. কোম্পানির গড়ের চেয়ে বেশি গড় বেতনের বিভাগ। (৮: ৭টা বিভাগ আর NULL)

### অংশ খ: Multi Row (৬টা)

7. Seattle-এর (`location_id` ১৭০০) কর্মী। (১৮)
8. যারা ম্যানেজার। (১৮)
9. যারা ম্যানেজার নন, `NOT IN` দিয়ে, ফাঁদ এড়িয়ে। (৮৯)
10. কর্মী ছাড়া বিভাগ, `NOT IN` দিয়ে। (১৬)
11. বিভাগ ৬০-এর সবার চেয়ে বেশি বেতন, `ALL` দিয়ে। তারপর `MAX` দিয়ে মিলাও।
12. প্রতিটা বিভাগের সর্বোচ্চ বেতনের কর্মী, জোড়া দিয়ে। (১১)

### অংশ গ: Correlated (৪টা)

13. নিজের বিভাগের গড়ের চেয়ে বেশি বেতন। বিভাগ ৬০-এ শুধু Hunold, Ernst।
14. যারা ম্যানেজার, `EXISTS` দিয়ে। (১৮)
15. কর্মী ছাড়া বিভাগ, `NOT EXISTS` দিয়ে। (১৬)
16. প্রতিটা বিভাগের নাম আর কর্মী সংখ্যা, `SELECT`-এ Subquery। (২৭)

### অংশ ঘ: Inline View (২টা)

17. প্রতিটা কর্মীর নাম, বেতন, আর নিজের বিভাগের গড় বেতন। JOIN + Inline View দিয়ে। (১০৬)
18. গড় বেতনে শীর্ষ বিভাগের নাম আর গড়। (Executive, ১৯৩৩৩.৩৩)

### অংশ ঙ: Set Operator (২টা)

19. কর্মী ছাড়া বিভাগ, `MINUS` দিয়ে। (১৬)
20. বর্তমান আর আগের পদের সব জোড়া, ডুপ্লিকেট ছাড়া। (১১৫)

FROM   employees m

       FROM   employees
       GROUP  BY department_id) s
       ON s.department_id = e.department_id;

-- ১৮
SELECT d.department_name, s.avg_salary
FROM   departments d
JOIN  (SELECT department_id, ROUND(AVG(salary), 2) AS avg_salary
       FROM   employees
       GROUP  BY department_id) s
       ON s.department_id = d.department_id
ORDER  BY s.avg_salary DESC
FETCH  FIRST 1 ROWS ONLY;

### সময় থাকলে: ERP ধরনের রিপোর্ট

`learn_freepdb1`-এ:

5. প্রতিটা আইটেমের ব্যালেন্স `UNION ALL` দিয়ে, `item_name` সহ।

<summary>ERP রিপোর্টের সমাধান</summary>

```sql
-- ১
SELECT i.item_name
FROM   item i
WHERE  NOT EXISTS (SELECT 1 FROM goods_issue g WHERE g.item_id = i.item_id);

-- ২
SELECT i.item_name
FROM   item i
WHERE  NOT EXISTS (SELECT 1 FROM supplier_item si WHERE si.item_id = i.item_id);

-- ৩
SELECT i.item_name, s.supplier_name, si.unit_price
FROM   supplier_item si
JOIN   item i     ON si.item_id = i.item_id
JOIN   supplier s ON si.supplier_id = s.supplier_id
WHERE  (si.item_id, si.unit_price) IN (SELECT item_id, MIN(unit_price)
                                       FROM   supplier_item
                                       GROUP  BY item_id);

-- ৪
SET DEFINE OFF

SELECT o.order_no, o.order_qty, b.buyer_name
FROM   w5_order o
JOIN   w5_style s ON o.style_id = s.style_id
JOIN   w5_buyer b ON s.buyer_id = b.buyer_id
WHERE  o.order_qty > (SELECT AVG(order_qty) FROM w5_order);

-- ৫
SELECT i.item_name, NVL(b.balance_qty, 0) AS balance_qty
FROM   item i
LEFT   JOIN (SELECT item_id, SUM(in_qty) - SUM(out_qty) AS balance_qty
             FROM  (SELECT item_id, qty AS in_qty, 0 AS out_qty FROM goods_receive
                    UNION ALL
                    SELECT item_id, 0, qty FROM goods_issue) ledger
             GROUP  BY item_id) b
       ON b.item_id = i.item_id
ORDER  BY i.item_name;
```
