## ১. IN (৩৫ মিনিট)

ভেতর থেকে **একাধিক রো** এলে `=` চলে না (`ORA-01427`)। লাগে `IN`।

```sql
-- যারা Seattle-এ (location 1700) কাজ করেন: ১৮ জন
SELECT last_name, department_id
FROM   employees
WHERE  department_id IN (SELECT department_id
                         FROM   departments
                         WHERE  location_id = 1700);
```

`IN` তালিকার সব মানের সাথে সমান কি না দেখে। এটা ক্লাস ২৮-এর `IN (10, 20, 30)`-এর মতোই, শুধু তালিকাটা Subquery থেকে আসছে।

```sql
-- দুই King-এর বিভাগের সবাই: বিভাগ ৯০ আর ৮০
SELECT last_name, department_id
FROM   employees
WHERE  department_id IN (SELECT department_id FROM employees WHERE last_name = 'King');

-- যারা ম্যানেজার: ১৮ জন
SELECT employee_id, last_name
FROM   employees
WHERE  employee_id IN (SELECT manager_id FROM employees);
```

শেষেরটায় ভেতরে NULL আছে (King-এর `manager_id`), তবু ফল ঠিক। `IN` শুধু মিল খোঁজে, NULL-এর সাথে মিল হয় না, বাকিগুলো ঠিক কাজ করে।

### কয়েক ধাপে

```sql
-- US-এ থাকা কর্মী: ৬৮ জন
SELECT last_name
FROM   employees
WHERE  department_id IN (SELECT department_id
                         FROM   departments
                         WHERE  location_id IN (SELECT location_id
                                                FROM   locations
                                                WHERE  country_id = 'US'));
```

ক্লাস ৪৫-এ এটা JOIN দিয়ে করেছিলে। যখন শুধু `employees`-এর কলাম দরকার, এটা পড়াও সহজ।

### ERP-তে (`learn_freepdb1`)

```sql
-- Oracle SQL for Beginners কারা নিয়েছেন: Sumon Mia, Rupa Khatun, Rubel Sarker, Shapla Rani
SELECT member_name
FROM   lib_member
WHERE  member_id IN (SELECT member_id
                     FROM   lib_book_issue
                     WHERE  copy_id IN (SELECT copy_id
                                        FROM   lib_book_copy
                                        WHERE  book_id = (SELECT book_id
                                                          FROM   lib_book
                                                          WHERE  book_title = 'Oracle SQL for Beginners')));

-- জরিমানা পাওয়া মেম্বার: ৫ জন
SELECT member_name
FROM   lib_member
WHERE  member_id IN (SELECT i.member_id
                     FROM   lib_book_issue i
                     JOIN   lib_fine f ON f.issue_id = i.issue_id);
```

### JOIN নাকি IN: ডুপ্লিকেট

| JOIN | `IN` |
|---|---|
| ডান পাশে অনেক রো মিললে রো গুণ হয় | প্রতিটা রো একবারই আসে |
| ডান পাশের কলাম দেখানো যায় | শুধু শর্ত |

```sql
-- JOIN: ২১টা ইস্যু থেকে ২১টা রো, মেম্বার ৩ দুইবার
SELECT m.member_name FROM lib_member m JOIN lib_book_issue i ON i.member_id = m.member_id;

-- IN: ২০ জন, প্রতিজন একবার
SELECT m.member_name FROM lib_member m WHERE m.member_id IN (SELECT member_id FROM lib_book_issue);
```

## ২. NOT IN (৩০ মিনিট)

```sql
-- যাদের স্টাইল আছে, তারা ছাড়া Buyer: Walmart (learn_freepdb1)
SET DEFINE OFF

SELECT buyer_name
FROM   buyer
WHERE  buyer_id NOT IN (SELECT buyer_id FROM style);
```

### সবচেয়ে বিপজ্জনক ফাঁদ

"যারা ম্যানেজার নন" খুঁজি:

```sql
-- কোনো রো না! এরর-ও না!
SELECT last_name
FROM   employees
WHERE  employee_id NOT IN (SELECT manager_id FROM employees);
```

ফল **০ রো**। ৮৯ জন থাকার কথা। কেন? ভেতরে একটা NULL আছে (King)। ক্লাস ২৮-এ দেখেছিলে:

```
employee_id NOT IN (100, 101, ..., NULL)
= employee_id <> 100 AND employee_id <> 101 AND ... AND employee_id <> NULL
                                                         └── সবসময় অজানা
```

**একটা NULL পুরো ফল শূন্য করে দেয়।** কোনো এরর আসে না, রিপোর্ট শুধু খালি। এটা কোডের সবচেয়ে কঠিন ভুলগুলোর একটা।

```sql
-- কর্মী ছাড়া বিভাগ, একই ফাঁদ: ০ রো (Grant-এর department_id NULL)
SELECT department_name
FROM   departments
WHERE  department_id NOT IN (SELECT department_id FROM employees);
```

### সমাধান

```sql
-- উপায় ১: NULL বাদ দাও। ৮৯ জন
SELECT last_name
FROM   employees
WHERE  employee_id NOT IN (SELECT manager_id
                           FROM   employees
                           WHERE  manager_id IS NOT NULL);

-- ১৬টা বিভাগ
SELECT department_name
FROM   departments
WHERE  department_id NOT IN (SELECT department_id
                             FROM   employees
                             WHERE  department_id IS NOT NULL);
```

**উপায় ২:** `NOT EXISTS`, আরো নিরাপদ। পরশু শিখবে।

**নিয়ম:** `NOT IN (SELECT ...)` লিখলে নিশ্চিত হও ভেতরের কলামে NULL নেই। PK বা Not Null কলাম হলে নিরাপদ। ভবিষ্যতে কলামে NULL ঢুকলেও যাতে না ভাঙে, তাই `NOT EXISTS` ভালো।

## ৩. ANY ও ALL (৩৫ মিনিট)

Multi Row Subquery-র সাথে `>`, `<` চালাতে এদের লাগে।

| লেখা | মানে | সমান |
|---|---|---|
| `> ANY (...)` | অন্তত একটার চেয়ে বড় | `> MIN(...)` |
| `< ANY (...)` | অন্তত একটার চেয়ে ছোট | `< MAX(...)` |
| `= ANY (...)` | যেকোনো একটার সমান | `IN (...)` |
| `> ALL (...)` | সবগুলোর চেয়ে বড় | `> MAX(...)` |
| `< ALL (...)` | সবগুলোর চেয়ে ছোট | `< MIN(...)` |
| `<> ALL (...)` | কোনোটার সমান না | `NOT IN (...)` |

বিভাগ ৯০-এর বেতন: ২৪০০০, ১৭০০০, ১৭০০০।

```sql
-- ১৭০০০-এর বেশি: King
SELECT last_name, salary
FROM   employees
WHERE  salary > ANY (SELECT salary FROM employees WHERE department_id = 90);

-- ২৪০০০-এর বেশি: কেউ না
SELECT last_name, salary
FROM   employees
WHERE  salary > ALL (SELECT salary FROM employees WHERE department_id = 90);

-- ২৪০০০ বা বেশি: King
SELECT last_name, salary
FROM   employees
WHERE  salary >= ALL (SELECT salary FROM employees WHERE department_id = 90);

-- ১৭০০০-এর কম: ১০৪ জন
SELECT last_name, salary
FROM   employees
WHERE  salary < ALL (SELECT salary FROM employees WHERE department_id = 90);
```

### MIN, MAX দিয়ে একই কাজ

```sql
WHERE salary > (SELECT MAX(salary) FROM employees WHERE department_id = 60)
WHERE salary > ALL (SELECT salary FROM employees WHERE department_id = 60)
```

**বাস্তবে `MIN`, `MAX` বেশি ব্যবহার হয়,** কারণ পড়তে সহজ। `ANY`, `ALL` পুরনো কোড আর ইন্টারভিউতে আসে।

### ফাঁদ

```sql
-- ভেতরে কিছু না এলে
SELECT COUNT(*) FROM employees WHERE salary > ALL (SELECT salary FROM employees WHERE department_id = 9999);   -- ১০৭!
SELECT COUNT(*) FROM employees WHERE salary > ANY (SELECT salary FROM employees WHERE department_id = 9999);   -- ০
```

- `ALL` খালি তালিকায় **সব রো** দেয়: "সবগুলোর চেয়ে বড়" কেউ মিথ্যা প্রমাণ করতে পারে না
- `ANY` খালি তালিকায় **কিছুই** দেয় না

`MAX` দিয়ে লিখলে খালি তালিকায় NULL আসে, তাই কোনো রো আসে না। তাই ফল আলাদা।

## ৪. একাধিক কলাম মিলিয়ে (২০ মিনিট)

**কাজ:** "প্রতিটা বিভাগের সবচেয়ে বেশি বেতনের কর্মী।"

```sql
-- ভুল: বিভাগ না মিলিয়ে শুধু বেতন
SELECT last_name, department_id, salary
FROM   employees
WHERE  salary IN (SELECT MAX(salary) FROM employees GROUP BY department_id);
```

এতে কেউ অন্য বিভাগের সর্বোচ্চ বেতনের সমান বেতন পেলেও আসে। সমাধান: **জোড়া মেলাও।**

```sql
-- ১১টা বিভাগের ১১ জন
SELECT last_name, department_id, salary
FROM   employees
WHERE  (department_id, salary) IN (SELECT department_id, MAX(salary)
                                   FROM   employees
                                   GROUP  BY department_id)
ORDER  BY department_id;
```

কলামের ক্রম আর সংখ্যা দুই পাশে একই। `department_id` NULL হওয়ায় Grant আসে না, যদিও ওই দলে তিনিই সর্বোচ্চ। `NULL = NULL` সত্য হয় না।

### গার্মেন্টসে (`learn_freepdb1`)

```sql
-- প্রতিটা আইটেমের সবচেয়ে কম দামের Supplier: ক্লাস ১৪-এর supplier_item
SELECT supplier_id, item_id, unit_price
FROM   supplier_item
WHERE  (item_id, unit_price) IN (SELECT item_id, MIN(unit_price)
                                 FROM   supplier_item
                                 GROUP  BY item_id);
```

Purchase-এ সরাসরি কাজে লাগে: "প্রতিটা আইটেম কোথা থেকে সবচেয়ে সস্তায় পাওয়া যায়।"

ক্লাস ১৪-এ শুধু আইটেম ৩-এর দাম বসিয়েছিলে, তাই ফলে একটাই রো: Supplier ২, 3.10। দাম NULL থাকা আইটেমগুলো আসে না, কারণ NULL মেলে না।

## ৬. হোমওয়ার্ক

1. `NOT IN` আর NULL-এর সমস্যা একজন নতুন মানুষকে বোঝাও: ক্লাসের উদাহরণ ছাড়া, গার্মেন্টসের উদাহরণ দিয়ে।
2. `IN`, `= ANY` আর `NOT IN`, `<> ALL` একই কি না, চালিয়ে মিলিয়ে দেখো।
3. `w9_order_ship` থাকলে: যেসব অর্ডারের কোনো শিপমেন্ট হয়নি, দেখাও।

## সারাংশ

- `IN`: Multi Row Subquery-র প্রধান উপায়, রো গুণ হয় না
- `NOT IN`-এ ভেতরে একটা NULL থাকলেই ফল শূন্য, এরর ছাড়া
- `ANY` অন্তত একটা, `ALL` সবগুলো। `MIN`, `MAX` দিয়ে পড়া সহজ
- জোড়া মেলাও: `(a, b) IN (SELECT ...)`

**পরের ক্লাস:** Correlated Subquery, EXISTS, NOT EXISTS।
