# ক্লাস ৫০: INTERSECT ও MINUS

**তারিখ:** ১৩ জানুয়ারি ২০২৭, বুধবার
**সময়:** সন্ধ্যা ৭:০০ থেকে রাত ১০:০০
**সপ্তাহ:** ১০ | **ধাপ:** ২ (Oracle SQL)

---

## আজকে কী শিখব

- `INTERSECT`: দুইটাতেই আছে
- `MINUS`: প্রথমটায় আছে, দ্বিতীয়টায় নেই
- ডাটা মেলানো (Reconciliation)
- কয়েকটা অপারেটর একসাথে
- Set Operator, JOIN আর Subquery-র তুলনা

---

## ১. INTERSECT (২৫ মিনিট)

**দুই ফলেই আছে এমন রো।** ডুপ্লিকেট বাদ দেয়।

```
A      B         A INTERSECT B
1      2         2
2      3         3
3      4
```

```sql
-- কর্মী আছে এমন বিভাগ: ১১টা
SELECT department_id FROM departments
INTERSECT
SELECT department_id FROM employees;

-- আগে যে পদে ছিলেন, এখনো সেই পদে: ২টা (employee_id 176, 200)
SELECT employee_id, job_id FROM employees
INTERSECT
SELECT employee_id, job_id FROM job_history;
```

### লাইব্রেরিতে (`learn_freepdb1`)

```sql
-- ইস্যু হয়েছে এমন কপি যা এখন AVAILABLE
SELECT copy_id FROM lib_book_issue
INTERSECT
SELECT copy_id FROM lib_book_copy WHERE copy_status = 'AVAILABLE';

-- জরিমানা পাওয়া মেম্বার আর এখন বই রাখা মেম্বার: কেউ না
SELECT i.member_id
FROM   lib_book_issue i
JOIN   lib_fine f ON f.issue_id = i.issue_id
INTERSECT
SELECT member_id
FROM   lib_book_issue
WHERE  return_date IS NULL;
```

### NULL

Set Operator-এ **NULL আর NULL একই।** এটা `=`-এর মতো না।

```sql
-- ১টা রো: NULL
SELECT NULL AS x FROM dual
INTERSECT
SELECT NULL FROM dual;
```

## ২. MINUS (৩৫ মিনিট)

**প্রথম ফলে আছে, দ্বিতীয় ফলে নেই।** ক্রম জরুরি: `A MINUS B` আর `B MINUS A` আলাদা।

```
A      B         A MINUS B     B MINUS A
1      2         1             4
2      3
3      4
```

```sql
-- কর্মী ছাড়া বিভাগ: ১৬টা
SELECT department_id FROM departments
MINUS
SELECT department_id FROM employees;

-- উল্টো: বিভাগ নেই কর্মীতে এমন: ১টা রো (NULL, Grant)
SELECT department_id FROM employees
MINUS
SELECT department_id FROM departments;

-- যিনি পদ কখনো বদলাননি বা আগের পদ বর্তমান থেকে আলাদা: ১০৫
SELECT employee_id, job_id FROM employees
MINUS
SELECT employee_id, job_id FROM job_history;
```

**`NOT IN`-এর NULL ফাঁদ এখানে নেই।** ১৬টা বিভাগ ঠিকঠাক এলো।

```sql
-- learn_freepdb1: কপি নেই এমন বই: ৫টা
SELECT book_id FROM lib_book
MINUS
SELECT book_id FROM lib_book_copy;

-- ইস্যু হয়নি এমন কপি: ৪টা
SELECT copy_id FROM lib_book_copy
MINUS
SELECT copy_id FROM lib_book_issue;
```

**সীমাবদ্ধতা:** ফলে শুধু নির্বাচিত কলামই থাকে। নাম দেখাতে আবার JOIN বা Subquery লাগে:

```sql
SELECT book_id, book_title
FROM   lib_book
WHERE  book_id IN (SELECT book_id FROM lib_book
                   MINUS
                   SELECT book_id FROM lib_book_copy);
```

> নতুন ভার্সনে (21c থেকে) `MINUS`-এর ANSI নাম `EXCEPT`-ও চলে, আর `MINUS ALL`, `INTERSECT ALL`-ও আছে। পুরনো ভার্সনে চলে না।

## ৩. ডাটা মেলানো: Reconciliation (৩০ মিনিট)

**MINUS-এর সবচেয়ে বড় বাস্তব কাজ।** ERP-তে পুরনো সিস্টেম থেকে ডাটা আনার সময়, বা দুই বিভাগের হিসাব মেলানোর সময়।

**দৃশ্য:** Store-এর GRN তালিকা আর Accounts-এর GRN তালিকা।

```sql
CREATE TABLE w10_store_grn (
    grn_no   VARCHAR2(20) CONSTRAINT w10_store_grn_pk PRIMARY KEY,
    item_id  NUMBER(10),
    amount   NUMBER(12,2)
);

CREATE TABLE w10_acc_grn (
    grn_no   VARCHAR2(20) CONSTRAINT w10_acc_grn_pk PRIMARY KEY,
    item_id  NUMBER(10),
    amount   NUMBER(12,2)
);

INSERT INTO w10_store_grn VALUES ('GRN-1', 1, 1000);
INSERT INTO w10_store_grn VALUES ('GRN-2', 2, 2000);
INSERT INTO w10_store_grn VALUES ('GRN-3', 3, 3000);
INSERT INTO w10_store_grn VALUES ('GRN-4', 4, 4000);

INSERT INTO w10_acc_grn VALUES ('GRN-1', 1, 1000);
INSERT INTO w10_acc_grn VALUES ('GRN-2', 2, 2500);
INSERT INTO w10_acc_grn VALUES ('GRN-3', 3, 3000);
INSERT INTO w10_acc_grn VALUES ('GRN-5', 5, 5000);
COMMIT;
```

### কোনটা কোথায় নেই

```sql
-- Store-এ আছে, Accounts-এ নেই: GRN-4
SELECT grn_no FROM w10_store_grn
MINUS
SELECT grn_no FROM w10_acc_grn;

-- Accounts-এ আছে, Store-এ নেই: GRN-5
SELECT grn_no FROM w10_acc_grn
MINUS
SELECT grn_no FROM w10_store_grn;
```

### মান আলাদা

**সব কলাম দিলে** `MINUS` একই রো-র যেকোনো পার্থক্যও ধরে:

```sql
-- GRN-2 (2000, Accounts-এ 2500), GRN-4
SELECT grn_no, item_id, amount FROM w10_store_grn
MINUS
SELECT grn_no, item_id, amount FROM w10_acc_grn;
```

```sql
-- দুই দিকের সব পার্থক্য, উৎসসহ
SELECT 'Store Only' AS source_name, x.*
FROM  (SELECT grn_no, item_id, amount FROM w10_store_grn
       MINUS
       SELECT grn_no, item_id, amount FROM w10_acc_grn) x
UNION ALL
SELECT 'Accounts Only', y.*
FROM  (SELECT grn_no, item_id, amount FROM w10_acc_grn
       MINUS
       SELECT grn_no, item_id, amount FROM w10_store_grn) y
ORDER  BY grn_no, source_name;
```

ফল: `GRN-2` দুই পাশে দুই টাকায়, `GRN-4` শুধু Store-এ, `GRN-5` শুধু Accounts-এ। দুই পাশ মিললে **কোনো রো আসবে না,** এটাই সবচেয়ে ভালো ফল।

### টেবিলের কপি মিলছে কি না

```sql
CREATE TABLE w10_book_bak AS SELECT book_id, book_title, publish_year FROM lib_book;

-- দুইটাতেই ০ রো হলে দুই টেবিল একই
SELECT book_id, book_title, publish_year FROM lib_book
MINUS
SELECT book_id, book_title, publish_year FROM w10_book_bak;

SELECT book_id, book_title, publish_year FROM w10_book_bak
MINUS
SELECT book_id, book_title, publish_year FROM lib_book;

DROP TABLE w10_book_bak;
```

**মাইগ্রেশনের পরে এই পরীক্ষা করা হয়।** বড় Update-এর আগে-পরে ব্যাকআপের সাথে মেলাতেও এটা কাজে লাগে।

### Set Operator বনাম Full Join

ক্লাস ৪৩-এ এই কাজ `FULL OUTER JOIN` দিয়ে করেছিলে।

| | `MINUS` | `FULL JOIN` |
|---|---|---|
| সহজ | হ্যাঁ, সব কলাম তুলনা হয় | প্রতিটা কলামের শর্ত লিখতে হয় |
| NULL | NULL = NULL ধরে | NULL-এ `<>` কাজ করে না |
| দুই পাশ পাশাপাশি দেখা | না | হ্যাঁ |

## ৪. কয়েকটা একসাথে ও তুলনা (১৫ মিনিট)

### ক্রম

বাম থেকে ডানে চলে। ব্র্যাকেট দিয়ে নিয়ন্ত্রণ করো।

```sql
-- ব্র্যাকেট ছাড়া: (A UNION B) MINUS C
SELECT department_id FROM departments
UNION
SELECT department_id FROM employees
MINUS
SELECT department_id FROM departments WHERE department_id = 10;
```

**কয়েকটা অপারেটর মেশালে সবসময় ব্র্যাকেট দাও,** ভুল এড়াতে:

```sql
SELECT department_id FROM departments
MINUS
(SELECT department_id FROM employees
 UNION
 SELECT department_id FROM departments WHERE department_id = 270);
```

### একই প্রশ্নের ৪ উপায়

"কর্মী ছাড়া বিভাগ":

| উপায় | সুবিধা | অসুবিধা |
|---|---|---|
| `MINUS` | সহজ, NULL নিরাপদ | শুধু একই কলাম |
| `NOT EXISTS` | NULL নিরাপদ, অন্য কলাম দেখানো যায় | একটু লম্বা |
| `LEFT JOIN + IS NULL` | পরিচিত, অন্য কলাম দেখানো যায় | ভুল করলে রো গুণ |
| `NOT IN` | সহজ পড়া | **NULL ফাঁদ** |

### Set Operator-এর নিয়ম, সংক্ষেপে

| অপারেটর | ডুপ্লিকেট | ক্রম জরুরি? |
|---|---|---|
| `UNION` | বাদ | না |
| `UNION ALL` | রাখে | না |
| `INTERSECT` | বাদ | না |
| `MINUS` | বাদ | **হ্যাঁ** |

## সারাংশ

- `INTERSECT`: দুইটাতেই, ডুপ্লিকেট বাদ
- `MINUS`: প্রথমটায় আছে, দ্বিতীয়টায় নেই। ক্রম জরুরি
- Set Operator-এ NULL = NULL, তাই `NOT IN`-এর ফাঁদ নেই
- দুই ডাটাসেট মেলাতে দুই দিকে `MINUS`
- কয়েকটা মেশালে ব্র্যাকেট দাও

**পরের দিন (বৃহস্পতিবার):** সপ্তাহ ১০-এর প্র্যাকটিস: Subquery দিয়ে ২০টা কোয়েরি।
