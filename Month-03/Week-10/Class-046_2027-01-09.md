## ১. Subquery কেন (২০ মিনিট)

ক্লাস ৩৮-এ আটকে গিয়েছিলে:

```sql
SELECT last_name FROM employees WHERE salary = MAX(salary);     -- ORA-00934
```

প্রশ্ন: **"Abel-এর চেয়ে বেশি বেতন কে পান?"** দুইটা ধাপ:

```sql
-- ধাপ ১: Abel-এর বেতন কত? উত্তর 11000
SELECT salary FROM employees WHERE last_name = 'Abel';

-- ধাপ ২: 11000-এর বেশি কে পান?
SELECT last_name, salary FROM employees WHERE salary > 11000;
```

কিন্তু কাল Abel-এর বেতন বদলালে কোড বদলাতে হবে। **Subquery** প্রথম ধাপকে দ্বিতীয় ধাপের ভেতরে বসিয়ে দেয়:

```sql
-- ১০ জন
SELECT last_name, salary
FROM   employees
WHERE  salary > (SELECT salary
                 FROM   employees
                 WHERE  last_name = 'Abel');
```

```
Oracle:
১. আগে ভেতরের কোয়েরি চালায়    → 11000
২. ফলটা বাইরের কোয়েরিতে বসায়   → salary > 11000
৩. বাইরের কোয়েরি চালায়
```

**নিয়ম:**
- Subquery ব্র্যাকেটে থাকে
- তুলনার ডান পাশে লিখলে পড়া সহজ
- `ORDER BY` সাধারণত ভেতরে লাগে না

## ২. Single Row Subquery (৪০ মিনিট)

**Single Row** মানে ভেতরের কোয়েরি **একটা রো, একটা মান** দেয়। তাই `=`, `<>`, `>`, `<`, `>=`, `<=` ব্যবহার করা যায়।

```sql
-- Ernst-এর পদের সবাই: ৫ জন (Ernst-সহ)
SELECT last_name, job_id
FROM   employees
WHERE  job_id = (SELECT job_id FROM employees WHERE last_name = 'Ernst');

-- কোম্পানির গড়ের চেয়ে বেশি বেতন: ৫১ জন
SELECT last_name, salary
FROM   employees
WHERE  salary > (SELECT AVG(salary) FROM employees);

-- সবচেয়ে কম বেতন: Olson
SELECT last_name, salary
FROM   employees
WHERE  salary = (SELECT MIN(salary) FROM employees);

-- ক্লাস ৩৮-এর সমস্যার সমাধান: King
SELECT last_name, salary
FROM   employees
WHERE  salary = (SELECT MAX(salary) FROM employees);
```

### অন্য টেবিল থেকে

JOIN ছাড়াই:

```sql
-- IT বিভাগের কর্মী: ৫ জন
SELECT last_name
FROM   employees
WHERE  department_id = (SELECT department_id
                        FROM   departments
                        WHERE  department_name = 'IT');
```

### একাধিক Subquery

```sql
-- Ernst-এর পদে, আর Ernst-এর চেয়ে বেশি বেতন: Hunold
SELECT last_name, job_id, salary
FROM   employees
WHERE  job_id = (SELECT job_id FROM employees WHERE last_name = 'Ernst')
AND    salary > (SELECT salary FROM employees WHERE last_name = 'Ernst');
```

### নেস্টেড: Subquery-র ভেতরে Subquery

```sql
-- দ্বিতীয় সর্বোচ্চ বেতন: 17000
SELECT MAX(salary) AS second_highest
FROM   employees
WHERE  salary < (SELECT MAX(salary) FROM employees);
```

ইন্টারভিউয়ের খুব সাধারণ প্রশ্ন।

### ERP-তে (`learn_freepdb1`)

```sql
-- গড় জরিমানা 33 টাকা। তার বেশি: ৩টা
SELECT issue_id, fine_amount
FROM   lib_fine
WHERE  fine_amount > (SELECT AVG(fine_amount) FROM lib_fine);

-- সবচেয়ে নতুন বই: Advanced SQL Queries
SELECT book_title, publish_year
FROM   lib_book
WHERE  publish_year = (SELECT MAX(publish_year) FROM lib_book);

-- ORD-501-এর স্টাইলের সব অর্ডার
SELECT order_no, order_qty
FROM   w5_order
WHERE  style_id = (SELECT style_id FROM w5_order WHERE order_no = 'ORD-501');
```

## ৩. WHERE ছাড়া অন্য জায়গায় (৪০ মিনিট)

### HAVING-এ

```sql
-- কোম্পানির গড়ের চেয়ে বেশি গড় বেতনের বিভাগ: ৮টা দল (৭টা বিভাগ আর NULL)
SELECT department_id, ROUND(AVG(salary), 2) AS avg_salary
FROM   employees
GROUP  BY department_id
HAVING AVG(salary) > (SELECT AVG(salary) FROM employees);
```

### SELECT-এ: Scalar Subquery

প্রতিটা রো-তে একটা মান:

```sql
SELECT last_name,
       salary,
       (SELECT ROUND(AVG(salary)) FROM employees) AS company_avg,
       salary - (SELECT ROUND(AVG(salary)) FROM employees) AS difference
FROM   employees;
```

### FROM-এ: Inline View

ভেতরের কোয়েরির ফলকে একটা অস্থায়ী টেবিল হিসেবে ব্যবহার। **Alias দাও।**

```sql
-- বিভাগভিত্তিক গড়, তার মধ্যে সর্বোচ্চ ৩টা
SELECT dept_id, avg_salary
FROM  (SELECT department_id AS dept_id,
              ROUND(AVG(salary), 2) AS avg_salary
       FROM   employees
       WHERE  department_id IS NOT NULL
       GROUP  BY department_id) dept_avg
WHERE  avg_salary > 10000
ORDER  BY avg_salary DESC;
```

ফল: ৯০ (১৯৩৩৩.৩৩), ১১০ (১০১৫৪)।

### JOIN-এর সাথে Inline View

**কাজ:** "প্রতিটা বিভাগের নাম, কর্মী সংখ্যা, মোট বেতন।" ক্লাস ৪৫-এর Fan-out এড়াতে আগে হিসাব, পরে JOIN:

```sql
SELECT d.department_name, s.headcount, s.total_salary
FROM   departments d
JOIN  (SELECT department_id, COUNT(*) AS headcount, SUM(salary) AS total_salary
       FROM   employees
       GROUP  BY department_id) s
       ON s.department_id = d.department_id
ORDER  BY s.total_salary DESC;
```

**গার্মেন্টসে:** অর্ডারের পরিমাণ এক হিসাবে, শিপমেন্টের পরিমাণ আরেক হিসাবে, তারপর জোড়া দিয়ে `order_qty - ship_qty` = বাকি। হোমওয়ার্কে করবে।

### INSERT আর UPDATE-এ

```sql
-- learn_freepdb1
-- Primark-এর সব স্টাইলের দাম, Primark-এর নাম দিয়ে
UPDATE w5_style
SET    fob_price = fob_price + 0.10
```

## ৪. ভুল ও ফাঁদ (২০ মিনিট)

### ফাঁদ ১: ORA-01427

ভেতর থেকে একাধিক রো এলে `=` চলে না।

```sql
SELECT last_name
FROM   employees
WHERE  salary = (SELECT salary FROM employees WHERE last_name = 'King');
```

```
ORA-01427: single-row subquery returns more than one row
```

দুইজন King। `IN` লাগবে (কাল), অথবা শর্ত আরো নির্দিষ্ট করো (`employee_id = 100`)।

**এই ভুল চালানোর সময় ধরা পড়ে, আর ডাটার উপর নির্ভর করে।** আজ এক King থাকলে চলবে, কাল আরেকজন যোগ হলে রিপোর্ট ভাঙবে। তাই নাম না দিয়ে **ID বা Unique কলাম** দিয়ে খোঁজো।

### ফাঁদ ২: ভেতর থেকে কিছুই না এলে

```sql
-- এরর নেই, কোনো রো-ও নেই
SELECT last_name
FROM   employees
WHERE  salary > (SELECT salary FROM employees WHERE last_name = 'NoSuchName');
```

Subquery-র ফল NULL ধরা হয়। `salary > NULL` সত্য হয় না।

### ফাঁদ ৩: কলাম বেশি

```sql
SELECT last_name
FROM   employees
WHERE  salary = (SELECT salary, last_name FROM employees WHERE employee_id = 100);
```

```
ORA-00913: too many values
```

### ফাঁদ ৪: GROUP BY-এর ফল

```sql
-- একাধিক রো: ORA-01427
SELECT last_name FROM employees
WHERE  salary = (SELECT MAX(salary) FROM employees GROUP BY department_id);
```

Aggregate থাকলেই একটা রো হবে না। `GROUP BY` থাকলে প্রতিটা দলের জন্য একটা রো।

### JOIN নাকি Subquery

| দরকার | ব্যবহার |
|---|---|
| অন্য টেবিলের কলাম **দেখাতে** | JOIN |
| শুধু **শর্তে** অন্য টেবিল | Subquery বা JOIN, যেটা পরিষ্কার |
| আগে হিসাব, তারপর তুলনা | Subquery |

## সারাংশ

- Subquery ব্র্যাকেটে, আগে ভেতরের কোয়েরি চলে
- Single Row: একটা মান, তাই `=`, `<`, `>` ইত্যাদি চলে
- একাধিক রো এলে `ORA-01427`, কিছু না এলে এরর ছাড়া খালি ফল
- Subquery `WHERE`, `HAVING`, `SELECT`, `FROM`, সব জায়গায় চলে
- Fan-out এড়াতে Inline View-তে আগে হিসাব, পরে JOIN

**পরের ক্লাস:** Multi Row Subquery: IN, ANY, ALL।
