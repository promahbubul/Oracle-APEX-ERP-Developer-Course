### ধাপ ১: View (৪৫ মিনিট)

ক্লাস ৫১-এ `lib_book_detail_v`, `lib_issue_detail_v`, `lib_fine_detail_v`, `lib_open_issue_v` বানিয়েছ কি না দেখো, না থাকলে আগে বানাও। তারপর:

4. `lib_available_copy_v`: শুধু `AVAILABLE` কপি, `WITH CHECK OPTION`। (১৩)

```sql
-- ১
CREATE OR REPLACE VIEW lib_copy_detail_v AS
SELECT c.copy_id, c.barcode, b.book_title, s.shelf_code, c.copy_status
FROM   lib_book_copy c
JOIN   lib_book b       ON c.book_id = b.book_id
LEFT   JOIN lib_shelf s ON c.shelf_id = s.shelf_id;

-- ২
CREATE OR REPLACE VIEW lib_book_author_v AS
SELECT b.book_id,
       b.book_title,
       LISTAGG(a.author_name, ', ') WITHIN GROUP (ORDER BY ba.author_order) AS authors
FROM   lib_book b
LEFT   JOIN lib_book_author ba ON ba.book_id = b.book_id
LEFT   JOIN lib_author a       ON ba.author_id = a.author_id
GROUP  BY b.book_id, b.book_title
WITH READ ONLY;

-- ৩
CREATE OR REPLACE VIEW lib_member_summary_v AS
SELECT m.member_id,
       m.member_name,
       t.type_name,
       (SELECT COUNT(*) FROM lib_book_issue i WHERE i.member_id = m.member_id) AS total_issues,
       (SELECT COUNT(*) FROM lib_book_issue i
        WHERE  i.member_id = m.member_id AND i.return_date IS NULL) AS open_issues,
       (SELECT NVL(SUM(f.fine_amount), 0)
        FROM   lib_book_issue i
        JOIN   lib_fine f ON f.issue_id = i.issue_id
        WHERE  i.member_id = m.member_id) AS total_fine
FROM   lib_member m
JOIN   lib_member_type t ON m.member_type_id = t.member_type_id
WITH READ ONLY;

-- ৪
CREATE OR REPLACE VIEW lib_available_copy_v AS
SELECT copy_id, book_id, shelf_id, barcode, copy_status
FROM   lib_book_copy
WHERE  copy_status = 'AVAILABLE'
WITH CHECK OPTION;

-- ৫: ORA-01402
UPDATE lib_available_copy_v SET copy_status = 'LOST' WHERE copy_id = 1;

-- ৬
SELECT member_name, open_issues FROM lib_member_summary_v WHERE open_issues > 0;

-- ৭
SELECT member_name, total_fine
FROM   lib_member_summary_v
ORDER  BY total_fine DESC, member_name
FETCH  FIRST 3 ROWS ONLY;
```

BUILD IMMEDIATE
REFRESH COMPLETE ON DEMAND
AS

FROM   lib_book_issue
GROUP  BY TO_CHAR(issue_date, 'YYYY-MM');

EXEC DBMS_MVIEW.REFRESH('LIB_MONTHLY_ISSUE_MV', 'C');

SELECT * FROM lib_monthly_issue_mv ORDER BY issue_month;

**১৮:** একটা সাধারণ B-Tree Index-এ যে রো-র মান NULL, সে রো থাকে না। তাই `IS NULL`-এ এই Index কাজে লাগে না। Function-based বা Composite Index দিয়ে সমাধান আছে, সপ্তাহ ৪০-এ দেখবে।
