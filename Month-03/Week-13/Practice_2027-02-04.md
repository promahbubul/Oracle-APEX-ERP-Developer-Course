## ৩. নিজের খাতা দেখা (২০ মিনিট)

<details>
<summary>অংশ ক-এর উত্তর (৯:৩০-এর পরে খুলবে)</summary>

1. `CREATE`, `ALTER`, `DROP` (`TRUNCATE`, `RENAME`, `COMMENT`-ও)
2. না, এটা DDL, নিজে থেকে `COMMIT` হয়
3. স্থায়ী হয়ে যায়, `CREATE TABLE` নিজে থেকে `COMMIT` করে
4. Transaction-এর ভেতরে চিহ্ন, সেখান পর্যন্ত আংশিক `ROLLBACK`
5. PK-তে NULL চলে না, UK-তে চলে। PK একটাই, UK অনেকগুলো
6. `NVL`: a NULL হলে b। `NVL2`: a NULL না হলে b, NULL হলে c
7. `COUNT(*)` সব রো গোনে, `COUNT(col)` NULL বাদ দিয়ে গোনে
8. `WHERE` দল করার আগে রো বাছে, `HAVING` দল করার পরে দল বাছে, Aggregate চলে
9. `FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → FETCH FIRST`
10. Inner শুধু মিল, Left বাম টেবিলের সব, অন্য পাশ NULL
11. `UNION` ডুপ্লিকেট বাদ, `UNION ALL` রাখে। স্টকে `UNION ALL`
12. কোনো রো আসে না, এররও আসে না
13. ভেতরের কোয়েরি অন্তত একটা রো দেয় কি না
14. `ROW_NUMBER`: ১, ২, ৩। `RANK`: ১, ১, ৩। `DENSE_RANK`: ১, ১, ২
15. View কোয়েরি জমা রাখে, ফল টাটকা। MV ফল জমা রাখে, Refresh পর্যন্ত পুরনো
16. `ROLLBACK`, `CACHE`, শুধু দেখা, এসবে নম্বর ফেরে না
17. Index আছে `name`-এর মানে। Function-based Index
18. `GROUP BY` রো কমায়, `PARTITION BY` কমায় না
19. Single Row Subquery থেকে একাধিক রো এলে
20. প্রথমটা Object Privilege-এ, ফেরত নিলে চেইন ধরে যায়। দ্বিতীয়টা System Privilege ও Role-এ, চেইন ভাঙে না

## ৪. ধাপ ২-এর হিসাব (১০ মিনিট)

**এই ধাপে যা পারা উচিত, টিক দাও:**

- [ ] Constraint সহ টেবিল বানাতে, `ALTER` দিয়ে বদলাতে পারি
- [ ] `INSERT`, `UPDATE`, `DELETE`, `MERGE` নিরাপদে চালাতে পারি
- [ ] `COMMIT`, `ROLLBACK`, `SAVEPOINT` বুঝি
- [ ] লেখা, সংখ্যা, তারিখ, Conversion ফাংশন ব্যবহার করতে পারি
- [ ] `GROUP BY`, `HAVING` দিয়ে সারাংশ রিপোর্ট বানাতে পারি
- [ ] ৪–৫টা টেবিল JOIN করতে পারি, Inner আর Left বেছে নিতে পারি
- [ ] Subquery, `EXISTS`, `NOT EXISTS` লিখতে পারি, `NOT IN`-এর ফাঁদ চিনি
- [ ] View, Sequence, Index বানাতে পারি
- [ ] `ROW_NUMBER`, `RANK`, `LAG`, Running Total লিখতে পারি
- [ ] `WITH`, `CONNECT BY`, `PIVOT` ব্যবহার করতে পারি
- [ ] Item Ledger আর স্টক ব্যালেন্সের কোয়েরি নিজে লিখতে পারি

**রোডম্যাপ:** [Roadmap.md](../../Roadmap.md)-এ ধাপ ২-এর শেষ করা জিনিসগুলোতে টিক দাও।

**সার্টিফিকেশন (ঐচ্ছিক):** রোডম্যাপে `1Z0-071` (Oracle Database SQL) আছে। এই ধাপের পরে প্রস্তুতি নেওয়া যায়। পরীক্ষাটা এখনো চালু আছে কি না, Oracle University-র সাইটে দেখে নিও।
