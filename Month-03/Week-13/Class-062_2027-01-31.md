# ক্লাস ৬২: Hierarchical Query: CONNECT BY, START WITH ও LEVEL

**তারিখ:** ৩১ জানুয়ারি ২০২৭, রবিবার
**সময়:** সন্ধ্যা ৭:০০ থেকে রাত ১০:০০
**সপ্তাহ:** ১৩ | **ধাপ:** ২ (Oracle SQL)

---

## আজকে কী শিখব

- গাছের মতো ডাটা (Hierarchy) কী
- `START WITH`, `CONNECT BY PRIOR`, `LEVEL`
- `SYS_CONNECT_BY_PATH`, `CONNECT_BY_ROOT`, `CONNECT_BY_ISLEAF`
- `ORDER SIBLINGS BY`, Loop আর `NOCYCLE`
- `LEVEL` দিয়ে সংখ্যা ও ক্যালেন্ডার বানানো

---

## ১. গাছের মতো ডাটা (১৫ মিনিট)

ক্লাস ৪৪-এ Self Join দিয়ে কর্মী → ম্যানেজার → তাঁর ম্যানেজার দেখেছিলে। কিন্তু **কত ধাপ তা না জানলে** কয়টা JOIN লিখবে?

ERP-তে এই আকারের ডাটা অনেক:

| ডাটা | গঠন |
|---|---|
| কর্মী | CEO → GM → Manager → Officer |
| মেনু | Inventory → Reports → Stock Report |
| আইটেম ক্যাটাগরি | Raw Material → Fabric → Knit |
| **BOM** | T-Shirt → Body Panel → Fabric, Thread |
| **Chart of Accounts** | Asset → Current Asset → Cash |

একটা টেবিল, যেখানে একটা কলাম নিজের টেবিলের অন্য রো-র দিকে যায়। ক্লাস ১৩-এর Self-Referencing।

## ২. CONNECT BY (৪৫ মিনিট)

```sql
SELECT LEVEL, কলাম
FROM   টেবিল
START  WITH শুরুর_শর্ত
CONNECT BY PRIOR উপরের_কলাম = নিচের_কলাম;
```

| অংশ | কাজ |
|---|---|
| `START WITH` | কোন রো থেকে শুরু (Root) |
| `CONNECT BY` | কীভাবে পরের রো খুঁজবে |
| `PRIOR` | "আগের রো-র" কলাম |
| `LEVEL` | কত নম্বর স্তরে, Root হলো ১ |

```sql
-- সব কর্মী, গাছের ক্রমে। ১০৭টা রো
SELECT LEVEL,
       employee_id,
       last_name,
       manager_id
FROM   employees
START  WITH manager_id IS NULL
CONNECT BY PRIOR employee_id = manager_id;
```

**কীভাবে পড়বে:** "আগের রো-র `employee_id`-ই এই রো-র `manager_id`।" অর্থাৎ **উপর থেকে নিচে।**

### সুন্দর করে দেখাও

```sql
START  WITH last_name = 'Kochhar'
CONNECT BY PRIOR employee_id = manager_id;
```

### উল্টো দিক: নিচ থেকে উপরে

`PRIOR` কোন পাশে, তাতেই দিক ঠিক হয়।

```sql
-- Lorentz → Hunold → De Haan → King: ৪ জন
SELECT LEVEL, last_name, manager_id
FROM   employees
START  WITH last_name = 'Lorentz'
CONNECT BY PRIOR manager_id = employee_id;
```

| লেখা | দিক | উদাহরণ |
|---|---|---|
| `PRIOR employee_id = manager_id` | উপর → নিচে | কার অধীনে কে কে |
| `PRIOR manager_id = employee_id` | নিচ → উপরে | আমার উপরে কে কে |

**এটাই সবচেয়ে ভুল হওয়ার জায়গা।** ফল উল্টো লাগলে `PRIOR`-এর পাশ দেখো।

## ৩. বিশেষ ফাংশন (৩৫ মিনিট)

### SYS_CONNECT_BY_PATH: পুরো পথ

```sql
SELECT cat_name,
       SYS_CONNECT_BY_PATH(cat_name, ' > ') AS cat_path
FROM   w13_item_cat
START  WITH parent_id IS NULL
CONNECT BY PRIOR cat_id = parent_id;
```

`Knit`-এর পাশে ` > Raw Material > Fabric > Knit`। মেনু আর ব্রেডক্রাম্ব বানাতে খুব কাজে লাগে।

### CONNECT_BY_ROOT: গাছের গোড়া

```sql
-- প্রতিটা ক্যাটাগরির শীর্ষ ক্যাটাগরি
SELECT cat_name,
       CONNECT_BY_ROOT cat_name AS root_cat
FROM   w13_item_cat
START  WITH parent_id IS NULL
CONNECT BY PRIOR cat_id = parent_id;
```

`T-Shirt`-এর `root_cat`: `Finished Goods`।

### CONNECT_BY_ISLEAF: পাতা কি না

যার নিচে আর কেউ নেই, তাকে বলে **Leaf** (পাতা)।

```sql
-- পাতা: Knit, Woven, Button, Zipper, T-Shirt
SELECT cat_name
FROM   w13_item_cat
WHERE  CONNECT_BY_ISLEAF = 1
START  WITH parent_id IS NULL
CONNECT BY PRIOR cat_id = parent_id;
```

বাস্তবে: "শুধু শেষ স্তরের ক্যাটাগরিতেই আইটেম যোগ করা যাবে"; Chart of Accounts-এ শুধু শেষ স্তরের Account-এ ভাউচার।

### ORDER SIBLINGS BY

সাধারণ `ORDER BY` গাছটাই নষ্ট করে দেয়। ভাইবোনদের ভেতরে সাজাতে:

```sql
SELECT LPAD(' ', (LEVEL - 1) * 3) || last_name AS org_chart
FROM   employees
START  WITH manager_id IS NULL
CONNECT BY PRIOR employee_id = manager_id
ORDER  SIBLINGS BY last_name;
```

গাছ ঠিক থাকে, প্রতিটা স্তরের ভেতরে নামের ক্রম।

### Loop: ORA-01436

ভুল ডাটায় A-র বস B, B-র বস A:

```sql
CREATE TABLE w13_loop (id NUMBER PRIMARY KEY, parent_id NUMBER);
INSERT INTO w13_loop VALUES (1, 2);
INSERT INTO w13_loop VALUES (2, 1);
COMMIT;

-- এরর ORA-01436: CONNECT BY loop in user data
SELECT id FROM w13_loop START WITH id = 1 CONNECT BY PRIOR id = parent_id;

-- NOCYCLE: এরর না দিয়ে থামে, আর কোথায় Loop তা দেখায়
SELECT id, CONNECT_BY_ISCYCLE AS is_cycle
FROM   w13_loop
START  WITH id = 1
CONNECT BY NOCYCLE PRIOR id = parent_id;

DROP TABLE w13_loop;
```

ইউজার যদি মেনু বা ক্যাটাগরির Parent ভুল করে দেয়, এই এরর আসে। APEX ফর্মে Validation দিয়ে আটকাতে হয়।

## ৪. ডাল কাটা নাকি পাতা কাটা (১৫ মিনিট)

```sql
-- WHERE: শুধু সেই রো বাদ। ১০৬ জন, De Haan-এর অধীনস্থরা থাকে
SELECT LEVEL, last_name
FROM   employees
WHERE  last_name <> 'De Haan'
START  WITH manager_id IS NULL
CONNECT BY PRIOR employee_id = manager_id;

-- CONNECT BY-তে শর্ত: পুরো ডাল বাদ। ১০১ জন, De Haan আর তাঁর ৫ জন
SELECT LEVEL, last_name
FROM   employees
START  WITH manager_id IS NULL
CONNECT BY PRIOR employee_id = manager_id
AND    last_name <> 'De Haan';
```

| শর্ত কোথায় | ফল |
|---|---|
| `WHERE` | শুধু ওই রো বাদ, নিচের রো থাকে |
| `CONNECT BY` | ওই রো আর তার নিচের সব বাদ |

## ৫. LEVEL দিয়ে সংখ্যা ও ক্যালেন্ডার (২০ মিনিট)

`CONNECT BY` Oracle-এর খুব পরিচিত একটা কৌশলের ভিত্তি: **রো বানানো।**

```sql
-- ১ থেকে ৫
SELECT LEVEL AS n FROM dual CONNECT BY LEVEL <= 5;
```

ক্লাস ৫৫-এ `w11_big`-এ ২ লাখ রো এভাবেই বানিয়েছিলে।

### ক্যালেন্ডার

```sql
-- জানুয়ারি ২০২৭: ৩১টা রো
SELECT DATE '2027-01-01' + LEVEL - 1 AS cal_date
FROM   dual
CONNECT BY LEVEL <= 31;

-- যেকোনো মাস
SELECT TRUNC(SYSDATE, 'MM') + LEVEL - 1 AS cal_date
FROM   dual
CONNECT BY LEVEL <= EXTRACT(DAY FROM LAST_DAY(SYSDATE));
```

### ফাঁকা দিন খোঁজা

ERP-র খুব কাজের রিপোর্ট: **"কোন দিন প্রোডাকশন এন্ট্রি দেওয়া হয়নি?"**

```sql
-- লাইন ১, ১–৭ জানুয়ারি। ফাঁকা: ১, ২, ৭ জানুয়ারি
WITH cal AS (
    SELECT DATE '2027-01-01' + LEVEL - 1 AS cal_date
    FROM   dual
    CONNECT BY LEVEL <= 7
)
SELECT c.cal_date
FROM   cal c
LEFT   JOIN w12_line_output o ON o.entry_date = c.cal_date AND o.line_id = 1
WHERE  o.entry_date IS NULL
ORDER  BY c.cal_date;
```

### কর্মদিবস গোনা

ক্লাস ৩৪-এর হোমওয়ার্কে বলেছিলাম পরে পারবে: এই মাসে শুক্রবার ছাড়া কয়দিন?

```sql
-- জানুয়ারি ২০২৭: ৩১ দিন, ৫টা শুক্রবার (১, ৮, ১৫, ২২, ২৯), ২৬ কর্মদিবস
SELECT COUNT(*) AS working_days
FROM  (SELECT DATE '2027-01-01' + LEVEL - 1 AS cal_date
       FROM   dual
       CONNECT BY LEVEL <= 31)
WHERE  TO_CHAR(cal_date, 'DY', 'NLS_DATE_LANGUAGE=ENGLISH') <> 'FRI';
```

বেতন শীটের হিসাবে এটা সরাসরি লাগে।

## সারাংশ

- Hierarchy: নিজের টেবিলের দিকে FK। কর্মী, মেনু, ক্যাটাগরি, BOM, Accounts
- `START WITH`: শুরু। `CONNECT BY PRIOR`: পথ। `LEVEL`: স্তর
- `PRIOR`-এর পাশ দিক ঠিক করে: উপর → নিচে, নাকি নিচ → উপরে
- `SYS_CONNECT_BY_PATH`, `CONNECT_BY_ROOT`, `CONNECT_BY_ISLEAF`
- সাজাতে `ORDER SIBLINGS BY`, Loop-এ `NOCYCLE`
- `CONNECT BY LEVEL <= n`: রো বানানো, ক্যালেন্ডার, ফাঁকা দিন

**পরের ক্লাস:** PIVOT, UNPIVOT।
