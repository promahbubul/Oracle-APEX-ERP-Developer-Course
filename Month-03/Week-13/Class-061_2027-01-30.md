## ১. কেন লাগে (২০ মিনিট)

ক্লাস ৩৯-এ `CASE`টা দুইবার লিখতে হয়েছিল। ক্লাস ৫৮-এ Inline View-এর ভেতরে Inline View ছিল। কোড ভেতর থেকে বাইরে পড়তে হয়, যা কঠিন।

**WITH Clause** (অন্য নাম **CTE: Common Table Expression**, **Subquery Factoring**) কোয়েরির শুরুতেই Subquery-কে একটা নাম দেয়, আর উপর থেকে নিচে পড়া যায়।

```sql
-- Inline View: ভেতর থেকে বাইরে পড়তে হয়
SELECT d.department_name, s.avg_salary
FROM   departments d
JOIN  (SELECT department_id, AVG(salary) AS avg_salary
       FROM   employees
       GROUP  BY department_id) s
       ON s.department_id = d.department_id;

-- WITH: উপর থেকে নিচে
WITH dept_stat AS (
    SELECT department_id, AVG(salary) AS avg_salary
    FROM   employees
    GROUP  BY department_id
)
SELECT d.department_name, s.avg_salary
FROM   departments d
JOIN   dept_stat s ON s.department_id = d.department_id;
```

ফল একই। দ্বিতীয়টা ধাপে ধাপে পড়া যায়।

| | Inline View | `WITH` | View (ক্লাস ৫১) |
|---|---|---|---|
| কোথায় থাকে | কোয়েরির ভেতরে | কোয়েরির শুরুতে | ডাটাবেসে |
| কতদিন | এই কোয়েরি | এই কোয়েরি | স্থায়ী |
| একাধিকবার ব্যবহার | কপি করতে হয় | **নাম দিয়ে** | নাম দিয়ে |
| পড়া | ভেতর থেকে | উপর থেকে | উপর থেকে |

## ২. কয়েকটা CTE (৩৫ মিনিট)

```sql
WITH নাম১ AS (
    SELECT ...
),
নাম২ AS (
    SELECT ... FROM নাম১        -- আগেরটা ব্যবহার করা যায়
)
SELECT ... FROM নাম২;
```

**নিয়ম:**
- প্রথমে `WITH`, দ্বিতীয় থেকে শুধু নাম আর কমা
- শেষ CTE-র পরে কমা না
- পরেরটা আগেরটাকে ব্যবহার করতে পারে, উল্টোটা না
- শেষে একটা মূল `SELECT` লাগবেই

### ধাপে ধাপে রিপোর্ট

**কাজ:** "কোম্পানির গড়ের চেয়ে বেশি গড় বেতনের বিভাগ, নামসহ।"

```sql
-- ৭টা বিভাগ
WITH dept_stat AS (
    SELECT department_id,
           COUNT(*) AS headcount,
           ROUND(AVG(salary), 2) AS avg_salary
    FROM   employees
    GROUP  BY department_id
),
company AS (
    SELECT ROUND(AVG(salary), 2) AS company_avg FROM employees
)
SELECT d.department_name, s.headcount, s.avg_salary, c.company_avg
FROM   dept_stat s
JOIN   departments d ON s.department_id = d.department_id
CROSS  JOIN company c
WHERE  s.avg_salary > c.company_avg
ORDER  BY s.avg_salary DESC;
```

ফল: Executive, Accounting, Public Relations, Marketing, Sales, Finance, Human Resources।

### একই CTE দুইবার

```sql
-- যে বিভাগের গড় সবচেয়ে বেশি: Executive 19333.33
WITH dept_stat AS (
    SELECT department_id, ROUND(AVG(salary), 2) AS avg_salary
    FROM   employees
    WHERE  department_id IS NOT NULL
    GROUP  BY department_id
)
SELECT d.department_name, s.avg_salary
FROM   dept_stat s
JOIN   departments d ON s.department_id = d.department_id
WHERE  s.avg_salary = (SELECT MAX(avg_salary) FROM dept_stat);
```

Inline View-তে একই Subquery দুইবার লিখতে হতো।

### ক্লাস ৩৯-এর সমস্যার সমাধান

```sql
WITH staff AS (
    SELECT CASE WHEN salary < 5000  THEN '1. Low'
                WHEN salary < 10000 THEN '2. Medium'
                ELSE '3. High'
           END AS salary_band
    FROM   employees
)
SELECT salary_band, COUNT(*) AS headcount
FROM   staff
GROUP  BY salary_band
ORDER  BY salary_band;
```

`CASE`টা একবারই লিখতে হলো।

## ৩. ERP রিপোর্টে (৩৫ মিনিট)

### Item Balance: আগের কোয়েরি, পরিষ্কার করে

```sql
WITH ledger AS (
    SELECT item_id, qty AS in_qty, 0 AS out_qty FROM goods_receive
    UNION ALL
    SELECT item_id, 0, qty FROM goods_issue
),
item_total AS (
    SELECT item_id,
           SUM(in_qty)  AS total_in,
           SUM(out_qty) AS total_out
    FROM   ledger
    GROUP  BY item_id
)
SELECT i.item_name,
       NVL(t.total_in, 0)  AS total_in,
       NVL(t.total_out, 0) AS total_out,
       NVL(t.total_in, 0) - NVL(t.total_out, 0) AS balance_qty
FROM   item i
LEFT   JOIN item_total t ON t.item_id = i.item_id
ORDER  BY i.item_name;
```

৮টা আইটেম। প্রতিটা ধাপের নাম বলে দিচ্ছে সে কী করে।

### Fan-out এড়ানো

ক্লাস ৪৫-এর ফাঁদ: Buyer-এর স্টাইল সংখ্যা আর অর্ডার পরিমাণ একসাথে। আলাদা হিসাব, তারপর জোড়া।

## ৪. Recursive WITH (২৫ মিনিট)

CTE নিজেকে ডাকতে পারে। **কলামের নাম লেখা বাধ্যতামূলক।**

```sql
-- ১ থেকে ৫
WITH nums (n) AS (
    SELECT 1 FROM dual              -- শুরু
    UNION ALL
    SELECT n + 1 FROM nums          -- নিজেকে ডাকা
    WHERE  n < 5                    -- কোথায় থামবে
)
SELECT n FROM nums;
```

```
ধাপ ১: 1
ধাপ ২: 1 + 1 = 2
ধাপ ৩: 2 + 1 = 3
ধাপ ৪: 3 + 1 = 4
ধাপ ৫: 4 + 1 = 5
ধাপ ৬: n < 5 মিথ্যা, থামল
```

কলামের নাম না দিলে `ORA-32039`। থামার শর্ত ভুলে গেলে `ORA-32044` (অসীম লুপ)।

### কাজে লাগে: জানুয়ারির সব তারিখ

```sql
-- ৩১টা রো
WITH days (d) AS (
    SELECT DATE '2027-01-01' FROM dual
    UNION ALL
    SELECT d + 1 FROM days WHERE d < DATE '2027-01-31'
)
SELECT d FROM days;
```

### গাছের মতো ডাটা

```sql
-- De Haan আর তাঁর অধীনস্থ: ৬ জন
WITH emp_tree (employee_id, last_name, manager_id, lvl) AS (
    SELECT employee_id, last_name, manager_id, 1
    FROM   employees
    WHERE  last_name = 'De Haan'
    UNION ALL
    SELECT e.employee_id, e.last_name, e.manager_id, t.lvl + 1
    FROM   employees e
    JOIN   emp_tree t ON e.manager_id = t.employee_id
)
SELECT last_name, lvl FROM emp_tree;
```

Oracle-এ এই কাজের নিজস্ব সহজ উপায় আছে: `CONNECT BY`। কালকের ক্লাসে। Recursive `WITH` ANSI SQL, অন্য ডাটাবেসেও চলে।

## ৫. হাতে-কলমে প্র্যাকটিস (৬৫ মিনিট)

```sql
-- লাইন ১: ৬ জানু (1200); লাইন ২: ৫ জানু (1300)
WITH ranked AS (
    SELECT line_id, entry_date, produced_qty,
           RANK() OVER (PARTITION BY line_id ORDER BY produced_qty DESC) AS rk
    FROM   w12_line_output
)
SELECT line_id, entry_date, produced_qty FROM ranked WHERE rk = 1;
```

## সারাংশ

- `WITH`: Subquery-কে নাম দেওয়া, উপর থেকে নিচে পড়া
- `WITH a AS (...), b AS (...) SELECT ...`
- জটিল রিপোর্ট ধাপে ভাগ করো: আগে হিসাব, তারপর জোড়া
- Fan-out এড়াতে আলাদা CTE-তে আলাদা হিসাব
- Recursive: কলামের নাম, শুরু, `UNION ALL`, থামার শর্ত

**পরের ক্লাস:** Hierarchical Query: CONNECT BY, START WITH, LEVEL।
