## ১. কেন লাগে (২০ মিনিট)

ডাটাবেসে ডাটা রাখা হয় এভাবে (ক্লাস ১৭, 1NF):

| COLOR_NAME | SIZE_CODE | ORDER_QTY |
|---|---|---|
| Black | S | 500 |
| Black | M | 800 |
| White | S | 300 |

Merchandiser দেখতে চান এভাবে:

| COLOR_NAME | S | M |
|---|---|---|
| Black | 500 | 800 |
| White | 300 | |

**ডাটা রাখা আর দেখানো দুইটা আলাদা ব্যাপার।** `PIVOT` রো-র মানকে কলাম বানায়।

ক্লাস ৩৯-এ এই কাজ `SUM(CASE ...)` দিয়ে করেছিলে:

```sql
SELECT color_name,
       SUM(CASE WHEN size_code = 'S' THEN order_qty END) AS s_qty,
       SUM(CASE WHEN size_code = 'M' THEN order_qty END) AS m_qty
FROM   order_size_qty
GROUP  BY color_name;
```

`PIVOT` একই কাজ ছোট করে।

## ২. PIVOT (৫০ মিনিট)

```sql
SELECT *
FROM  (যে কলামগুলো লাগবে)
PIVOT (
    Aggregate(মানের কলাম)
    FOR কলাম_হবে_যেটা IN ('মান১' AS নাম১, 'মান২' AS নাম২)
);
```

```sql
-- learn_freepdb1, ক্লাস ১১-এর order_size_qty
SELECT *
FROM  (SELECT color_name, size_code, order_qty FROM order_size_qty)
PIVOT (
    SUM(order_qty)
    FOR size_code IN ('S' AS s_qty, 'M' AS m_qty, 'L' AS l_qty, 'XL' AS xl_qty)
);
```

| COLOR_NAME | S_QTY | M_QTY | L_QTY | XL_QTY |
|---|---|---|---|---|
| Black | 500 | 800 | | |
| White | 300 | | | |

তিন ধরনের কলাম:

| কলাম | ভূমিকা | উদাহরণ |
|---|---|---|
| `FOR`-এর কলাম | মানগুলো কলাম হয় | `size_code` |
| Aggregate-এর কলাম | ঘরের মান | `order_qty` |
| **বাকি সব** | রো-র দল হয় | `color_name` |

### নতুন উদাহরণ: Buyer × মাস

```sql
SET DEFINE OFF

SELECT *
FROM  (SELECT buyer_name, ship_month, ship_qty FROM w12_buyer_ship)
PIVOT (
    SUM(ship_qty)
    FOR ship_month IN (DATE '2026-01-01' AS jan,
                       DATE '2026-02-01' AS feb,
                       DATE '2026-03-01' AS mar)
)
ORDER  BY buyer_name;
```

| BUYER_NAME | JAN | FEB | MAR |
|---|---|---|---|
| H&M | 5000 | 6000 | 4000 |
| Primark | 4000 | 5000 | 3000 |
| Zara | 3000 | 2000 | 7000 |

### মোট যোগ করা, NULL সরানো

`PIVOT`-এর ফলের উপর সাধারণ `SELECT`।

```sql
SELECT color_name,
       NVL(s_qty, 0) AS s_qty,
       NVL(m_qty, 0) AS m_qty,
       NVL(l_qty, 0) AS l_qty,
       NVL(s_qty, 0) + NVL(m_qty, 0) + NVL(l_qty, 0) AS total_qty
FROM  (SELECT color_name, size_code, order_qty FROM order_size_qty)
PIVOT (SUM(order_qty) FOR size_code IN ('S' AS s_qty, 'M' AS m_qty, 'L' AS l_qty));
```

Black ১৩০০, White ৩০০।

### COUNT দিয়ে

```sql
-- কপির অবস্থা এক লাইনে: AVAILABLE 14, ISSUED 6, DAMAGED 1, LOST 1
SELECT *
FROM  (SELECT copy_status FROM lib_book_copy)
PIVOT (COUNT(*) FOR copy_status IN ('AVAILABLE' AS available,
                                    'ISSUED'    AS issued,
                                    'DAMAGED'   AS damaged,
                                    'LOST'      AS lost));

-- জরিমানা: Y 100, N 65
SELECT *
FROM  (SELECT is_paid, fine_amount FROM lib_fine)
PIVOT (SUM(fine_amount) FOR is_paid IN ('Y' AS paid, 'N' AS due));
```

ড্যাশবোর্ডের KPI কার্ডে এই এক লাইনের ফলই লাগে। `COUNT(*)` থেকে না মিললে `0` আসে, `SUM` থেকে NULL।

### HR-এ (`hr_freepdb1`)

```sql
-- বিভাগ ৫০: ST_MAN 5, ST_CLERK 20, SH_CLERK 20
SELECT *
FROM  (SELECT department_id, job_id FROM employees WHERE department_id = 50)
PIVOT (COUNT(*) FOR job_id IN ('ST_MAN' AS st_man, 'ST_CLERK' AS st_clerk, 'SH_CLERK' AS sh_clerk));
```

### একাধিক Aggregate

```sql
SELECT *
FROM  (SELECT department_id, job_id, salary FROM employees WHERE department_id = 50)
PIVOT (
    COUNT(*)    AS cnt,
    SUM(salary) AS total
    FOR job_id IN ('ST_MAN' AS st_man, 'ST_CLERK' AS st_clerk)
);
```

কলাম হয়: `ST_MAN_CNT`, `ST_MAN_TOTAL`, `ST_CLERK_CNT`, `ST_CLERK_TOTAL`।

### PIVOT নাকি SUM(CASE)

| | `PIVOT` | `SUM(CASE)` |
|---|---|---|
| লেখা | ছোট | লম্বা |
| পুরনো ভার্সন (10g) | চলে না | চলে |
| এক কলামে নিজের মতো শর্ত | না | হ্যাঁ, যেকোনো শর্ত |
| ফাঁদ | নিচে দেখো | কম |

## ৩. ফাঁদ (২০ মিনিট)

### ফাঁদ ১: পুরো টেবিল দিলে

```sql
-- ১০৭টা রো! দল বাঁধে সব বাকি কলাম দিয়ে
SELECT *
FROM   employees
PIVOT (COUNT(employee_id) FOR job_id IN ('IT_PROG' AS it_prog));
```

**যা `FOR` বা Aggregate-এ নেই, সব কলাম দলের অংশ হয়।** `last_name`, `email` সবই। তাই প্রায় প্রতিটা রো আলাদা দল। **সবসময় Inline View-তে শুধু দরকারি কলাম নাও।**

### ফাঁদ ২: IN-এর মান নির্দিষ্ট

`IN`-এর তালিকায় Subquery চলে না:

```sql
SELECT *
FROM  (SELECT color_name, size_code, order_qty FROM order_size_qty)
PIVOT (SUM(order_qty) FOR size_code IN (SELECT size_code FROM w9_size));
```

```
ORA-56901: non-constant expression is not allowed for pivot|unpivot values
```

নতুন সাইজ (`XXL`) এলে কোড বদলাতে হয়। ডাইনামিক কলামের জন্য Dynamic SQL (সপ্তাহ ২২), আর APEX-এ Interactive Report-এর নিজস্ব Pivot আছে।

### ফাঁদ ৩: Aggregate বাধ্যতামূলক

```sql
SELECT *
FROM  (SELECT color_name, size_code, order_qty FROM order_size_qty)
PIVOT (order_qty FOR size_code IN ('S' AS s_qty));
```

```
ORA-56902: expect aggregate function inside pivot operation
```

### ফাঁদ ৪: তালিকার বাইরের মান

`IN`-এ `XL` না লিখলে `XL`-এর ডাটা চুপচাপ হারায়। মোট মিলিয়ে দেখো।

## ৪. UNPIVOT (৩০ মিনিট)

উল্টো কাজ: কলাম থেকে রো। **Excel থেকে আসা ডাটা ডাটাবেসে ঢোকানোর আগে এটাই লাগে।**

```sql
-- Buyer যে Excel পাঠিয়েছে: সাইজগুলো কলামে
CREATE TABLE w13_size_sheet (
    color_name  VARCHAR2(30),
    s_qty       NUMBER(8),
    m_qty       NUMBER(8),
    l_qty       NUMBER(8)
);

INSERT INTO w13_size_sheet VALUES ('Black', 500, 800, 300);
INSERT INTO w13_size_sheet VALUES ('White', 200, 400, 100);
INSERT INTO w13_size_sheet VALUES ('Navy', 150, NULL, 50);
COMMIT;

SELECT color_name, size_code, order_qty
FROM   w13_size_sheet
UNPIVOT (
    order_qty FOR size_code IN (s_qty AS 'S', m_qty AS 'M', l_qty AS 'L')
)
ORDER  BY color_name, size_code;
```

| COLOR_NAME | SIZE_CODE | ORDER_QTY |
|---|---|---|
| Black | L | 300 |
| Black | M | 800 |
| Black | S | 500 |
| Navy | L | 50 |
| Navy | S | 150 |
| White | L | 100 |
| White | M | 400 |
| White | S | 200 |

৮টা রো। Navy-র `M` NULL, তাই বাদ।

### NULL রাখতে

```sql
SELECT color_name, size_code, order_qty
FROM   w13_size_sheet
UNPIVOT INCLUDE NULLS (
    order_qty FOR size_code IN (s_qty AS 'S', m_qty AS 'M', l_qty AS 'L')
);
```

এবার ৯টা রো।

### সরাসরি টেবিলে ঢোকানো

```sql
CREATE TABLE w13_order_break (
    order_no    VARCHAR2(20),
    color_name  VARCHAR2(30),
    size_code   VARCHAR2(10),
    order_qty   NUMBER(10),
    CONSTRAINT w13_order_break_pk PRIMARY KEY (order_no, color_name, size_code)
);

INSERT INTO w13_order_break (order_no, color_name, size_code, order_qty)
SELECT 'ORD-777', color_name, size_code, order_qty
FROM   w13_size_sheet
UNPIVOT (order_qty FOR size_code IN (s_qty AS 'S', m_qty AS 'M', l_qty AS 'L'));
COMMIT;

SELECT COUNT(*), SUM(order_qty) FROM w13_order_break;      -- 8, 2500
```

Excel-এর মোট আর টেবিলের মোট মিলিয়ে দেখো: ৫০০ + ৮০০ + ৩০০ + ২০০ + ৪০০ + ১০০ + ১৫০ + ৫০ = ২৫০০।

### আবার PIVOT করে মেলানো

```sql
SELECT *
FROM  (SELECT color_name, size_code, order_qty FROM w13_order_break)
PIVOT (SUM(order_qty) FOR size_code IN ('S' AS s_qty, 'M' AS m_qty, 'L' AS l_qty));
```

শুরুর Excel ফিরে এলো। **Excel → UNPIVOT → টেবিল → PIVOT → রিপোর্ট:** গার্মেন্টস ERP-র Color-Size-এর পুরো পথ।

## ৬. হোমওয়ার্ক

1. কাল `MERGE`। ক্লাস ২৪-এর `INSERT` আর `UPDATE` একবার দেখে আসো।
2. `SUM(CASE)` আর `PIVOT` দিয়ে একই রিপোর্ট লেখো, ফল মিলাও।
3. একটা Excel শীটের মতো টেবিল বানাও (Buyer, Jan, Feb, Mar), `UNPIVOT` করে রো-তে আনো, মোট মিলাও।

- `PIVOT`: রো → কলাম। `FOR`-এর কলাম কলাম হয়, Aggregate ঘর ভরে, বাকিগুলো দল
- সবসময় Inline View-তে শুধু দরকারি কলাম
- `IN`-এর মান নির্দিষ্ট, ডাইনামিক না
- `UNPIVOT`: কলাম → রো, NULL বাদ
- Excel → `UNPIVOT` → টেবিল → `PIVOT` → রিপোর্ট

**পরের ক্লাস:** MERGE Statement।
