# ক্লাস ৬৪: MERGE Statement

**তারিখ:** ২ ফেব্রুয়ারি ২০২৭, মঙ্গলবার
**সময়:** সন্ধ্যা ৭:০০ থেকে রাত ১০:০০
**সপ্তাহ:** ১৩ | **ধাপ:** ২ (Oracle SQL)

---

## আজকে কী শিখব

- `MERGE` কী, কেন লাগে
- `WHEN MATCHED`, `WHEN NOT MATCHED`
- শর্ত দিয়ে আপডেট, `DELETE`
- `dual` দিয়ে একটা রো-র Upsert
- `ORA-30926`, `ORA-38104`

---

## ১. কেন লাগে (২০ মিনিট)

সাপ্লায়ার প্রতি মাসে দামের Excel পাঠায়। আগের আইটেমের দাম **বদলাতে** হবে, নতুন আইটেম **ঢোকাতে** হবে।

**এখন পর্যন্ত যা পারো:**

```sql
-- ১. যেগুলো আছে, আপডেট
UPDATE ... WHERE EXISTS (...);

-- ২. যেগুলো নেই, ইনসার্ট
INSERT ... WHERE NOT EXISTS (...);
```

দুই কমান্ড, দুইবার পড়া, ডাটা বদলে গেলে মাঝখানে গোলমাল। **MERGE** এক কমান্ডে দুইটা করে। একে বলে **Upsert** (Update + Insert)।

### ERP-তে কোথায়

| কাজ | উৎস | গন্তব্য |
|---|---|---|
| Excel থেকে আইটেম লোড | Stage টেবিল | Item Master |
| সাপ্লায়ারের নতুন দামের তালিকা | Stage টেবিল | Price List |
| মাসিক স্টক হিসাব | Ledger-এর `SUM` | Stock Summary |
| অন্য সিস্টেম থেকে ডাটা | API, DB Link | নিজের টেবিল |

**Stage টেবিল:** ইমপোর্টের জন্য অস্থায়ী টেবিল। আগে এখানে ঢোকাও, যাচাই করো, তারপর মূল টেবিলে `MERGE`।

## ২. MERGE (৪০ মিনিট)

```sql
MERGE INTO গন্তব্য t
USING উৎস s
ON (t.id = s.id)
WHEN MATCHED THEN
    UPDATE SET t.col = s.col
WHEN NOT MATCHED THEN
    INSERT (id, col) VALUES (s.id, s.col);
```

| অংশ | কাজ |
|---|---|
| `INTO` | যে টেবিল বদলাবে |
| `USING` | যেখান থেকে ডাটা: টেবিল, View, Subquery |
| `ON` | মেলানোর শর্ত, **ব্র্যাকেট লাগে** |
| `WHEN MATCHED` | মিললে: `UPDATE` |
| `WHEN NOT MATCHED` | না মিললে: `INSERT` |

### আজকের টেবিল

```sql
CREATE TABLE w13_item_master (
    item_id     NUMBER(5) CONSTRAINT w13_item_master_pk PRIMARY KEY,
    item_name   VARCHAR2(50) NOT NULL,
    unit_price  NUMBER(8,2) NOT NULL
);

INSERT INTO w13_item_master VALUES (1, 'Button 18L', 0.02);
INSERT INTO w13_item_master VALUES (2, 'Zipper 7 inch', 0.15);
INSERT INTO w13_item_master VALUES (3, 'Main Label', 0.05);

CREATE TABLE w13_item_stage (
    item_id     NUMBER(5),
    item_name   VARCHAR2(50),
    unit_price  NUMBER(8,2)
);

INSERT INTO w13_item_stage VALUES (2, 'Zipper 7 inch', 0.18);   -- দাম বদলেছে
INSERT INTO w13_item_stage VALUES (3, 'Main Label', 0.05);      -- একই
INSERT INTO w13_item_stage VALUES (4, 'Hang Tag', 0.03);        -- নতুন
INSERT INTO w13_item_stage VALUES (5, 'Poly Bag', 0.04);        -- নতুন
COMMIT;
```

### চালাও

```sql
MERGE INTO w13_item_master t
USING w13_item_stage s
ON (t.item_id = s.item_id)
WHEN MATCHED THEN
    UPDATE SET t.item_name  = s.item_name,
               t.unit_price = s.unit_price
WHEN NOT MATCHED THEN
    INSERT (item_id, item_name, unit_price)
    VALUES (s.item_id, s.item_name, s.unit_price);

SELECT * FROM w13_item_master ORDER BY item_id;
```

বার্তা: `4 rows merged.` (২টা আপডেট + ২টা ইনসার্ট)

| ITEM_ID | ITEM_NAME | UNIT_PRICE |
|---|---|---|
| 1 | Button 18L | 0.02 |
| 2 | Zipper 7 inch | 0.18 |
| 3 | Main Label | 0.05 |
| 4 | Hang Tag | 0.03 |
| 5 | Poly Bag | 0.04 |

`item_id = 1`-এ হাত পড়েনি, কারণ উৎসে নেই।

```sql
ROLLBACK;       -- পরের অংশের জন্য আগের অবস্থায়
```

`MERGE` DML, তাই `COMMIT` লাগে, আর `ROLLBACK` চলে।

### একটা অংশ বাদ

```sql
-- শুধু নতুনগুলো ঢোকাও: 2 rows merged
MERGE INTO w13_item_master t
USING w13_item_stage s
ON (t.item_id = s.item_id)
WHEN NOT MATCHED THEN
    INSERT (item_id, item_name, unit_price)
    VALUES (s.item_id, s.item_name, s.unit_price);

ROLLBACK;
```

## ৩. শর্ত, DELETE, dual (৩০ মিনিট)

### WHERE: শুধু বদলেছে এমন

উপরের `MERGE`-এ `item_id = 3` একই মানে আবার আপডেট হয়েছে। অপ্রয়োজনীয় লেখা, আর Audit Trigger থাকলে ভুয়া লগ।

```sql
-- 3 rows merged: ১টা আপডেট + ২টা ইনসার্ট
MERGE INTO w13_item_master t
USING w13_item_stage s
ON (t.item_id = s.item_id)
WHEN MATCHED THEN
    UPDATE SET t.unit_price = s.unit_price
    WHERE  t.unit_price <> s.unit_price
WHEN NOT MATCHED THEN
    INSERT (item_id, item_name, unit_price)
    VALUES (s.item_id, s.item_name, s.unit_price)
    WHERE  s.unit_price > 0;

SELECT * FROM w13_item_master ORDER BY item_id;

ROLLBACK;
```

### DELETE

`WHEN MATCHED`-এর ভেতরে `DELETE`। **আগে আপডেট হয়, তারপর নতুন মানে শর্ত দেখে।**

```sql
-- দাম ০ পাঠালে আইটেম মুছে দাও
UPDATE w13_item_stage SET unit_price = 0 WHERE item_id = 3;

MERGE INTO w13_item_master t
USING w13_item_stage s
ON (t.item_id = s.item_id)
WHEN MATCHED THEN
    UPDATE SET t.unit_price = s.unit_price
    DELETE WHERE t.unit_price = 0
WHEN NOT MATCHED THEN
    INSERT (item_id, item_name, unit_price)
    VALUES (s.item_id, s.item_name, s.unit_price);

-- item_id 3 নেই
SELECT * FROM w13_item_master ORDER BY item_id;

ROLLBACK;
```

ERP-তে সাধারণত মোছা না, `is_active = 'N'` (ক্লাস ২০)। `DELETE` জেনে রাখো।

### dual: এক রো-র Upsert

ফর্ম থেকে একটা আইটেম এলো: থাকলে বদলাও, না থাকলে ঢোকাও।

```sql
MERGE INTO w13_item_master t
USING (SELECT 6 AS item_id, 'Elastic' AS item_name, 0.10 AS unit_price FROM dual) s
ON (t.item_id = s.item_id)
WHEN MATCHED THEN
    UPDATE SET t.unit_price = s.unit_price
WHEN NOT MATCHED THEN
    INSERT (item_id, item_name, unit_price)
    VALUES (s.item_id, s.item_name, s.unit_price);

ROLLBACK;
```

APEX Process-এ এই ছাঁচ প্রায়ই পাবে।

### উৎসে হিসাব: স্টক সামারি

```sql
CREATE TABLE w13_stock_summary (
    item_id      NUMBER(10) CONSTRAINT w13_stock_summary_pk PRIMARY KEY,
    balance_qty  NUMBER(14,3) NOT NULL
);

-- ৬টা আইটেম (লেনদেন আছে এমন)
MERGE INTO w13_stock_summary t
USING (SELECT item_id, SUM(in_qty) - SUM(out_qty) AS balance_qty
       FROM  (SELECT item_id, qty AS in_qty, 0 AS out_qty FROM goods_receive
              UNION ALL
              SELECT item_id, 0, qty FROM goods_issue) x
       GROUP  BY item_id) s
ON (t.item_id = s.item_id)
WHEN MATCHED THEN
    UPDATE SET t.balance_qty = s.balance_qty
WHEN NOT MATCHED THEN
    INSERT (item_id, balance_qty) VALUES (s.item_id, s.balance_qty);
COMMIT;

SELECT * FROM w13_stock_summary ORDER BY item_id;
```

বারবার চালালেও ফল একই থাকে। এটা রাতের Job-এ ঠিক এভাবে চলে (সপ্তাহ ২২)।

## ৪. ফাঁদ (২০ মিনিট)

### ফাঁদ ১: ORA-30926 উৎসে একই ID দুইবার

```sql
INSERT INTO w13_item_stage VALUES (2, 'Zipper 7 inch', 0.20);  -- আবার item 2

MERGE INTO w13_item_master t
USING w13_item_stage s
ON (t.item_id = s.item_id)
WHEN MATCHED THEN
    UPDATE SET t.unit_price = s.unit_price;
```

```
ORA-30926: unable to get a stable set of rows in the source tables
```

একটা রো-কে দুইটা মানে বদলাবে কীভাবে? **`MERGE`-এর আগে উৎসে ডুপ্লিকেট দেখো** (ক্লাস ৪০, ৫৭):

```sql
SELECT item_id, COUNT(*) FROM w13_item_stage GROUP BY item_id HAVING COUNT(*) > 1;

ROLLBACK;
```

### ফাঁদ ২: ORA-38104 ON-এর কলাম আপডেট

```sql
MERGE INTO w13_item_master t
USING w13_item_stage s
ON (t.item_id = s.item_id)
WHEN MATCHED THEN
    UPDATE SET t.item_id = s.item_id;
```

```
ORA-38104: Columns referenced in the ON Clause cannot be updated
```

### ফাঁদ ৩: ON-এর শর্তে Unique না হলে

`ON` শর্ত গন্তব্যে একাধিক রো মেলালে সবগুলো আপডেট হয়। সাধারণত `ON`-এ PK বা Unique দাও।

### ফাঁদ ৪: `INSERT`-এর সময় Constraint

`NOT NULL` কলাম `INSERT`-এ না দিলে এরর। সব রো একসাথে ফেল করে: এক রো-র জন্য পুরো `MERGE` বাতিল। আগে Stage যাচাই করো।

### MERGE বনাম আলাদা কমান্ড

| | `MERGE` | `INSERT` + `UPDATE` |
|---|---|---|
| কয় কমান্ড | ১ | ২ |
| উৎস পড়া | ১ বার | ২ বার |
| অনেক রো | দ্রুত | ধীর |
| এক রো | ঠিক আছে | ঠিক আছে |
| অন্য ডাটাবেসে | প্রায় একই (ANSI) | |

```sql
CREATE TABLE w13_member_stat (
    member_id  NUMBER(10) CONSTRAINT w13_member_stat_pk PRIMARY KEY,
    issues     NUMBER(6),
    fines      NUMBER(8,2)
);

MERGE INTO w13_member_stat t
USING (SELECT m.member_id,
              (SELECT COUNT(*) FROM lib_book_issue i WHERE i.member_id = m.member_id) AS issues,
              (SELECT NVL(SUM(f.fine_amount), 0)
               FROM   lib_fine f
               JOIN   lib_book_issue i ON f.issue_id = i.issue_id
               WHERE  i.member_id = m.member_id) AS fines
       FROM   lib_member m) s
ON (t.member_id = s.member_id)
WHEN MATCHED THEN
    UPDATE SET t.issues = s.issues, t.fines = s.fines
WHEN NOT MATCHED THEN
    INSERT (member_id, issues, fines) VALUES (s.member_id, s.issues, s.fines);
COMMIT;

                     ROW_NUMBER() OVER (PARTITION BY item_id ORDER BY effective_date DESC) AS rn
              FROM   w12_item_price) x
       WHERE  rn = 1) s
ON (t.item_id = s.item_id)
WHEN MATCHED THEN
    UPDATE SET t.unit_price = s.unit_price
WHEN NOT MATCHED THEN
    INSERT (item_id, unit_price) VALUES (s.item_id, s.unit_price);
COMMIT;
```

**ভুলগুলো:**

- **১২:** `ON`-এর শর্ত ব্র্যাকেটে হতে হবে। `ORA-00969`
- **১৩:** `NOT MATCHED`-এ `UPDATE` হয় না, শুধু `INSERT`। এরর

</details>

## সারাংশ

- `MERGE`: এক কমান্ডে `UPDATE` + `INSERT`
- `INTO` গন্তব্য, `USING` উৎস, `ON (...)` মেলানো
- `WHEN MATCHED` আপডেট, `WHEN NOT MATCHED` ইনসার্ট, দুই জায়গায় `WHERE`
- উৎসে একই ID দুইবার হলে `ORA-30926`, আগে দেখে নাও
- Stage টেবিল → যাচাই → `MERGE`: ERP-র ডাটা ইমপোর্টের নিয়ম

**পরের ক্লাস:** DCL: GRANT, REVOKE, Role।
