## ১. ROW_NUMBER (৩৫ মিনিট)

প্রতিটা রো-কে ক্রমিক নম্বর দেয়। **`ORDER BY` বাধ্যতামূলক।**

```sql
SELECT ROW_NUMBER() OVER (ORDER BY salary DESC) AS rn,
       last_name,
       salary
FROM   employees
ORDER  BY rn;
```

`OVER`-এর `ORDER BY` নম্বর দেওয়ার ক্রম। শেষের `ORDER BY` ফল দেখানোর ক্রম। দুইটা আলাদা।

```sql
-- ORDER BY ছাড়া
SELECT ROW_NUMBER() OVER () FROM employees;
```

```

```

### সমান মান: অনিশ্চিত

Kochhar আর De Haan দুইজনেরই ১৭০০০। `ROW_NUMBER` একজনকে ২, অন্যজনকে ৩ দেবে, **কে কোনটা পাবে নিশ্চিত না।** নিশ্চিত করতে দ্বিতীয় কলাম দাও:

```sql
SELECT ROW_NUMBER() OVER (ORDER BY salary DESC, employee_id) AS rn,
       employee_id, last_name, salary
FROM   employees;
```

### পেজিং (ক্লাস ৩০-এর পুরনো উপায়)

```sql
-- ১১–২০ নম্বর
SELECT employee_id, last_name
FROM  (SELECT employee_id, last_name,
              ROW_NUMBER() OVER (ORDER BY employee_id) AS rn
       FROM   employees) x
WHERE  rn BETWEEN 11 AND 20;
```

`OFFSET ... FETCH` না থাকা পুরনো ভার্সনের (11g) কোডে এটা পাবে।

## ২. RANK ও DENSE_RANK (৩৫ মিনিট)

সমান মানে তিনটার আচরণ আলাদা। **এটাই আজকের মূল জিনিস,** আর ইন্টারভিউয়ের প্রিয় প্রশ্ন।

```sql
-- বিভাগ ৬০
SELECT last_name,
       salary,
       ROW_NUMBER() OVER (ORDER BY salary DESC) AS row_num,
       RANK()       OVER (ORDER BY salary DESC) AS rank_no,
       DENSE_RANK() OVER (ORDER BY salary DESC) AS dense_no
FROM   employees
WHERE  department_id = 60;
```

| LAST_NAME | SALARY | ROW_NUMBER | RANK | DENSE_RANK |
|---|---|---|---|---|
| Hunold | 9000 | 1 | 1 | 1 |
| Ernst | 6000 | 2 | 2 | 2 |
| Austin | 4800 | 3 | 3 | 3 |
| Pataballa | 4800 | 4 | 3 | 3 |
| Lorentz | 4200 | 5 | **5** | **4** |

| ফাংশন | সমান মান | পরের নম্বর | মনে রাখো |
|---|---|---|---|
| `ROW_NUMBER` | আলাদা নম্বর | পরের সংখ্যা | সবসময় ইউনিক |
| `RANK` | একই নম্বর | **ফাঁকা রাখে** (৩, ৩, ৫) | পরীক্ষার মেধাতালিকা |
| `DENSE_RANK` | একই নম্বর | ফাঁকা রাখে না (৩, ৩, ৪) | "কততম সর্বোচ্চ মান" |

### জরিমানায় (`learn_freepdb1`)

```sql
SELECT issue_id,
       fine_amount,
       ROW_NUMBER() OVER (ORDER BY fine_amount DESC, issue_id) AS row_num,
       RANK()       OVER (ORDER BY fine_amount DESC) AS rank_no,
       DENSE_RANK() OVER (ORDER BY fine_amount DESC) AS dense_no
FROM   lib_fine
ORDER  BY row_num;
```

| ISSUE_ID | FINE | ROW_NUMBER | RANK | DENSE_RANK |
|---|---|---|---|---|
| 5 | 40 | 1 | 1 | 1 |
| 9 | 40 | 2 | 1 | 1 |
| 12 | 35 | 3 | 3 | 2 |
| 14 | 30 | 4 | 4 | 3 |
| 2 | 20 | 5 | 5 | 4 |

### কোনটা নেব

| প্রশ্ন | ফাংশন |
|---|---|
| প্রতি রো-তে একটাই নম্বর, পেজিং, ডুপ্লিকেট মোছা | `ROW_NUMBER` |
| সমান নম্বর পেলে পরের জন পেছায়: মেধাতালিকা | `RANK` |
| ২য় বা ৩য় সর্বোচ্চ **মান** | `DENSE_RANK` |

## ৩. Top-N (৩০ মিনিট)

**Analytic `WHERE`-এ চলে না,** তাই Inline View।

```sql
-- কোম্পানির সর্বোচ্চ ৩ জন বেতনে
SELECT last_name, salary
FROM  (SELECT last_name, salary,
              ROW_NUMBER() OVER (ORDER BY salary DESC) AS rn
       FROM   employees) x
WHERE  rn <= 3;
```

এটা `FETCH FIRST 3 ROWS ONLY`-এর মতো। তবে ROW_NUMBER কৌশলটা কাল "প্রতি বিভাগের টপ ৩"-এ লাগবে, যা `FETCH FIRST` দিয়ে হয় না।

### কততম সর্বোচ্চ বেতন

```sql
-- দ্বিতীয় সর্বোচ্চ: 17000। ২ জন
SELECT last_name, salary
FROM  (SELECT last_name, salary,
              DENSE_RANK() OVER (ORDER BY salary DESC) AS dr
       FROM   employees) x
WHERE  dr = 2;

-- তৃতীয় সর্বোচ্চ: 14000, Russell
SELECT last_name, salary
FROM  (SELECT last_name, salary,
              DENSE_RANK() OVER (ORDER BY salary DESC) AS dr
       FROM   employees) x
WHERE  dr = 3;
```

| Top বেতন | বেতন | `RANK` | `DENSE_RANK` |
|---|---|---|---|
| King | 24000 | 1 | 1 |
| Kochhar | 17000 | 2 | 2 |
| De Haan | 17000 | 2 | 2 |
| Russell | 14000 | **4** | **3** |
| Partners | 13500 | 5 | 4 |

`RANK = 3` দিলে **কেউ আসে না!** তাই "তৃতীয় সর্বোচ্চ বেতন" মানে `DENSE_RANK`। ক্লাস ৪৬-এ নেস্টেড Subquery দিয়ে করেছিলে, এটা অনেক সহজ।

### সমান হলে সবাইকে

```sql
-- শীর্ষ ২ জন, সমান হলে সবাই: King, Kochhar, De Haan
SELECT last_name, salary
FROM  (SELECT last_name, salary,
              RANK() OVER (ORDER BY salary DESC) AS rk
       FROM   employees) x
WHERE  rk <= 2;
```

এটা ক্লাস ৩০-এর `FETCH FIRST 2 ROWS WITH TIES`-এর মতো।

### ERP-তে

```sql
-- সবচেয়ে নতুন বই: Advanced SQL Queries, Fabric Science Basics (২০২৫)
SELECT book_title, publish_year
FROM  (SELECT book_title, publish_year,
              RANK() OVER (ORDER BY publish_year DESC) AS rk
       FROM   lib_book) x
WHERE  rk = 1;
```

`ROW_NUMBER` দিলে একটা বই বাদ পড়ত, যদিও দুইটাই সবচেয়ে নতুন।

## ৪. ডুপ্লিকেট মোছা (২০ মিনিট)

ROW_NUMBER-এর সবচেয়ে কাজের ব্যবহার। Excel থেকে আনা ডাটায় একই রো কয়েকবার এসে গেছে।

```sql
CREATE TABLE w12_import (
    item_code  VARCHAR2(20),
    item_name  VARCHAR2(50),
    qty        NUMBER
);

INSERT INTO w12_import VALUES ('A1', 'Button', 100);
INSERT INTO w12_import VALUES ('A1', 'Button', 100);
INSERT INTO w12_import VALUES ('A1', 'Button', 100);
INSERT INTO w12_import VALUES ('B1', 'Zipper', 50);
INSERT INTO w12_import VALUES ('C1', 'Label', 75);
INSERT INTO w12_import VALUES ('C1', 'Label', 75);
COMMIT;

-- ডুপ্লিকেট দেখো: A1 ৩ বার, C1 ২ বার
SELECT item_code, COUNT(*) FROM w12_import GROUP BY item_code HAVING COUNT(*) > 1;

-- প্রতিটা দলে নম্বর দাও, আর ROWID দিয়ে রো চেনো
SELECT ROWID AS rid, item_code, item_name, qty,
       ROW_NUMBER() OVER (PARTITION BY item_code, item_name, qty ORDER BY ROWID) AS rn
FROM   w12_import;
```

`PARTITION BY` কাল বিস্তারিত। এখন শুধু দেখো, প্রতিটা একই রো-র দলে নম্বর আলাদা। `ROWID` হলো Oracle-এর রো-র ঠিকানা, PK না থাকলেও রো চিনতে পারে।

```sql
-- ২ বা বেশি নম্বরের রো মোছা: ৩টা রো
DELETE FROM w12_import
WHERE  ROWID IN (SELECT rid
                 FROM  (SELECT ROWID AS rid,
                               ROW_NUMBER() OVER (PARTITION BY item_code, item_name, qty ORDER BY ROWID) AS rn
                        FROM   w12_import) x
                 WHERE  rn > 1);

-- ৩টা রো থাকল
SELECT * FROM w12_import;

ROLLBACK;
```

**এটা বাস্তব প্রজেক্টে সত্যিই কাজে লাগে।** মোছার আগে ব্যাকআপ নাও, আর একই শর্তে `SELECT` চালাও (ক্লাস ২৪)।

## ৬. হোমওয়ার্ক

1. `RANK`, `DENSE_RANK`, `ROW_NUMBER`-এর পার্থক্য একটা নিজের উদাহরণে ছকে লেখো। ইন্টারভিউয়ের মতো মুখে বলো।
2. "৩য় সর্বোচ্চ বেতন" ৩ উপায়ে লেখো: `DENSE_RANK`, নেস্টেড Subquery, `OFFSET ... FETCH` (`DISTINCT` সহ)।
3. কেন Top-N-এ ROW_NUMBER দিলে সমান নম্বরের কেউ বাদ পড়তে পারে? গার্মেন্টসের উদাহরণ দাও, যেখানে এই ভুল অন্যায় হবে।

<details>
<summary>হোমওয়ার্ক ২-এর সমাধান</summary>

```sql

FROM  (SELECT salary, DENSE_RANK() OVER (ORDER BY salary DESC) AS dr FROM employees) x

-- নেস্টেড Subquery
SELECT MAX(salary)
FROM   employees
WHERE  salary < (SELECT MAX(salary)
                 FROM   employees
                 WHERE  salary < (SELECT MAX(salary) FROM employees));

-- OFFSET
SELECT DISTINCT salary
FROM   employees
ORDER  BY salary DESC
OFFSET 2 ROWS FETCH NEXT 1 ROW ONLY;
```

## সারাংশ

- `ROW_NUMBER`: সবসময় ইউনিক
- `RANK`: সমান মানে একই নম্বর, পরে ফাঁক (১, ১, ৩)
