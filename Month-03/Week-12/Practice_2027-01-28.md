## ১. রিভিশন (২০ মিনিট)

খাতা না দেখে উত্তর দাও। না পারলে সেই ক্লাসের ফাইল আবার পড়ো।

**ক্লাস ৫৬:** Analytic কি রো কমায়? `WHERE`-এ কেন চলে না, আর সমাধান কী?

**ক্লাস ৫৭:** `ROW_NUMBER`, `RANK`, `DENSE_RANK`-এর পার্থক্য কী? "৩য় সর্বোচ্চ বেতন" কোনটায়?

**ক্লাস ৫৮:** `PARTITION BY` আর `GROUP BY`-এর পার্থক্য কী? প্রতি দলের শেষ রেকর্ড কীভাবে আনো?

**ক্লাস ৫৯:** `LAG(x, 1, 0)`-এর তিনটা মান কী? `PARTITION BY` না দিলে কী হয়?

**ক্লাস ৬০:** `ROWS` আর `RANGE`-এর পার্থক্য কী? `LAST_VALUE`-এর ফাঁদ কী?

### অংশ ক: বিভাগে টপ ৩ বেতন (HR, ৮টা)

`hr_freepdb1`-এ:

1. প্রতি বিভাগের সর্বোচ্চ ৩ জন, `ROW_NUMBER` দিয়ে, বিভাগ আছে এমন কর্মী। (২৫)
2. একই, `RANK` দিয়ে। কোন বিভাগে ৩-এর বেশি জন? (বিভাগ ৬০)
3. একই, `DENSE_RANK` দিয়ে। পার্থক্য খাতায় লেখো।
4. ৩ নম্বরের ফলে বিভাগের নাম যোগ করো।
5. প্রতি বিভাগের সর্বোচ্চ বেতনের কর্মী, নামসহ। (১১, বিভাগ আছে এমন)
6. প্রতি বিভাগে দ্বিতীয় সর্বোচ্চ বেতন।
7. প্রতি পদে সর্বোচ্চ ২ জন (`job_title` সহ)।
8. প্রতি শহরের সর্বোচ্চ বেতনের কর্মী (`employees`, `departments`, `locations`)। (৭)

### অংশ খ: মাসভিত্তিক রানিং টোটাল (গার্মেন্টস, ৮টা)

`learn_freepdb1`-এ, `w12_buyer_ship` থেকে:

9. প্রতি Buyer-এর চলমান শিপমেন্ট। (H&M: ৫০০০, ১১০০০, ১৫০০০; Zara: ৩০০০, ৫০০০, ১২০০০; Primark: ৪০০০, ৯০০০, ১২০০০)
10. মাসভিত্তিক মোট, আর পুরো কোম্পানির চলমান মোট। (১২০০০, ২৫০০০, ৩৯০০০)
11. প্রতি মাসে প্রতি Buyer-এর শেয়ার %। (জানুয়ারিতে H&M ৪১.৬৭)
12. প্রতি মাসে Buyer-দের র‍্যাঙ্ক। (জানু: H&M, Primark, Zara; মার্চ: Zara, H&M, Primark)
13. প্রতি মাসের সেরা Buyer। (জানু H&M, ফেব্রু H&M, মার্চ Zara)
14. প্রতি Buyer-এর আগের মাসের সাথে পরিবর্তন। (Zara মার্চে +৫০০০)
15. প্রতি Buyer-এর মোট, আর সবচেয়ে বেশি কোন মাসে। (`FIRST_VALUE`)
16. সবচেয়ে বেশি মোট শিপমেন্টের Buyer। (H&M ১৫০০০)

### অংশ গ: ERP রিপোর্ট (৪টা)

17. Item Ledger, সব আইটেম, নামসহ, চলমান ব্যালেন্স (`goods_receive`, `goods_issue`, `item`)।
18. প্রতিটা আইটেমের শেষ রিসিভের তারিখ, পরিমাণ, Supplier-এর নাম। (`ROW_NUMBER`)
19. গড়ের চেয়ে বেশি জরিমানা, মেম্বারের নামসহ, চলমান যোগ। (৪০, ৮০, ১১৫)
20. প্রতি মাসের ইস্যু, চলমান মোট, আগের মাসের সাথে পরিবর্তন।

```sql
-- ১
SELECT department_id, last_name, salary
FROM  (SELECT last_name, department_id, salary,
              ROW_NUMBER() OVER (PARTITION BY department_id ORDER BY salary DESC) AS rn
       FROM   employees
       WHERE  department_id IS NOT NULL) x
WHERE  rn <= 3
ORDER  BY department_id, rn;

-- ২
SELECT department_id, last_name, salary, rk
FROM  (SELECT last_name, department_id, salary,
              RANK() OVER (PARTITION BY department_id ORDER BY salary DESC) AS rk
       FROM   employees
       WHERE  department_id IS NOT NULL) x
WHERE  rk <= 3
ORDER  BY department_id, rk;

-- ৩
SELECT department_id, last_name, salary, dr
FROM  (SELECT last_name, department_id, salary,
              DENSE_RANK() OVER (PARTITION BY department_id ORDER BY salary DESC) AS dr
       FROM   employees
       WHERE  department_id IS NOT NULL) x
WHERE  dr <= 3
ORDER  BY department_id, dr;

-- ৪
SELECT d.department_name, x.last_name, x.salary, x.dr
FROM  (SELECT last_name, department_id, salary,
              DENSE_RANK() OVER (PARTITION BY department_id ORDER BY salary DESC) AS dr
       FROM   employees) x
JOIN   departments d ON x.department_id = d.department_id
WHERE  x.dr <= 3
ORDER  BY d.department_name, x.dr;

-- ৫
SELECT d.department_name, x.last_name, x.salary
FROM  (SELECT last_name, department_id, salary,
              RANK() OVER (PARTITION BY department_id ORDER BY salary DESC) AS rk
       FROM   employees) x
JOIN   departments d ON x.department_id = d.department_id
WHERE  x.rk = 1
ORDER  BY d.department_name;

-- ৬
SELECT department_id, last_name, salary

              DENSE_RANK() OVER (PARTITION BY department_id ORDER BY salary DESC) AS dr
       FROM   employees) x

ORDER  BY department_id;

-- ৭
SELECT j.job_title, x.last_name, x.salary
FROM  (SELECT last_name, job_id, salary,
              ROW_NUMBER() OVER (PARTITION BY job_id ORDER BY salary DESC) AS rn
       FROM   employees) x
JOIN   jobs j ON x.job_id = j.job_id
WHERE  x.rn <= 2
ORDER  BY j.job_title, x.rn;

-- ৮
SELECT city, last_name, salary
FROM  (SELECT l.city, e.last_name, e.salary,
              RANK() OVER (PARTITION BY l.city ORDER BY e.salary DESC) AS rk
       FROM   employees e
       JOIN   departments d ON e.department_id = d.department_id
       JOIN   locations l   ON d.location_id = l.location_id) x
```

```sql
-- ১৭
SELECT i.item_name, l.txn_date, l.txn_type, l.in_qty, l.out_qty,
       SUM(l.in_qty - l.out_qty) OVER (PARTITION BY l.item_id ORDER BY l.txn_date ROWS UNBOUNDED PRECEDING) AS balance_qty
FROM  (SELECT item_id, receive_date AS txn_date, 'RECEIVE' AS txn_type, qty AS in_qty, 0 AS out_qty
       FROM   goods_receive
       UNION ALL
       SELECT item_id, issue_date, 'ISSUE', 0, qty
       FROM   goods_issue) l
JOIN   item i ON l.item_id = i.item_id
ORDER  BY i.item_name, l.txn_date;

-- ১৮
SELECT i.item_name, x.receive_date, x.qty, s.supplier_name
FROM  (SELECT item_id, supplier_id, receive_date, qty,
              ROW_NUMBER() OVER (PARTITION BY item_id ORDER BY receive_date DESC, receive_id DESC) AS rn
       FROM   goods_receive) x
JOIN   item i     ON x.item_id = i.item_id
JOIN   supplier s ON x.supplier_id = s.supplier_id
WHERE  x.rn = 1
ORDER  BY i.item_name;

-- ১৯
SELECT member_name, fine_amount,
       SUM(fine_amount) OVER (ORDER BY issue_id ROWS UNBOUNDED PRECEDING) AS running_fine
FROM  (SELECT f.issue_id, m.member_name, f.fine_amount,
              AVG(f.fine_amount) OVER () AS avg_fine
       FROM   lib_fine f
       JOIN   lib_book_issue i ON f.issue_id = i.issue_id
       JOIN   lib_member m     ON i.member_id = m.member_id) x
WHERE  fine_amount > avg_fine
ORDER  BY issue_id;

-- ২০
SELECT TO_CHAR(issue_date, 'YYYY-MM') AS issue_month,
       COUNT(*) AS issues,
       SUM(COUNT(*)) OVER (ORDER BY TO_CHAR(issue_date, 'YYYY-MM') ROWS UNBOUNDED PRECEDING) AS running_issues,
       COUNT(*) - LAG(COUNT(*)) OVER (ORDER BY TO_CHAR(issue_date, 'YYYY-MM')) AS change_count
FROM   lib_book_issue
GROUP  BY TO_CHAR(issue_date, 'YYYY-MM')
ORDER  BY issue_month;
```
