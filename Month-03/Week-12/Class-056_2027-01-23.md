# ক্লাস ৫৬: Analytic Function কী ও OVER Clause

**তারিখ:** ২৩ জানুয়ারি ২০২৭, শনিবার
**সময়:** সন্ধ্যা ৭:০০ থেকে রাত ১০:০০
**সপ্তাহ:** ১২ | **ধাপ:** ২ (Oracle SQL)

## আজকে কী শিখব

- Analytic Function কেন লাগে
- `OVER ()` দিয়ে পুরো টেবিলের হিসাব পাশে দেখানো
- `GROUP BY` আর Analytic-এর পার্থক্য
- নিয়ম আর চলার ক্রম, `ORA-30483`

> HR-এর কোয়েরি `hr_freepdb1`-এ, আর `lib_`, `w5_`, `w12_` টেবিলের কোয়েরি `learn_freepdb1`-এ চালাবে। HR-এর সংখ্যা ভার্সনভেদে সামান্য আলাদা হতে পারে।

## ১. কেন লাগে (২৫ মিনিট)

**প্রশ্ন:** প্রতিটা কর্মীর নাম, বেতন, আর **তাঁর বেতন কোম্পানির মোট বেতনের কত শতাংশ**।

সমস্যা: `SUM(salary)` রো কমিয়ে একটা করে দেয়, নাম আর থাকে না।

```sql
SELECT last_name, SUM(salary) FROM employees;     -- ORA-00937
```

এখন পর্যন্ত উপায় (ক্লাস ৪৬):

```sql
SELECT last_name, salary,
       (SELECT SUM(salary) FROM employees) AS total_salary
FROM   employees;
```

চলে, কিন্তু প্রতিটা হিসাবে একটা করে Subquery। **Analytic Function** এই কাজ সহজে করে:

```sql
SELECT last_name,
       salary,
       SUM(salary) OVER ()                         AS total_salary,   -- 691416
       ROUND(salary / SUM(salary) OVER () * 100, 2) AS pct_of_total    -- King 3.47
FROM   employees;
```

**১০৭টা রো-ই থাকল,** আর প্রতিটার পাশে মোট বেতন। `OVER` বলে দেয়: এটা Analytic, রো কমাবে না।

### কী কী করা যায়

| প্রশ্ন | ফাংশন | কবে |
|---|---|---|
| মোটের কত শতাংশ? | `SUM() OVER` | আজ |
| বিভাগের ভেতরে র‍্যাঙ্ক | `RANK() OVER` | ক্লাস ৫৭ |
| প্রতি বিভাগের টপ ৩ | `ROW_NUMBER() OVER` | ক্লাস ৫৮ |
| গতকালের চেয়ে কত বাড়ল | `LAG() OVER` | ক্লাস ৫৯ |
| চলমান ব্যালেন্স | `SUM() OVER (ORDER BY ...)` | ক্লাস ৬০ |

> ERP-র রিপোর্টে এগুলো খুব লাগে: Item Ledger-এর চলমান ব্যালেন্স, Line-wise Efficiency র‍্যাঙ্ক, মাসভিত্তিক বৃদ্ধি। ইন্টারভিউতেও SQL-এর সবচেয়ে সাধারণ কঠিন প্রশ্ন এগুলোই।

## ২. OVER () (৪০ মিনিট)

```sql
ফাংশন(...) OVER (
    PARTITION BY ...     -- কীভাবে দলে ভাগ (ক্লাস ৫৮)
    ORDER BY ...         -- দলের ভেতরে ক্রম (ক্লাস ৫৭)
    ROWS BETWEEN ...     -- কোন রো-গুলো নিয়ে (ক্লাস ৬০)
)
```

তিনটাই ঐচ্ছিক। আজ খালি `OVER ()`: **পুরো ফলের সব রো** এক দল।

```sql
SELECT last_name,
       salary,
       COUNT(*)    OVER () AS total_staff,    -- 107
       SUM(salary) OVER () AS total_salary,   -- 691416
       ROUND(AVG(salary) OVER (), 2) AS avg_salary,   -- 6461.83
       MIN(salary) OVER () AS min_salary,     -- 2100
       MAX(salary) OVER () AS max_salary      -- 24000
FROM   employees;
```

### কাজের হিসাব

```sql
-- গড়ের চেয়ে কত বেশি বা কম। King: 17538.17
SELECT last_name,
       salary,
       ROUND(salary - AVG(salary) OVER (), 2) AS diff_from_avg
FROM   employees
ORDER  BY diff_from_avg DESC;

-- সর্বোচ্চ বেতনের কত শতাংশ। King: 100
SELECT last_name,
       salary,
       ROUND(salary / MAX(salary) OVER () * 100, 2) AS pct_of_max
FROM   employees;
```

### WHERE-এর পরে

Analytic হিসাব হয় `WHERE`-এর **পরে,** শুধু বেছে নেওয়া রো-গুলো নিয়ে।

```sql
-- বিভাগ ৬০-এর ৫ জন। মোট 28800, Hunold 31.25%
SELECT last_name,
       salary,
       SUM(salary) OVER () AS dept_total,
       ROUND(salary / SUM(salary) OVER () * 100, 2) AS pct
FROM   employees
WHERE  department_id = 60;
```

| LAST_NAME | SALARY | DEPT_TOTAL | PCT |
|---|---|---|---|
| Hunold | 9000 | 28800 | 31.25 |
| Ernst | 6000 | 28800 | 20.83 |
| Austin | 4800 | 28800 | 16.67 |
| Pataballa | 4800 | 28800 | 16.67 |
| Lorentz | 4200 | 28800 | 14.58 |

### পেজিংয়ের সাথে: মোট কয়টা রো

```sql
-- ১০ রো দেখাচ্ছি, কিন্তু মোট কয়টা তা-ও জানি
SELECT employee_id, last_name, COUNT(*) OVER () AS total_rows
FROM   employees
ORDER  BY employee_id
FETCH  FIRST 10 ROWS ONLY;
```

"১০৭-এর মধ্যে ১–১০": রিপোর্ট পেজিংয়ে এই কৌশল লাগে।

## ৩. GROUP BY বনাম Analytic (২৫ মিনিট)

```sql
-- GROUP BY: ১২টা রো
SELECT department_id, SUM(salary) AS dept_total
FROM   employees
GROUP  BY department_id;

-- Analytic: ১০৭টা রো
SELECT last_name, department_id,
       SUM(salary) OVER (PARTITION BY department_id) AS dept_total
FROM   employees;
```

| | `GROUP BY` | Analytic |
|---|---|---|
| রো | কমে, দল প্রতি একটা | **থাকে** |
| সাধারণ কলাম | `GROUP BY`-তে থাকতে হয় | যেকোনো কলাম চলে |
| লেখা | `SUM(x)` | `SUM(x) OVER (...)` |
| কখন | শুধু সারাংশ লাগে | প্রতিটা রো-র পাশে হিসাব লাগে |

### দুইটা একসাথে

`GROUP BY`-এর ফলের উপর Analytic চলে।

```sql
-- প্রতি বিভাগের মোট, আর কোম্পানির মোটের কত শতাংশ
SELECT department_id,
       SUM(salary) AS dept_total,
       ROUND(SUM(salary) / SUM(SUM(salary)) OVER () * 100, 2) AS pct_of_company
FROM   employees
GROUP  BY department_id
ORDER  BY dept_total DESC;
```

`SUM(SUM(salary)) OVER ()`: ভেতরের `SUM` দল ধরে, বাইরের `SUM` সব দল মিলে। প্রথমবার দেখলে অদ্ভুত লাগে। ফল: বিভাগ ৮০ ৪৪.০৪%, বিভাগ ৫০ ২২.৬২%।

## ৪. নিয়ম ও চলার ক্রম (২৫ মিনিট)

### চলার ক্রম

| ক্রম | অংশ |
|---|---|
| ১ | `FROM`, `JOIN` |
| ২ | `WHERE` |
| ৩ | `GROUP BY` |
| ৪ | `HAVING` |
| ৫ | **Analytic Function** |
| ৬ | `SELECT`-এর বাকি, `DISTINCT` |
| ৭ | `ORDER BY` |
| ৮ | `FETCH FIRST` |

### সবচেয়ে বড় নিয়ম: WHERE-এ Analytic চলে না

```sql
SELECT last_name, salary
FROM   employees
WHERE  salary > AVG(salary) OVER ();
```

```
ORA-30483: window functions are not allowed here
```

`WHERE` চলে আগে, Analytic পরে। সমাধান: Inline View।

```sql
-- গড়ের চেয়ে বেশি বেতন: ৫১ জন
SELECT last_name, salary, avg_salary
FROM  (SELECT last_name, salary,
              ROUND(AVG(salary) OVER (), 2) AS avg_salary
       FROM   employees) x
WHERE  salary > avg_salary;
```

**এই আকারটা মুখস্থ করো।** টপ N, প্রতি বিভাগের টপ ৩, ইত্যাদি সবখানে এই একই কৌশল।

`GROUP BY`, `HAVING`-এও Analytic চলে না। শুধু `SELECT` আর `ORDER BY`-তে চলে।

### Alias

```sql
-- ঠিক: ORDER BY-তে Alias
SELECT last_name, salary - AVG(salary) OVER () AS diff
FROM   employees
ORDER  BY diff DESC;
```

## ৬. হোমওয়ার্ক

1. `GROUP BY` আর Analytic-এর পার্থক্য একজন নতুন মানুষকে বোঝাও, গার্মেন্টসের উদাহরণ দিয়ে।
2. চলার ক্রম না দেখে লেখো, আর Analytic কোথায়। `WHERE`-এ কেন চলে না, ২ লাইনে।
3. `w5_order_detail_v` থেকে Buyer-ভিত্তিক মোট মূল্য, আর মোটের কত শতাংশ। (H&M, Primark, Zara)

## সারাংশ

- Analytic: হিসাব হয়, রো কমে না
- `SUM(x) OVER ()`: প্রতিটা রো-র পাশে মোট
- চলে `WHERE`, `GROUP BY`-এর পরে, `ORDER BY`-এর আগে
- `WHERE`-এ চলে না: Inline View-তে হিসাব, বাইরে শর্ত

**পরের ক্লাস:** ROW_NUMBER, RANK, DENSE_RANK।
