## ১. PARTITION BY (৪০ মিনিট)

এতদিন পুরো টেবিল এক দল ছিল। **`PARTITION BY`** রো-গুলোকে দলে ভাগ করে, আর প্রতিটা দলে আলাদা হিসাব করে। `GROUP BY`-এর মতো, কিন্তু **রো কমে না।**

```sql
SELECT last_name,
       department_id,
       salary,
       SUM(salary) OVER (PARTITION BY department_id) AS dept_total,
       COUNT(*)    OVER (PARTITION BY department_id) AS dept_staff,
       ROUND(AVG(salary) OVER (PARTITION BY department_id), 2) AS dept_avg
FROM   employees
ORDER  BY department_id, salary DESC;
```

১০৭টা রো। বিভাগ ৬০ অংশটা:

| LAST_NAME | SALARY | DEPT_TOTAL | DEPT_STAFF | DEPT_AVG |
|---|---|---|---|---|
| Hunold | 9000 | 28800 | 5 | 5760 |
| Ernst | 6000 | 28800 | 5 | 5760 |
| Austin | 4800 | 28800 | 5 | 5760 |
| Pataballa | 4800 | 28800 | 5 | 5760 |
| Lorentz | 4200 | 28800 | 5 | 5760 |

`department_id` NULL (Grant) নিজে একটা দল। এখানে NULL-গুলো একসাথে থাকে, `GROUP BY`-এর মতো।

```
PARTITION BY department_id

┌── বিভাগ ৬০ ──┐ ┌── বিভাগ ৯০ ──┐
│ SUM = 28800  │ │ SUM = 58000  │
└──────────────┘ └──────────────┘
```

### Correlated Subquery-র সহজ রূপ

ক্লাস ৪৮-এ নিজের বিভাগের গড়ের সাথে তুলনা করেছিলে:

```sql
-- পুরনো
SELECT e.last_name, e.salary,
       (SELECT AVG(i.salary) FROM employees i WHERE i.department_id = e.department_id) AS dept_avg
FROM   employees e;

-- নতুন: সহজ, আর সাধারণত দ্রুত
SELECT last_name, salary,
       AVG(salary) OVER (PARTITION BY department_id) AS dept_avg
FROM   employees;
```

দুইটার একটা পার্থক্য: পুরনোটায় NULL বিভাগের Grant-এর `dept_avg` NULL, কারণ `NULL = NULL` সত্য না। নতুনটায় ৭০০০।

## ২. দলের ভেতরে হিসাব (৩০ মিনিট)

```sql
-- বিভাগের মোটের কত শতাংশ, আর গড় থেকে কত দূরে
SELECT last_name,
       department_id,
       salary,
       ROUND(salary / SUM(salary) OVER (PARTITION BY department_id) * 100, 2) AS pct_of_dept,
       ROUND(salary - AVG(salary) OVER (PARTITION BY department_id), 2)       AS diff_from_avg
FROM   employees
WHERE  department_id = 60
ORDER  BY salary DESC;
```

| LAST_NAME | SALARY | PCT_OF_DEPT | DIFF_FROM_AVG |
|---|---|---|---|
| Hunold | 9000 | 31.25 | 3240 |
| Ernst | 6000 | 20.83 | 240 |
| Austin | 4800 | 16.67 | -960 |
| Pataballa | 4800 | 16.67 | -960 |
| Lorentz | 4200 | 14.58 | -1560 |

### নিজের বিভাগের গড়ের চেয়ে বেশি

```sql
-- বিভাগ ৬০-এ: Hunold, Ernst
SELECT last_name, department_id, salary, dept_avg
FROM  (SELECT last_name, department_id, salary,
              ROUND(AVG(salary) OVER (PARTITION BY department_id), 2) AS dept_avg
       FROM   employees) x
WHERE  salary > dept_avg
ORDER  BY department_id, salary DESC;
```

## ৩. প্রতি দলের টপ N (৩০ মিনিট)

**"প্রতি বিভাগের সর্বোচ্চ বেতনের ৩ জন"।** কোম্পানিজুড়ে `FETCH FIRST` দিয়ে হয় না। `PARTITION BY` + `ROW_NUMBER` + Inline View।

```sql
SELECT ROW_NUMBER() OVER (PARTITION BY department_id ORDER BY salary DESC) AS rn,
       last_name,
       department_id,
       salary
FROM   employees
ORDER  BY department_id, rn;
```

প্রতিটা নতুন বিভাগে নম্বর আবার ১ থেকে শুরু হয়।

```sql
-- প্রতি বিভাগের সর্বোচ্চ ৩ জন: ২৬টা রো
SELECT department_id, last_name, salary, rn
FROM  (SELECT last_name, department_id, salary,
              ROW_NUMBER() OVER (PARTITION BY department_id ORDER BY salary DESC) AS rn
       FROM   employees) x
WHERE  rn <= 3
ORDER  BY department_id, rn;
```

### ROW_NUMBER, RANK, DENSE_RANK: কোনটা?

বিভাগ ৬০-এ সর্বোচ্চ ৩: Austin আর Pataballa দুইজনেরই ৪৮০০।

| ফাংশন | `<= 3` ফল | কতজন |
|---|---|---|
| `ROW_NUMBER` | Hunold, Ernst, Austin **বা** Pataballa | ৩ |
| `RANK` | Hunold, Ernst, Austin, Pataballa | ৪ |
| `DENSE_RANK` | Hunold, Ernst, Austin, Pataballa | ৪ |

**আগে জিজ্ঞেস করো:** ঠিক ৩ জন লাগবে, নাকি সমান হলে সবাই? `ROW_NUMBER` চুপচাপ একজনকে বাদ দেয়।

### প্রতি দলের সর্বোচ্চ জন

```sql
-- প্রতি বিভাগের সর্বোচ্চ: ১২ জন (Grant-সহ)
SELECT department_id, last_name, salary
FROM  (SELECT last_name, department_id, salary,
              RANK() OVER (PARTITION BY department_id ORDER BY salary DESC) AS rk
       FROM   employees) x
WHERE  rk = 1
ORDER  BY department_id;
```

ক্লাস ৪৭-এ `(department_id, salary) IN (...)` দিয়ে ১১ জন এসেছিল, Grant বাদ পড়েছিল। এখানে আসে।

### প্রতি দলের সবচেয়ে নতুন: ERP-তে খুব কাজের

**"প্রতিটা কপির শেষ ইস্যু"**, **"প্রতিটা আইটেমের শেষ GRN"**, **"প্রতিটা স্টাইলের সর্বশেষ দাম"**।

```sql
-- কপিগুলোর শেষ ইস্যু: ১৭টা কপি (learn_freepdb1)
SELECT copy_id, issue_id, member_id, issue_date
FROM  (SELECT copy_id, issue_id, member_id, issue_date,
              ROW_NUMBER() OVER (PARTITION BY copy_id ORDER BY issue_date DESC, issue_id DESC) AS rn
       FROM   lib_book_issue) x
WHERE  rn = 1
ORDER  BY copy_id;
```

`MAX(issue_date)` দিলে তারিখ পেতে, কিন্তু সেই রো-র `member_id` পেতে না। এই কৌশলে পুরো রো পাও।

## ৪. একাধিক কলাম ও অন্য কথা (১৫ মিনিট)

### একাধিক কলামে Partition

```sql
-- বিভাগ আর পদ মিলে দল
SELECT department_id, job_id, last_name, salary,
       RANK() OVER (PARTITION BY department_id, job_id ORDER BY salary DESC) AS rk
FROM   employees
WHERE  department_id = 50;
```

বিভাগ ৫০-এ `ST_MAN`, `ST_CLERK`, `SH_CLERK` আলাদা র‍্যাঙ্ক। গার্মেন্টসে: Buyer + Style ধরে।

### এক কোয়েরিতে আলাদা Partition

```sql
SELECT last_name,
       salary,
       RANK() OVER (ORDER BY salary DESC)                            AS company_rank,
       RANK() OVER (PARTITION BY department_id ORDER BY salary DESC) AS dept_rank,
       RANK() OVER (PARTITION BY job_id ORDER BY salary DESC)        AS job_rank
FROM   employees
ORDER  BY company_rank;
```

প্রতিটা `OVER` নিজের মতো। King সব জায়গায় ১। Russell কোম্পানিতে ৪, বিভাগে ১।

### কয়েকটা ফাংশনের একই OVER: WINDOW (21c থেকে)

একই `OVER` বারবার লিখতে হলে নতুন ভার্সনে নাম দেওয়া যায়: `WINDOW w AS (PARTITION BY ...)`। পুরনোয় চলে না, তাই নাম জেনে রাখো।

### NTILE: সমান ভাগে

```sql
-- বিভাগ ৫০-এর কর্মীদের বেতনের ক্রমে ৪ ভাগে
SELECT last_name, salary, NTILE(4) OVER (ORDER BY salary DESC) AS quartile
FROM   employees
WHERE  department_id = 50;
```

3. `GROUP BY department_id` আর `PARTITION BY department_id`-এর পার্থক্য ৩টা লেখো।

## ৭. কুইজ

1. `PARTITION BY` আর `GROUP BY`-এর মূল পার্থক্য কী?
2. `PARTITION BY`-তে NULL কি আলাদা দল হয়?
3. প্রতি বিভাগে নম্বর ১ থেকে আবার শুরু করতে কী লিখবে?
4. প্রতি দলের শেষ রেকর্ড আনতে কোন ফাংশন, কোন ক্রমে?
5. এক কোয়েরিতে কয়েকটা আলাদা `PARTITION BY` দেওয়া যায়?

3. `ROW_NUMBER() OVER (PARTITION BY department_id ORDER BY ...)`

## সারাংশ

- `PARTITION BY`: দলে ভাগ, রো কমে না। NULL-ও একটা দল
- `SUM(x) OVER (PARTITION BY ...)`: প্রতিটা রো-র পাশে দলের হিসাব
- প্রতি দলের টপ N: `ROW_NUMBER` বা `RANK` + `PARTITION BY` + Inline View
- প্রতি দলের শেষ রেকর্ড: `ROW_NUMBER` + তারিখ `DESC`, পুরো রো পাওয়া যায়
- ঠিক N জন? `ROW_NUMBER`। সমান হলে সবাই? `RANK` বা `DENSE_RANK`
