## ২. মূল কাজ (১১৫ মিনিট)

`learn_freepdb1`-এ করো। প্রতিটা প্রোগ্রাম `week17.sql`-এ কমেন্টে নম্বর দিয়ে রাখো। ফাইলের শুরুতে ক্লাস ৮৪-এর এরর নম্বরের তালিকা কমেন্টে।

**আজকের নিয়ম, প্রতিটা প্রোগ্রামে:**

1. ব্যবসার নিয়ম ভাঙলে `RAISE_APPLICATION_ERROR`, ঠিক নম্বর আর পরিষ্কার বার্তা
2. `SELECT INTO`-এর `NO_DATA_FOUND` নিজের নম্বরে রূপান্তর
3. অপ্রত্যাশিত এরর: তথ্য তোলো, `ROLLBACK`, `w17_error_log`-এ লগ + `COMMIT`, `RAISE`
4. `WHEN OTHERS THEN NULL` কোথাও না
5. প্রতিটা প্রোগ্রাম ঠিক মান আর প্রতিটা ভুলের মান দিয়ে পরীক্ষা

শুরুর আগে মিলিয়ে নাও: `w14_stock` ৬০০ / ৬০ / ১৮০, `w16_salary`-তে জানুয়ারির ৯টা রো, `w17_error_log` আছে।

### অংশ ক: স্টক (৪টা)

1. **স্টক ইস্যু (পুরো):** ক্লাস ৮৪-এর স্টক ইস্যুতে ক্লাস ৮৫-এর লগের Handler যোগ করো (শুধু অপ্রত্যাশিত এরর লগ)। মডিউল `STOCK_ISSUE`। সফল হলে `COMMIT` না, `ROLLBACK` দিয়ে পরীক্ষা। মান: (১, ১০০), (১, ০), (১, ৬০০), (৯, ১০), (২, ৫০)। লগে কয়টা রো যোগ হলো? (০, সবই ব্যবসার নিয়ম)
2. **স্টক রিসিভ:** আইটেম আর পরিমাণ নিয়ে স্টক বাড়াও আর `w14_txn`-এ `RECEIVE`। নিয়ম: পরিমাণ > ০ (`-20002`), আইটেম আছে (`-20003`, `UPDATE`-এর পরে `SQL%NOTFOUND` দিয়ে), একবারে ৫০০০-এর বেশি না (`-20005: Receive of n looks wrong, check unit`)। (৩, ২০০), (৩, ৬০০০), (৮, ১০) দিয়ে পরীক্ষা।
3. **স্টক ট্রান্সফার:** আইটেম ক থেকে খ-তে পরিমাণ সরাও (দুইটা `UPDATE`)। খ না থাকলে পুরোটাই বাতিল, ক-এর স্টকও আগের মতো থাকবে। (১ থেকে ৩-এ ৫০: ঠিক; ১ থেকে ৯-এ ৫০: `-20003`, আইটেম ১ এখনো ৬০০)

### অংশ খ: স্যালারি (৫টা)

5. **নিরাপদ স্যালারি প্রসেস:** সপ্তাহ ১৬-এর প্র্যাকটিস ৩ নতুন করে লেখো:

   - প্রতিজনের আগে `SAVEPOINT`, Nested Block
   - `LEFT` হলে `-20203`, Basic ৮০০০-এর কম হলে `-20202`
   - এই দুইটা `PRAGMA` দিয়ে ধরে `Skipped: SQLERRM` ছাপাও, লগ না
   - অন্য যেকোনো এরর: সেই কর্মচারীর কাজ `ROLLBACK TO`, লগে `PAYROLL` মডিউল, `emp=n`, তারপর চালিয়ে যাও
   - শেষে: প্রসেস, Skip, এরর-এর সংখ্যা আর মোট Net
   - শুরুতে ওই মাসের পুরনো রো মোছা থাকবে, শেষে `COMMIT`

### অংশ গ: লাইব্রেরি (৩টা)

10. **ইস্যু যাচাই:** ক্লাস ৮৪-এর প্র্যাকটিস ৫ (`-20101` থেকে `-20105`) চারটা মান দিয়ে আবার চালাও, আর একটা পঞ্চম নিয়ম যোগ করো: মেম্বারের কোনো বই Due Date পার হয়ে ফেরত না দেওয়া থাকলে `-20106: Member has n overdue book(s)`। (`due_date < DATE '2027-03-04' AND return_date IS NULL`)
11. **বই ফেরত:** `copy_id` দিয়ে খোলা ইস্যু খুঁজে `return_date` বসাও আর কপি `AVAILABLE` করো। কপির কোনো খোলা ইস্যু না থাকলে `-20107: Copy n is not issued`। দুইটা খোলা ইস্যু থাকলে (ডাটার ভুল) `TOO_MANY_ROWS` লগ করে `RAISE`। পরীক্ষার পরে `ROLLBACK`।
12. **নতুন মেম্বার:** নাম আর মোবাইল দিয়ে `lib_member`-এ রো (ID = `MAX + 1`)। ডুপ্লিকেট মোবাইলে `-20108: Mobile already registered to member n` (কার নামে, সেটাও খুঁজে বের করো)। `ROLLBACK`।

### অংশ ঘ: সপ্তাহ ১৫-এর প্রোগ্রাম (৩টা)

13. **Efficiency:** সপ্তাহ ১৫-এর প্র্যাকটিস ১১ একটা Nested Block-এ। অপারেটর বা ঘণ্টা ০ বা NULL হলে `-20901: Operators and hours must be more than zero`। পিস ঋণাত্মক হলে `-20902`। (১২০০, ৪০, ৮), (১২০০, ০, ৮), (-৫, ৪০, ৮)

```sql
SET SERVEROUTPUT ON

-- ১
DECLARE
    c_min_stock CONSTANT NUMBER := 20;
    c_max_issue CONSTANT NUMBER := 500;

    v_item_id  w14_stock.item_id%TYPE := 1;
    v_qty      NUMBER := 100;
    v_balance  w14_stock.balance_qty%TYPE;

    v_code NUMBER;
    v_msg  VARCHAR2(4000);
    v_bt   VARCHAR2(4000);
BEGIN
    IF v_qty IS NULL OR v_qty <= 0 THEN
        RAISE_APPLICATION_ERROR(-20002, 'Quantity must be more than zero');
    END IF;
    IF v_qty > c_max_issue THEN
        RAISE_APPLICATION_ERROR(-20004, 'Issue of ' || v_qty || ' needs manager approval');
    END IF;

    BEGIN
        SELECT balance_qty INTO v_balance FROM w14_stock WHERE item_id = v_item_id FOR UPDATE;
    EXCEPTION
        WHEN NO_DATA_FOUND THEN
            RAISE_APPLICATION_ERROR(-20003, 'Item ' || v_item_id || ' not found');
    END;

    IF v_balance - v_qty < c_min_stock THEN
        RAISE_APPLICATION_ERROR(-20001,
            'Cannot issue ' || v_qty || ': only ' || v_balance || ' in stock, minimum ' || c_min_stock);
    END IF;

    UPDATE w14_stock SET balance_qty = balance_qty - v_qty WHERE item_id = v_item_id;
    INSERT INTO w14_txn (item_id, txn_type, qty) VALUES (v_item_id, 'ISSUE', v_qty);
    DBMS_OUTPUT.PUT_LINE('Issued ' || v_qty || ', new balance ' || (v_balance - v_qty));
    ROLLBACK;
EXCEPTION
    WHEN OTHERS THEN
        v_code := SQLCODE;
        v_msg  := SQLERRM;
        v_bt   := DBMS_UTILITY.FORMAT_ERROR_BACKTRACE;
        ROLLBACK;
        IF v_code NOT BETWEEN -20999 AND -20000 THEN
            INSERT INTO w17_error_log (module_name, error_code, error_msg, backtrace, context_info)
            VALUES ('STOCK_ISSUE', v_code, v_msg, v_bt, 'item=' || v_item_id || ', qty=' || v_qty);
            COMMIT;
        END IF;
        RAISE;
END;
/

DECLARE
```

```sql
SET SERVEROUTPUT ON

-- ৫
DECLARE
    c_month      CONSTANT VARCHAR2(7) := '2027-01';
    c_house_pct  CONSTANT NUMBER := 0.5;
    c_medical    CONSTANT NUMBER := 750;
    c_transport  CONSTANT NUMBER := 450;
    c_month_days CONSTANT NUMBER := 30;
    c_min_wage   CONSTANT NUMBER := 8000;

    CURSOR c_emp (p_month VARCHAR2) IS
        SELECT e.emp_id, e.emp_name, e.status, e.basic_salary,
               NVL(a.absent_days, 0) AS absent_days
        FROM   w16_emp e
               LEFT JOIN w16_absent a
                      ON a.emp_id = e.emp_id AND a.absent_month = p_month
        ORDER  BY e.emp_id;

    e_left EXCEPTION;
    e_wage EXCEPTION;
    PRAGMA EXCEPTION_INIT(e_left, -20203);
    PRAGMA EXCEPTION_INIT(e_wage, -20202);

    v_house NUMBER;
    v_gross NUMBER;
    v_ded   NUMBER;
    v_ok    NUMBER := 0;
    v_skip  NUMBER := 0;
    v_err   NUMBER := 0;
    v_total NUMBER := 0;
    v_code  NUMBER;
    v_msg   VARCHAR2(4000);
    v_bt    VARCHAR2(4000);
BEGIN
    DELETE FROM w16_salary WHERE salary_month = c_month;

    FOR r IN c_emp(c_month) LOOP
        SAVEPOINT before_emp;
        BEGIN
            IF r.status = 'LEFT' THEN
                RAISE_APPLICATION_ERROR(-20203, r.emp_name || ' has left, no salary');
            END IF;
            IF r.basic_salary < c_min_wage THEN
                RAISE_APPLICATION_ERROR(-20202,
                    r.emp_name || ': basic ' || r.basic_salary || ' below minimum wage ' || c_min_wage);
            END IF;

            v_house := r.basic_salary * c_house_pct;
            v_gross := r.basic_salary + v_house + c_medical + c_transport;
            v_ded   := ROUND(r.basic_salary / c_month_days * r.absent_days);

            INSERT INTO w16_salary
                   (salary_month, emp_id, basic_salary, house_rent, medical, transport,
                    gross_salary, absent_days, deduction, net_salary)
            VALUES (c_month, r.emp_id, r.basic_salary, v_house, c_medical, c_transport,
                    v_gross, r.absent_days, v_ded, v_gross - v_ded);

            v_ok    := v_ok + 1;
            v_total := v_total + (v_gross - v_ded);
        EXCEPTION
            WHEN e_left OR e_wage THEN
                DBMS_OUTPUT.PUT_LINE('Skipped: ' || SQLERRM);
                v_skip := v_skip + 1;
            WHEN OTHERS THEN
                v_code := SQLCODE;
                v_msg  := SQLERRM;
                v_bt   := DBMS_UTILITY.FORMAT_ERROR_BACKTRACE;
                ROLLBACK TO before_emp;
                INSERT INTO w17_error_log (module_name, error_code, error_msg, backtrace, context_info)
                VALUES ('PAYROLL', v_code, v_msg, v_bt, 'month=' || c_month || ', emp=' || r.emp_id);
                v_err := v_err + 1;
        END;
    END LOOP;

    COMMIT;
    DBMS_OUTPUT.PUT_LINE(v_ok || ' processed, ' || v_skip || ' skipped, ' || v_err || ' error(s)');
    DBMS_OUTPUT.PUT_LINE('Total net: ' || v_total);
END;
/
-- Skipped: ORA-20203: Tania has left, no salary
-- 9 processed, 1 skipped, 0 error(s)
-- Total net: 176090
```

**৬:** `COMMIT` রেখে চালালে Nasima-র ৭৫০০-ও সেভ হয়ে যেত, তাই `ROLLBACK`। ফল: `8 processed, 2 skipped`, Net ১৬০৫১৭ (১৭৬০৯০ − ১৫৫৭৩)।

এটাই ক্লাস ৮৫-এ বলা দুর্বলতা: প্রোগ্রামের `COMMIT` কলকারীর আগের কাজও সেভ করে। সপ্তাহ ১৮-তে Procedure বানানোর সময় নিয়ম হবে: `COMMIT` কলকারীর হাতে।

```sql
DECLARE
    c_limit   CONSTANT NUMBER := 20000;        -- কাদের বাড়বে
    c_pct     CONSTANT NUMBER := 1.00;         -- প্রথমে 0.05
    c_ceiling CONSTANT NUMBER := 20000;
    CURSOR c_inc IS
        SELECT emp_name, basic_salary FROM w16_emp
        WHERE  status = 'ACTIVE' AND basic_salary < c_limit
        ORDER  BY emp_id
        FOR UPDATE OF basic_salary;
    v_new NUMBER;

    FOR r IN c_inc LOOP
        v_new := ROUND(r.basic_salary * (1 + c_pct));
        IF v_new > c_ceiling THEN
            RAISE_APPLICATION_ERROR(-20205,
                'Increment would push ' || r.emp_name || ' to ' || v_new || ', above ' || c_ceiling);

        UPDATE w16_emp SET basic_salary = v_new WHERE CURRENT OF c_inc;
    END LOOP;

    ROLLBACK;
END;
```
