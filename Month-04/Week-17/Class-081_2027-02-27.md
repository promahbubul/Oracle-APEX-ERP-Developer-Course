## আজকে কী শিখব

- Exception কী, Compile Error থেকে কীভাবে আলাদা
- `EXCEPTION` অংশ: এরর হলে কোড কোন দিকে যায়
- না ধরা Exception-এ ডাটার কী হয়
- `NO_DATA_FOUND` বিস্তারিত
- `TOO_MANY_ROWS`, কয়েকটা `WHEN`, `WHEN a OR b`
- Predefined Exception-এর তালিকা

> সব কোড `learn_freepdb1`-এ। সপ্তাহ ১৪–১৬-এর টেবিল (`w14_stock`, `w16_emp`, `w16_salary`) আর লাইব্রেরির টেবিল লাগবে।

## ১. Exception কী (২৫ মিনিট)

দুই ধরনের এরর তুমি এ পর্যন্ত দেখেছ:

| ধরন | কখন ধরা পড়ে | উদাহরণ | কোড চলে? |
|---|---|---|---|
| **Compile Error** | চালানোর আগে, Oracle কোড পড়ার সময় | `PLS-00103` (সেমিকোলন নেই), `PLS-00201` (নাম নেই) | একদমই না |
| **Runtime Error** | চলার মাঝে | `ORA-01403` (রো নেই), `ORA-01476` (০ দিয়ে ভাগ) | এরর পর্যন্ত চলে, তারপর থামে |

Runtime Error-কে PL/SQL-এ বলে **Exception**। কোড ঠিক আছে, কিন্তু **ডাটা** যা ভেবেছিলে তেমন না।

ফ্যাক্টরির উদাহরণ:

| পরিস্থিতি | Exception |
|---|---|
| স্টোরকিপার ভুল আইটেম কোড দিল | রো নেই |
| দুইটা বায়ারের একই নাম | একাধিক রো |
| লাইনে আজ কোনো অপারেটর আসেনি, Efficiency-র ভাগে ০ | ০ দিয়ে ভাগ |
| একই স্টাইল নম্বর দুইবার সেভ | Duplicate |

এগুলো **ঘটবেই**। প্রশ্ন হলো ঘটলে প্রোগ্রাম লাল এরর দিয়ে মারা যাবে, নাকি ভদ্রভাবে বলবে "এই আইটেম কোড নেই, আবার দেখুন"।

### ব্লকের পুরো কাঠামো

ক্লাস ৬৬ থেকে:

```sql
DECLARE
    -- Variable, Cursor
BEGIN
    -- কাজ
EXCEPTION
    -- এরর হলে কী করবে
END;
/
```

`EXCEPTION` অংশ ঐচ্ছিক। এ সপ্তাহে এটাই আমাদের বিষয়।

## ২. EXCEPTION অংশ: কোড কোন দিকে যায় (৩৫ মিনিট)

```sql
SET SERVEROUTPUT ON

DECLARE
    v_name w16_emp.emp_name%TYPE;
BEGIN
    DBMS_OUTPUT.PUT_LINE('Step 1');
    SELECT emp_name INTO v_name FROM w16_emp WHERE emp_id = 99;   -- এখানে এরর
    DBMS_OUTPUT.PUT_LINE('Step 2');                                -- চলবে না
    DBMS_OUTPUT.PUT_LINE('Step 3');                                -- চলবে না
EXCEPTION
    WHEN NO_DATA_FOUND THEN
        DBMS_OUTPUT.PUT_LINE('Employee not found');
END;
/
```

```
Step 1
Employee not found
PL/SQL procedure successfully completed.
```

নিয়মগুলো:

1. এরর হওয়ার সাথে সাথে `BEGIN`-এর বাকি লাইন **বাদ**। সোজা `EXCEPTION`-এ লাফ।
2. মেলা `WHEN` খুঁজে সেটা চলে।
3. Handler শেষ হলে ব্লক **শেষ**। `BEGIN`-এ ফেরত যায় না।
4. ব্লক "সফলভাবে" শেষ হয়েছে, কারণ এরর ধরা হয়েছে।

ক্লাস ৭৩-এর `EXIT`-এর মতো ভাবো: একবার বের হলে Loop-এ আর ফেরা নেই।

### এরর না হলে

`emp_id = 1` দাও:

```
Step 1
Step 2
Step 3
```

`EXCEPTION` অংশ ছোঁয়াই হয় না।

### না ধরলে

`EXCEPTION` অংশ মুছে চালাও:

```
Step 1
ORA-01403: no data found
ORA-06512: at line 5
```

- `ORA-06512` বলছে কোন লাইনে হয়েছে। খুঁজতে খুব কাজের
- আগে ছাপানো `Step 1` সাধারণত দেখা যায়

### না ধরা Exception-এ ডাটার কী হয়

```sql
BEGIN
    UPDATE w14_stock SET balance_qty = balance_qty + 100 WHERE item_id = 1;
    DBMS_OUTPUT.PUT_LINE('Updated: ' || SQL%ROWCOUNT);

    UPDATE w14_stock SET balance_qty = balance_qty / 0 WHERE item_id = 2;   -- ORA-01476
END;
/

SELECT item_id, balance_qty FROM w14_stock WHERE item_id = 1;    -- 600, 700 না
```

**ব্লক না ধরা এরর দিয়ে শেষ হলে ব্লকের ভেতরের সব বদল Oracle ফেরত নেয়।** SQL Developer থেকে পুরো ব্লক একটা Statement, আর কোনো Statement ব্যর্থ হলে Oracle শুধু সেই Statement-এর কাজ বাতিল করে (একে বলে Statement-level Rollback)। আগের `COMMIT` না করা কাজ, যা এই ব্লকের আগে করেছিলে, তা থেকে যায়।

### ধরলে ডাটার কী হয়

```sql
BEGIN
    UPDATE w14_stock SET balance_qty = balance_qty + 100 WHERE item_id = 1;
    UPDATE w14_stock SET balance_qty = balance_qty / 0 WHERE item_id = 2;
EXCEPTION
    WHEN ZERO_DIVIDE THEN
        DBMS_OUTPUT.PUT_LINE('Division by zero');
END;
/

SELECT item_id, balance_qty FROM w14_stock WHERE item_id = 1;    -- 700!
ROLLBACK;
```

এবার প্রথম `UPDATE` রয়ে গেছে, `COMMIT` হয়নি কিন্তু বাতিলও হয়নি। **Exception ধরলে আগের কাজ কী হবে সেটা তোমার সিদ্ধান্ত।** সাধারণত:

```sql
EXCEPTION
    WHEN ZERO_DIVIDE THEN
        ROLLBACK;
        DBMS_OUTPUT.PUT_LINE('Division by zero, nothing saved');
```

এই পার্থক্যটা এই সপ্তাহের সবচেয়ে জরুরি কথা।

| | ব্লকের ভেতরের বদল |
|---|---|
| এরর ধরা হয়নি | Oracle নিজে বাতিল করে |
| এরর ধরা হয়েছে | যেমন ছিল থাকে, `ROLLBACK`/`COMMIT` তোমার হাতে |

## ৩. NO_DATA_FOUND (২৫ মিনিট)

`ORA-01403`। **`SELECT INTO` কোনো রো পায়নি।**

```sql
DECLARE
    v_qty w14_stock.balance_qty%TYPE;
    v_id  NUMBER := 9;
BEGIN
    SELECT balance_qty INTO v_qty FROM w14_stock WHERE item_id = v_id;
    DBMS_OUTPUT.PUT_LINE('Balance: ' || v_qty);
EXCEPTION
    WHEN NO_DATA_FOUND THEN
        DBMS_OUTPUT.PUT_LINE('Item ' || v_id || ' does not exist');
END;
/
```

### কোথায় আসে না

| কাজ | ০ রো-তে |
|---|---|
| `SELECT INTO` | **NO_DATA_FOUND** |
| `UPDATE`, `DELETE` | এরর না, `SQL%NOTFOUND` (ক্লাস ৭৬) |
| Explicit Cursor `FETCH` | এরর না, `c%NOTFOUND` (ক্লাস ৭৮) |
| Cursor FOR Loop | এরর না, Loop চলে না |
| `SELECT COUNT(*) INTO`, `SUM`, `MAX` | এরর না, Aggregate সবসময় ১টা রো দেয় |

`SELECT MAX(basic_salary) INTO v FROM w16_emp WHERE dept_name = 'Washing'` এরর দেয় না, `v` NULL হয়। অনেকে ভাবে NO_DATA_FOUND ধরে ফেলবে, কিন্তু ধরে না।

### Default মান দিয়ে চালিয়ে যাওয়া

কখনো রো না থাকাটাই স্বাভাবিক। যেমন কারো অনুপস্থিতির রো না থাকলে অনুপস্থিতি ০।

```sql
DECLARE
    v_days w16_absent.absent_days%TYPE;
BEGIN
    BEGIN
        SELECT absent_days INTO v_days
        FROM   w16_absent
        WHERE  emp_id = 1 AND absent_month = '2027-01';
    EXCEPTION
        WHEN NO_DATA_FOUND THEN
            v_days := 0;
    END;

    DBMS_OUTPUT.PUT_LINE('Absent days: ' || v_days);     -- 0
END;
/
```

ভেতরে একটা ছোট `BEGIN ... EXCEPTION ... END`। এতে এরর ধরে **বাইরের ব্লক চলতে থাকে**। এটাকে বলে Nested Block, কাল বিস্তারিত।

## ৪. TOO_MANY_ROWS আর কয়েকটা WHEN (৩০ মিনিট)

`ORA-01422`। **`SELECT INTO` একাধিক রো পেয়েছে।**

```sql
DECLARE
    v_name w16_emp.emp_name%TYPE;
BEGIN
    SELECT emp_name INTO v_name FROM w16_emp WHERE dept_name = 'Sewing';
EXCEPTION
    WHEN TOO_MANY_ROWS THEN
        DBMS_OUTPUT.PUT_LINE('More than one employee in Sewing, use a cursor');
END;
/
```

TOO_MANY_ROWS প্রায় সবসময় **ডিজাইনের ভুল** বোঝায়: `WHERE`-এ এমন কলাম যেটা Unique না। ধরা ভালো, কিন্তু আসল সমাধান হয় Primary Key দিয়ে খোঁজা, নয়তো Cursor।

### দুইটা একসাথে

```sql
DECLARE
    v_dept  VARCHAR2(30) := 'Store';     -- 'Sewing', 'Washing' দিয়েও চালাও
    v_name  w16_emp.emp_name%TYPE;
BEGIN
    SELECT emp_name INTO v_name
    FROM   w16_emp
    WHERE  dept_name = v_dept AND status = 'ACTIVE';

    DBMS_OUTPUT.PUT_LINE('Only staff: ' || v_name);
EXCEPTION
    WHEN NO_DATA_FOUND THEN
        DBMS_OUTPUT.PUT_LINE('No active staff in ' || v_dept);
    WHEN TOO_MANY_ROWS THEN
        DBMS_OUTPUT.PUT_LINE('Many staff in ' || v_dept);
END;
/
```

| `v_dept` | ফল |
|---|---|
| Store | `No active staff in Store` (Tania `LEFT`) |
| Sewing | `Many staff in Sewing` |
| Washing | `No active staff in Washing` |

যেকোনো একটা `WHEN`-ই চলে, যেটা মেলে। `CASE`-এর মতো (ক্লাস ৭২)।

### একই কাজে দুইটা

```sql
EXCEPTION
    WHEN NO_DATA_FOUND OR TOO_MANY_ROWS THEN
        DBMS_OUTPUT.PUT_LINE('Need exactly one employee');
```

### Predefined Exception: নাম আছে এমন এরর

Oracle কিছু সাধারণ এররের আগেই নাম দিয়ে রেখেছে:

| নাম | এরর | কখন |
|---|---|---|
| `NO_DATA_FOUND` | ORA-01403 | `SELECT INTO` কোনো রো পায়নি |
| `TOO_MANY_ROWS` | ORA-01422 | `SELECT INTO` একাধিক রো |
| `ZERO_DIVIDE` | ORA-01476 | ০ দিয়ে ভাগ |
| `DUP_VAL_ON_INDEX` | ORA-00001 | Primary Key / Unique-এ ডুপ্লিকেট |
| `VALUE_ERROR` | ORA-06502 | মান আঁটে না বা রূপান্তর হয় না |
| `INVALID_NUMBER` | ORA-01722 | SQL-এর ভেতরে লেখা থেকে সংখ্যা হয় না |
| `INVALID_CURSOR` | ORA-01001 | বন্ধ Cursor-এ `FETCH` (ক্লাস ৭৭) |
| `CURSOR_ALREADY_OPEN` | ORA-06511 | খোলা Cursor আবার `OPEN` |

প্রথম দুইটা আজ, পরের তিনটা কাল। বাকি হাজার হাজার ORA এররের নাম নেই, সেগুলো ক্লাস ৮৩-এ।

## ৫. হাতে-কলমে প্র্যাকটিস (৬৫ মিনিট)

সব `learn_freepdb1`-এ। টেবিল বদলালে শেষে `ROLLBACK`।

1. `emp_id` Variable-এ নিয়ে নাম আর বিভাগ ছাপাও। না পেলে `Employee n not found`। ৫ আর ৫০ দিয়ে চালাও।
2. `book_id` দিয়ে `lib_book`-এর শিরোনাম, না পেলে `Book not found`।
3. `w16_emp`-এ `dept_name` দিয়ে একজনের নাম আনো। দুইটা Exception আলাদা বার্তায়। Quality, Store, Washing দিয়ে পরীক্ষা।
4. ৩ নম্বর `WHEN ... OR ...` দিয়ে এক বার্তায়।
5. `SELECT MAX(basic_salary) INTO` দিয়ে Washing বিভাগের সর্বোচ্চ Basic আনো, `NO_DATA_FOUND` ধরো। Handler চলে? কী ছাপায়? (চলে না, ফাঁকা)
6. ৫ নম্বর ঠিক করো: NULL হলে `No staff` ছাপাও।
7. "Step 1/2/3" কোড চালাও তিনভাবে: এরর নেই, এরর ধরা, এরর না ধরা। আউটপুট খাতায় লেখো।
8. ক্লাসের "না ধরা Exception-এ ডাটার কী হয়" পরীক্ষাটা করো। আইটেম ১ কত? (৬০০)
9. ৮ নম্বরে Exception ধরো কিন্তু `ROLLBACK` দিও না। আইটেম ১ কত? (৭০০) তারপর `ROLLBACK`।
10. ৯ নম্বরের Handler-এ `ROLLBACK` যোগ করো, তারপর আইটেম ১ দেখো। (৬০০)
11. প্রতিটা কর্মচারীর জানুয়ারির অনুপস্থিতি Nested Block দিয়ে, না থাকলে ০। Cursor FOR-এর ভেতরে `SELECT INTO`। (Salma ২, Nasima ১, Habib ৩, বাকিরা ০)
12. `w16_salary` থেকে একজনের জানুয়ারির Net আনো। না পেলে `Salary not processed`। ৩ আর ১০ দিয়ে। (১৬৯৬৭; Tania-র নেই)

**গার্মেন্টস ও লাইব্রেরি:**

13. ব্যবহারকারী আইটেমের **নাম** দিয়ে খোঁজে (`item_name = v_name`)। রো নেই আর একাধিক, দুইটাই ধরো। `'Pique'` আর `'Rib'` দিয়ে।
14. `lib_member`-এ মোবাইল নম্বর দিয়ে মেম্বারের নাম খোঁজো। মোবাইল Unique, তাহলে কোন Exception কখনো আসবে না? কেন?

```sql
                v_days := 0;
        END;
        DBMS_OUTPUT.PUT_LINE(RPAD(r.emp_name, 10) || v_days);
    END LOOP;
END;
/

-- ১৩
DECLARE
    v_name w14_stock.item_name%TYPE := 'Pique';      -- তারপর 'Rib'
    v_qty  w14_stock.balance_qty%TYPE;
BEGIN
    SELECT balance_qty INTO v_qty FROM w14_stock WHERE item_name = v_name;
    DBMS_OUTPUT.PUT_LINE(v_name || ': ' || v_qty);              -- Pique: 180
EXCEPTION
    WHEN NO_DATA_FOUND THEN
        DBMS_OUTPUT.PUT_LINE('No item named ' || v_name);
    WHEN TOO_MANY_ROWS THEN
        DBMS_OUTPUT.PUT_LINE('Several items named ' || v_name || ', use item code');
END;
/
```

**১৪:** `TOO_MANY_ROWS`। `lib_member_mobile_uk` একই মোবাইল দুইবার ঢুকতেই দেয় না। Unique Constraint থাকলে ওই কলাম দিয়ে `SELECT INTO` সবচেয়ে বেশি ১টা রো দেয়।

**ভুল:**

- **১৫:** রো না পেলে `SELECT INTO` NULL দেয় না, এরর দেয়। `IF` পর্যন্ত যায়ই না। `EXCEPTION WHEN NO_DATA_FOUND` লাগবে।
- **১৬:** `'Done'` Handler-এর ভেতরেই আছে (পরের `WHEN` বা `END` পর্যন্ত সব Handler-এর অংশ), তাই এক্ষেত্রে ছাপায়। কিন্তু এরর না হলে ছাপাবে না। সবসময় ছাপাতে চাইলে `BEGIN`-এর শেষে আর Handler-এ দুই জায়গায় দাও, অথবা Nested Block।
- **১৭:** কোনো এরর নেই, কিন্তু Handler অকেজো। `COUNT(*)` কখনো NO_DATA_FOUND দেয় না। `0 staff` ছাপায়।

## সারাংশ

- Exception = চলার সময়ের এরর, কারণ সাধারণত ডাটা
- এরর হলে `BEGIN`-এর বাকি বাদ, মেলা `WHEN` চলে, তারপর ব্লক শেষ
- না ধরলে ব্লকের বদল বাতিল, ধরলে বদল থাকে, `ROLLBACK` তোমার কাজ
- `NO_DATA_FOUND`: শুধু `SELECT INTO`-তে, Aggregate বা `UPDATE`-এ না
- `TOO_MANY_ROWS`: সাধারণত `WHERE`-এর কলাম Unique না
- ভেতরের `BEGIN ... EXCEPTION ... END` এরর ধরে বাইরের কাজ চালিয়ে যায়

**পরের ক্লাস (রবিবার):** `ZERO_DIVIDE`, `DUP_VAL_ON_INDEX`, `VALUE_ERROR`, আর সব ধরার `OTHERS`।
