## ১. WHILE (৪০ মিনিট)

```sql
WHILE শর্ত LOOP
    কাজ;
END LOOP;
```

**শর্ত সত্য থাকা পর্যন্ত চলে।** প্রতিবার শুরুতে শর্ত দেখে।

```sql
DECLARE
    v_i NUMBER := 1;
BEGIN
    WHILE v_i <= 5 LOOP
        DBMS_OUTPUT.PUT_LINE(v_i);
        v_i := v_i + 1;
    END LOOP;
END;
/
```

```
v_i = 1: 1 <= 5 সত্য, চলে
v_i = 2: সত্য, চলে
...
v_i = 5: সত্য, চলে
v_i = 6: 6 <= 5 মিথ্যা, থামে
```

### শর্ত শুরুতেই মিথ্যা: একবারও চলে না

```sql
DECLARE
    v_i NUMBER := 100;
BEGIN
    WHILE v_i <= 5 LOOP
        DBMS_OUTPUT.PUT_LINE('Never');
        v_i := v_i + 1;
    END LOOP;

    DBMS_OUTPUT.PUT_LINE('Done');
END;
/
```

ফল শুধু `Done`।

### যোগফল

```sql
DECLARE
    v_i   NUMBER := 1;
    v_sum NUMBER := 0;
BEGIN
    WHILE v_i <= 100 LOOP
        v_sum := v_sum + v_i;
        v_i := v_i + 1;
    END LOOP;

    DBMS_OUTPUT.PUT_LINE('Sum: ' || v_sum);     -- 5050
END;
/
```

### অঙ্কের যোগফল

```sql
DECLARE
    v_n   NUMBER := 12345;
    v_sum NUMBER := 0;
BEGIN
    WHILE v_n > 0 LOOP
        v_sum := v_sum + MOD(v_n, 10);
        v_n := TRUNC(v_n / 10);
    END LOOP;

    DBMS_OUTPUT.PUT_LINE('Digit sum: ' || v_sum);     -- 15
END;
/
```

### লেখা উল্টানো

```sql
DECLARE
    v_text VARCHAR2(50) := 'Oracle';
    v_rev  VARCHAR2(50);
    v_pos  NUMBER;
BEGIN
    v_pos := LENGTH(v_text);

    WHILE v_pos >= 1 LOOP
        v_rev := v_rev || SUBSTR(v_text, v_pos, 1);
        v_pos := v_pos - 1;
    END LOOP;

    DBMS_OUTPUT.PUT_LINE(v_rev);     -- elcarO
END;
/
```

## ২. LOOP বনাম WHILE (২০ মিনিট)

| | `LOOP` | `WHILE` |
|---|---|---|
| শর্ত কোথায় | যেকোনো জায়গায়, `EXIT WHEN` | শুরুতে |
| কমপক্ষে কয়বার | ১ | ০ |
| শর্তের মানে | **থামার** শর্ত | **চলার** শর্ত |
| কখন | কাজের মাঝে থামার সিদ্ধান্ত | শুরুতেই পরীক্ষা |

শর্ত দুইটা উল্টো:

```sql
EXIT WHEN v_i > 5;        -- থামবে যখন বড়
WHILE v_i <= 5 LOOP       -- চলবে যখন ছোট বা সমান
```

### NULL শর্ত

```sql
DECLARE
    v_i NUMBER;       -- NULL
BEGIN
    WHILE v_i <= 5 LOOP
        DBMS_OUTPUT.PUT_LINE('Never');
    END LOOP;

    DBMS_OUTPUT.PUT_LINE('No error, no rows');
END;
/
```

শর্ত `NULL`, Loop চলে না, এরর আসে না। অদৃশ্য বাগ।

`LOOP`-এর উল্টো ফাঁদ: `EXIT WHEN v_i > 5`-এ `v_i` NULL হলে কখনো থামে না!

## ৩. ERP-র হিসাব (৪০ মিনিট)

### তারিখ ধরে Loop

তারিখেও `+ 1` চলে।

```sql
-- ফেব্রুয়ারি ২০২৭-এ শুক্রবার ছাড়া দিন: ২৪
DECLARE
    v_date  DATE := DATE '2027-02-01';
    v_end   DATE := LAST_DAY(DATE '2027-02-01');
    v_count NUMBER := 0;
BEGIN
    WHILE v_date <= v_end LOOP
        IF TO_CHAR(v_date, 'DY', 'NLS_DATE_LANGUAGE=ENGLISH') <> 'FRI' THEN
            v_count := v_count + 1;
        END IF;

        v_date := v_date + 1;
    END LOOP;

    DBMS_OUTPUT.PUT_LINE('Working days: ' || v_count);
END;
/
```

ক্লাস ৬২-এ `CONNECT BY` দিয়ে একই ফল পেয়েছিলে। সরকারি ছুটির টেবিল বাদ দেওয়ার মতো জটিল নিয়ম এলে Loop-এ লেখা সহজ, তবে SQL সাধারণত দ্রুত।

### প্রোডাকশন প্ল্যান

৫০০০ পিসের অর্ডার। লাইনের দৈনিক ক্ষমতা ১২০০। ২০ ফেব্রুয়ারি ২০২৭ (শনিবার) শুরু। শুক্রবার বন্ধ। কবে শেষ?

```sql
DECLARE
    c_daily_capacity CONSTANT NUMBER := 1200;
    v_remaining NUMBER := 5000;
    v_date      DATE := DATE '2027-02-20';
    v_today     NUMBER;
BEGIN
    WHILE v_remaining > 0 LOOP
        IF TO_CHAR(v_date, 'DY', 'NLS_DATE_LANGUAGE=ENGLISH') <> 'FRI' THEN
            v_today     := LEAST(v_remaining, c_daily_capacity);
            v_remaining := v_remaining - v_today;

            DBMS_OUTPUT.PUT_LINE(TO_CHAR(v_date, 'DD-Mon-YYYY Dy') || ' : '
                                 || v_today || ' pcs, left ' || v_remaining);
        END IF;

        v_date := v_date + 1;
    END LOOP;
END;
/
```

```
20-Feb-2027 Sat : 1200 pcs, left 3800
21-Feb-2027 Sun : 1200 pcs, left 2600
22-Feb-2027 Mon : 1200 pcs, left 1400
23-Feb-2027 Tue : 1200 pcs, left 200
24-Feb-2027 Wed : 200 pcs, left 0
```

**Planning মডিউলের ভিত্তি।** ক্যাপাসিটি, ছুটি, কতগুলো লাইন যোগ করলে এটাই বড় হয়। `IF` যদি `v_date := v_date + 1`-এর বাইরে না থাকত, তাহলে শুক্রবারে আটকে অসীম Loop হতো।

### শিপমেন্ট ভাগ

৩৫০০ পিস, এক কন্টেইনারে সর্বোচ্চ ১০০০:

```sql
DECLARE
    c_container CONSTANT NUMBER := 1000;
    v_remaining NUMBER := 3500;
    v_no        NUMBER := 0;
    v_load      NUMBER;
BEGIN
    WHILE v_remaining > 0 LOOP
        v_load := LEAST(v_remaining, c_container);
        v_no   := v_no + 1;
        DBMS_OUTPUT.PUT_LINE('Container ' || v_no || ': ' || v_load);
        v_remaining := v_remaining - v_load;
    END LOOP;
END;
/
```

৪টা কন্টেইনার: ১০০০, ১০০০, ১০০০, ৫০০।

### FIFO: পুরনো ব্যাচ থেকে ইস্যু

Store-এ আগে আসা মাল আগে দেওয়া হয়। ২৫০ কেজি ইস্যু, ব্যাচে ১০০, ৮০, ২০০:

```sql
DECLARE
    v_need   NUMBER := 250;
    v_batch1 NUMBER := 100;
    v_batch2 NUMBER := 80;
    v_batch3 NUMBER := 200;
    v_batch  NUMBER := 1;
    v_stock  NUMBER;
    v_take   NUMBER;
BEGIN
    WHILE v_need > 0 AND v_batch <= 3 LOOP
        v_stock := CASE v_batch WHEN 1 THEN v_batch1 WHEN 2 THEN v_batch2 ELSE v_batch3 END;
        v_take  := LEAST(v_need, v_stock);
        v_need  := v_need - v_take;

        DBMS_OUTPUT.PUT_LINE('Batch ' || v_batch || ': take ' || v_take);
        v_batch := v_batch + 1;
    END LOOP;

    DBMS_OUTPUT.PUT_LINE('Still need: ' || v_need);
END;
/
```

ব্যাচ ১: ১০০; ব্যাচ ২: ৮০; ব্যাচ ৩: ৭০; বাকি ০। আসল প্রজেক্টে ব্যাচগুলো টেবিলে থাকবে, আর Cursor দিয়ে ঘুরবে (সপ্তাহ ১৬)।

## ৪. ফাঁদ (২০ মিনিট)

### ফাঁদ ১: Variable না বাড়ানো

```sql
WHILE v_i <= 5 LOOP
    DBMS_OUTPUT.PUT_LINE(v_i);
    -- v_i := v_i + 1 ভুলে গেছ: অসীম Loop
END LOOP;
```

### ফাঁদ ২: IF-এর ভেতরে বাড়ানো

```sql
WHILE v_date <= v_end LOOP
    IF TO_CHAR(v_date, 'DY') <> 'FRI' THEN
        v_count := v_count + 1;
        v_date := v_date + 1;     -- শুক্রবারে বাড়ে না: অসীম Loop!
    END IF;
END LOOP;
```

**Loop-এর Variable বাড়ানোর লাইন সব পথে চলতে হবে।**

### ফাঁদ ৩: দশমিক তুলনা

```sql
DECLARE
    v_x NUMBER := 0;
BEGIN
    WHILE v_x <> 1 LOOP
        v_x := v_x + 0.3;       -- 0.3, 0.6, 0.9, 1.2, ... কখনো 1 না!
        EXIT WHEN v_x > 5;      -- নিরাপত্তা
    END LOOP;

    DBMS_OUTPUT.PUT_LINE(v_x);    -- 5.1
END;
/
```

`<>` দিয়ে থামানো বিপজ্জনক। `<` বা `<=` দাও।

### ফাঁদ ৪: কম বা বেশি একবার (Off-by-one)

```sql
WHILE v_i < 5 LOOP    -- ১, ২, ৩, ৪: ৫ আসে না
WHILE v_i <= 5 LOOP   -- ১, ২, ৩, ৪, ৫
```

`<` আর `<=` মিলিয়ে দেখো। ছোট সংখ্যা দিয়ে হাতে হিসাব করো।

```sql
    v_date      DATE := DATE '2027-03-24';
    v_holiday   NUMBER;
BEGIN
    WHILE v_remaining > 0 LOOP
        SELECT COUNT(*) INTO v_holiday FROM w15_holiday WHERE holiday_date = v_date;

        IF TO_CHAR(v_date, 'DY', 'NLS_DATE_LANGUAGE=ENGLISH') <> 'FRI' AND v_holiday = 0 THEN
            v_remaining := v_remaining - LEAST(v_remaining, c_daily_capacity);
            DBMS_OUTPUT.PUT_LINE(TO_CHAR(v_date, 'DD-Mon Dy') || ', left ' || v_remaining);
        END IF;

        v_date := v_date + 1;
    END LOOP;
END;
/
```

## সারাংশ

- `WHILE শর্ত LOOP ... END LOOP;`: চলার শর্ত, শুরুতে দেখে, ০ বারও চলতে পারে
- `LOOP` থামার শর্ত, `WHILE` চলার শর্ত
- তারিখে `+ 1`: প্ল্যানিং, কর্মদিবস গোনা
- `LEAST(বাকি, ক্ষমতা)`: ভাগ করার ছাঁচ
- Loop Variable সব পথে বদলাও। থামাতে `<>` না, `<`, `<=`

**পরের ক্লাস:** FOR LOOP, Nested Loop।
