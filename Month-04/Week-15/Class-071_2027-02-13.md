## ১. শর্ত (২০ মিনিট)

সপ্তাহ ১৪-এর ব্লক উপর থেকে নিচে সব লাইন চালায়। বাস্তবে সিদ্ধান্ত লাগে: **"স্টক থাকলে ইস্যু করো, নাহলে না।"**

শর্ত মানে এমন কিছু, যার উত্তর `TRUE`, `FALSE` বা `NULL`।

| শর্ত | উদাহরণ |
|---|---|
| তুলনা | `v_qty > 0`, `v_status = 'OPEN'`, `v_a <> v_b` |
| সীমা | `v_qty BETWEEN 1 AND 100` |
| তালিকা | `v_status IN ('OPEN', 'HOLD')` |
| লেখা | `v_name LIKE 'K%'` |
| NULL | `v_date IS NULL` |
| জোড়া | `v_a > 0 AND v_b > 0`, `NOT v_flag` |
| `BOOLEAN` | `v_is_late` |

সপ্তাহ ৬-এর `WHERE`-এর সব নিয়ম এখানেও চলে।

## ২. IF-THEN (২৫ মিনিট)

```sql
IF শর্ত THEN
    কাজ;
END IF;
```

```sql
DECLARE
    v_qty NUMBER := 6000;
BEGIN
    IF v_qty > 5000 THEN
        DBMS_OUTPUT.PUT_LINE('Bulk Order');
    END IF;

    DBMS_OUTPUT.PUT_LINE('Done');
END;
/
```

ফল: `Bulk Order`, তারপর `Done`। `v_qty` ৩০০০ করে আবার চালাও: শুধু `Done`।

**`END IF;`-এ `IF` আর `END` আলাদা শব্দ, শেষে `;`।** `IF`-এর পরে `THEN`, `THEN`-এর পরে `;` না।

### এক শর্তে কয়েকটা কাজ

```sql
DECLARE
    v_ship_date DATE := DATE '2027-02-10';
    v_days_late NUMBER;
BEGIN
    IF v_ship_date < DATE '2027-02-13' THEN
        v_days_late := DATE '2027-02-13' - v_ship_date;
        DBMS_OUTPUT.PUT_LINE('Shipment delayed');
        DBMS_OUTPUT.PUT_LINE('Days late: ' || v_days_late);       -- 3
    END IF;
END;
/
```

### BOOLEAN

ক্লাস ৬৭-এ `BOOLEAN` সরাসরি দেখানো যায়নি। `IF`-এই এর আসল ব্যবহার।

```sql
DECLARE
    v_is_rush BOOLEAN := TRUE;
BEGIN
    IF v_is_rush THEN
        DBMS_OUTPUT.PUT_LINE('Rush order: Priority line');
    END IF;
END;
/
```

`IF v_is_rush = TRUE`-ও চলে, কিন্তু দরকার নেই।

## ৩. IF-THEN-ELSE (২৫ মিনিট)

```sql
IF শর্ত THEN
    সত্য হলে;
ELSE
    বাকি সব ক্ষেত্রে;
END IF;
```

```sql
DECLARE
    v_balance NUMBER := 60;
    v_need    NUMBER := 100;
BEGIN
    IF v_balance >= v_need THEN
        DBMS_OUTPUT.PUT_LINE('Issue OK');
    ELSE
        DBMS_OUTPUT.PUT_LINE('Short by ' || (v_need - v_balance));    -- Short by 40
    END IF;
END;
/
```

`ELSE`-এর পরে `THEN` বা `;` না।

### জোড়, বিজোড়

```sql
DECLARE
    v_number NUMBER := 7;
BEGIN
    IF MOD(v_number, 2) = 0 THEN
        DBMS_OUTPUT.PUT_LINE(v_number || ' is even');
    ELSE
        DBMS_OUTPUT.PUT_LINE(v_number || ' is odd');
    END IF;
END;
/
```

### AND, OR

```sql
DECLARE
    v_status VARCHAR2(10) := 'OPEN';
    v_qty    NUMBER := 5000;
BEGIN
    IF v_status = 'OPEN' AND v_qty > 1000 THEN
        DBMS_OUTPUT.PUT_LINE('Can plan');
    ELSE
        DBMS_OUTPUT.PUT_LINE('Cannot plan');
    END IF;
END;
/
```

### Nested IF

```sql
DECLARE
    v_status  VARCHAR2(10) := 'OPEN';
    v_balance NUMBER := 40;
BEGIN
    IF v_status = 'OPEN' THEN
        IF v_balance > 0 THEN
            DBMS_OUTPUT.PUT_LINE('Issue');
        ELSE
            DBMS_OUTPUT.PUT_LINE('No stock');
        END IF;
    ELSE
        DBMS_OUTPUT.PUT_LINE('Order closed');
    END IF;
END;
/
```

প্রতিটা `IF`-এর নিজের `END IF;`। কোড ভেতরে সরিয়ে লিখলে (Indent) গোনা সহজ হয়।

## ৪. NULL-এর ফাঁদ (২০ মিনিট)

**শর্ত `NULL` হলে `IF` চলে না, `ELSE`-এ যায়।**

```sql
DECLARE
    v_commission NUMBER;     -- NULL
BEGIN
    IF v_commission > 0 THEN
        DBMS_OUTPUT.PUT_LINE('Has commission');
    ELSE
        DBMS_OUTPUT.PUT_LINE('No commission');
    END IF;

    IF NOT (v_commission > 0) THEN
        DBMS_OUTPUT.PUT_LINE('Not positive');
    ELSE
        DBMS_OUTPUT.PUT_LINE('Positive?');
    END IF;
END;
/
```

ফল:

```
No commission
Positive?
```

দ্বিতীয়টা অবাক করে! `NOT NULL` অজানাই থাকে, সত্য হয় না। তাই `ELSE`-এ যায়, আর "Positive?" দেখায়, যা ভুল।

```sql
-- ভুল: সবসময় ELSE
IF v_x = NULL THEN

-- ঠিক
IF v_x IS NULL THEN
```

**নিয়ম:**

- NULL হতে পারে এমন Variable আগে `IS NULL` দিয়ে দেখো, অথবা `NVL` দাও
- `ELSE` মানে "মিথ্যা" না, মানে **"সত্য না"**: মিথ্যা **অথবা অজানা**

```sql
IF NVL(v_commission, 0) > 0 THEN
```

## ৫. ERP-র যাচাই (৩৫ মিনিট)

### স্টক যাচাই করে ইস্যু

ক্লাস ৭০-এ Check Constraint আটকাত, আর ইউজার দেখত `ORA-02290`। এবার নিজে যাচাই করে পরিষ্কার বার্তা।

```sql
DECLARE
    v_item_id w14_stock.item_id%TYPE := 2;
    v_qty     w14_txn.qty%TYPE := 40;
    v_balance w14_stock.balance_qty%TYPE;
BEGIN
    SELECT balance_qty INTO v_balance FROM w14_stock WHERE item_id = v_item_id;

    IF v_qty > v_balance THEN
        DBMS_OUTPUT.PUT_LINE('Not enough stock. Available: ' || v_balance);
    ELSE
        INSERT INTO w14_txn (item_id, txn_type, qty) VALUES (v_item_id, 'ISSUE', v_qty);

        UPDATE w14_stock
        SET    balance_qty = balance_qty - v_qty
        WHERE  item_id = v_item_id;

        DBMS_OUTPUT.PUT_LINE('Issued. New balance: ' || (v_balance - v_qty));    -- 20
    END IF;

    ROLLBACK;     -- পরীক্ষা, ডাটা আগের মতো রাখছি
END;
/
```

`v_qty` ৫০০ করে চালাও: `Not enough stock. Available: 60`।

> **সতর্কতা:** যাচাই আর আপডেটের মাঝখানে অন্য কেউ একই স্টক নিয়ে নিতে পারে। এজন্য `SELECT ... FOR UPDATE` লাগে (ক্লাস ৮০)। আর Check Constraint শেষ রক্ষা হিসেবে থাকে।

### রো আছে কি না

```sql
DECLARE
    v_book_id lib_book.book_id%TYPE := 9999;
    v_count   NUMBER;
BEGIN
    SELECT COUNT(*) INTO v_count FROM lib_book WHERE book_id = v_book_id;

    IF v_count = 0 THEN
        DBMS_OUTPUT.PUT_LINE('Book not found');
    ELSE
        DBMS_OUTPUT.PUT_LINE('Book exists');
    END IF;
END;
/
```

### UPDATE কাজ করেছে কি না

ক্লাস ৭০-এর সবচেয়ে সাধারণ বাগের সমাধান:

```sql
DECLARE
    v_note_id w14_note.note_id%TYPE := 999999;
BEGIN
    UPDATE w14_note SET note_text = 'New text' WHERE note_id = v_note_id;

    IF SQL%ROWCOUNT = 0 THEN
        DBMS_OUTPUT.PUT_LINE('Note not found, nothing changed');
    ELSE
        DBMS_OUTPUT.PUT_LINE('Saved');
    END IF;

    ROLLBACK;
END;
/
```

`SQL%NOTFOUND` দিয়েও লেখা যায়: `IF SQL%NOTFOUND THEN`।

### মেম্বার বই নিতে পারবেন?

```sql
DECLARE
    v_member_id lib_member.member_id%TYPE := 10;
    v_active    lib_member.is_active%TYPE;
BEGIN
    SELECT is_active INTO v_active FROM lib_member WHERE member_id = v_member_id;

    IF v_active = 'Y' THEN
        DBMS_OUTPUT.PUT_LINE('Can borrow');
    ELSE
        DBMS_OUTPUT.PUT_LINE('Member is inactive');      -- মেম্বার ১০
    END IF;
END;
/
```

### সাধারণ এরর

| ভুল | ঠিক |
|---|---|
| `IF v_a > 0` (`THEN` নেই) | `IF v_a > 0 THEN` |
| `ENDIF;` | `END IF;` |
| `IF v_a := 1 THEN` | `IF v_a = 1 THEN` |
| `IF v_a = 1 THEN;` | `;` না |
| `SELECT ... IF` | `IF`-এর ভেতরে SQL চলে, SQL-এর ভেতরে `IF` চলে না |

SQL-এর ভেতরে শর্ত `CASE` দিয়ে (ক্লাস ৩৭)। আর `IF (SELECT COUNT(*) ...) > 0` Oracle-এ চলে না, আগে `SELECT INTO`।

## ৬. হাতে-কলমে প্র্যাকটিস (৫৫ মিনিট)

1. `v_age` = ১৭: ১৮-র কম হলে `Not eligible`, নাহলে `Eligible`। (গার্মেন্টসে নিয়োগের ন্যূনতম বয়স।)
2. `v_number`: ধনাত্মক হলে `Positive`, নাহলে `Not positive`। `0` দিয়ে পরীক্ষা করো।
3. `v_year`: অধিবর্ষ কি না। (`MOD`, ৪ দিয়ে ভাগ যায়, ১০০ দিয়ে যায় না, অথবা ৪০০ দিয়ে যায়।) ২০২৮, ১৯০০, ২০০০ দিয়ে পরীক্ষা করো।
4. `v_produced`, `v_target`: টার্গেট পূরণ হলে `Target Achieved`, নাহলে `Short by n`।
5. `w5_order`-এর `ORD-501`-এর স্ট্যাটাস `OPEN` হলে `Can Ship`।
6. `lib_book_copy`-র `BC-0012`-এর অবস্থা `AVAILABLE` হলে `Can issue`, নাহলে `Not available: ...`। (ISSUED)
7. `lib_book_issue`-র ইস্যু ২: দেরি হলে কত দিন আর কত জরিমানা, দিনে ৫ টাকা। (৪, ২০)
8. ইস্যু ১৬: ফেরত এসেছে কি না। (NULL)
9. `w14_stock`-এ Pique ৫০ কেজি ইস্যু: যথেষ্ট হলে Transaction, নাহলে বার্তা। `ROLLBACK` দিয়ে শেষ।
10. `w14_note`-এ নেই এমন ID `UPDATE`, `SQL%ROWCOUNT` দিয়ে বার্তা।
11. `v_x` NULL রেখে `IF v_x = NULL`, `IF v_x IS NULL`, `IF v_x <> 1` দেখো। কোনটা কী দেখাল?
12. মেম্বার ১-এর ধরন ধরে সীমা: `lib_member_type.max_books`-এর চেয়ে কম বই বাইরে থাকলে `Can borrow`।

## সারাংশ

- `IF শর্ত THEN ... ELSE ... END IF;`
- শর্ত `WHERE`-এর মতোই। `BOOLEAN` সরাসরি
- NULL শর্ত `ELSE`-এ যায়: `ELSE` মানে "সত্য না"
- `SELECT INTO`, তারপর `IF`, তারপর DML: ERP-র নিয়মের ছাঁচ
- `UPDATE`-এর পরে `SQL%ROWCOUNT` দেখো

**পরের ক্লাস:** IF-ELSIF, CASE Statement।
