## ১. FOR LOOP (৪০ মিনিট)

**কতবার চলবে আগে জানা থাকলে** এটাই সহজ।

```sql
FOR i IN শুরু..শেষ LOOP
    কাজ;
END LOOP;
```

```sql
BEGIN
    FOR i IN 1..5 LOOP
        DBMS_OUTPUT.PUT_LINE(i);
    END LOOP;
END;
/
```

- `i` **ঘোষণা করতে হয় না**
- `i` নিজে বাড়ে, প্রতিবার ১ করে
- `..` দুইটা ডট, মাঝে স্পেস ছাড়া বা সহ

`LOOP`-এর ৩টা জিনিস (শুরুর মান, বদল, থামার শর্ত) এক লাইনে। তাই **অসীম Loop-এর ভয় প্রায় নেই।**

### উল্টো

```sql
BEGIN
    FOR i IN REVERSE 1..5 LOOP
        DBMS_OUTPUT.PUT_LINE(i);       -- 5, 4, 3, 2, 1
    END LOOP;
END;
/
```

**`REVERSE 5..1` না!** ছোটটা সবসময় আগে। `FOR i IN 5..1` একবারও চলে না, এররও দেয় না।

### Loop Variable-এর নিয়ম

```sql
BEGIN
    FOR i IN 1..3 LOOP
        i := 10;     -- PLS-00363: i-তে মান দেওয়া যায় না
    END LOOP;
END;
/
```

```sql
BEGIN
    FOR i IN 1..3 LOOP
        NULL;
    END LOOP;

    DBMS_OUTPUT.PUT_LINE(i);     -- PLS-00201: Loop-এর বাইরে i নেই
END;
/
```

বাইরে দরকার হলে নিজের Variable-এ রাখো।

### ধাপ

প্রতিবার ১ করেই বাড়ে। ২ করে বাড়াতে:

```sql
-- ২, ৪, ৬, ৮, ১০
BEGIN
    FOR i IN 1..5 LOOP
        DBMS_OUTPUT.PUT_LINE(i * 2);
    END LOOP;
END;
/
```

অথবা `MOD` দিয়ে `CONTINUE`:

```sql
BEGIN
    FOR i IN 1..10 LOOP
        CONTINUE WHEN MOD(i, 2) <> 0;
        DBMS_OUTPUT.PUT_LINE(i);
    END LOOP;
END;
/
```

> নতুন ভার্সনে (21c থেকে) `FOR i IN 1..10 BY 2 LOOP`-ও চলে।

### সীমা Variable বা হিসাব থেকে

```sql
DECLARE
    v_days NUMBER;
BEGIN
    SELECT EXTRACT(DAY FROM LAST_DAY(SYSDATE)) INTO v_days FROM dual;

    FOR i IN 1..v_days LOOP
        DBMS_OUTPUT.PUT_LINE('Day ' || i);
    END LOOP;
END;
/
```

সীমা **একবারই** হিসাব হয়, শুরুতে। ভেতরে `v_days` বদলালেও Loop বদলায় না।

সীমা NULL হলে `ORA-06502`।

### কাজের উদাহরণ

```sql
-- নামতা
BEGIN
    FOR i IN 1..10 LOOP
        DBMS_OUTPUT.PUT_LINE('7 x ' || i || ' = ' || 7 * i);
    END LOOP;
END;
/

-- যোগফল: 5050
DECLARE
    v_sum NUMBER := 0;
BEGIN
    FOR i IN 1..100 LOOP
        v_sum := v_sum + i;
    END LOOP;
    DBMS_OUTPUT.PUT_LINE(v_sum);
END;
/

-- Factorial: 120
DECLARE
    v_result NUMBER := 1;
BEGIN
    FOR i IN 2..5 LOOP
        v_result := v_result * i;
    END LOOP;
    DBMS_OUTPUT.PUT_LINE(v_result);
END;
/
```

### এগিয়ে দেখো: টেবিলের রো ধরে

`FOR` সংখ্যার পাশাপাশি **কোয়েরির রো** ধরেও চলে। ক্লাস ৭৯-এ বিস্তারিত, এখন শুধু দেখো:

```sql
BEGIN
    FOR rec IN (SELECT book_title FROM lib_book WHERE category_id = 2) LOOP
        DBMS_OUTPUT.PUT_LINE(rec.book_title);
    END LOOP;
END;
/
```

## ২. Nested Loop (৩০ মিনিট)

Loop-এর ভেতরে Loop। ভেতরেরটা পুরো চলে, তারপর বাইরেরটা এক ধাপ এগোয়।

```sql
BEGIN
    FOR i IN 1..3 LOOP
        FOR j IN 1..2 LOOP
            DBMS_OUTPUT.PUT_LINE('i=' || i || ', j=' || j);
        END LOOP;
    END LOOP;
END;
/
```

৩ × ২ = ৬ লাইন। ক্লাস ৪৩-এর `CROSS JOIN`-এর মতো।

### নামতার ছক

```sql
BEGIN
    FOR n IN 2..4 LOOP
        DBMS_OUTPUT.PUT_LINE('--- Table of ' || n || ' ---');
        FOR i IN 1..3 LOOP
            DBMS_OUTPUT.PUT_LINE(n || ' x ' || i || ' = ' || n * i);
        END LOOP;
    END LOOP;
END;
/
```

### আকৃতি

```sql
-- *
-- **
-- ***
-- ****
BEGIN
    FOR i IN 1..4 LOOP
        FOR j IN 1..i LOOP
            DBMS_OUTPUT.PUT('*');
        END LOOP;
        DBMS_OUTPUT.NEW_LINE;
    END LOOP;
END;
/
```

ইন্টারভিউয়ের পছন্দের প্রশ্ন। ভেতরের Loop-এর সীমা বাইরের Variable থেকে আসছে।

### Label: বাইরের Loop থেকে বের হওয়া

```sql
BEGIN
    <<outer_loop>>
    FOR i IN 1..3 LOOP
        FOR j IN 1..3 LOOP
            DBMS_OUTPUT.PUT_LINE(i || ',' || j);
            EXIT outer_loop WHEN i = 2 AND j = 1;
        END LOOP;
    END LOOP outer_loop;
END;
/
```

`EXIT` একা শুধু ভেতরের Loop থেকে বের হয়। `EXIT outer_loop` দুইটা থেকেই। `CONTINUE outer_loop`-ও চলে।

### কত রো: খেয়াল রাখো

১০০০ × ১০০০ = ১০ লাখ বার। ভেতরে SQL থাকলে অনেক ধীর। ভেতরে `SELECT` না রেখে JOIN করা যায় কি না, আগে ভাবো। সপ্তাহ ২১-এ দেখবে।

## ৩. টেবিলে রো বানানো (৩০ মিনিট)

**ERP-র বাস্তব কাজ।** প্রতিটা লাইনের প্রতিটা ঘণ্টার জন্য খালি রো, যাতে ইউজার শুধু সংখ্যা বসায়। প্রজেক্ট ৩-এ লাগবে।

```sql
CREATE TABLE w15_hourly (
    entry_date  DATE,
    line_id     NUMBER(3),
    hour_no     NUMBER(2),
    target_qty  NUMBER(6) DEFAULT 120 NOT NULL,
    actual_qty  NUMBER(6),
    CONSTRAINT w15_hourly_pk PRIMARY KEY (entry_date, line_id, hour_no)
);
```

```sql
-- ৩টা লাইন × ৮ ঘণ্টা = ২৪টা রো
DECLARE
    v_date  DATE := DATE '2027-02-17';
    v_count NUMBER := 0;
BEGIN
    FOR v_line IN 1..3 LOOP
        FOR v_hour IN 1..8 LOOP
            INSERT INTO w15_hourly (entry_date, line_id, hour_no)
            VALUES (v_date, v_line, v_hour);

            v_count := v_count + 1;
        END LOOP;
    END LOOP;

    COMMIT;

    DBMS_OUTPUT.PUT_LINE(v_count || ' rows');     -- 24
END;
/

SELECT line_id, COUNT(*), SUM(target_qty)
FROM   w15_hourly
GROUP  BY line_id
ORDER  BY line_id;
```

প্রতি লাইনে ৮ রো, টার্গেট ৯৬০।

### মাসের ক্যালেন্ডার টেবিল

```sql
CREATE TABLE w15_calendar (
    cal_date  DATE CONSTRAINT w15_calendar_pk PRIMARY KEY,
    day_name  VARCHAR2(10) NOT NULL,
    is_work   CHAR(1) NOT NULL
);
```

```sql
-- ফেব্রুয়ারি ২০২৭: ২৮ দিন
DECLARE
    v_start DATE := DATE '2027-02-01';
    v_date  DATE;
    v_day   VARCHAR2(10);
BEGIN
    FOR i IN 0..27 LOOP
        v_date := v_start + i;
        v_day  := TO_CHAR(v_date, 'fmDay', 'NLS_DATE_LANGUAGE=ENGLISH');

        INSERT INTO w15_calendar (cal_date, day_name, is_work)
        VALUES (v_date, v_day, CASE WHEN v_day = 'Friday' THEN 'N' ELSE 'Y' END);
    END LOOP;

    COMMIT;
END;
/

-- Y 24, N 4
SELECT is_work, COUNT(*) FROM w15_calendar GROUP BY is_work;
```

> **আগে ভাবো:** এটা SQL দিয়েও হয়: `INSERT ... SELECT ... CONNECT BY LEVEL`। এক কমান্ডে, আর অনেক দ্রুত। বড় ডাটায় SQL বেছে নাও। Loop তখন, যখন প্রতি রো-তে জটিল সিদ্ধান্ত থাকে। সপ্তাহ ২১-এর পরীক্ষায় গতির তফাত দেখবে।

```sql
-- একই কাজ, এক লাইনের ধারণা
INSERT INTO w15_hourly (entry_date, line_id, hour_no)
SELECT DATE '2027-02-18', l.n, h.n
FROM  (SELECT LEVEL AS n FROM dual CONNECT BY LEVEL <= 3) l
CROSS JOIN (SELECT LEVEL AS n FROM dual CONNECT BY LEVEL <= 8) h;

SELECT COUNT(*) FROM w15_hourly WHERE entry_date = DATE '2027-02-18';     -- 24

ROLLBACK;
```

## ৪. তিনটার তুলনা (১৫ মিনিট)

| | `LOOP` | `WHILE` | `FOR` |
|---|---|---|---|
| কখন | থামার সিদ্ধান্ত ভেতরে | শর্ত সত্য থাকা পর্যন্ত | **কতবার জানা** |
| কমপক্ষে | ১ বার | ০ বার | ০ বার |
| Variable ঘোষণা | তুমি | তুমি | নিজে থেকে |
| বাড়ানো | তুমি | তুমি | নিজে থেকে |
| অসীম Loop-এর ঝুঁকি | আছে | আছে | প্রায় নেই |

**সিদ্ধান্তের ক্রম:**

1. কতবার জানা আছে? → `FOR`
2. প্রতিটা রো ধরে? → Cursor `FOR` (ক্লাস ৭৯)
3. জানা নেই, শুরুতেই শর্ত? → `WHILE`
4. জানা নেই, মাঝে বা শেষে সিদ্ধান্ত? → `LOOP`

## ৬. হোমওয়ার্ক

## সারাংশ

- `FOR i IN 1..n LOOP`: কতবার জানা থাকলে
- `i` নিজে আসে, শুধু Loop-এর ভেতরে, পড়ার জন্য
- উল্টো: `REVERSE 1..n`, ছোটটা আগে
- Nested Loop: ভেতরেরটা পুরো চলে, Label দিয়ে দুইটা থেকে বের হওয়া যায়
- খালি রো বানানো ERP-তে বাস্তব কাজ। বড় ডাটায় SQL আগে ভাবো
