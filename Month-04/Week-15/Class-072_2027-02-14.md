## ১. IF-ELSIF (৪০ মিনিট)

দুইয়ের বেশি পথ থাকলে।

```sql
IF শর্ত১ THEN
    ...
ELSIF শর্ত২ THEN
    ...
ELSIF শর্ত৩ THEN
    ...
ELSE
    ...
END IF;
```

**বানান `ELSIF`,** `ELSEIF` বা `ELSE IF` না। এটা সবচেয়ে সাধারণ টাইপো। `ELSEIF` লিখলে `PLS-00103`।

```sql
-- পরীক্ষার গ্রেড
DECLARE
    v_marks NUMBER := 75;
    v_grade VARCHAR2(5);
BEGIN
    IF v_marks >= 80 THEN
        v_grade := 'A+';
    ELSIF v_marks >= 70 THEN
        v_grade := 'A';
    ELSIF v_marks >= 60 THEN
        v_grade := 'A-';
    ELSIF v_marks >= 50 THEN
        v_grade := 'B';
    ELSIF v_marks >= 40 THEN
        v_grade := 'C';
    ELSIF v_marks >= 33 THEN
        v_grade := 'D';
    ELSE
        v_grade := 'F';
    END IF;

    DBMS_OUTPUT.PUT_LINE('Grade: ' || v_grade);       -- A
END;
/
```

**প্রথম সত্য শর্তে থামে।** ক্লাস ৩৭-এর `CASE`-এর মতো, তাই ক্রম জরুরি। `v_marks >= 33` আগে লিখলে ৭৫-ও `D` হতো। আর `v_marks >= 70 AND v_marks < 80` লেখার দরকার নেই, আগের শর্ত পার হওয়াই মানে ৮০-র কম।

### Efficiency-র রেটিং

```sql
DECLARE
    v_produced  NUMBER := 1200;
    v_smv       NUMBER := 15;
    v_operators NUMBER := 40;
    v_hours     NUMBER := 8;
    v_eff       NUMBER;
    v_rating    VARCHAR2(20);
BEGIN
    v_eff := ROUND(v_produced * v_smv / (v_operators * v_hours * 60) * 100, 2);

    IF v_eff >= 90 THEN
        v_rating := 'Excellent';
    ELSIF v_eff >= 75 THEN
        v_rating := 'Good';
    ELSIF v_eff >= 60 THEN
        v_rating := 'Average';
    ELSE
        v_rating := 'Poor';
    END IF;

    DBMS_OUTPUT.PUT_LINE(v_eff || '% : ' || v_rating);       -- 93.75% : Excellent
END;
/
```

## ২. Simple CASE (২৫ মিনিট)

একটা মানকে কয়েকটার সাথে মেলানো।

```sql
CASE মান
    WHEN মান১ THEN কাজ;
    WHEN মান২ THEN কাজ;
    ELSE কাজ;
END CASE;
```

```sql
DECLARE
    v_status VARCHAR2(20) := 'SHIPPED';
BEGIN
    CASE v_status
        WHEN 'OPEN' THEN
            DBMS_OUTPUT.PUT_LINE('Order is running');
        WHEN 'SHIPPED' THEN
            DBMS_OUTPUT.PUT_LINE('Order delivered');
        WHEN 'CANCELLED' THEN
            DBMS_OUTPUT.PUT_LINE('Order cancelled');
        ELSE
            DBMS_OUTPUT.PUT_LINE('Unknown status');
    END CASE;
END;
/
```

**`END CASE;`,** শুধু `END` না। প্রতিটা `THEN`-এর পরে সম্পূর্ণ স্টেটমেন্ট, শেষে `;`।

## ৩. Searched CASE (২৫ মিনিট)

`CASE`-এর পরে কিছু না, প্রতিটা `WHEN`-এ পুরো শর্ত।

```sql
DECLARE
    v_efficiency NUMBER := 82;
    v_incentive  NUMBER;
BEGIN
    CASE
        WHEN v_efficiency >= 90 THEN
            v_incentive := 1000;
        WHEN v_efficiency >= 80 THEN
            v_incentive := 500;
        WHEN v_efficiency >= 70 THEN
            v_incentive := 200;
        ELSE
            v_incentive := 0;
    END CASE;

    DBMS_OUTPUT.PUT_LINE('Incentive: ' || v_incentive);      -- 500
END;
/
```

`IF-ELSIF`-এর সাথে কাজ একই।

### CASE_NOT_FOUND

**`CASE` Statement-এ কোনো `WHEN` না মিললে আর `ELSE` না থাকলে এরর।** `IF`-এর সাথে এখানেই পার্থক্য।

```sql
DECLARE
    v_status VARCHAR2(20) := 'HOLD';
BEGIN
    CASE v_status
        WHEN 'OPEN' THEN
            DBMS_OUTPUT.PUT_LINE('Running');
        WHEN 'SHIPPED' THEN
            DBMS_OUTPUT.PUT_LINE('Delivered');
    END CASE;
END;
/
```

```
ORA-06592: CASE not found while executing CASE statement
```

এটা **ভালো** জিনিসও হতে পারে: নতুন স্ট্যাটাস এলে এরর দিয়ে জানায়। "কিছু করার নেই" বোঝাতে `ELSE NULL;` লেখো।

## ৪. Statement নাকি Expression (২০ মিনিট)

দুইটা দেখতে এক রকম, আলাদা জিনিস।

| | `CASE` Statement | `CASE` Expression |
|---|---|---|
| শেষ | **`END CASE;`** | **`END`** |
| কী করে | কাজ করে | **মান দেয়** |
| `THEN`-এর পরে | স্টেটমেন্ট, `;` সহ | মান, `;` ছাড়া |
| কোথায় | PL/SQL | PL/SQL আর SQL |
| না মিললে | **এরর** | **NULL** |

```sql
DECLARE
    v_status VARCHAR2(20) := 'SHIPPED';
    v_label  VARCHAR2(30);
BEGIN
    -- Expression: মান দেয়, ছোট আর পরিষ্কার
    v_label := CASE v_status
                   WHEN 'OPEN'    THEN 'Running'
                   WHEN 'SHIPPED' THEN 'Delivered'
                   ELSE 'Other'
               END;

    DBMS_OUTPUT.PUT_LINE(v_label);
END;
/
```

**সুপারিশ:** শুধু একটা মান বসানোর জন্য Expression। শর্তে একাধিক কাজ থাকলে `IF` বা Statement।

### কোনটা কখন

| পরিস্থিতি | ব্যবহার |
|---|---|
| ২টা পথ | `IF-ELSE` |
| অনেক শর্ত, সীমা | `IF-ELSIF` বা Searched `CASE` |
| একটা মানের অনেক অবস্থা | Simple `CASE` |
| শুধু মান বসানো | `CASE` Expression |
| SQL-এর ভেতরে | `CASE` Expression |

## ৫. ERP-র নিয়ম (২০ মিনিট)

### TNA-র অবস্থা

ক্লাস ৩৭-এর হোমওয়ার্কের নিয়ম:

```sql
DECLARE
    v_plan   DATE := DATE '2027-02-10';
    v_actual DATE;
    v_status VARCHAR2(20);
BEGIN
    IF v_actual IS NULL AND v_plan < TRUNC(SYSDATE) THEN
        v_status := 'DELAYED';
    ELSIF v_actual IS NULL THEN
        v_status := 'PENDING';
    ELSIF v_actual > v_plan THEN
        v_status := 'DONE LATE';
    ELSE
        v_status := 'DONE';
    END IF;

    DBMS_OUTPUT.PUT_LINE(v_status);
END;
/
```

### কাজের ধরন ধরে ভিন্ন কাজ

```sql
DECLARE
    v_txn_type VARCHAR2(10) := 'ISSUE';
    v_item_id  w14_stock.item_id%TYPE := 1;
    v_qty      NUMBER := 100;
BEGIN
    CASE v_txn_type
        WHEN 'RECEIVE' THEN
            UPDATE w14_stock SET balance_qty = balance_qty + v_qty WHERE item_id = v_item_id;
        WHEN 'ISSUE' THEN
            UPDATE w14_stock SET balance_qty = balance_qty - v_qty WHERE item_id = v_item_id;
    END CASE;

    DBMS_OUTPUT.PUT_LINE(SQL%ROWCOUNT || ' row(s)');

    ROLLBACK;
END;
/
```

`IF`-এ `ELSE` না দিলে ভুল টাইপ চুপচাপ পার হয়ে যেত। `CASE`-এ এরর আসবে।

## ৬. হাতে-কলমে প্র্যাকটিস (৫০ মিনিট)

1. গ্রেড: নম্বর ৮৫, ৭০, ৬৫, ৪৫, ৩২ দিয়ে পরীক্ষা করো। (A+, A, A-, C, F)
2. `v_day`: ১ হলে `Saturday`, ২ হলে `Sunday`, ... Simple `CASE` দিয়ে। `v_day` = ৭ হলে `Friday (Holiday)`।

4. `v_qty` দিয়ে দামের ধাপ: ১০০০ পর্যন্ত ৩.০০, ৫০০০ পর্যন্ত ২.৭৫, তার বেশি ২.৫০। ৬০০০ পিসের মোট দাম। (১৫০০০)

8. `lib_fine`-এর ইস্যু ১২-র জরিমানা ধরে `High`, `Medium`, `Low`। (৩৫ বা বেশি High, ২৫ বা বেশি Medium)

## সারাংশ

- `ELSIF`, `ELSEIF` না। প্রথম সত্য শর্তে থামে, তাই ক্রম জরুরি
- Simple `CASE`: এক মান, অনেক অবস্থা। Searched `CASE`: যেকোনো শর্ত
- Statement শেষ `END CASE;`, না মিললে এরর
- Expression শেষ `END`, না মিললে NULL, মান বসাতে
- `IF`-এ `ELSE` না থাকলে চুপচাপ পার হয়

**পরের ক্লাস:** Basic LOOP, EXIT WHEN।
