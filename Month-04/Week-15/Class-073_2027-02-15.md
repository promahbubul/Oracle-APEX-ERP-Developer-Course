## ১. Loop কেন (২০ মিনিট)

১ থেকে ৫ পর্যন্ত লিখতে:

```sql
BEGIN
    DBMS_OUTPUT.PUT_LINE(1);
    DBMS_OUTPUT.PUT_LINE(2);
    DBMS_OUTPUT.PUT_LINE(3);
    DBMS_OUTPUT.PUT_LINE(4);
    DBMS_OUTPUT.PUT_LINE(5);
END;
/
```

১০০০ হলে? **Loop** একই কাজ বারবার করে।

| ধরন | কখন | ক্লাস |
|---|---|---|
| `LOOP` | অন্তত একবার, পরে শর্তে থামবে | আজ |
| `WHILE` | শর্ত সত্য থাকা পর্যন্ত | ৭৪ |
| `FOR` | কতবার জানা আছে | ৭৫ |

ERP-তে: প্রতিটা রো ধরে কাজ (Cursor, সপ্তাহ ১৬), ঘণ্টাভিত্তিক খালি রো বানানো, মাসের সব দিনের হিসাব।

> **আগে ভাবো, SQL দিয়ে হয় কি না।** `UPDATE t SET x = x + 1`-এর জন্য Loop লাগে না। Loop-এ একটা একটা রো করা অনেক ধীর। সপ্তাহ ২১-এ দেখবে।

## ২. LOOP (৪০ মিনিট)

```sql
LOOP
    কাজ;
    EXIT WHEN শর্ত;
END LOOP;
```

```sql
DECLARE
    v_i NUMBER := 1;
BEGIN
    LOOP
        DBMS_OUTPUT.PUT_LINE(v_i);
        v_i := v_i + 1;
        EXIT WHEN v_i > 5;
    END LOOP;

    DBMS_OUTPUT.PUT_LINE('Loop ended at v_i = ' || v_i);     -- 6
END;
/
```

```
ধাপ   v_i দেখায়   v_i হয়   EXIT?
১      1            2        না
২      2            3        না
৩      3            4        না
৪      4            5        না
৫      5            6        হ্যাঁ
```

তিনটা জিনিস লাগে: **শুরুর মান, বদল, থামার শর্ত।**

### EXIT আর EXIT WHEN

```sql
-- EXIT WHEN: সহজ
EXIT WHEN v_i > 5;

-- IF + EXIT: একই কাজ
IF v_i > 5 THEN
    EXIT;
END IF;
```

শর্তে বের হওয়ার আগে অন্য কাজ থাকলে `IF`। নাহলে `EXIT WHEN`।

### Loop অন্তত একবার চলে

```sql
DECLARE
    v_i NUMBER := 100;
BEGIN
    LOOP
        DBMS_OUTPUT.PUT_LINE('Runs once: ' || v_i);
        v_i := v_i + 1;
        EXIT WHEN v_i > 5;
    END LOOP;
END;
/
```

শর্ত শেষে, তাই একবার চলে। `EXIT WHEN` Loop-এর শুরুতে লিখলে `WHILE`-এর মতো কাজ করে।

### যোগফল

```sql
DECLARE
    v_i   NUMBER := 1;
    v_sum NUMBER := 0;
BEGIN
    LOOP
        v_sum := v_sum + v_i;
        v_i := v_i + 1;
        EXIT WHEN v_i > 10;
    END LOOP;

    DBMS_OUTPUT.PUT_LINE('Sum: ' || v_sum);     -- 55
END;
/
```

**`v_sum`-এ `0` না দিলে NULL + সংখ্যা = NULL,** আর ফল খালি। ক্লাস ৬৭-এর ফাঁদ।

### নামতা

```sql
DECLARE
    v_n NUMBER := 7;
    v_i NUMBER := 1;
BEGIN
    LOOP
        DBMS_OUTPUT.PUT_LINE(v_n || ' x ' || v_i || ' = ' || v_n * v_i);
        v_i := v_i + 1;
        EXIT WHEN v_i > 10;
    END LOOP;
END;
/
```

## ৩. অসীম Loop ও CONTINUE (৩০ মিনিট)

### অসীম Loop

```sql
-- চালাবে না! v_i কখনো বাড়ে না, থামবে না
DECLARE
    v_i NUMBER := 1;
BEGIN
    LOOP
        DBMS_OUTPUT.PUT_LINE(v_i);
        EXIT WHEN v_i > 5;
    END LOOP;
END;
/
```

`EXIT` ভুলে গেলে, বা Variable না বাড়ালে Loop কখনো থামে না।

**কী হয়:** SQL Developer আটকে থাকে, CPU বাড়ে, আর `DBMS_OUTPUT` মেমোরি ভরে এরর দিতে পারে।

**আটকে গেলে:** উপরের লাল **Cancel** বোতাম। কাজ না করলে অ্যাডমিন সেশন বন্ধ করতে পারে।

**অভ্যাস:** নতুন Loop-এ একটা Safety Counter রাখো:

```sql
DECLARE
    v_i       NUMBER := 1;
    v_counter NUMBER := 0;
BEGIN
    LOOP
        v_counter := v_counter + 1;
        EXIT WHEN v_counter > 1000;      -- নিরাপত্তা

        -- আসল কাজ
        EXIT WHEN v_i > 5;
        v_i := v_i + 1;
    END LOOP;
END;
/
```

### CONTINUE: এই ধাপ বাদ

11g থেকে আছে।

```sql
-- শুধু বিজোড়: 1, 3, 5, 7, 9
DECLARE
    v_i NUMBER := 0;
BEGIN
    LOOP
        v_i := v_i + 1;
        EXIT WHEN v_i > 10;
        CONTINUE WHEN MOD(v_i, 2) = 0;
        DBMS_OUTPUT.PUT_LINE(v_i);
    END LOOP;
END;
/
```

`CONTINUE` পরের লাইনগুলো বাদ দিয়ে Loop-এর শুরুতে যায়।

**সাবধান:** `v_i := v_i + 1` যদি `CONTINUE`-এর পরে থাকে, Variable বাড়ে না, আর অসীম Loop হয়।

| কমান্ড | কাজ |
|---|---|
| `EXIT` | Loop শেষ, বাইরে যায় |
| `CONTINUE` | এই ধাপ শেষ, পরের ধাপে যায় |

## ৪. ERP-র হিসাব (৩০ মিনিট)

### কত দিনে স্টক সীমার নিচে যাবে

১০০০ কেজি কাপড়, দিনে ১৮০ কেজি খরচ, ২০০ কেজির নিচে গেলে নতুন অর্ডার।

```sql
DECLARE
    v_stock     NUMBER := 1000;
    c_daily_use CONSTANT NUMBER := 180;
    c_min_stock CONSTANT NUMBER := 200;
    v_days      NUMBER := 0;
BEGIN
    LOOP
        v_stock := v_stock - c_daily_use;
        v_days  := v_days + 1;
        DBMS_OUTPUT.PUT_LINE('Day ' || v_days || ': ' || v_stock || ' kg');
        EXIT WHEN v_stock < c_min_stock;
    END LOOP;

    DBMS_OUTPUT.PUT_LINE('Reorder after ' || v_days || ' days');     -- 5
END;
/
```

```
Day 1: 820 kg
Day 2: 640 kg
Day 3: 460 kg
Day 4: 280 kg
Day 5: 100 kg
Reorder after 5 days
```

### লক্ষ্যে পৌঁছাতে কত মাস

মাসে ১০০০ পিস, প্রতি মাসে ৫% বাড়ে। ১৫০০-তে পৌঁছাতে কত মাস?

```sql
DECLARE
    v_qty    NUMBER := 1000;
    v_months NUMBER := 0;
BEGIN
    LOOP
        v_qty    := v_qty * 1.05;
        v_months := v_months + 1;
        EXIT WHEN v_qty >= 1500;
    END LOOP;

    DBMS_OUTPUT.PUT_LINE(v_months || ' months, ' || ROUND(v_qty) || ' pcs');    -- 9 months, 1551 pcs
END;
/
```

এই ধরনের কাজে কতবার চলবে আগে জানা নেই। তাই `FOR` না, `LOOP`।

### টেবিলে ঢোকানো

```sql
CREATE TABLE w15_carton (
    carton_no  NUMBER(6) CONSTRAINT w15_carton_pk PRIMARY KEY,
    order_no   VARCHAR2(20) NOT NULL,
    pcs        NUMBER(4) NOT NULL
);
```

```sql
-- ৫০ পিস, প্রতি কার্টনে ১২: ৫টা কার্টন, শেষটায় ২ পিস
DECLARE
    v_remaining NUMBER := 50;
    v_carton_no NUMBER := 0;
    v_pcs       NUMBER;
BEGIN
    LOOP
        EXIT WHEN v_remaining <= 0;

        v_pcs       := LEAST(v_remaining, 12);
        v_carton_no := v_carton_no + 1;

        INSERT INTO w15_carton (carton_no, order_no, pcs)
        VALUES (v_carton_no, 'ORD-TEST', v_pcs);

        v_remaining := v_remaining - v_pcs;
    END LOOP;

    COMMIT;

    DBMS_OUTPUT.PUT_LINE(v_carton_no || ' cartons');     -- 5
END;
/

SELECT carton_no, pcs FROM w15_carton ORDER BY carton_no;

DELETE FROM w15_carton;
COMMIT;
```

`LEAST` দুইটার ছোটটা দেয়। ছোট ফাংশন, খুব কাজের। উল্টোটা `GREATEST`।

## সারাংশ

- `LOOP ... EXIT WHEN ... END LOOP;`
- লাগে: শুরুর মান, বদল, থামার শর্ত
- কতবার জানা না থাকলে `LOOP`
- অসীম Loop-এ Cancel
- `EXIT` বের হয়, `CONTINUE` পরের ধাপে যায়
- SQL দিয়ে হলে Loop লিখো না

**পরের ক্লাস:** WHILE LOOP।
