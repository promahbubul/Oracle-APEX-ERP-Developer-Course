## ১. Variable (৪০ মিনিট)

**Variable** হলো মেমোরিতে একটা নাম দেওয়া জায়গা, যেখানে ব্লক চলার সময় মান রাখা হয়। ব্লক শেষে চলে যায়।

```sql
DECLARE
    v_order_no   VARCHAR2(20);
    v_order_qty  NUMBER(10);
    v_fob_price  NUMBER(10,4);
    v_ship_date  DATE;
    v_is_active  BOOLEAN;
BEGIN
    NULL;
END;
/
```

`নাম  Data Type;`

### Data Type

| Data Type | কাজ | উদাহরণ |
|---|---|---|
| `VARCHAR2(n)` | লেখা, সাইজ বাধ্যতামূলক | `VARCHAR2(50)` |
| `NUMBER(p,s)` | সংখ্যা | `NUMBER(10,2)` |
| `DATE` | তারিখ-সময় | |
| `BOOLEAN` | `TRUE`, `FALSE`, `NULL` | ফ্ল্যাগ |
| `PLS_INTEGER` | পূর্ণ সংখ্যা, দ্রুত | লুপের কাউন্টার |
| `CLOB` | বড় লেখা | |

**টেবিল থেকে পার্থক্য:**

| | টেবিলের কলাম | PL/SQL Variable |
|---|---|---|
| `VARCHAR2` সর্বোচ্চ | ৪০০০ byte (সাধারণত) | **৩২৭৬৭ byte** |
| `BOOLEAN` | পুরনো ভার্সনে নেই (ক্লাস ৭) | **আছে** |

```sql
DECLARE
    v_name VARCHAR2;      -- PLS-00215: সাইজ দিতে হবে
BEGIN
    NULL;
END;
/
```

### নাম রাখার নিয়ম

ক্লাস ৬-এর নিয়মই। আর এই প্রচলিত উপসর্গ:

| উপসর্গ | মানে | উদাহরণ |
|---|---|---|
| `v_` | Variable | `v_order_qty` |
| `c_` | Constant | `c_vat_rate` |
| `p_` | Parameter (সপ্তাহ ১৮) | `p_item_id` |
| `cur_` | Cursor (সপ্তাহ ১৬) | `cur_orders` |
| `rec_` | Record | `rec_order` |

**কেন `v_`?** কলামের নাম আর Variable-এর নাম আলাদা রাখে। একই নাম হলে কী বিপদ, ক্লাস ৬৯-এ দেখবে।

## ২. মান দেওয়া (২৫ মিনিট)

```sql
DECLARE
    v_qty    NUMBER := 5000;              -- ঘোষণার সময়
    v_price  NUMBER DEFAULT 2.35;         -- DEFAULT, একই কাজ
    v_total  NUMBER;                      -- মান নেই, এখন NULL
BEGIN
    v_total := v_qty * v_price;           -- BEGIN-এর ভেতরে
    DBMS_OUTPUT.PUT_LINE(v_total);        -- 11750
END;
/
```

**`:=` মান দেয়। `=` তুলনা করে।** PL/SQL-এ সবচেয়ে সাধারণ টাইপো:

```sql
v_total = 100;    -- PLS-00103
v_total := 100;   -- ঠিক
```

### শুরুতে NULL

ঘোষণা করে মান না দিলে Variable **NULL**, `0` না।

```sql
DECLARE
    v_qty   NUMBER;
    v_total NUMBER;
BEGIN
    v_total := v_qty + 100;
    DBMS_OUTPUT.PUT_LINE('Total: ' || v_total);     -- Total:   (খালি!)
    DBMS_OUTPUT.PUT_LINE('Total: ' || NVL(v_total, 0));
END;
/
```

ক্লাস ২৬-এর নিয়ম: NULL-এর সাথে হিসাবের ফল NULL। **কোনো এরর আসে না,** শুধু ভুল ফল। Variable-এ শুরুর মান দেওয়ার অভ্যাস করো।

### NOT NULL

```sql
DECLARE
    v_qty NUMBER NOT NULL := 0;       -- শুরুর মান বাধ্যতামূলক
BEGIN
    v_qty := 100;                     -- চলে
    -- v_qty := NULL;                 -- চালালে এরর
    DBMS_OUTPUT.PUT_LINE(v_qty);
END;
/
```

### Boolean

```sql
DECLARE
    v_is_late BOOLEAN := TRUE;
BEGIN
    DBMS_OUTPUT.PUT_LINE(CASE WHEN v_is_late THEN 'Late' ELSE 'On time' END);
END;
/
```

`DBMS_OUTPUT.PUT_LINE(v_is_late)` চলে না: `PLS-00306`। `BOOLEAN` লেখা নয়, তাই সরাসরি দেখানো যায় না। আগে লেখায় বদলাও। `IF` দিয়ে ব্যবহার সামনের সপ্তাহে।

## ৩. DBMS_OUTPUT (২০ মিনিট)

```sql
BEGIN
    DBMS_OUTPUT.PUT('Order: ');          -- একই লাইনে থাকে
    DBMS_OUTPUT.PUT('ORD-501');
    DBMS_OUTPUT.NEW_LINE;                -- লাইন শেষ

    DBMS_OUTPUT.PUT_LINE('Qty: ' || 5000);
    DBMS_OUTPUT.PUT_LINE('-------------------');
    DBMS_OUTPUT.PUT_LINE('Total: ' || TO_CHAR(11750, 'FM99,999.00'));
END;
/
```

### সাজানো রিপোর্টের মতো

```sql
DECLARE
    v_order_no VARCHAR2(20) := 'ORD-501';
    v_qty      NUMBER       := 5000;
    v_ship     DATE         := DATE '2027-01-15';
BEGIN
    DBMS_OUTPUT.PUT_LINE(RPAD('Order No', 12) || ': ' || v_order_no);
    DBMS_OUTPUT.PUT_LINE(RPAD('Quantity', 12) || ': ' || TO_CHAR(v_qty, 'FM99,999'));
    DBMS_OUTPUT.PUT_LINE(RPAD('Ship Date', 12) || ': ' || TO_CHAR(v_ship, 'DD-Mon-YYYY'));
END;
/
```

### যা মনে রাখবে

- আউটপুট চলার সময় না, **ব্লক শেষ হওয়ার পরে** একসাথে দেখায়। ধীর প্রোগ্রামে "কতদূর এলো" দেখা যায় না
- একটা বাফারে জমা থাকে, খুব বড় হলে সীমায় আটকাতে পারে
- **শুধু শেখা আর ডিবাগের জন্য।** APEX পেজে বা Job-এ এটা কারো চোখে পড়ে না। সেখানে Log টেবিল বা `APEX_DEBUG`

## ৪. CONSTANT ও Variable-এর নিয়ম (২৫ মিনিট)

### CONSTANT

মান একবারই। পরে বদলানো যায় না।

```sql
DECLARE
    c_vat_rate     CONSTANT NUMBER := 0.15;
    c_cartons_size CONSTANT NUMBER := 12;
    c_company      CONSTANT VARCHAR2(50) := 'Delta Garments Ltd';
    v_amount       NUMBER := 1000;
BEGIN
    DBMS_OUTPUT.PUT_LINE(c_company);
    DBMS_OUTPUT.PUT_LINE('VAT: ' || v_amount * c_vat_rate);       -- 150
END;
/
```

```sql
-- এরর PLS-00363: expression 'C_VAT_RATE' cannot be used as an assignment target
DECLARE
    c_vat_rate CONSTANT NUMBER := 0.15;
BEGIN
    c_vat_rate := 0.20;
END;
/
```

শুরুর মান না দিলে `PLS-00322`।

**কেন Constant?** কোডে সরাসরি `0.15` লিখলে (**Magic Number**) ৫০ জায়গায় বদলাতে হবে, আর বোঝাও যায় না সেটা কী। একটা Constant বদলালেই হয়।

> বাস্তবে যে হার সময়ে সময়ে বদলায় (VAT, Exchange Rate), সেটা Constant-এও না, টেবিলে রাখা ভালো। ইউজার বদলাবে, ডেভেলপার না।

### এক লাইনে একটা

```sql
v_a, v_b NUMBER;    -- PLS-00103: Oracle-এ এক লাইনে দুইটা ঘোষণা চলে না
```

### আগে ঘোষণা, পরে ব্যবহার

```sql
DECLARE
    v_total NUMBER := v_qty * 2;    -- PLS-00320: v_qty এখনো ঘোষণা হয়নি
    v_qty   NUMBER := 10;
BEGIN
    NULL;
END;
/
```

ক্রম উল্টে দিলে ঠিক।

### Variable আর হিসাবের ফাংশন

| চলে | চলে না (শুধু SQL-এ) |
|---|---|
| `UPPER`, `SUBSTR`, `ROUND`, `MOD`, `TO_CHAR`, `NVL`, `ADD_MONTHS` | `SUM`, `AVG`, `COUNT`, `DECODE` |

```sql
v_x := DECODE(v_a, 1, 'One', 'Other');     -- PLS-00204
v_x := CASE v_a WHEN 1 THEN 'One' ELSE 'Other' END;   -- ঠিক
```

## ৫. গার্মেন্টসের হিসাব (২০ মিনিট)

```sql
-- অর্ডারের কাপড়ের হিসাব
DECLARE
    c_wastage_pct CONSTANT NUMBER := 5;
    v_order_qty   NUMBER := 5000;
    v_kg_per_pc   NUMBER := 0.18;
    v_net_kg      NUMBER;
    v_gross_kg    NUMBER;
BEGIN
    v_net_kg   := v_order_qty * v_kg_per_pc;
    v_gross_kg := CEIL(v_net_kg * (1 + c_wastage_pct / 100));

    DBMS_OUTPUT.PUT_LINE('Net Fabric   : ' || v_net_kg || ' kg');      -- 900
    DBMS_OUTPUT.PUT_LINE('Gross Fabric : ' || v_gross_kg || ' kg');    -- 945
END;
/
```

```sql
-- Sewing Line-এর Efficiency
DECLARE
    v_produced   NUMBER := 1200;
    v_smv        NUMBER := 15;
    v_operators  NUMBER := 40;
    v_hours      NUMBER := 8;
    v_earned     NUMBER;
    v_available  NUMBER;
BEGIN
    v_earned    := v_produced * v_smv;
    v_available := v_operators * v_hours * 60;

    DBMS_OUTPUT.PUT_LINE('Earned Minutes    : ' || v_earned);       -- 18000
    DBMS_OUTPUT.PUT_LINE('Available Minutes : ' || v_available);    -- 19200
    DBMS_OUTPUT.PUT_LINE('Efficiency        : ' || ROUND(v_earned / v_available * 100, 2) || '%');   -- 93.75%
END;
/
```

```sql
-- শিপমেন্টের TNA
DECLARE
    v_ship_date DATE := DATE '2027-03-15';
BEGIN
    DBMS_OUTPUT.PUT_LINE('Fabric In-House : ' || TO_CHAR(v_ship_date - 45, 'DD-Mon-YYYY'));   -- 29-Jan-2027
    DBMS_OUTPUT.PUT_LINE('Cutting Start   : ' || TO_CHAR(v_ship_date - 30, 'DD-Mon-YYYY'));   -- 13-Feb-2027
    DBMS_OUTPUT.PUT_LINE('Finishing End   : ' || TO_CHAR(v_ship_date - 7, 'DD-Mon-YYYY'));    -- 08-Mar-2027
END;
/
```

## ৬. হাতে-কলমে প্র্যাকটিস (৫০ মিনিট)

1. `v_style_no`, `v_order_qty`, `v_fob_price`, `v_ship_date`: সঠিক Data Type-এ মান দিয়ে সাজিয়ে দেখাও।
2. `v_qty` = ৮০০০, `v_price` = ৪.৫, `c_discount` = ১০%: মোট, ছাড়, দেয় টাকা। (৩৬০০০, ৩৬০০, ৩২৪০০)
3. প্রতি পিসে ০.২৫ কেজি, ৮০০০ পিস, ৮% অপচয়: Gross Fabric। (২১৬০)
4. ১৫০০ পিস, SMV ১২, ৫০ জন, ৮ ঘণ্টা: Efficiency। (৭৫%)
5. ১৩৫০০ পিস, ২৪ পিসে কার্টন: মোট কার্টন, পুরো কার্টন, শেষ কার্টনের পিস। (৫৬৩, ৫৬২, ১২)
6. `v_salary` = ১৮৫০০: Basic ৬০%, House Rent ৩০%, Medical ১০%। (১১১০০, ৫৫৫০, ১৮৫০)
7. আজ থেকে ৪৫ দিন পরের তারিখ, আর সেই বারের নাম।
8. নিজের জন্মতারিখ দিয়ে বয়স বছরে। (`MONTHS_BETWEEN`)
9. একটা `BOOLEAN` Variable-এ `TRUE` দিয়ে `CASE` দিয়ে দেখাও।
10. `c_rate` Constant বদলানোর চেষ্টা করো, এরর পড়ো।

## ৭. হোমওয়ার্ক

1. কোন মানগুলো Variable, কোনগুলো Constant, কোনগুলো টেবিলে থাকবে? ক. VAT-এর হার; খ. Excel-এর একটা রো-র পরিমাণ; গ. ১ কেজি = ১০০০ গ্রাম; ঘ. ডলার রেট।
2. একটা বেতন শীটের ব্লক লেখো: Basic, HRA, Medical, OT, Deduction থেকে Net Pay।
3. `DBMS_OUTPUT` কেন শুধু শেখা আর ডিবাগের জন্য? ২ লাইনে।

<details>
<summary>হোমওয়ার্ক ১-এর সমাধান</summary>

- **ক:** টেবিল, সরকার বদলাতে পারে
- **খ:** Variable
- **গ:** Constant, কখনো বদলায় না
- **ঘ:** টেবিল, প্রতিদিন বদলায়

## সারাংশ

- `v_নাম  Data Type := মান;`
- `:=` মান দেয়। শুরুর মান না দিলে NULL
- `VARCHAR2`-এ সাইজ বাধ্যতামূলক, PL/SQL-এ ৩২৭৬৭ পর্যন্ত
- `CONSTANT`: একবারই মান। Magic Number না
- `DBMS_OUTPUT` শুধু শেখা আর ডিবাগের জন্য

**পরের ক্লাস:** %TYPE, %ROWTYPE।
