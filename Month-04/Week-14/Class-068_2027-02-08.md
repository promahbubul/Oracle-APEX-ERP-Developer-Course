# ক্লাস ৬৮: %TYPE ও %ROWTYPE

**তারিখ:** ৮ ফেব্রুয়ারি ২০২৭, সোমবার
**সময়:** সন্ধ্যা ৭:০০ থেকে রাত ১০:০০
**সপ্তাহ:** ১৪ | **ধাপ:** ৩ (PL/SQL)

---

## আজকে কী শিখব

- হাতে Data Type লিখলে কী সমস্যা
- `%TYPE`: কলামের ধরন নেওয়া
- `%ROWTYPE`: পুরো রো-র ধরন নেওয়া
- Record-এর কলামে কাজ, `INSERT`, `UPDATE`
- কোনটা কখন

---

## ১. সমস্যা (১৫ মিনিট)

```sql
DECLARE
    v_item_name VARCHAR2(50);
BEGIN
    SELECT item_name INTO v_item_name FROM item WHERE item_id = 1;
END;
/
```

ঠিক চলছে। `item_name` কলামের সাইজ `VARCHAR2(150)`, আর কারো নাম ৫০ অক্ষরের মধ্যে।

ছয় মাস পরে একটা ৮০ অক্ষরের আইটেমের নাম এলো:

```
ORA-06502: PL/SQL: numeric or value error: character string buffer too small
```

কোড এতদিন ঠিক চলছিল, হঠাৎ ভাঙল। শত শত প্রোগ্রামে একই সমস্যা হলে?

**সমাধান:** Variable-এর ধরন হাতে না লিখে **কলাম থেকে নেওয়া।**

---

## ২. %TYPE (৪০ মিনিট)

```sql
v_item_name  item.item_name%TYPE;
```

**"`item` টেবিলের `item_name` কলামের যে ধরন, এই Variable-ও সেই ধরনের।"**

```sql
DECLARE
    v_item_name item.item_name%TYPE;
    v_min_stock item.min_stock%TYPE;
BEGIN
    SELECT item_name, min_stock
    INTO   v_item_name, v_min_stock
    FROM   item
    WHERE  item_id = 1;

    DBMS_OUTPUT.PUT_LINE(v_item_name || ' | Min: ' || v_min_stock);
END;
/
```

ফল: `Single Jersey 160 GSM | Min: 500`।

### লাভ

```sql
-- কলাম বড় করলে
ALTER TABLE item MODIFY (item_name VARCHAR2(200));
```

`%TYPE` থাকলে **কোড না বদলেই** Variable বড় হয়ে যায়। কোড Oracle নিজে আবার Compile করে। বাস্তব ERP-তে এটাই ভালো অভ্যাস।

### Variable থেকেও নেওয়া যায়

```sql
DECLARE
    v_salary NUMBER(10,2) := 18500;
    v_bonus  v_salary%TYPE;
    v_net    v_salary%TYPE;
BEGIN
    v_bonus := v_salary * 0.10;
    v_net   := v_salary + v_bonus;
    DBMS_OUTPUT.PUT_LINE('Net: ' || v_net);       -- 20350
END;
/
```

### অন্য Schema-র কলাম

```sql
DECLARE
    v_salary hr.employees.salary%TYPE;
BEGIN
    SELECT salary INTO v_salary FROM hr.employees WHERE employee_id = 100;
    DBMS_OUTPUT.PUT_LINE(v_salary);        -- 24000
END;
/
```

### কী আসে, কী আসে না

| জিনিস | `%TYPE` নেয়? |
|---|---|
| Data Type, সাইজ, Precision | হ্যাঁ |
| কলামের `NOT NULL` | **না** |
| কলামের `DEFAULT` | **না** |
| Variable থেকে `NOT NULL` | হ্যাঁ |

```sql
DECLARE
    v_name item.item_name%TYPE;    -- কলাম NOT NULL, Variable-এ NULL চলে
BEGIN
    v_name := NULL;
    DBMS_OUTPUT.PUT_LINE('চলেছে');
END;
/
```

### APEX-এ

`P5_ITEM_NAME`-এর মতো পেজ আইটেম VARCHAR2-এ আসে। PL/SQL Process-এ `%TYPE` দিয়ে টেবিলের ধরনে নাও, আর ঢোকানোর সময় নিশ্চিত থাকো।

## ৩. %ROWTYPE (৪৫ মিনিট)

১০টা কলাম আনতে ১০টা Variable? **`%ROWTYPE`** পুরো রো-র জন্য একটা Variable (**Record**) দেয়।

```sql
DECLARE
    rec_book lib_book%ROWTYPE;
BEGIN
    SELECT * INTO rec_book FROM lib_book WHERE book_id = 1;

    DBMS_OUTPUT.PUT_LINE('Title: ' || rec_book.book_title);        -- Oracle SQL for Beginners
    DBMS_OUTPUT.PUT_LINE('Year : ' || rec_book.publish_year);      -- 2021
    DBMS_OUTPUT.PUT_LINE('ISBN : ' || rec_book.isbn);
END;
/
```

**`rec.কলাম`** দিয়ে প্রতিটা কলামে যাওয়া যায়। `rec_book`-এ `lib_book`-এর সব কলাম আছে।

### এখানে SELECT * ঠিক আছে

ক্লাস ২৬-এ `*` নিষেধ করেছিলাম। `%ROWTYPE`-এর সাথে এটা নিরাপদ: টেবিলে কলাম বাড়লে Record-ও বাড়ে।

### সরাসরি দেখানো যায় না

```sql
DBMS_OUTPUT.PUT_LINE(rec_book);     -- PLS-00306
```

প্রতিটা কলাম আলাদা লিখতে হয়।

### কলামে কাজ

```sql
DECLARE
    rec_book lib_book%ROWTYPE;
BEGIN
    SELECT * INTO rec_book FROM lib_book WHERE book_id = 2;

    rec_book.book_title := UPPER(rec_book.book_title);
    rec_book.publish_year := rec_book.publish_year + 1;

    DBMS_OUTPUT.PUT_LINE(rec_book.book_title);         -- PLSQL STEP BY STEP
    DBMS_OUTPUT.PUT_LINE(rec_book.publish_year);       -- 2023
END;
/
```

**টেবিল বদলায়নি,** শুধু মেমোরির Record।

### View থেকে

```sql
DECLARE
    rec_order w5_order_detail_v%ROWTYPE;
BEGIN
    SELECT * INTO rec_order FROM w5_order_detail_v WHERE order_no = 'ORD-501';

    DBMS_OUTPUT.PUT_LINE(rec_order.order_no || ' | ' || rec_order.buyer_name
                         || ' | ' || rec_order.order_value);       -- ORD-501 | H&M | 11750
END;
/
```

`SET DEFINE OFF` দরকার নেই: কোডে `&` লেখা নেই।

### Record দিয়ে INSERT

```sql
CREATE TABLE w14_book_copy AS SELECT * FROM lib_book WHERE 1 = 0;
```

```sql
DECLARE
    rec_book lib_book%ROWTYPE;
BEGIN
    SELECT * INTO rec_book FROM lib_book WHERE book_id = 1;

    rec_book.book_id := 5001;
    rec_book.isbn    := NULL;

    INSERT INTO w14_book_copy VALUES rec_book;
    COMMIT;
END;
/

SELECT book_id, book_title FROM w14_book_copy;
```

`VALUES rec_book`, ব্র্যাকেট ছাড়া।

### Record দিয়ে UPDATE

```sql
DECLARE
    rec_book w14_book_copy%ROWTYPE;
BEGIN
    SELECT * INTO rec_book FROM w14_book_copy WHERE book_id = 5001;

    rec_book.publish_year := 2030;

    UPDATE w14_book_copy
    SET    ROW = rec_book
    WHERE  book_id = rec_book.book_id;

    DBMS_OUTPUT.PUT_LINE('Rows: ' || SQL%ROWCOUNT);    -- 1

    ROLLBACK;
END;
/
```

`SET ROW`-এ **সব কলাম** আপডেট হয়, PK-ও। তাই লেখা সহজ হলেও ব্যবহার করবে বুঝে।

### Record কপি

```sql
DECLARE
    rec_a lib_book%ROWTYPE;
    rec_b lib_book%ROWTYPE;
BEGIN
    SELECT * INTO rec_a FROM lib_book WHERE book_id = 1;
    rec_b := rec_a;
    DBMS_OUTPUT.PUT_LINE(rec_b.book_title);
END;
/
```

### আংশিক কলাম: ভুল

```sql
DECLARE
    rec_book lib_book%ROWTYPE;
BEGIN
    SELECT book_id, book_title INTO rec_book FROM lib_book WHERE book_id = 1;
END;
/
```

```
PL/SQL: ORA-00947: not enough values
```

`INTO rec_book` চায় সব কলাম। আংশিকের জন্য Variable, অথবা `rec_book.book_id, rec_book.book_title` আলাদা করে লেখো।

## ৪. কোনটা কখন (১৫ মিনিট)

| পরিস্থিতি | ব্যবহার |
|---|---|
| ১–৩টা কলাম | `%TYPE` |
| অনেক কলাম, বা পুরো রো | `%ROWTYPE` |
| JOIN-এর কলাম একসাথে | View-এর `%ROWTYPE`, বা Cursor (সপ্তাহ ১৬) |
| ফলের ধরন হিসাব করা (গড়, শতাংশ) | সাধারণ `NUMBER` |
| ব্লকের নিজের কাউন্টার | `PLS_INTEGER` |

### ভালো অভ্যাস

```sql
-- খারাপ: হাতে লেখা
v_order_no VARCHAR2(20);

-- ভালো: টেবিলের সাথে বাঁধা
v_order_no w5_order.order_no%TYPE;
```

**নিয়ম:** টেবিল থেকে আসা বা টেবিলে যাওয়া সব মানে `%TYPE` বা `%ROWTYPE`। এই সামান্য বাড়তি লেখা বড় ERP-তে অনেক বাগ বাঁচায়।

## সারাংশ

- হাতে লেখা ধরন একদিন ভাঙবে। `%TYPE` কলামের সাথে বাঁধে
- `%TYPE` ধরন আর সাইজ নেয়, `NOT NULL` আর `DEFAULT` নেয় না
- `%ROWTYPE`: পুরো রো-র Record, `rec.কলাম`
- `INSERT ... VALUES rec`, `UPDATE ... SET ROW = rec`
- টেবিলে আসা-যাওয়া সব মানে `%TYPE` বা `%ROWTYPE`

**পরের ক্লাস:** SELECT INTO দিয়ে টেবিল থেকে ডাটা আনা।
