## ২. মূল কাজ: ১০টা ব্লক (১১৫ মিনিট)

`learn_freepdb1`-এ করো। প্রতিটা ব্লক `week14.sql`-এ কমেন্টে নম্বর দিয়ে রাখো।

**নিয়ম:**
- টেবিলের সাথে সম্পর্কিত মানে `%TYPE` বা `%ROWTYPE`
- Variable-এর নাম `v_`, Constant-এর `c_`
- `COMMIT` শুধু যেখানে সত্যিই লাগে
- আগে নিজে চেষ্টা করো, আটকে গেলে সমাধান দেখো

> এই ব্লকগুলোর ফল সপ্তাহ ১–১৩-এর সমাধানের ডাটা ধরে।

```sql
-- ব্লক ১০
DECLARE
    v_item_id w14_stock.item_id%TYPE := 2;
    v_qty     w14_txn.qty%TYPE := 40;
    v_balance w14_stock.balance_qty%TYPE;
BEGIN
    INSERT INTO w14_txn (item_id, txn_type, qty) VALUES (v_item_id, 'ISSUE', v_qty);

    UPDATE w14_stock
    SET    balance_qty = balance_qty - v_qty
    WHERE  item_id = v_item_id
    RETURNING balance_qty INTO v_balance;

    COMMIT;

    DBMS_OUTPUT.PUT_LINE('Stock now: ' || v_balance);
EXCEPTION
    WHEN OTHERS THEN
        ROLLBACK;
        RAISE;
END;
/

SELECT * FROM w14_stock;
SELECT * FROM w14_txn ORDER BY txn_id;
```

## পরের সপ্তাহ (সপ্তাহ ১৫): Control Structure

| ক্লাস | তারিখ | বিষয় |
|---|---|---|
| ৭১ | ১৩ ফেব্রুয়ারি ২০২৭, শনিবার | IF-THEN, IF-THEN-ELSE |
| ৭২ | ১৪ ফেব্রুয়ারি ২০২৭, রবিবার | IF-ELSIF, CASE Statement |
| ৭৩ | ১৫ ফেব্রুয়ারি ২০২৭, সোমবার | Basic LOOP, EXIT WHEN |
| ৭৪ | ১৬ ফেব্রুয়ারি ২০২৭, মঙ্গলবার | WHILE LOOP |
| ৭৫ | ১৭ ফেব্রুয়ারি ২০২৭, বুধবার | FOR LOOP, Nested Loop |
| প্র্যাকটিস | ১৮ ফেব্রুয়ারি ২০২৭, বৃহস্পতিবার | নামতা, যোগফল, গ্রেড বের করার প্রোগ্রাম লেখা |
