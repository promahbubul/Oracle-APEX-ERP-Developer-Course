## ১. PL/SQL কী (৩০ মিনিট)

**PL/SQL = Procedural Language extension to SQL।** Oracle-এর নিজস্ব প্রোগ্রামিং ভাষা।

ক্লাস ২১-এ দেখেছিলে: SQL-এ বলো **কী চাও**। কিন্তু ERP-র কাজ প্রায়ই ধাপে ধাপে:

> "মাল ইস্যু করতে হবে। **যদি** স্টক যথেষ্ট থাকে, ইস্যুর রো ঢোকাও, স্টক কমাও। **নাহলে** এরর দেখাও। সব ঠিক থাকলে `COMMIT`, ভুল হলে `ROLLBACK`।"

এখানে `যদি`, `নাহলে`, একাধিক ধাপ, ভুল সামলানো, এগুলো শুধু SQL দিয়ে হয় না।

| | SQL | PL/SQL |
|---|---|---|
| ধরন | কী চাই | ধাপে ধাপে কীভাবে |
| Variable | নেই | আছে |
| `IF`, `LOOP` | নেই | আছে |
| ভুল সামলানো | নেই | `EXCEPTION` |
| SQL চালাতে পারে | | **হ্যাঁ, ভেতরেই** |

### কেন ডাটাবেসের ভেতরে

```
অন্য ভাষায় (Java, PHP):            PL/SQL:
প্রোগ্রাম ──SQL──► ডাটাবেস          ডাটাবেসের ভেতরেই চলে
প্রোগ্রাম ◄─ফল─── ডাটাবেস           নেটওয়ার্কে যাওয়া-আসা নেই
(প্রতিবার নেটওয়ার্ক)
```

- **দ্রুত:** ডাটার পাশেই চলে
- **এক জায়গায় লজিক:** ফর্ম, API, Job, সবাই একই Procedure ডাকে
- **APEX-এর ভাষা:** প্রতিটা Process, Validation, Computation আসলে PL/SQL

ক্লাস ১-এ বলেছিলাম: "আসল লজিক সেখানেই থাকে।" এই ধাপটাই সেই জায়গা।

### কী কী শিখব

| সপ্তাহ | বিষয় |
|---|---|
| ১৪ | Block, Variable, `SELECT INTO`, DML |
| ১৫ | `IF`, `CASE`, `LOOP` |
| ১৬ | Cursor |
| ১৭ | Exception |
| ১৮–১৯ | Procedure, Function, Package |
| ২০ | Trigger |
| ২১–২২ | Collection, Bulk, Dynamic SQL, Scheduler |

## ২. Block-এর গঠন (৪০ মিনিট)

PL/SQL কোড **Block**-এ লেখা হয়।

```sql
DECLARE
    -- ঐচ্ছিক: Variable এখানে
BEGIN
    -- বাধ্যতামূলক: কাজ এখানে
EXCEPTION
    -- ঐচ্ছিক: ভুল সামলানো এখানে
END;
/
```

| অংশ | কাজ | বাধ্যতামূলক? |
|---|---|---|
| `DECLARE` | Variable, Constant ঘোষণা | না |
| `BEGIN` | আসল কাজ | **হ্যাঁ** |
| `EXCEPTION` | ভুল হলে কী করবে | না |
| `END;` | শেষ | **হ্যাঁ** |
| `/` | টুলকে বলে "ব্লক চালাও" | SQL*Plus, Script-এ হ্যাঁ |

### নিয়ম

- প্রতিটা স্টেটমেন্টের শেষে `;`
- `DECLARE`, `BEGIN`, `EXCEPTION`-এর পরে `;` না
- `END`-এর পরে `;`
- `BEGIN` আর `END`-এর মাঝে অন্তত একটা স্টেটমেন্ট। কিছু করার না থাকলে `NULL;`
- ছোট-বড় হাতের অক্ষরে পার্থক্য নেই, শুধু লেখার মানে আছে
- কমেন্ট: `--` আর `/* */`

### ধরন

| ধরন | মানে | উদাহরণ |
|---|---|---|
| **Anonymous Block** | নামহীন, জমা থাকে না, চালালে শেষ | এই সপ্তাহের সব |
| **Named Block** | নাম আছে, ডাটাবেসে জমা থাকে | Procedure, Function, Trigger |

APEX-এর Process-এ আসলে Anonymous Block লেখা হয়।

## ৩. প্রথম প্রোগ্রাম (৩০ মিনিট)

```sql
SET SERVEROUTPUT ON

BEGIN
    DBMS_OUTPUT.PUT_LINE('Hello PL/SQL');
END;
/
```

পুরোটা সিলেক্ট করে `F5`। Script Output-এ:

```
Hello PL/SQL

PL/SQL procedure successfully completed.
```

- **`DBMS_OUTPUT.PUT_LINE`:** স্ক্রিনে লেখা দেখায়। শেখা আর ডিবাগের জন্য। **APEX পেজে এটা দেখায় না।**
- **`SET SERVEROUTPUT ON`:** টুলকে বলে আউটপুট দেখাও। SQL Developer-এর প্রতিটা নতুন সেশনে একবার লাগে। না দিলে ব্লক চলে, কিন্তু কিছু দেখায় না। নতুনদের সবচেয়ে সাধারণ ভুল।

### Variable সহ

```sql
DECLARE
    v_message VARCHAR2(50);
BEGIN
    v_message := 'Assalamu Alaikum';
    DBMS_OUTPUT.PUT_LINE(v_message);
END;
/
```

### হিসাব, আর SQL ফাংশন

```sql
DECLARE
    v_order_qty NUMBER := 5000;
    v_cartons   NUMBER;
BEGIN
    v_cartons := CEIL(v_order_qty / 12);
    DBMS_OUTPUT.PUT_LINE('Total cartons: ' || v_cartons);      -- 417
    DBMS_OUTPUT.PUT_LINE('Today: ' || TO_CHAR(SYSDATE, 'DD-Mon-YYYY'));
END;
/
```

`CEIL`, `TO_CHAR`, `SYSDATE`, ক্লাস ৩১–৩৫-এর প্রায় সব ফাংশন এখানেও চলে। ব্যতিক্রম: `DECODE` আর Aggregate (`SUM`, `AVG`) শুধু SQL স্টেটমেন্টের ভেতরে।

### টেবিল থেকে

```sql
DECLARE
    v_total NUMBER;
BEGIN
    SELECT COUNT(*) INTO v_total FROM lib_book;
    DBMS_OUTPUT.PUT_LINE('Total books: ' || v_total);    -- 21
END;
/
```

`SELECT`-এর ফল `INTO` দিয়ে Variable-এ যায়। বিস্তারিত ক্লাস ৬৯-এ।

### Exception-এর প্রথম দেখা

```sql
DECLARE
    v_a NUMBER := 10;
    v_b NUMBER := 0;
BEGIN
    DBMS_OUTPUT.PUT_LINE(v_a / v_b);
    DBMS_OUTPUT.PUT_LINE('এই লাইন চলবে না');
EXCEPTION
    WHEN ZERO_DIVIDE THEN
        DBMS_OUTPUT.PUT_LINE('শূন্য দিয়ে ভাগ করা যায় না');
END;
/
```

এরর হওয়ার সাথে সাথে `EXCEPTION` অংশে চলে যায়। বাকি লাইন চলে না। সপ্তাহ ১৭-এ বিস্তারিত।

## ৪. এরর পড়া (২০ মিনিট)

PL/SQL-এর এরর দুই ধরনের।

| ধরন | কখন | উদাহরণ |
|---|---|---|
| **Compile Error** | চালানোর আগে | `PLS-00103`, `PLS-00201` |
| **Runtime Error** | চলার সময় | `ORA-01476`, `ORA-01403` |

```sql
BEGIN
    DBMS_OUTPUT.PUT_LINE('Hello')
END;
/
```

```
ORA-06550: line 3, column 1:
PLS-00103: Encountered the symbol "END" when expecting one of the following: ...
```

**কীভাবে পড়বে:**

1. `line 3, column 1`: Oracle এখানে আটকেছে। ভুল প্রায়ই **আগের লাইনে:** এখানে `;` নেই
2. `PLS-00103`: কী সমস্যা

### সাধারণ এরর

| এরর | কারণ |
|---|---|
| `PLS-00103` | বানান, `;`, বা গঠনের ভুল |
| `PLS-00201` | Variable ঘোষণা করোনি, বা নাম ভুল |
| `PLS-00428` | `SELECT`-এ `INTO` নেই |
| `PLS-00363` | Constant-এ মান দিতে চেয়েছ |
| `PLS-00306` | ফাংশনে ভুল ধরনের মান |
| `PLS-00204` | `DECODE`, `SUM` ইত্যাদি SQL-এর বাইরে |

```sql
-- PLS-00428
BEGIN
    SELECT COUNT(*) FROM lib_book;
END;
/
```

PL/SQL-এ `SELECT` একা চলে না: ফল কোথায় রাখবে?

```sql
-- PLS-00103: CREATE TABLE সরাসরি চলে না
BEGIN
    CREATE TABLE w14_x (id NUMBER);
END;
/
```

PL/SQL-এ DDL সরাসরি লেখা যায় না, `EXECUTE IMMEDIATE` লাগে (সপ্তাহ ২২)। `SELECT INTO`, `INSERT`, `UPDATE`, `DELETE`, `MERGE`, `COMMIT`, `ROLLBACK` চলে।

## ৫. Nested Block ও Scope (১৫ মিনিট)

ব্লকের ভেতরে ব্লক লেখা যায়।

```sql
DECLARE
    v_outer VARCHAR2(20) := 'Outer';
BEGIN
    DECLARE
        v_inner VARCHAR2(20) := 'Inner';
    BEGIN
        DBMS_OUTPUT.PUT_LINE(v_outer);     -- চলে
        DBMS_OUTPUT.PUT_LINE(v_inner);     -- চলে
    END;

    DBMS_OUTPUT.PUT_LINE(v_outer);         -- চলে
    -- DBMS_OUTPUT.PUT_LINE(v_inner);      -- PLS-00201
END;
/
```

- ভেতরের ব্লক বাইরের Variable দেখে
- বাইরের ব্লক ভেতরের Variable দেখে না

ভেতরের ব্লকের বড় কাজ হলো Exception আলাদা করা। সপ্তাহ ১৭-এ দেখবে।

## ৬. হাতে-কলমে প্র্যাকটিস (৪৫ মিনিট)

সবগুলো Anonymous Block।

1. নিজের নাম লেখো।
2. ৩টা লাইনে: নাম, কোর্সের নাম, আজকের তারিখ।
3. `v_qty` = ৮০০০, `v_price` = ৪.৫: মোট টাকা দেখাও। (৩৬০০০)
4. `v_qty` = ১৩৫০০, প্রতি কার্টনে ২৪ পিস: মোট কার্টন আর শেষ কার্টনের পিস। (৫৬৩, ১২)
5. `lib_member`-এর মোট সংখ্যা দেখাও। (২১)
6. `lib_fine`-এর মোট টাকা দেখাও। (১৬৫)
7. ২০ ÷ ০ চালাও, Exception সহ।
8. একটা Nested Block, ভেতরে আর বাইরে নিজের Variable।

## সারাংশ

- PL/SQL: SQL-এর সাথে Variable, `IF`, `LOOP`, ভুল সামলানো
- Block: `DECLARE` (ঐচ্ছিক), `BEGIN`, `EXCEPTION` (ঐচ্ছিক), `END;`
- `SET SERVEROUTPUT ON` ছাড়া আউটপুট দেখা যায় না
- `SELECT`-এ `INTO` লাগে, DDL সরাসরি চলে না
- ভুলের লাইন নম্বর দেখো, ভুল প্রায়ই আগের লাইনে

**পরের ক্লাস:** Variable, Constant, DBMS_OUTPUT.PUT_LINE।
