## ২. Cursor কী (২০ মিনিট)

তুমি যখন কোনো SQL চালাও, Oracle মেমোরিতে একটা জায়গা খোলে। সেখানে থাকে:

- SQL-টা কী
- কোন রো-গুলো এল বা বদলাল
- কয়টা রো
- এখন কোন রো-তে আছি

এই জায়গাটার নাম **Context Area**, আর তার দিকে ইশারা করা নামটা **Cursor**।

ধরো বাজারের ফর্দ। ফর্দটা হলো Query, আর ফর্দে আঙুল রেখে এক এক করে জিনিস দেখা হলো Cursor।

### দুই ধরন

| ধরন | কে বানায় | কখন |
|---|---|---|
| **Implicit** | Oracle নিজে | প্রতিটা `INSERT`, `UPDATE`, `DELETE`, `MERGE`, `SELECT INTO` |
| **Explicit** | তুমি, `CURSOR` লিখে | অনেক রো এক এক করে পড়তে (কাল) |

আজ Implicit। তুমি কিছু ঘোষণা করো না, Oracle খোলে, চালায়, বন্ধ করে। তুমি শুধু পরে জিজ্ঞেস করতে পারো, "কী হলো?" এর নাম সবসময় `SQL`।

## ৩. SQL%ROWCOUNT (৩৫ মিনিট)

**শেষ SQL কয়টা রো ছুঁয়েছে।**

```sql
BEGIN
    UPDATE w16_emp
    SET    basic_salary = basic_salary + 500
    WHERE  dept_name = 'Sewing';

    DBMS_OUTPUT.PUT_LINE('Updated: ' || SQL%ROWCOUNT);     -- 3
    ROLLBACK;
END;
/
```

SQL Developer-এ `3 rows updated` দেখাত। PL/SQL-এর ভেতরে সেই বার্তা আসে না, তাই `SQL%ROWCOUNT` লাগে।

### কোনো রো না মিললে

```sql
BEGIN
    DELETE FROM w16_emp WHERE emp_id = 99;
    DBMS_OUTPUT.PUT_LINE('Deleted: ' || SQL%ROWCOUNT);     -- 0
END;
/
```

**এরর আসে না।** `UPDATE`/`DELETE` কিছু না পেলে চুপচাপ ০। এটাই সবচেয়ে বড় কারণ `SQL%ROWCOUNT` দেখার। না দেখলে ভাববে কাজ হয়েছে।

### শুধু শেষ SQL-টার কথা বলে

```sql
BEGIN
    UPDATE w16_emp SET basic_salary = basic_salary WHERE dept_name = 'Sewing';    -- 3
    UPDATE w16_emp SET basic_salary = basic_salary WHERE dept_name = 'Cutting';   -- 2
    DBMS_OUTPUT.PUT_LINE(SQL%ROWCOUNT);      -- 2, প্রথমটার 3 হারিয়ে গেছে
    ROLLBACK;
END;
/
```

**নিয়ম:** যেটা দরকার, পরের SQL-এর আগেই Variable-এ রাখো।

```sql
DECLARE
    v_sewing  NUMBER;
    v_cutting NUMBER;
BEGIN
    UPDATE w16_emp SET basic_salary = basic_salary WHERE dept_name = 'Sewing';
    v_sewing := SQL%ROWCOUNT;

    UPDATE w16_emp SET basic_salary = basic_salary WHERE dept_name = 'Cutting';
    v_cutting := SQL%ROWCOUNT;

    DBMS_OUTPUT.PUT_LINE('Sewing ' || v_sewing || ', Cutting ' || v_cutting);  -- 3, 2
    DBMS_OUTPUT.PUT_LINE('Total ' || (v_sewing + v_cutting));                  -- 5
    ROLLBACK;
END;
/
```

`DBMS_OUTPUT.PUT_LINE` SQL না, তাই সেটা `SQL%ROWCOUNT` বদলায় না।

### ব্লকে কোনো SQL চলার আগে

```sql
BEGIN
    DBMS_OUTPUT.PUT_LINE('[' || SQL%ROWCOUNT || ']');      -- [] মানে NULL
END;
/
```

### কাজের উদাহরণ: স্টক কমানো

`w14_stock`-এ এখন Single Jersey ৬০০, Button 18L ৬০, Pique ১৮০।

```sql
DECLARE
    v_item_id w14_stock.item_id%TYPE := 2;
    v_qty     NUMBER := 50;
BEGIN
    UPDATE w14_stock
    SET    balance_qty = balance_qty - v_qty
    WHERE  item_id = v_item_id;

    IF SQL%ROWCOUNT = 0 THEN
        DBMS_OUTPUT.PUT_LINE('Item ' || v_item_id || ' not found');
    ELSE
        DBMS_OUTPUT.PUT_LINE('Stock reduced by ' || v_qty);
    END IF;
    ROLLBACK;
END;
/
```

`v_item_id := 99` দিয়ে চালাও: `Item 99 not found`।

### `INSERT ... SELECT`

```sql
CREATE TABLE w16_emp_copy AS SELECT * FROM w16_emp WHERE 1 = 2;

BEGIN
    INSERT INTO w16_emp_copy
    SELECT * FROM w16_emp WHERE status = 'ACTIVE';
    DBMS_OUTPUT.PUT_LINE('Copied: ' || SQL%ROWCOUNT);      -- 9
    COMMIT;
END;
/
```

`w16_emp_copy` প্র্যাকটিসে কাজে লাগবে।

## ৪. SQL%FOUND, SQL%NOTFOUND, SQL%ISOPEN (৩০ মিনিট)

| Attribute | মানে | কোনো SQL-এর আগে |
|---|---|---|
| `SQL%ROWCOUNT` | কয়টা রো | NULL |
| `SQL%FOUND` | অন্তত ১টা রো ছুঁয়েছে? | NULL |
| `SQL%NOTFOUND` | একটাও ছোঁয়নি? | NULL |
| `SQL%ISOPEN` | খোলা আছে? | সবসময় FALSE |

`SQL%FOUND` হলো `SQL%ROWCOUNT > 0`, আর `SQL%NOTFOUND` তার উল্টো।

```sql
BEGIN
    UPDATE w16_emp SET status = 'ACTIVE' WHERE emp_id = 1;

    IF SQL%FOUND THEN
        DBMS_OUTPUT.PUT_LINE('Found');
    END IF;

    DELETE FROM w16_emp WHERE emp_id = 99;

    IF SQL%NOTFOUND THEN
        DBMS_OUTPUT.PUT_LINE('Nothing deleted');
    END IF;
    ROLLBACK;
END;
/
```

### BOOLEAN সরাসরি ছাপানো যায় না

```sql
BEGIN
    UPDATE w16_emp SET status = status WHERE emp_id = 1;
    DBMS_OUTPUT.PUT_LINE(SQL%FOUND);        -- PLS-00306: wrong number or types of arguments
END;
/
```

`PUT_LINE` লেখা নেয়, `BOOLEAN` না। এভাবে লেখো:

```sql
DBMS_OUTPUT.PUT_LINE(CASE WHEN SQL%FOUND THEN 'TRUE' ELSE 'FALSE' END);
```

### SQL%ISOPEN কেন সবসময় FALSE

Implicit Cursor-এ Oracle SQL শেষ হওয়ার সাথে সাথে বন্ধ করে দেয়। তুমি `SQL%ISOPEN` পড়ার সময় সেটা আর খোলা নেই। এর আসল কাজ Explicit Cursor-এ (ক্লাস ৭৮)।

### "না থাকলে ঢোকাও" প্যাটার্ন

```sql
DECLARE
    v_id   NUMBER := 3;
    v_name VARCHAR2(50) := 'Pique';
BEGIN
    UPDATE w14_stock SET item_name = v_name WHERE item_id = v_id;

    IF SQL%NOTFOUND THEN
        INSERT INTO w14_stock (item_id, item_name, balance_qty) VALUES (v_id, v_name, 0);
        DBMS_OUTPUT.PUT_LINE('Inserted');
    ELSE
        DBMS_OUTPUT.PUT_LINE('Updated');
    END IF;
    ROLLBACK;
END;
/
```

`v_id` ৩ হলে `Updated`, ৪ হলে `Inserted`। ERP-তে মাস্টার ডাটা ইমপোর্টে এটা খুব চলে।

## ৫. SELECT INTO আর Implicit Cursor (২০ মিনিট)

`SELECT INTO`-ও Implicit Cursor ব্যবহার করে। কিন্তু আচরণ আলাদা।

| ঘটনা | `UPDATE`/`DELETE` | `SELECT INTO` |
|---|---|---|
| ০টা রো | এরর না, `SQL%ROWCOUNT` = 0 | `NO_DATA_FOUND` (ORA-01403) |
| ১টা রো | ১ | ১ |
| অনেক রো | সংখ্যা | `TOO_MANY_ROWS` (ORA-01422) |

### এই কোড কখনো "Not found" ছাপাবে না

```sql
DECLARE
    v_name w16_emp.emp_name%TYPE;
BEGIN
    SELECT emp_name INTO v_name FROM w16_emp WHERE emp_id = 99;

    IF SQL%NOTFOUND THEN
        DBMS_OUTPUT.PUT_LINE('Not found');     -- এখানে আসবেই না
    END IF;
END;
/
```

`SELECT INTO` রো না পেলে সাথে সাথে এরর দিয়ে ব্লক থামায়। `IF` পর্যন্ত যায় না। ঠিক উপায় ক্লাস ৬৯-এ দেখেছ:

```sql
DECLARE
    v_name w16_emp.emp_name%TYPE;
BEGIN
    SELECT emp_name INTO v_name FROM w16_emp WHERE emp_id = 99;
    DBMS_OUTPUT.PUT_LINE(v_name);
EXCEPTION
    WHEN NO_DATA_FOUND THEN
        DBMS_OUTPUT.PUT_LINE('Not found');
END;
/
```

পরের সপ্তাহে Exception বিস্তারিত।

### `COUNT(*)` কখনো NO_DATA_FOUND দেয় না

```sql
DECLARE
    v_cnt NUMBER;
BEGIN
    SELECT COUNT(*) INTO v_cnt FROM w16_emp WHERE dept_name = 'Washing';
    DBMS_OUTPUT.PUT_LINE(v_cnt);              -- 0
END;
/
```

Aggregate সবসময় ১টা রো ফেরত দেয়। "আছে কি না" দেখার নিরাপদ উপায়।

### অনেক রো পড়তে কী করব?

`SELECT INTO` একটা রো-ই নিতে পারে। ৯ জন কর্মচারীর নাম এক এক করে ছাপাতে হলে? সেটাই **Explicit Cursor**, কাল।

- **১৬:** Sewing-এ ৩ জন, `SELECT INTO` একটা রো নেয়: `ORA-01422 TOO_MANY_ROWS`। `WHERE emp_id = 3` দাও, অথবা কাল Explicit Cursor।
- **১৭:** মাঝের `SELECT COUNT(*) INTO`-ও একটা SQL। `SQL%ROWCOUNT` এখন তার কথা বলছে (১), তাই ১ - ১ = ০। `DELETE`-এর ঠিক পরেই `v_del := SQL%ROWCOUNT;` রাখো।

</details>

## সারাংশ

- প্রতিটা SQL-এর জন্য Oracle একটা Cursor খোলে, নিজে বানালে Implicit, নাম `SQL`
- `SQL%ROWCOUNT`: শেষ SQL কয়টা রো ছুঁয়েছে, দরকার হলে সাথে সাথে Variable-এ রাখো
- `SQL%FOUND` / `SQL%NOTFOUND`: BOOLEAN, ছাপাতে `CASE` লাগে
- `UPDATE`/`DELETE` ০ রো-তে চুপ থাকে, তাই সবসময় যাচাই করো
- `SELECT INTO` ০ রো-তে এরর দেয়, `COUNT(*)` দেয় না

**পরের ক্লাস (রবিবার):** Explicit Cursor: `CURSOR`, `OPEN`, `FETCH`, `CLOSE` দিয়ে অনেক রো এক এক করে পড়া।
