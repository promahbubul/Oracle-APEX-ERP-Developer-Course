# ক্লাস ৮০: Parameterized Cursor, FOR UPDATE, WHERE CURRENT OF

**তারিখ:** ২৪ ফেব্রুয়ারি ২০২৭, বুধবার
**সময়:** সন্ধ্যা ৭:০০ থেকে রাত ১০:০০
**সপ্তাহ:** ১৬ | **ধাপ:** ৩ (PL/SQL)

---

## আজকে কী শিখব

- Parameterized Cursor: এক Cursor, অনেক মান
- Default মান আর একাধিক Parameter
- `FOR UPDATE`: পড়ার সময়েই রো Lock করা
- `NOWAIT`, `WAIT n`, `FOR UPDATE OF`
- `WHERE CURRENT OF`: যে রো পড়ছি সেটাই বদলাও
- ফাঁকা ছাড়া ইনভয়েস নম্বর (ক্লাস ৫৩-এর প্রতিশ্রুতি)

## ১. Parameterized Cursor (৪০ মিনিট)

### সমস্যা

Sewing আর Cutting-এর তালিকা আলাদা করে লাগবে। দুইটা Cursor?

```sql
CURSOR c_sewing  IS SELECT emp_name FROM w16_emp WHERE dept_name = 'Sewing';
CURSOR c_cutting IS SELECT emp_name FROM w16_emp WHERE dept_name = 'Cutting';
```

বিভাগ ২০টা হলে ২০টা Cursor। ক্লাস ৭৮-এ Variable দিয়ে করেছিলে, কিন্তু Variable-টা Cursor-এর বাইরে ঝুলে থাকে, আর `OPEN`-এর আগে মনে করে বদলাতে হয়।

### সমাধান: Cursor-কে Parameter দাও

```sql
SET SERVEROUTPUT ON

DECLARE
    CURSOR c_dept (p_dept VARCHAR2) IS
        SELECT emp_name, basic_salary
        FROM   w16_emp
        WHERE  dept_name = p_dept
        AND    status = 'ACTIVE'
        ORDER  BY emp_id;
BEGIN
    DBMS_OUTPUT.PUT_LINE('-- Sewing --');
    FOR r IN c_dept('Sewing') LOOP
        DBMS_OUTPUT.PUT_LINE(r.emp_name || ' ' || r.basic_salary);
    END LOOP;

    DBMS_OUTPUT.PUT_LINE('-- Cutting --');
    FOR r IN c_dept('Cutting') LOOP
        DBMS_OUTPUT.PUT_LINE(r.emp_name || ' ' || r.basic_salary);
    END LOOP;
END;
/
```

Function-এর মতো: ঘোষণার সময় নাম, ব্যবহারের সময় মান।

### OPEN দিয়েও

```sql
OPEN c_dept('Quality');
LOOP
    FETCH c_dept INTO r;
    EXIT WHEN c_dept%NOTFOUND;
    ...
END LOOP;
CLOSE c_dept;
```

`FETCH` আর `CLOSE`-এ Parameter লাগে না, শুধু `OPEN`-এ।

একই Cursor অন্য মানে খুলতে আগে `CLOSE` লাগে, না হলে `ORA-06511`।

### Parameter-এর নিয়ম

| নিয়ম | উদাহরণ |
|---|---|
| ধরনে সাইজ দেওয়া যায় না | `p_dept VARCHAR2` ঠিক, `p_dept VARCHAR2(30)` **PLS-00103** |
| `%TYPE` চলে | `p_dept w16_emp.dept_name%TYPE` |
| শুধু ভেতরে আসে (`IN`) | Cursor-এর ভেতরে মান বদলানো যায় না |
| শুধু Cursor-এর Query-তে দেখা যায় | `BEGIN`-এ `p_dept` লিখলে এরর |

`%TYPE` সবচেয়ে ভালো: কলামের ধরন বদলালে Cursor নিজে মানিয়ে নেয়।

### Nested Loop-এ সবচেয়ে কাজের

কালকের Nested রিপোর্ট পরিষ্কার হয়ে যায়:

```sql
DECLARE
    CURSOR c_depts IS
        SELECT DISTINCT dept_name FROM w16_emp WHERE status = 'ACTIVE' ORDER BY dept_name;

    CURSOR c_emps (p_dept w16_emp.dept_name%TYPE) IS
        SELECT emp_name, basic_salary
        FROM   w16_emp
        WHERE  dept_name = p_dept AND status = 'ACTIVE'
        ORDER  BY emp_id;

    v_sub NUMBER;
BEGIN
    FOR d IN c_depts LOOP
        DBMS_OUTPUT.PUT_LINE('== ' || d.dept_name || ' ==');
        v_sub := 0;
        FOR e IN c_emps(d.dept_name) LOOP
            DBMS_OUTPUT.PUT_LINE('  ' || e.emp_name || ' ' || e.basic_salary);
            v_sub := v_sub + e.basic_salary;
        END LOOP;
        DBMS_OUTPUT.PUT_LINE('  Subtotal: ' || v_sub);
    END LOOP;
END;
/
```

দুইটা Query-ই উপরে সাজানো, নিচে শুধু কাজ।

## ২. Default মান আর একাধিক Parameter (২০ মিনিট)

```sql
DECLARE
    CURSOR c_emp (p_dept      VARCHAR2,
                  p_min_basic NUMBER   DEFAULT 0,
                  p_status    VARCHAR2 DEFAULT 'ACTIVE') IS
        SELECT emp_name, dept_name, basic_salary
        FROM   w16_emp
        WHERE  (dept_name = p_dept OR p_dept IS NULL)
        AND    basic_salary >= p_min_basic
        AND    status = p_status
        ORDER  BY emp_id;
BEGIN
    FOR r IN c_emp('Sewing') LOOP                       -- ৩ জন
        DBMS_OUTPUT.PUT_LINE('A ' || r.emp_name);
    END LOOP;

    FOR r IN c_emp('Sewing', 11000) LOOP                -- Salma, Jamal
        DBMS_OUTPUT.PUT_LINE('B ' || r.emp_name);
    END LOOP;

    FOR r IN c_emp(NULL, 14000) LOOP                    -- সব বিভাগ: Rahim, Farida, Habib
        DBMS_OUTPUT.PUT_LINE('C ' || r.emp_name);
    END LOOP;

    FOR r IN c_emp(NULL, p_status => 'LEFT') LOOP       -- Tania
        DBMS_OUTPUT.PUT_LINE('D ' || r.emp_name);
    END LOOP;
END;
/
```

- Default থাকলে শেষের দিকের Parameter বাদ দেওয়া যায়
- `=>` দিয়ে নাম ধরে মান দেওয়া (Named Notation), মাঝের Parameter বাদ দিতে কাজে লাগে
- `(dept_name = p_dept OR p_dept IS NULL)`: NULL দিলে "সব"। APEX-এর রিপোর্ট ফিল্টারে এই কৌশল প্রতিদিন লাগবে

## ৩. FOR UPDATE (৩০ মিনিট)

### সমস্যা

হিসাব বিভাগ Sewing-এর Basic ৫% বাড়াবে। তুমি Cursor খুলে পড়ছ, হিসাব করছ। এর মাঝে অন্য কেউ একই কর্মচারীর Basic বদলে দিল। তোমার `UPDATE` তার কাজ মুছে দেবে, কেউ টেরও পাবে না।

ক্লাস ২৫-এ দেখেছ: `UPDATE` রো Lock করে। কিন্তু Cursor-এর `SELECT` Lock করে না।

### সমাধান: পড়ার সময়েই Lock

```sql
CURSOR c_emp IS
    SELECT emp_id, basic_salary
    FROM   w16_emp
    WHERE  dept_name = 'Sewing'
    FOR UPDATE;
```

- `OPEN`-এর মুহূর্তে মেলা সব রো Lock হয়ে যায়
- অন্য সেশন এই রো পড়তে পারে, কিন্তু বদলাতে পারে না, অপেক্ষা করে
- Lock ছাড়ে `COMMIT` বা `ROLLBACK`-এ, `CLOSE`-এ না

### দুই সেশনে পরীক্ষা

SQL Developer-এ দুইটা Worksheet খোলো, দুইটাতেই `learn_freepdb1`। প্রতিটা Worksheet আলাদা সেশন ধরতে **Unshared Worksheet** (`Ctrl+Shift+N`) দিয়ে খোলো।

**সেশন A:**

```sql
DECLARE
    CURSOR c IS SELECT emp_id FROM w16_emp WHERE emp_id = 3 FOR UPDATE;
BEGIN
    OPEN c;
    CLOSE c;
    -- COMMIT নেই, Lock থেকে গেল
END;
/
```

**সেশন B:**

```sql
UPDATE w16_emp SET basic_salary = 12000 WHERE emp_id = 3;
-- আটকে আছে, ঘুরছে...
```

**সেশন A:** `ROLLBACK;` দাও। B সাথে সাথে চলে যাবে। তারপর B-তেও `ROLLBACK;`।

### অপেক্ষা না করে

| লেখা | রো Lock থাকলে |
|---|---|
| `FOR UPDATE` | যতক্ষণ না ছাড়ে অপেক্ষা |
| `FOR UPDATE NOWAIT` | সাথে সাথে `ORA-00054: resource busy` |
| `FOR UPDATE WAIT 5` | ৫ সেকেন্ড অপেক্ষা, তারপর `ORA-30006` |

ERP স্ক্রিনে ব্যবহারকারী অনন্তকাল ঘুরতে দেখলে ভাবে সিস্টেম হ্যাং। তাই `NOWAIT` বা `WAIT n` দিয়ে "অন্য কেউ এটা এডিট করছে" বার্তা দেখানো ভালো (Exception-এ শিখবে)।

### FOR UPDATE OF

JOIN থাকলে শুধু কোন টেবিলের রো Lock হবে, সেটা বলে দেওয়া:

```sql
CURSOR c IS
    SELECT t.txn_id, t.qty, s.balance_qty
    FROM   w14_txn t
           JOIN w14_stock s ON s.item_id = t.item_id
    FOR UPDATE OF s.balance_qty;        -- শুধু w14_stock-এর রো Lock
```

`OF`-এর পরে কলামের নাম, কিন্তু Lock হয় পুরো রো। কলাম শুধু টেবিল চেনায়।

## ৪. WHERE CURRENT OF (২৫ মিনিট)

Lock করা রো বদলাতে আবার `WHERE emp_id = r.emp_id` লেখার দরকার নেই।

```sql
DECLARE
    CURSOR c_emp IS
        SELECT emp_name, basic_salary
        FROM   w16_emp
        WHERE  dept_name = 'Sewing'
        FOR UPDATE OF basic_salary;
BEGIN
    FOR r IN c_emp LOOP
        UPDATE w16_emp
        SET    basic_salary = ROUND(basic_salary * 1.05)
        WHERE  CURRENT OF c_emp;

        DBMS_OUTPUT.PUT_LINE(r.emp_name || ': ' || r.basic_salary
                             || ' -> ' || ROUND(r.basic_salary * 1.05));
    END LOOP;
    -- Loop শেষে COMMIT, ভেতরে না
    ROLLBACK;      -- পরীক্ষার জন্য
END;
/
-- Salma: 11000 -> 11550
-- Rina: 10500 -> 11025
-- Jamal: 13000 -> 13650
```

`WHERE CURRENT OF c_emp` মানে "Cursor যে রো-তে দাঁড়িয়ে আছে, সেটা"। Oracle ভেতরে রো-র ঠিকানা (`ROWID`) দিয়ে খোঁজে, তাই দ্রুত। `DELETE ... WHERE CURRENT OF`-ও চলে।

### নিয়ম

| ভুল | এরর |
|---|---|
| `FOR UPDATE` ছাড়া Cursor-এ `WHERE CURRENT OF` | `PLS-00404: cursor must be declared with FOR UPDATE` |
| Loop-এর ভেতরে `COMMIT`, তারপর পরের `FETCH` | `ORA-01002: fetch out of sequence` |

দ্বিতীয়টা কেন? `COMMIT` সব Lock ছেড়ে দেয়, আর `FOR UPDATE` Cursor-এর রো আর Lock করা থাকে না। Oracle তাই পরের রো দিতে রাজি হয় না।

**নিয়ম: `FOR UPDATE` Cursor-এর পুরো কাজ শেষে একবার `COMMIT`।**

### ফাঁকা ছাড়া ইনভয়েস নম্বর

ক্লাস ৫৩-এ বলেছিলাম: Sequence-এ নম্বর ফাঁকা পড়ে, কিন্তু Accounts-এর ভাউচার নম্বরে ফাঁকা চলে না। সমাধান Counter টেবিল আর `FOR UPDATE`।

```sql
CREATE TABLE w16_doc_counter (
    doc_type  VARCHAR2(10) CONSTRAINT w16_doc_counter_pk PRIMARY KEY,
    last_no   NUMBER(10)   NOT NULL
);

INSERT INTO w16_doc_counter VALUES ('INV', 1000);
INSERT INTO w16_doc_counter VALUES ('GRN', 500);
COMMIT;
```

```sql
DECLARE
    v_no w16_doc_counter.last_no%TYPE;
BEGIN
    SELECT last_no + 1
    INTO   v_no
    FROM   w16_doc_counter
    WHERE  doc_type = 'INV'
    FOR UPDATE;                         -- অন্য কেউ এখন এই রো পড়ে নম্বর নিতে পারবে না

    UPDATE w16_doc_counter SET last_no = v_no WHERE doc_type = 'INV';

    -- এখানে ইনভয়েস INSERT হতো, একই Transaction-এ
    DBMS_OUTPUT.PUT_LINE('New invoice: INV-' || v_no);      -- INV-1001
    COMMIT;
END;
/
```

দুইজন একসাথে চালালে দ্বিতীয়জন অপেক্ষা করবে, তারপর ১০০২ পাবে। আর কোনো কারণে `ROLLBACK` হলে Counter-ও ফেরত যায়, ফলে ফাঁকা পড়ে না। দাম: একসাথে একজনই নম্বর নিতে পারে, তাই শুধু যেখানে আইন বলে, সেখানে।

`SELECT INTO`-তেও `FOR UPDATE` চলে, Cursor লাগে না।

    DBMS_OUTPUT.PUT_LINE('Updated: ' || v_cnt);       -- 3 (Rina, Nasima, Sumon)
    ROLLBACK;
END;

DECLARE
    CURSOR c IS SELECT item_name, balance_qty FROM w14_stock FOR UPDATE;
    v_cnt NUMBER := 0;
BEGIN
    FOR r IN c LOOP
        IF r.balance_qty < 100 THEN
            UPDATE w14_stock SET balance_qty = balance_qty + 200 WHERE CURRENT OF c;
            v_cnt := v_cnt + 1;
        END IF;

    ROLLBACK;

## সারাংশ

- `CURSOR c (p_x TYPE) IS ...`: সাইজ ছাড়া ধরন, ভালো হয় `%TYPE`, মান দাও `OPEN`-এ বা `FOR r IN c(...)`-এ
- Default আর `=>` দিয়ে লম্বা Parameter তালিকা সহজ, `p IS NULL` মানে "সব"
- `FOR UPDATE`: `OPEN`-এর সময় রো Lock, ছাড়ে `COMMIT`/`ROLLBACK`-এ; `NOWAIT`/`WAIT n` অপেক্ষা কমায়
- `WHERE CURRENT OF c`: Cursor-এর এখনকার রো বদলাও, `FOR UPDATE` লাগবেই
- `FOR UPDATE` Loop-এ `COMMIT` একবার, শেষে

**পরের দিন (বৃহস্পতিবার):** সপ্তাহ ১৬-এর প্র্যাকটিস: Cursor দিয়ে কর্মচারীদের পুরো মাসের স্যালারি শিট আর রিপোর্ট।
