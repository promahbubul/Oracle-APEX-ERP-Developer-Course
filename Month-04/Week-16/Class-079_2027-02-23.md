# ক্লাস ৭৯: Cursor FOR Loop

**তারিখ:** ২৩ ফেব্রুয়ারি ২০২৭, মঙ্গলবার
**সময়:** সন্ধ্যা ৭:০০ থেকে রাত ১০:০০
**সপ্তাহ:** ১৬ | **ধাপ:** ৩ (PL/SQL)

---

## আজকে কী শিখব

- Cursor FOR Loop: `OPEN`/`FETCH`/`CLOSE` ছাড়া
- নাম দেওয়া Cursor দিয়ে আর সরাসরি `SELECT` দিয়ে
- Loop Record-এর নিয়ম
- বিভাগভিত্তিক সাবটোটালের রিপোর্ট (Control Break)
- Nested Cursor FOR Loop
- কখন কোন ধরন

---

## ১. একই কাজ, কম কোড (২০ মিনিট)

কালকের কোড:

```sql
DECLARE
    CURSOR c_emp IS
        SELECT emp_id, emp_name FROM w16_emp WHERE status = 'ACTIVE' ORDER BY emp_id;
    r c_emp%ROWTYPE;
BEGIN
    OPEN c_emp;
    LOOP
        FETCH c_emp INTO r;
        EXIT WHEN c_emp%NOTFOUND;
        DBMS_OUTPUT.PUT_LINE(r.emp_id || '. ' || r.emp_name);
    END LOOP;
    CLOSE c_emp;
END;
/
```

আজকের কোড:

```sql
DECLARE
    CURSOR c_emp IS
        SELECT emp_id, emp_name FROM w16_emp WHERE status = 'ACTIVE' ORDER BY emp_id;
BEGIN
    FOR r IN c_emp LOOP
        DBMS_OUTPUT.PUT_LINE(r.emp_id || '. ' || r.emp_name);
    END LOOP;
END;
/
```

একই ফল, ৯ লাইন। Oracle নিজে করে দেয়:

| কাজ | কে করে |
|---|---|
| `r`-কে `c_emp%ROWTYPE` ঘোষণা | Oracle |
| `OPEN` | Loop শুরুতে |
| `FETCH` | প্রতি ধাপে |
| `EXIT WHEN %NOTFOUND` | নিজে থেকে |
| `CLOSE` | Loop শেষে, মাঝপথে `EXIT` দিলেও |

**ভুলে `CLOSE` না দেওয়া, `EXIT WHEN` ভুল জায়গায় দেওয়া, শেষ রো দুইবার ছাপা: সব সমস্যা শেষ।**

ক্লাস ৭৫-এর `FOR i IN 1..10`-এর সাথে মিল দেখো: সেখানে `i` সংখ্যা, এখানে `r` একটা পুরো রো।

## ২. নাম দেওয়া Cursor দিয়ে (৩৫ মিনিট)

```sql
FOR record_name IN cursor_name LOOP
    ...
END LOOP;
```

### Record-এর নিয়ম

```sql
DECLARE
    CURSOR c_emp IS SELECT emp_name, basic_salary FROM w16_emp WHERE dept_name = 'Cutting';
BEGIN
    FOR r IN c_emp LOOP
        DBMS_OUTPUT.PUT_LINE(r.emp_name);
    END LOOP;

    DBMS_OUTPUT.PUT_LINE(r.emp_name);       -- PLS-00201: identifier 'R.EMP_NAME' must be declared
END;
/
```

- `r` ঘোষণা করতে হয় না, করলেও Loop-এর `r` আলাদা (ক্লাস ৭৫-এর `FOR i`-এর মতো)
- `r` শুধু Loop-এর ভেতরে থাকে
- `r`-এর কলামে মান বসানো যায়, কিন্তু টেবিলে যায় না। টেবিল বদলাতে `UPDATE` লাগে

### Loop-এর পরে কয়টা রো ছিল?

```sql
FOR r IN c_emp LOOP
    ...
END LOOP;
DBMS_OUTPUT.PUT_LINE(c_emp%ROWCOUNT);      -- ORA-01001: Cursor বন্ধ
```

Loop শেষে Cursor বন্ধ। সমাধান নিজের Counter:

```sql
DECLARE
    CURSOR c_emp IS SELECT emp_name FROM w16_emp WHERE status = 'ACTIVE';
    v_cnt NUMBER := 0;
BEGIN
    FOR r IN c_emp LOOP
        v_cnt := v_cnt + 1;
        DBMS_OUTPUT.PUT_LINE(c_emp%ROWCOUNT || '. ' || r.emp_name);   -- ভেতরে চলে
    END LOOP;
    DBMS_OUTPUT.PUT_LINE('Total: ' || v_cnt);                        -- 9
END;
/
```

Loop-এর ভেতরে `c_emp%ROWCOUNT` পড়া যায়, কারণ তখন Cursor খোলা।

### খালি Cursor

রো না থাকলে Loop একবারও চলে না, এরর আসে না। "কাউকে পেলাম না" বলতে চাইলে Counter দেখো:

```sql
IF v_cnt = 0 THEN
    DBMS_OUTPUT.PUT_LINE('No employee found');
END IF;
```

### হিসাবসহ

```sql
DECLARE
    CURSOR c_emp IS
        SELECT emp_name,
               basic_salary,
               basic_salary * 0.5        AS house_rent,
               basic_salary * 1.5 + 1200 AS gross
        FROM   w16_emp
        WHERE  status = 'ACTIVE'
        ORDER  BY emp_id;

    v_total NUMBER := 0;
BEGIN
    DBMS_OUTPUT.PUT_LINE(RPAD('Name', 10) || LPAD('Basic', 9) || LPAD('House', 9) || LPAD('Gross', 9));
    DBMS_OUTPUT.PUT_LINE(RPAD('-', 37, '-'));

    FOR r IN c_emp LOOP
        DBMS_OUTPUT.PUT_LINE(RPAD(r.emp_name, 10)
                             || LPAD(r.basic_salary, 9)
                             || LPAD(r.house_rent, 9)
                             || LPAD(r.gross, 9));
        v_total := v_total + r.gross;
    END LOOP;

    DBMS_OUTPUT.PUT_LINE(RPAD('-', 37, '-'));
    DBMS_OUTPUT.PUT_LINE(RPAD('Total', 28) || LPAD(v_total, 9));      -- 178800

/
```

## ৩. সরাসরি SELECT দিয়ে (২৫ মিনিট)

Cursor-এর নাম না দিয়ে `IN`-এর পরে বন্ধনীতে `SELECT`। ক্লাস ৭৫-এ এক ঝলক দেখেছিলে।

```sql
BEGIN
    FOR r IN (SELECT emp_name, dept_name
              FROM   w16_emp
              WHERE  basic_salary >= 14000
              ORDER  BY basic_salary DESC)
    LOOP
        DBMS_OUTPUT.PUT_LINE(r.emp_name || ' - ' || r.dept_name);
    END LOOP;
END;
/
-- Habib - Quality
-- Rahim - Cutting
-- Farida - Quality
```

`DECLARE` লাগলই না।

### কোনটা কখন

| নাম দেওয়া Cursor | সরাসরি `SELECT` |
|---|---|
| একই Query কয়েক জায়গায় | একবারই লাগবে |
| Query লম্বা, উপরে রাখলে কোড পরিষ্কার | ছোট Query |
| `c%ROWCOUNT` লাগবে | Counter দিয়ে চলে |
| Parameter লাগবে (কাল) | Variable সরাসরি `WHERE`-এ লেখা যায় |

```sql
DECLARE
    v_dept VARCHAR2(30) := 'Sewing';
BEGIN
    FOR r IN (SELECT emp_name FROM w16_emp WHERE dept_name = v_dept) LOOP
        DBMS_OUTPUT.PUT_LINE(r.emp_name);
    END LOOP;
END;
/
```

### তিন ধরনের তুলনা

| | `OPEN`/`FETCH`/`CLOSE` | Cursor FOR | সরাসরি `SELECT` |
|---|---|---|---|
| কোড | বেশি | কম | সবচেয়ে কম |
| Record ঘোষণা | তুমি | Oracle | Oracle |
| ভুলে খোলা থাকার ভয় | আছে | নেই | নেই |
| Loop-এর পরে `%ROWCOUNT` | `CLOSE`-এর আগে পারো | না | না |
| মাঝপথে থেমে পরে আবার পড়া | পারো | না | না |

**নিয়ম:** সাধারণভাবে Cursor FOR। এক এক রো নিজের হাতে নিয়ন্ত্রণ করতে হলে (যেমন দুইটা Cursor পাশাপাশি মিলিয়ে পড়া) `OPEN`/`FETCH`/`CLOSE`।

## ৪. সাবটোটালের রিপোর্ট (৩৫ মিনিট)

ফ্যাক্টরির হিসাব বিভাগ চায়: প্রতিটা বিভাগের নিচে তার মোট, শেষে সবার মোট।

### উপায় ১: Control Break

রো বিভাগ অনুযায়ী সাজানো থাকলে, বিভাগ বদলানোর মুহূর্তে আগেরটার মোট ছাপাও।

```sql
DECLARE
    CURSOR c_emp IS
        SELECT dept_name, emp_name, basic_salary
        FROM   w16_emp
        WHERE  status = 'ACTIVE'
        ORDER  BY dept_name, emp_id;

    v_prev_dept  w16_emp.dept_name%TYPE;
    v_dept_total NUMBER := 0;
    v_grand      NUMBER := 0;
BEGIN
    FOR r IN c_emp LOOP
        -- বিভাগ বদলেছে, আর আগে একটা বিভাগ ছিল
        IF v_prev_dept IS NOT NULL AND r.dept_name <> v_prev_dept THEN
            DBMS_OUTPUT.PUT_LINE('  Subtotal ' || v_prev_dept || ': ' || v_dept_total);
            v_dept_total := 0;
        END IF;

        IF v_prev_dept IS NULL OR r.dept_name <> v_prev_dept THEN
            DBMS_OUTPUT.PUT_LINE('== ' || r.dept_name || ' ==');
        END IF;

        DBMS_OUTPUT.PUT_LINE('  ' || RPAD(r.emp_name, 10) || LPAD(r.basic_salary, 8));
        v_dept_total := v_dept_total + r.basic_salary;
        v_grand      := v_grand + r.basic_salary;
        v_prev_dept  := r.dept_name;
    END LOOP;

    -- শেষ বিভাগের মোট Loop-এর বাইরে
    IF v_prev_dept IS NOT NULL THEN
        DBMS_OUTPUT.PUT_LINE('  Subtotal ' || v_prev_dept || ': ' || v_dept_total);
    END IF;
    DBMS_OUTPUT.PUT_LINE('Grand Total: ' || v_grand);
END;
/
```

```
== Cutting ==
  Rahim        15000
  Karim        12000
  Subtotal Cutting: 27000
== Finishing ==
  Nasima        9800
  Sumon        10200
  Subtotal Finishing: 20000
== Quality ==
  ...
  Subtotal Quality: 30500
== Sewing ==
  ...
  Subtotal Sewing: 34500
Grand Total: 112000
```

**সবচেয়ে সাধারণ ভুল:** শেষ বিভাগের Subtotal ভুলে যাওয়া। Loop-এর ভেতরে শুধু "বদলালে" ছাপা হয়, আর শেষ বিভাগের পরে কোনো বদল আসে না।

`ORDER BY dept_name` না দিলে রিপোর্ট ভেঙে যাবে: একই বিভাগ কয়েকবার আসবে।

### উপায় ২: Nested Cursor FOR Loop

বাইরের Loop বিভাগ, ভেতরের Loop সেই বিভাগের কর্মচারী।

```sql
DECLARE
    v_dept_total NUMBER;
    v_grand      NUMBER := 0;
BEGIN
    FOR d IN (SELECT DISTINCT dept_name
              FROM   w16_emp
              WHERE  status = 'ACTIVE'
              ORDER  BY dept_name)
    LOOP
        DBMS_OUTPUT.PUT_LINE('== ' || d.dept_name || ' ==');
        v_dept_total := 0;

        FOR e IN (SELECT emp_name, basic_salary
                  FROM   w16_emp
                  WHERE  dept_name = d.dept_name
                  AND    status = 'ACTIVE'
                  ORDER  BY emp_id)
        LOOP
            DBMS_OUTPUT.PUT_LINE('  ' || RPAD(e.emp_name, 10) || LPAD(e.basic_salary, 8));
            v_dept_total := v_dept_total + e.basic_salary;
        END LOOP;

        DBMS_OUTPUT.PUT_LINE('  Subtotal: ' || v_dept_total);
        v_grand := v_grand + v_dept_total;
    END LOOP;
    DBMS_OUTPUT.PUT_LINE('Grand Total: ' || v_grand);
END;
/
```

ভেতরের Query বাইরের Record `d.dept_name` ব্যবহার করছে।

| | Control Break | Nested |
|---|---|---|
| Query | ১টা | বাইরের ১ + প্রতিটা বিভাগে ১টা |
| কোড বোঝা | কঠিন | সহজ |
| বড় ডাটায় | দ্রুত | ধীর (বিভাগ ১০০টা হলে ১০১ Query) |

শেখার সময় Nested সহজ। আসল প্রজেক্টে কয়েক হাজার রো হলে Control Break।

**ভুল:**

- **১৪:** Cursor FOR নিজেই `OPEN` করে। আগে `OPEN` দেওয়ায় `ORA-06511: cursor already open`। `OPEN c;` মুছে দাও।
- **১৫:** `basic_salary * 2`-এর কোনো Alias নেই, আর `r.basic_salary` নামের কলাম Cursor-এ নেই। `basic_salary * 2 AS double_basic` দিয়ে `r.double_basic` পড়ো।
- **১৬:** Loop শেষে Cursor বন্ধ, `c%ROWCOUNT`: `ORA-01001`। Loop-এর ভেতরে Counter বাড়াও।

</details>

## সারাংশ

- `FOR r IN c LOOP ... END LOOP;`: খোলা, পড়া, থামা, বন্ধ করা সব Oracle-এর
- `FOR r IN (SELECT ...)`: `DECLARE` ছাড়াই
- `r` শুধু Loop-এর ভেতরে, Loop শেষে Cursor বন্ধ, মোট লাগলে নিজের Counter
- সাবটোটাল: Control Break (১টা Query, দ্রুত) বা Nested Loop (সহজ, ধীর)
- সাধারণ কাজে Cursor FOR-ই প্রথম পছন্দ

**পরের ক্লাস (বুধবার):** Parameterized Cursor, `FOR UPDATE`, `WHERE CURRENT OF`।
