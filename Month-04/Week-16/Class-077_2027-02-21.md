- কেন Explicit Cursor লাগে

## ১. সমস্যা (২০ মিনিট)

কালকের হোমওয়ার্ক মনে আছে? Sewing-এর ৩ জনের নাম ছাপাতে হবে।

```sql
DECLARE
    v_name w16_emp.emp_name%TYPE;
BEGIN
    SELECT emp_name INTO v_name FROM w16_emp WHERE dept_name = 'Sewing';
END;
/
-- ORA-01422: exact fetch returns more than requested number of rows
```

`SELECT INTO` একটা বালতি, একবারে একটা রো ধরে। ৩টা রো আসলে উপচে পড়ে।

**সমাধান:** Query-কে একটা নাম দাও, তারপর রো-গুলো এক এক করে তুলে আনো। এটাই **Explicit Cursor**।

| | Implicit | Explicit |
|---|---|---|
| কে ঘোষণা করে | Oracle | তুমি, `DECLARE`-এ |
| রো | ০ বা ১ (`SELECT INTO`) | যত খুশি |
| নিয়ন্ত্রণ | নেই | খোলা, পড়া, বন্ধ করা তোমার হাতে |
| নাম | `SQL` | তোমার দেওয়া, যেমন `c_emp` |

## ২. চার ধাপ (৪০ মিনিট)

| ধাপ | কোথায় | কী হয় |
|---|---|---|
| ১. `CURSOR c IS SELECT ...;` | `DECLARE` | Query-কে নাম দেওয়া, এখনো চলে না |
| ২. `OPEN c;` | `BEGIN` | Query চলে, ফলাফল তৈরি, আঙুল প্রথম রো-র আগে |
| ৩. `FETCH c INTO ...;` | `BEGIN` | একটা রো Variable-এ আসে, আঙুল এক ধাপ এগোয় |
| ৪. `CLOSE c;` | `BEGIN` | মেমোরি ছেড়ে দেওয়া |

### প্রথম Cursor

```sql
SET SERVEROUTPUT ON

DECLARE
    CURSOR c_sewing IS
        SELECT emp_name
        FROM   w16_emp
        WHERE  dept_name = 'Sewing'
        ORDER  BY emp_id;

    v_name w16_emp.emp_name%TYPE;
BEGIN
    OPEN c_sewing;

    FETCH c_sewing INTO v_name;
    DBMS_OUTPUT.PUT_LINE(v_name);         -- Salma

    FETCH c_sewing INTO v_name;
    DBMS_OUTPUT.PUT_LINE(v_name);         -- Rina

    FETCH c_sewing INTO v_name;
    DBMS_OUTPUT.PUT_LINE(v_name);         -- Jamal

    CLOSE c_sewing;
END;
/
```

খেয়াল করো:

- `CURSOR` Variable-এর মতো `DECLARE`-এ, তবে Variable-এর পরে বা আগে দুইভাবেই চলে
- `ORDER BY` না দিলে রো-র ক্রম নিশ্চিত না
- নামের আগে `c_` দিলে কোডে চেনা সহজ

### কয়েকটা কলাম

`INTO`-তে Variable-এর সংখ্যা আর ক্রম `SELECT`-এর কলামের মতো হতে হবে।

```sql
DECLARE
    CURSOR c_emp IS
        SELECT emp_id, emp_name, basic_salary
        FROM   w16_emp
        WHERE  dept_name = 'Cutting'
        ORDER  BY emp_id;

    v_id    w16_emp.emp_id%TYPE;
    v_name  w16_emp.emp_name%TYPE;
    v_basic w16_emp.basic_salary%TYPE;
BEGIN
    OPEN c_emp;

    FETCH c_emp INTO v_id, v_name, v_basic;
    DBMS_OUTPUT.PUT_LINE(v_id || ' ' || v_name || ' ' || v_basic);    -- 1 Rahim 15000

    FETCH c_emp INTO v_id, v_name, v_basic;
    DBMS_OUTPUT.PUT_LINE(v_id || ' ' || v_name || ' ' || v_basic);    -- 2 Karim 12000

    CLOSE c_emp;
END;
/
```

### OPEN-এর সময় ডাটা আটকে যায়

`OPEN`-এর মুহূর্তে যা ছিল, Cursor সেটাই দেখায়। খোলার পরে টেবিল বদলালেও Cursor-এর ফলাফল বদলায় না। Oracle-এর এই গুণকে বলে **Read Consistency**।

```sql
DECLARE
    CURSOR c IS SELECT basic_salary FROM w16_emp WHERE emp_id = 1;
    v_basic NUMBER;
BEGIN
    OPEN c;
    UPDATE w16_emp SET basic_salary = 99999 WHERE emp_id = 1;
    FETCH c INTO v_basic;
    DBMS_OUTPUT.PUT_LINE(v_basic);        -- 15000, 99999 না
    CLOSE c;
    ROLLBACK;
END;
/
```

## ৩. Record-এ FETCH (৩০ মিনিট)

অনেক কলামে আলাদা Variable বানানো ঝামেলা। ক্লাস ৬৮-এর `%ROWTYPE` মনে আছে? Cursor-এরও `%ROWTYPE` হয়।

```sql
DECLARE
    CURSOR c_emp IS
        SELECT emp_id, emp_name, dept_name, basic_salary
        FROM   w16_emp
        WHERE  dept_name = 'Quality'
        ORDER  BY emp_id;

    r_emp c_emp%ROWTYPE;          -- Cursor-এর কলামগুলো নিয়ে Record
BEGIN
    OPEN c_emp;

    FETCH c_emp INTO r_emp;
    DBMS_OUTPUT.PUT_LINE(r_emp.emp_name || ' - ' || r_emp.basic_salary);   -- Farida - 14000

    FETCH c_emp INTO r_emp;
    DBMS_OUTPUT.PUT_LINE(r_emp.emp_name || ' - ' || r_emp.basic_salary);   -- Habib - 16500

    CLOSE c_emp;
END;
/
```

| ঘোষণা | কাঠামো আসে |
|---|---|
| `w16_emp%ROWTYPE` | টেবিলের সব কলাম |
| `c_emp%ROWTYPE` | Cursor-এর `SELECT`-এর কলাম |

Cursor-এ ৪টা কলাম থাকলে `w16_emp%ROWTYPE`-এ (৫টা কলাম) `FETCH` করা যাবে না। তাই `c_emp%ROWTYPE` সবচেয়ে নিরাপদ।

### হিসাবের কলামে Alias দাও

```sql
DECLARE
    CURSOR c_emp IS
        SELECT emp_name,
               basic_salary * 0.5 AS house_rent
        FROM   w16_emp
        WHERE  emp_id = 3;

    r c_emp%ROWTYPE;
BEGIN
    OPEN c_emp;
    FETCH c_emp INTO r;
    DBMS_OUTPUT.PUT_LINE(r.emp_name || ' house rent ' || r.house_rent);  -- Salma house rent 5500
    CLOSE c_emp;
END;
/
```

Alias না দিলে Record-এ কলামটার কোনো ব্যবহারযোগ্য নাম থাকে না, তাই পড়া যায় না। **হিসাবের কলামে সবসময় Alias।**

### JOIN আর GROUP BY-ও চলে

Cursor-এর ভেতরে যেকোনো `SELECT` লেখা যায়, যা মাস ২–৩-এ শিখেছ।

```sql
DECLARE
    CURSOR c_dept IS
        SELECT dept_name, COUNT(*) AS emp_cnt, SUM(basic_salary) AS total_basic
        FROM   w16_emp
        WHERE  status = 'ACTIVE'
        GROUP  BY dept_name
        ORDER  BY dept_name;

    r c_dept%ROWTYPE;
BEGIN
    OPEN c_dept;
    FETCH c_dept INTO r;
    DBMS_OUTPUT.PUT_LINE(r.dept_name || ': ' || r.emp_cnt || ', ' || r.total_basic);  -- Cutting: 2, 27000
    CLOSE c_dept;
END;
/
```

## ৪. Loop দিয়ে সব রো, আর সাধারণ ভুল (২৫ মিনিট)

কয়টা রো আছে আগে জানো না। তাই `FETCH` বারবার, আর রো শেষ হলে থামো। থামার শর্ত `c%NOTFOUND`, কাল এটা বিস্তারিত।

```sql
DECLARE
    CURSOR c_emp IS
        SELECT emp_id, emp_name, dept_name
        FROM   w16_emp
        WHERE  status = 'ACTIVE'
        ORDER  BY emp_id;

    r c_emp%ROWTYPE;
BEGIN
    OPEN c_emp;
    LOOP
        FETCH c_emp INTO r;
        EXIT WHEN c_emp%NOTFOUND;          -- FETCH-এর ঠিক পরে
        DBMS_OUTPUT.PUT_LINE(r.emp_id || '. ' || r.emp_name || ' (' || r.dept_name || ')');
    END LOOP;
    CLOSE c_emp;
END;
/
```

```
1. Rahim (Cutting)
2. Karim (Cutting)
...
9. Habib (Quality)
```

৯টা লাইন, Tania নেই।

### শেষ রো-র পরে FETCH করলে?

**এরর আসে না।** Variable-এ আগের রো-র মানই থেকে যায়, আর `%NOTFOUND` TRUE হয়। তাই `EXIT WHEN` না দিলে Loop কখনো থামবে না।

### সাধারণ এরর

| ভুল | এরর |
|---|---|
| `OPEN` ছাড়া `FETCH` | `ORA-01001: invalid cursor` |
| খোলা Cursor আবার `OPEN` | `ORA-06511: cursor already open` |
| `CLOSE`-এর পরে `FETCH` বা আবার `CLOSE` | `ORA-01001: invalid cursor` |
| `INTO`-তে Variable-এর সংখ্যা কম-বেশি | `PLS-00394: wrong number of values in the INTO list` |
| `CLOSE` ভুলে যাওয়া | এরর না, কিন্তু মেমোরি আটকে থাকে। বড় প্রোগ্রামে `ORA-01000: maximum open cursors exceeded` |

**অভ্যাস:** `OPEN` লিখেই নিচে `CLOSE` লিখে ফেলো, তারপর মাঝে কাজ।

### বন্ধ করে আবার খোলা যায়

```sql
OPEN c_emp;   ... CLOSE c_emp;
OPEN c_emp;   -- Query আবার চলে, নতুন ডাটা নিয়ে
```

## সারাংশ

- অনেক রো এক এক করে পড়তে Explicit Cursor
- চার ধাপ: `CURSOR ... IS` (DECLARE), `OPEN`, `FETCH ... INTO`, `CLOSE`
- `OPEN`-এর মুহূর্তের ডাটাই Cursor দেখায়
- `c%ROWTYPE` Record সবচেয়ে সহজ, হিসাবের কলামে Alias দাও
- Loop-এ `EXIT WHEN c%NOTFOUND` `FETCH`-এর ঠিক পরে

**পরের ক্লাস (সোমবার):** Cursor Attribute: `%FOUND`, `%NOTFOUND`, `%ISOPEN`, `%ROWCOUNT` বিস্তারিত।
