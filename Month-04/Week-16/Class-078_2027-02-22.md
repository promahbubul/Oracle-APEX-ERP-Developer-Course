# ক্লাস ৭৮: Cursor Attribute: %FOUND, %NOTFOUND, %ISOPEN, %ROWCOUNT

**তারিখ:** ২২ ফেব্রুয়ারি ২০২৭, সোমবার
**সময়:** সন্ধ্যা ৭:০০ থেকে রাত ১০:০০
**সপ্তাহ:** ১৬ | **ধাপ:** ৩ (PL/SQL)

---

## আজকে কী শিখব

- Explicit Cursor-এর ৪টা Attribute
- প্রতিটা ধাপে কোন Attribute-এর কী মান
- `%NOTFOUND` আর `%FOUND` দিয়ে Loop
- `%ROWCOUNT` দিয়ে ক্রমিক নম্বর আর প্রথম N টা রো
- `%ISOPEN` দিয়ে নিরাপদে বন্ধ করা
- Implicit আর Explicit Attribute-এর তুলনা

---

## ১. চারটা Attribute (৩০ মিনিট)

ক্লাস ৭৬-এ `SQL%...` দেখেছ। Explicit Cursor-এ `SQL`-এর জায়গায় Cursor-এর নাম বসে।

| Attribute | প্রশ্ন | ধরন |
|---|---|---|
| `c%FOUND` | শেষ `FETCH` রো পেয়েছে? | BOOLEAN |
| `c%NOTFOUND` | শেষ `FETCH` রো পায়নি? | BOOLEAN |
| `c%ISOPEN` | Cursor খোলা? | BOOLEAN |
| `c%ROWCOUNT` | এ পর্যন্ত কয়টা রো `FETCH` হয়েছে? | NUMBER |

### প্রতি ধাপে মান

Sewing-এর ৩টা রো ধরে:

| মুহূর্ত | `%ISOPEN` | `%FOUND` | `%NOTFOUND` | `%ROWCOUNT` |
|---|---|---|---|---|
| `OPEN`-এর আগে | FALSE | **ORA-01001** | **ORA-01001** | **ORA-01001** |
| `OPEN`-এর পরে, `FETCH`-এর আগে | TRUE | NULL | NULL | 0 |
| ১ম `FETCH` (Salma) | TRUE | TRUE | FALSE | 1 |
| ২য় `FETCH` (Rina) | TRUE | TRUE | FALSE | 2 |
| ৩য় `FETCH` (Jamal) | TRUE | TRUE | FALSE | 3 |
| ৪র্থ `FETCH` (কিছু নেই) | TRUE | FALSE | TRUE | **3** |
| `CLOSE`-এর পরে | FALSE | **ORA-01001** | **ORA-01001** | **ORA-01001** |

তিনটা জিনিস মুখস্থ রাখো:

1. **`%ISOPEN` সবসময় নিরাপদ।** বাকি তিনটা বন্ধ Cursor-এ এরর দেয়।
2. **প্রথম `FETCH`-এর আগে `%FOUND`/`%NOTFOUND` NULL।**
3. **ব্যর্থ `FETCH` `%ROWCOUNT` বাড়ায় না।** শেষে এটাই মোট রো সংখ্যা।

### নিজে দেখো

```sql
SET SERVEROUTPUT ON

DECLARE
    CURSOR c IS SELECT emp_name FROM w16_emp WHERE dept_name = 'Sewing' ORDER BY emp_id;
    v_name w16_emp.emp_name%TYPE;

    FUNCTION b(p BOOLEAN) RETURN VARCHAR2 IS
    BEGIN
        RETURN CASE WHEN p THEN 'T' WHEN NOT p THEN 'F' ELSE 'NULL' END;
    END;
BEGIN
    DBMS_OUTPUT.PUT_LINE('before open: isopen=' || b(c%ISOPEN));
    OPEN c;
    DBMS_OUTPUT.PUT_LINE('after open: found=' || b(c%FOUND) || ' rowcount=' || c%ROWCOUNT);

    FOR i IN 1..4 LOOP
        FETCH c INTO v_name;
        DBMS_OUTPUT.PUT_LINE('fetch ' || i || ': found=' || b(c%FOUND)
                             || ' notfound=' || b(c%NOTFOUND)
                             || ' rowcount=' || c%ROWCOUNT || ' name=' || v_name);
    END LOOP;

    CLOSE c;
    DBMS_OUTPUT.PUT_LINE('after close: isopen=' || b(c%ISOPEN));
END;
/
```

`b` একটা ছোট Function, BOOLEAN-কে লেখায় বদলায়। Function সপ্তাহ ১৮-তে শিখবে, এখন শুধু ব্যবহার করো।

৪র্থ লাইনে `name=Jamal` আবার আসবে, কারণ ব্যর্থ `FETCH` Variable বদলায় না।

## ২. %NOTFOUND আর %FOUND দিয়ে Loop (৩০ মিনিট)

### ধরন ১: LOOP + EXIT WHEN %NOTFOUND (সবচেয়ে প্রচলিত)

```sql
OPEN c;
LOOP
    FETCH c INTO r;
    EXIT WHEN c%NOTFOUND;
    -- কাজ
END LOOP;
CLOSE c;
```

### ধরন ২: WHILE %FOUND

```sql
OPEN c;
FETCH c INTO r;                 -- আগে একবার
WHILE c%FOUND LOOP
    -- কাজ
    FETCH c INTO r;             -- শেষে আবার
END LOOP;
CLOSE c;
```

প্রথম `FETCH` না দিলে `c%FOUND` NULL, তাই `WHILE` একবারও চলবে না। এরর আসবে না, শুধু কিছু ছাপাবে না। খুঁজে পাওয়া কঠিন ভুল।

### খালি Cursor

```sql
DECLARE
    CURSOR c IS SELECT emp_name FROM w16_emp WHERE dept_name = 'Washing';
    v_name w16_emp.emp_name%TYPE;
BEGIN
    OPEN c;
    FETCH c INTO v_name;
    IF c%NOTFOUND THEN
        DBMS_OUTPUT.PUT_LINE('No employee in Washing');
    END IF;
    CLOSE c;
END;
/
```

`SELECT INTO`-র মতো এরর না, শুধু `%NOTFOUND`। "আছে কি না" দেখার আরেক উপায়।

### `EXIT WHEN` কোথায়?

| `EXIT WHEN` কোথায় | ফল |
|---|---|
| `FETCH`-এর ঠিক পরে | ঠিক |
| কাজের পরে | শেষ রো দুইবার |
| `FETCH`-এর আগে | প্রথমবার NULL, `EXIT` হয় না, পরে শেষ রো দুইবার |

## ৩. %ROWCOUNT (২৫ মিনিট)

### ক্রমিক নম্বর

আলাদা Counter লাগে না।

```sql
DECLARE
    CURSOR c_emp IS
        SELECT emp_name, dept_name FROM w16_emp WHERE status = 'ACTIVE' ORDER BY emp_name;
    r c_emp%ROWTYPE;
BEGIN
    OPEN c_emp;
    LOOP
        FETCH c_emp INTO r;
        EXIT WHEN c_emp%NOTFOUND;
        DBMS_OUTPUT.PUT_LINE(c_emp%ROWCOUNT || '. ' || r.emp_name || ' - ' || r.dept_name);
    END LOOP;
    DBMS_OUTPUT.PUT_LINE('Total: ' || c_emp%ROWCOUNT);     -- 9, CLOSE-এর আগে পড়ো
    CLOSE c_emp;
END;
/
```

```
1. Farida - Quality
2. Habib - Quality
3. Jamal - Sewing
...
9. Sumon - Finishing
Total: 9
```

### প্রথম N টা রো

সবচেয়ে বেশি Basic-এর ৩ জন:

```sql
DECLARE
    CURSOR c_top IS
        SELECT emp_name, basic_salary
        FROM   w16_emp
        WHERE  status = 'ACTIVE'
        ORDER  BY basic_salary DESC;
    r c_top%ROWTYPE;
BEGIN
    OPEN c_top;
    LOOP
        FETCH c_top INTO r;
        EXIT WHEN c_top%NOTFOUND OR c_top%ROWCOUNT > 3;
        DBMS_OUTPUT.PUT_LINE(c_top%ROWCOUNT || '. ' || r.emp_name || ' ' || r.basic_salary);
    END LOOP;
    CLOSE c_top;
END;
/
-- 1. Habib 16500
-- 2. Rahim 15000
-- 3. Farida 14000
```

শুধু রিপোর্টের জন্য হলে SQL-এ `FETCH FIRST 3 ROWS ONLY` (ক্লাস ২৯) আরও ভালো, Oracle পুরো ফলাফল বানায় না।

### প্রতি N টা পরে বিরতি

কাগজে ৪ জনের পরে একটা লাইন:

```sql
IF MOD(c_emp%ROWCOUNT, 4) = 0 THEN
    DBMS_OUTPUT.PUT_LINE('----------');
END IF;
```

## ৪. %ISOPEN (২০ মিনিট)

### বন্ধ করার আগে দেখো

```sql
IF c_emp%ISOPEN THEN
    CLOSE c_emp;
END IF;
```

কোথায় কাজে লাগে? বড় প্রোগ্রামে মাঝপথে বের হয়ে যাওয়ার অনেক রাস্তা থাকে। শেষে এভাবে লিখলে "খোলা ছিল কি না" না জেনেও নিরাপদে বন্ধ হয়।

পরের সপ্তাহে Exception-এ এটা প্রায় সবসময় লাগবে:

```sql
EXCEPTION
    WHEN OTHERS THEN
        IF c_emp%ISOPEN THEN
            CLOSE c_emp;
        END IF;
        RAISE;
```

### খোলা থাকলে আবার না খোলা

```sql
IF NOT c_emp%ISOPEN THEN
    OPEN c_emp;
END IF;
```

### Implicit বনাম Explicit

| | `SQL%` (Implicit) | `c%` (Explicit) |
|---|---|---|
| `%ISOPEN` | সবসময় FALSE | খোলা থাকলে TRUE |
| `%ROWCOUNT` | শেষ SQL কয়টা রো ছুঁয়েছে | এ পর্যন্ত কয়টা `FETCH` |
| কাজের আগে | NULL | বন্ধ থাকলে ORA-01001 (`%ISOPEN` ছাড়া) |
| কোন SQL-এর কথা | শেষ `INSERT`/`UPDATE`/`DELETE`/`SELECT INTO` | শুধু ওই Cursor |

Explicit Cursor-এর Loop-এর ভেতরে `UPDATE` দিলে `SQL%ROWCOUNT` বদলায়, `c%ROWCOUNT` বদলায় না। দুইটা আলাদা।

## ৫. হাতে-কলমে প্র্যাকটিস (৭৫ মিনিট)

11. Cursor শেষ হলে মোট সংখ্যা `0` হলে `Empty`, `1` হলে `1 row`, বেশি হলে `n rows`। Sewing আর Store `ACTIVE` দিয়ে পরীক্ষা করো। (৩ rows, Empty)

- **১৬:** `CLOSE`-এর পরে `c%ROWCOUNT`: `ORA-01001`। `CLOSE`-এর আগে Variable-এ রাখো।

## সারাংশ

- `c%FOUND`, `c%NOTFOUND`: শেষ `FETCH` রো পেল কি না, প্রথম `FETCH`-এর আগে NULL
- `c%ROWCOUNT`: এ পর্যন্ত কয়টা রো, ব্যর্থ `FETCH`-এ বাড়ে না, `CLOSE`-এর আগে পড়ো
- `c%ISOPEN`: একমাত্র Attribute যা বন্ধ Cursor-এ এরর দেয় না
- `LOOP + EXIT WHEN %NOTFOUND` সবচেয়ে প্রচলিত, `WHILE %FOUND`-এ আগে একবার `FETCH`
- `SQL%` আর `c%` আলাদা জিনিস

**পরের ক্লাস (মঙ্গলবার):** Cursor FOR Loop: `OPEN`, `FETCH`, `CLOSE` ছাড়াই সব রো।
