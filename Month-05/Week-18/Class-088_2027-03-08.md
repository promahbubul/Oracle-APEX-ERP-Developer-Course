# ক্লাস ৮৮: Function তৈরি, SQL-এর ভেতর Function ব্যবহার

**তারিখ:** ৮ মার্চ ২০২৭, সোমবার
**সময়:** সন্ধ্যা ৭:০০ থেকে রাত ১০:০০
**সপ্তাহ:** ১৮ | **ধাপ:** ৩ (PL/SQL)

## আজকে কী শিখব

- Function কী, Procedure থেকে কোথায় আলাদা
- `CREATE OR REPLACE FUNCTION ... RETURN`
- PL/SQL থেকে Function ডাকা
- `SELECT`, `WHERE`, `ORDER BY`-এর ভেতরে নিজের Function
- SQL-এ Function-এর নিয়ম আর ফাঁদ

---

## ১. Function কী (২৫ মিনিট)

তুমি মাস ২ থেকে Function ব্যবহার করছ: `UPPER`, `ROUND`, `NVL`, `TO_CHAR`, `MONTHS_BETWEEN`। সবার একটাই ধরন: **মান নাও, একটা মান ফেরত দাও।**

```sql
SELECT ROUND(16967.4) FROM dual;     -- 16967
```

আজ নিজের Function বানাবে:

```sql
SELECT emp_name, w18_gross(basic_salary) FROM w16_emp;
```

| | Procedure | Function |
|---|---|---|
| কাজ | কিছু **করা** (সেভ, আপডেট, প্রসেস) | কিছু **হিসাব করে ফেরত দেওয়া** |
| ফেরত | `OUT` দিয়ে, ০ বা অনেক | `RETURN` দিয়ে, **ঠিক একটা** |
| ডাকা | নিজে এক লাইন: `w18_x(1);` | কোনো Expression-এর অংশ: `v := w18_x(1);` |
| SQL-এর ভেতরে | না | **হ্যাঁ** (নিয়ম মেনে) |

কালকের `w18_calc_salary`-তে ৩টা `OUT` ছিল। শুধু Gross লাগলেও তিনটা Variable দিতে হয়। Gross-এর একটা Function হলে সহজ।

## ২. Function বানানো (৩৫ মিনিট)

```sql
CREATE OR REPLACE FUNCTION w18_gross (
    p_basic IN NUMBER
) RETURN NUMBER
IS
    c_house_pct CONSTANT NUMBER := 0.5;
    c_medical   CONSTANT NUMBER := 750;
    c_transport CONSTANT NUMBER := 450;
BEGIN
    RETURN p_basic + p_basic * c_house_pct + c_medical + c_transport;
END w18_gross;
/
```

| অংশ | মানে |
|---|---|
| `RETURN NUMBER` (মাথায়) | কোন ধরনের মান ফেরত দেবে, সাইজ ছাড়া |
| `RETURN expression;` (ভেতরে) | মান ফেরত দিয়ে **সাথে সাথে বের হওয়া** |

### PL/SQL থেকে ডাকা

```sql
SET SERVEROUTPUT ON

DECLARE
    v_gross NUMBER;
BEGIN
    v_gross := w18_gross(11000);
    DBMS_OUTPUT.PUT_LINE('Gross: ' || v_gross);                -- 17700

    DBMS_OUTPUT.PUT_LINE('Rahim: ' || w18_gross(15000));        -- সরাসরি Expression-এ: 23700

    IF w18_gross(9800) < 16000 THEN
        DBMS_OUTPUT.PUT_LINE('Nasima below 16000');
    END IF;
END;
/
```

শুধু এক লাইনে ডাকলে এরর:

```sql
BEGIN
    w18_gross(11000);
END;
/
-- PLS-00221: 'W18_GROSS' is not a procedure or is undefined
```

ফেরত আসা মান কোথাও রাখতে বা ব্যবহার করতে হবে।

### কয়েকটা RETURN

```sql
CREATE OR REPLACE FUNCTION w18_grade (
    p_marks IN NUMBER
) RETURN VARCHAR2
IS
BEGIN
    IF p_marks IS NULL THEN
        RETURN NULL;
    ELSIF p_marks >= 80 THEN
        RETURN 'A+';
    ELSIF p_marks >= 70 THEN
        RETURN 'A';
    ELSIF p_marks >= 60 THEN
        RETURN 'A-';
    ELSIF p_marks >= 50 THEN
        RETURN 'B';
    ELSIF p_marks >= 40 THEN
        RETURN 'C';
    ELSIF p_marks >= 33 THEN
        RETURN 'D';
    END IF;
    RETURN 'F';
END w18_grade;
/
```

প্রথম যে `RETURN`-এ পৌঁছায়, সেখানেই শেষ।

### RETURN ছাড়া শেষ হলে

```sql
CREATE OR REPLACE FUNCTION w18_no_return (p_x IN NUMBER) RETURN NUMBER
IS
BEGIN
    IF p_x > 0 THEN
        RETURN p_x;
    END IF;
END;
/

SELECT w18_no_return(-1) FROM dual;
-- ORA-06503: PL/SQL: Function returned without value
```

Compile হয় (হয়তো একটা Warning দিয়ে), কিন্তু চালালে এরর। **প্রতিটা পথে `RETURN` থাকতে হবে।** সবচেয়ে নিরাপদ: শেষ লাইনে একটা `RETURN`।

### ডাটাবেস থেকে মান

```sql
CREATE OR REPLACE FUNCTION w18_stock_balance (
    p_item_id IN w14_stock.item_id%TYPE
) RETURN NUMBER
IS
    v_bal w14_stock.balance_qty%TYPE;
BEGIN
    SELECT balance_qty INTO v_bal FROM w14_stock WHERE item_id = p_item_id;
    RETURN v_bal;
EXCEPTION
    WHEN NO_DATA_FOUND THEN
        RAISE_APPLICATION_ERROR(-20003, 'Item ' || p_item_id || ' not found');
END w18_stock_balance;
/

BEGIN
    DBMS_OUTPUT.PUT_LINE(w18_stock_balance(1));        -- 600
END;
/
```

## ৩. SQL-এর ভেতরে (৩৫ মিনিট)

এটাই Function-এর আসল শক্তি।

```sql
SELECT emp_name,
       basic_salary,
       w18_gross(basic_salary) AS gross
FROM   w16_emp
WHERE  status = 'ACTIVE'
ORDER  BY emp_id;
```

| EMP_NAME | BASIC_SALARY | GROSS |
|---|---|---|
| Rahim | 15000 | 23700 |
| Karim | 12000 | 19200 |
| ... | ... | ... |

### WHERE, ORDER BY, GROUP BY-তেও

```sql
SELECT emp_name, w18_gross(basic_salary) AS gross
FROM   w16_emp
WHERE  w18_gross(basic_salary) > 20000
ORDER  BY w18_gross(basic_salary) DESC;
-- Habib 25950, Rahim 23700, Farida 22200, Jamal 20700
```

```sql
SELECT dept_name, SUM(w18_gross(basic_salary)) AS total_gross
FROM   w16_emp
WHERE  status = 'ACTIVE'
GROUP  BY dept_name
ORDER  BY dept_name;
-- Cutting 42900, Finishing 32400, Quality 48150, Sewing 55350
```

### আরো উদাহরণ

```sql
CREATE OR REPLACE FUNCTION w18_deduction (
    p_basic IN NUMBER,
    p_days  IN NUMBER
) RETURN NUMBER
IS
BEGIN
    RETURN ROUND(p_basic / 30 * NVL(p_days, 0));
END w18_deduction;
/

CREATE OR REPLACE FUNCTION w18_emp_name (
    p_emp_id IN w16_emp.emp_id%TYPE
) RETURN VARCHAR2
IS
    v_name w16_emp.emp_name%TYPE;
BEGIN
    SELECT emp_name INTO v_name FROM w16_emp WHERE emp_id = p_emp_id;
    RETURN v_name;
EXCEPTION
    WHEN NO_DATA_FOUND THEN
        RETURN '(unknown)';
END w18_emp_name;
/
```

```sql
SELECT a.emp_id,
       w18_emp_name(a.emp_id) AS name,
       a.absent_days,
       w18_deduction(e.basic_salary, a.absent_days) AS deduction
FROM   w16_absent a
       JOIN w16_emp e ON e.emp_id = a.emp_id
WHERE  a.absent_month = '2027-01';
-- Salma 733, Nasima 327, Habib 1650
```

### Function বনাম JOIN

`w18_emp_name(a.emp_id)` প্রতিটা রো-র জন্য একটা আলাদা `SELECT` চালায়। ১০টা রো-তে সমস্যা না, ১ লাখ রো-তে ১ লাখ বাড়তি Query। এই ক্ষেত্রে `JOIN` দ্রুত।

**নিয়ম:**
- হিসাব (Gross, Deduction, Grade): Function দারুণ, কোনো টেবিল পড়ে না
- অন্য টেবিল থেকে মান আনা: সম্ভব হলে `JOIN`, Function শুধু ছোট রিপোর্ট বা PL/SQL-এ

### View-এর ভেতরে

```sql
CREATE OR REPLACE VIEW w18_emp_salary_v AS
SELECT emp_id, emp_name, dept_name, basic_salary,
       w18_gross(basic_salary) AS gross_salary
FROM   w16_emp
WHERE  status = 'ACTIVE';

SELECT * FROM w18_emp_salary_v ORDER BY gross_salary DESC;
```

APEX-এর রিপোর্ট এমন View থেকে বানালে নিয়ম থাকে ডাটাবেসে, পেজে না।

## ৪. SQL-এ Function-এর নিয়ম আর ফাঁদ (২৫ মিনিট)

### নিয়ম ১: SELECT থেকে ডাকা Function DML করতে পারে না

```sql
CREATE OR REPLACE FUNCTION w18_bad_fn (p_id IN NUMBER) RETURN NUMBER
IS
BEGIN
    UPDATE w16_emp SET basic_salary = basic_salary WHERE emp_id = p_id;
    RETURN 1;
END;
/

SELECT w18_bad_fn(1) FROM dual;
-- ORA-14551: cannot perform a DML operation inside a query
```

একটা `SELECT` পড়ার সময় টেবিল বদলাতে পারে না। PL/SQL থেকে (`v := w18_bad_fn(1);`) ডাকলে চলে, কিন্তু DML করা Function বানানোই খারাপ অভ্যাস। **বদল করলে Procedure।**

### নিয়ম ২: SQL-এ OUT Parameter চলে না

`OUT` বা `IN OUT` Parameter থাকলে Function SQL থেকে ডাকা যায় না। SQL-এ Function শুধু `IN` নেবে, একটা মান দেবে।

### নিয়ম ৩: ধরন SQL-এর হতে হবে

`NUMBER`, `VARCHAR2`, `DATE` ঠিক আছে। `BOOLEAN` রিটার্ন করা Function পুরনো ভার্সনে (২১c পর্যন্ত) SQL-এ চলে না। Oracle 23ai-তে `BOOLEAN` SQL-এরও ধরন হয়েছে, তাই চলে। তবু অন্য ভার্সনে চলবে এমন কোড চাইলে `'Y'`/`'N'` ফেরত দাও।

### ফাঁদ: SQL-এ NO_DATA_FOUND চুপ হয়ে যায়

`w18_stock_balance`-এর একটা সংস্করণ, Handler ছাড়া:

```sql
CREATE OR REPLACE FUNCTION w18_bal_unsafe (p_item_id IN NUMBER) RETURN NUMBER
IS
    v_bal NUMBER;
BEGIN
    SELECT balance_qty INTO v_bal FROM w14_stock WHERE item_id = p_item_id;
    RETURN v_bal;
END;
/

SELECT w18_bal_unsafe(99) AS bal FROM dual;      -- NULL, কোনো এরর নেই!

BEGIN
    DBMS_OUTPUT.PUT_LINE(w18_bal_unsafe(99));    -- ORA-01403
END;
/
```

PL/SQL থেকে ডাকলে এরর, কিন্তু **SQL থেকে ডাকলে Oracle NO_DATA_FOUND-কে "কোনো মান নেই" ধরে NULL দেখায়।** রিপোর্টে খালি ঘর আসবে, কেউ টের পাবে না কেন।

**নিয়ম:** `SELECT INTO` থাকা Function-এ `NO_DATA_FOUND` সবসময় নিজে ধরো। হয় অর্থবহ মান (`'(unknown)'`), নয় `RAISE_APPLICATION_ERROR` (SQL থেকেও এটা আসল এরর দেখায়)।

### দেখো তো, আমার Function কোথায়

```sql
SELECT object_name, object_type, status
FROM   user_objects
WHERE  object_name LIKE 'W18%'
ORDER  BY object_type, object_name;

DROP FUNCTION w18_bad_fn;
```

## ৫. হাতে-কলমে প্র্যাকটিস (৬০ মিনিট)

সব `learn_freepdb1`-এ, নামের আগে `w18_`।

1. `w18_gross` বানাও। PL/SQL আর SQL দুই জায়গা থেকে ১১০০০ দিয়ে। (১৭৭০০)
2. `SELECT` দিয়ে সব `ACTIVE`-এর Gross, আর মোট। (১৭৮৮০০)
3. `w18_deduction` বানাও, `w16_absent`-এর সাথে Query। (মোট ২৭১০)
4. `w18_net(p_basic, p_days)` বানাও, ভেতরে `w18_gross` আর `w18_deduction` ব্যবহার করে। `w16_salary`-র সাথে মিলাও: যেখানে `w18_net` ≠ `net_salary` এমন রো খোঁজো। (০টা)
5. `w18_grade` বানাও, ৮০, ৭৯, ৩৩, ৩২, NULL দিয়ে SQL-এ।
6. `w18_stock_balance` বানাও। SQL-এ `w14_stock`-এর সব আইটেমের সাথে, আর আইটেম ৯৯ দিয়ে। কী আসে?
7. `w18_bal_unsafe` দিয়ে ফাঁদটা নিজে দেখো: SQL থেকে আর PL/SQL থেকে।
8. `w18_emp_name` বানাও, `w16_salary`-র সাথে Query: নাম আর Net।
9. ৮ নম্বরের Query আবার `JOIN` দিয়ে লেখো। ফলাফল একই?
10. `w18_is_low_stock(p_item_id) RETURN VARCHAR2`: ১০০-র কম হলে `'Y'`, না হলে `'N'`। `WHERE w18_is_low_stock(item_id) = 'Y'`। (Button 18L)
11. `w18_age_years(p_dob DATE) RETURN NUMBER`: `MONTHS_BETWEEN` দিয়ে পূর্ণ বছর। `DATE '1995-08-15'` থেকে `DATE '2027-03-08'` পর্যন্ত। (৩১) আজকের তারিখ Parameter হিসেবে দাও, যাতে পরীক্ষা সহজ হয়।
12. `w18_ctn_count(p_qty, p_per_ctn) RETURN NUMBER`: কয়টা কার্টন। (৫০, ১২) → ৫।
13. `w18_emp_salary_v` View বানাও, ১৭৮৮০০ মিলাও।
14. `w18_bad_fn` দিয়ে `ORA-14551` দেখো। তারপর মুছে ফেলো।
15. `w18_no_return` দিয়ে `ORA-06503` দেখো, ঠিক করো।

## সারাংশ

- Function: `IN` নাও, `RETURN` দিয়ে ঠিক একটা মান দাও
- মাথায় `RETURN type`, ভেতরে প্রতিটা পথে `RETURN value;`
- Expression-এর অংশ হিসেবে ডাকো, এক লাইনে নিজে না
- SQL-এর `SELECT`, `WHERE`, `ORDER BY`, `GROUP BY`, View-এ চলে
- SQL-এ: DML না, `OUT` না, SQL-এর ধরন; NO_DATA_FOUND নিজে ধরো
- অন্য টেবিল থেকে মান আনার Function-এর চেয়ে `JOIN` দ্রুত

**পরের ক্লাস (মঙ্গলবার):** Procedure বনাম Function: কখন কোনটা, `COMMIT` কার দায়িত্ব, Dependency আর অনুমতি।
