# ক্লাস ৯১: Package কী, Specification ও Body

**তারিখ:** ১৩ মার্চ ২০২৭, শনিবার
**সময়:** সন্ধ্যা ৭:০০ থেকে রাত ১০:০০
**সপ্তাহ:** ১৯ | **ধাপ:** ৩ (PL/SQL)

---

## আজকে কী শিখব

- ৩০টা ছড়ানো Procedure-এর সমস্যা, Package কেন
- Package-এর দুই অংশ: Specification আর Body
- প্রথম Package: স্টকের কাজ এক জায়গায়
- `package.procedure` দিয়ে কল করা
- Spec আর Body না মিললে এরর, Data Dictionary-তে Package

> সব কোড `learn_freepdb1`-এ। এই সপ্তাহের Package-এর নাম `w19_..._pkg`।

## ১. কেন Package (২৫ মিনিট)

গত সপ্তাহের শেষে:

```sql
SELECT object_type, COUNT(*) FROM user_objects
WHERE  object_name LIKE 'W18%' GROUP BY object_type;
-- PROCEDURE  ~20
-- FUNCTION   ~15
```

তিন মাস পরে ৩০০টা। সমস্যা:

| সমস্যা | উদাহরণ |
|---|---|
| কোনটা কোন মডিউলের, বোঝা যায় না | `w18_check_emp` স্যালারির, না HR-এর? |
| সবাই সবকিছু ডাকতে পারে | `w18_process_one_emp` শুধু Payroll-এর ভেতরের জন্য, তবু APEX পেজ সরাসরি ডেকে ফেলল |
| একটা বদলালে অনেক কিছু INVALID | ক্লাস ৮৯ |
| অনুমতি আলাদা আলাদা | ৩০টা `GRANT EXECUTE` |

**Package:** সম্পর্কিত Procedure, Function, Variable, Constant, Exception, Cursor একসাথে বাঁধা একটা বাক্স।

বাস্তব জীবনে একটা ফ্যাক্টরির Store বিভাগের মতো। বাইরে একটা কাউন্টার (কী কী চাওয়া যায়: Receive, Issue, Balance)। ভেতরে র‍্যাক, রেজিস্টার, হিসাবের নিয়ম, যা বাইরের লোক দেখে না।

| অংশ | কাজ | ফ্যাক্টরির উদাহরণ |
|---|---|---|
| **Specification (Spec)** | বাইরে থেকে কী কী ডাকা যায় তার তালিকা | কাউন্টারের নোটিশ বোর্ড |
| **Body** | আসল কোড | স্টোরের ভেতরের কাজ |

Oracle নিজে শত শত Package দিয়ে বানানো। `DBMS_OUTPUT.PUT_LINE`: `DBMS_OUTPUT` Package, `PUT_LINE` তার Procedure। `DBMS_UTILITY.FORMAT_ERROR_BACKTRACE`ও তাই। তুমি সপ্তাহ ১৪ থেকে Package ব্যবহার করছ।

## ২. Specification (৩০ মিনিট)

**শুধু ঘোষণা, কোনো কোড না।**

```sql
CREATE OR REPLACE PACKAGE w19_stock_pkg
IS
    -- এখনকার ব্যালেন্স, না থাকলে -20003
    FUNCTION stock_balance (
        p_item_id IN w14_stock.item_id%TYPE
    ) RETURN NUMBER;

    -- স্টকে যোগ আর w14_txn-এ RECEIVE
    PROCEDURE stock_receive (
        p_item_id     IN  w14_stock.item_id%TYPE,
        p_qty         IN  NUMBER,
        p_max_receive IN  NUMBER DEFAULT 5000,
        p_txn_id      OUT w14_txn.txn_id%TYPE
    );

    -- স্টক থেকে বাদ আর w14_txn-এ ISSUE
    PROCEDURE stock_issue (
        p_item_id   IN  w14_stock.item_id%TYPE,
        p_qty       IN  NUMBER,
        p_min_stock IN  NUMBER DEFAULT 20,
        p_max_issue IN  NUMBER DEFAULT 500,
        p_txn_id    OUT w14_txn.txn_id%TYPE
    );
END w19_stock_pkg;
/
```

- প্রতিটা Procedure/Function-এর মাথা (নাম, Parameter, `RETURN`), শেষে `;`, কোনো `IS ... BEGIN ... END` না
- Package-এর ভেতরে নামে `w19_` লাগে না, Package-এর নামই সেটা বলে
- উপরে এক লাইনের কমেন্ট: Spec-ই অন্য ডেভেলপারের পড়ার জায়গা

`F5`: `Package W19_STOCK_PKG compiled`। Body ছাড়াই Spec Compile হয়।

### Body ছাড়া ডাকলে

```sql
SELECT w19_stock_pkg.stock_balance(1) FROM dual;
-- ORA-04067: not executed, package body "LEARN.W19_STOCK_PKG" does not exist
```

Spec একটা প্রতিশ্রুতি। কাজ এখনো হয়নি।

### এর সুবিধা

টিমে একজন Spec লিখে দিলে APEX-এর ডেভেলপার পেজ বানানো শুরু করতে পারে, আর আরেকজন একই সময়ে Body লেখে। APEX পেজ Compile হতে শুধু Spec লাগে।

## ৩. Body (৪০ মিনিট)

**Spec-এর প্রতিটা ঘোষণার আসল কোড।**

```sql
CREATE OR REPLACE PACKAGE BODY w19_stock_pkg
IS
    -------------------------------------------------------------------
    FUNCTION stock_balance (
        p_item_id IN w14_stock.item_id%TYPE
    ) RETURN NUMBER
    IS
        v_bal w14_stock.balance_qty%TYPE;
    BEGIN
        SELECT balance_qty INTO v_bal FROM w14_stock WHERE item_id = p_item_id;
        RETURN v_bal;
    EXCEPTION
        WHEN NO_DATA_FOUND THEN
            RAISE_APPLICATION_ERROR(-20003, 'Item ' || p_item_id || ' not found');
    END stock_balance;

    -------------------------------------------------------------------
    PROCEDURE stock_receive (
        p_item_id     IN  w14_stock.item_id%TYPE,
        p_qty         IN  NUMBER,
        p_max_receive IN  NUMBER DEFAULT 5000,
        p_txn_id      OUT w14_txn.txn_id%TYPE
    )
    IS
    BEGIN
        IF p_qty IS NULL OR p_qty <= 0 THEN
            RAISE_APPLICATION_ERROR(-20002, 'Quantity must be more than zero');
        END IF;
        IF p_qty > p_max_receive THEN
            RAISE_APPLICATION_ERROR(-20005, 'Receive of ' || p_qty || ' looks wrong, check unit');
        END IF;

        UPDATE w14_stock SET balance_qty = balance_qty + p_qty WHERE item_id = p_item_id;
        IF SQL%NOTFOUND THEN
            RAISE_APPLICATION_ERROR(-20003, 'Item ' || p_item_id || ' not found');
        END IF;

        INSERT INTO w14_txn (item_id, txn_type, qty)
        VALUES (p_item_id, 'RECEIVE', p_qty)
        RETURNING txn_id INTO p_txn_id;
    END stock_receive;

    -------------------------------------------------------------------
    PROCEDURE stock_issue (
        p_item_id   IN  w14_stock.item_id%TYPE,
        p_qty       IN  NUMBER,
        p_min_stock IN  NUMBER DEFAULT 20,
        p_max_issue IN  NUMBER DEFAULT 500,
        p_txn_id    OUT w14_txn.txn_id%TYPE
    )
    IS
        v_balance w14_stock.balance_qty%TYPE;
    BEGIN
        IF p_qty IS NULL OR p_qty <= 0 THEN
            RAISE_APPLICATION_ERROR(-20002, 'Quantity must be more than zero');
        END IF;
        IF p_qty > p_max_issue THEN
            RAISE_APPLICATION_ERROR(-20004, 'Issue of ' || p_qty || ' needs manager approval');
        END IF;

        BEGIN
            SELECT balance_qty INTO v_balance
            FROM   w14_stock WHERE item_id = p_item_id
            FOR UPDATE;
        EXCEPTION
            WHEN NO_DATA_FOUND THEN
                RAISE_APPLICATION_ERROR(-20003, 'Item ' || p_item_id || ' not found');
        END;

        IF v_balance - p_qty < p_min_stock THEN
            RAISE_APPLICATION_ERROR(-20001,
                'Cannot issue ' || p_qty || ': only ' || v_balance || ' in stock, minimum ' || p_min_stock);
        END IF;

        UPDATE w14_stock SET balance_qty = balance_qty - p_qty WHERE item_id = p_item_id;

        INSERT INTO w14_txn (item_id, txn_type, qty)
        VALUES (p_item_id, 'ISSUE', p_qty)
        RETURNING txn_id INTO p_txn_id;
    END stock_issue;

END w19_stock_pkg;
/
```

- `CREATE OR REPLACE PACKAGE BODY` আলাদা আদেশ, আলাদা `/`
- প্রতিটা Procedure/Function পুরো: মাথা হুবহু Spec-এর মতো, তারপর `IS ... BEGIN ... END name;`
- `CREATE` শব্দ ভেতরে নেই, প্রতিটা শুধু `PROCEDURE ...` বা `FUNCTION ...`
- ভাগ করা লাইন (`-----`) শুধু পড়ার সুবিধার জন্য

গত সপ্তাহের কোডই, শুধু নতুন বাক্সে। সপ্তাহ ১৮-এর লগ করার অংশ (`WHEN OTHERS`) এখানে রাখিনি, ক্লাস ৯৫-এ আলাদা Utility Package থেকে আসবে।

### ফাইলে সাজানো

আসল প্রজেক্টে দুইটা ফাইল:

```
w19_stock_pkg.pks   ← Spec  (Package Specification)
w19_stock_pkg.pkb   ← Body  (Package Body)
```

এই কোর্সে এক `.sql` ফাইলে আগে Spec, তারপর Body, পুরোটা `F5`।

## ৪. কল করা, এরর, Data Dictionary (২৫ মিনিট)

### কল করা: `package.name`

```sql
SET SERVEROUTPUT ON

SELECT w19_stock_pkg.stock_balance(1) FROM dual;          -- 600

VARIABLE g_txn NUMBER
EXEC w19_stock_pkg.stock_receive(3, 200, p_txn_id => :g_txn);
PRINT g_txn
SELECT w19_stock_pkg.stock_balance(3) FROM dual;          -- 380
ROLLBACK;
```

`DBMS_OUTPUT.PUT_LINE`-এর মতোই: Package-এর নাম, ডট, Procedure-এর নাম।

### Spec আর Body না মিললে

**১. Spec-এ আছে, Body-তে নেই:**

Body থেকে `stock_issue` মুছে Compile করো:

```
PLS-00323: subprogram or cursor 'STOCK_ISSUE' is declared in a package
           specification and must be defined in the package body
```

**২. Parameter আলাদা:**

Body-তে `p_qty IN NUMBER`-এর জায়গায় `p_quantity IN NUMBER` লেখো: আবার `PLS-00323`। Oracle এটাকে আলাদা Procedure ভাবে, আর Spec-এরটা খুঁজে পায় না।

**৩. Body-তে আছে, Spec-এ নেই:** কোনো এরর না! সেটা **Private** হয়ে যায়, বাইরে থেকে ডাকা যায় না। কাল এটাই বিষয়।

**নিয়ম:** Spec থেকে মাথা কপি করে Body-তে বসাও, হাতে আবার লিখো না।

### এরর দেখা

```sql
SHOW ERRORS PACKAGE w19_stock_pkg
SHOW ERRORS PACKAGE BODY w19_stock_pkg
```

```sql
SELECT name, type, line, text
FROM   user_errors
WHERE  name = 'W19_STOCK_PKG'
ORDER  BY type, sequence;
```

### Data Dictionary-তে

```sql
SELECT object_name, object_type, status
FROM   user_objects
WHERE  object_name = 'W19_STOCK_PKG';
-- W19_STOCK_PKG  PACKAGE       VALID
-- W19_STOCK_PKG  PACKAGE BODY  VALID
```

দুইটা আলাদা অবজেক্ট, একই নাম।

```sql
SELECT procedure_name
FROM   user_procedures
WHERE  object_name = 'W19_STOCK_PKG'
AND    procedure_name IS NOT NULL;
-- STOCK_BALANCE, STOCK_RECEIVE, STOCK_ISSUE
```

### মোছা

```sql
DROP PACKAGE BODY w19_stock_pkg;     -- শুধু Body, Spec থাকে
DROP PACKAGE w19_stock_pkg;          -- Spec আর Body দুইটাই
```

### অনুমতি একবারে

```sql
GRANT EXECUTE ON w19_stock_pkg TO store_user;
```

Package-এর Spec-এ যা আছে সব একবারে। আলাদা ৩টা `GRANT` না।

## ৫. হাতে-কলমে প্র্যাকটিস (৬০ মিনিট)

সব `learn_freepdb1`-এ।

1. `w19_stock_pkg`-এর Spec বানাও। Body ছাড়া `stock_balance` ডেকে এরর দেখো।
2. Body বানাও। `stock_balance(1)`, `stock_balance(99)` SQL থেকে।
3. Package দিয়ে সপ্তাহ ১৮-এর পরীক্ষার ক্রম ক থেকে জ চালাও (receive আর issue)। ফল আগের মতো? (৫০০ / ৬০ / ৩৮০) `ROLLBACK`।
4. Spec আর Body-তে আরো দুইটা Function যোগ করো: `item_exists` আর `is_low_stock (p_item_id, p_min DEFAULT 100)`। ক্লাস ৮৮/প্র্যাকটিস ১৮-এর কোড।
5. `stock_transfer (p_from_item, p_to_item, p_qty)` যোগ করো, Package-এর ভেতরের `stock_issue` আর `stock_receive` ডেকে। ভেতর থেকে ডাকতে Package-এর নাম লাগে? (না, লাগে না, তবে লিখলেও চলে)
6. পরীক্ষা ঝ, ঞ, ট চালাও। (৪৫০ / ৬০ / ৪৩০ আর এরর দুইটা) `ROLLBACK`।
7. ইচ্ছা করে Body থেকে `item_exists` মুছে Compile। এরর লেখো। ফিরিয়ে দাও।
8. Body-তে `stock_issue`-এর একটা Parameter-এর নাম বদলে Compile। এরর? ফিরিয়ে দাও।
9. `USER_OBJECTS` আর `USER_PROCEDURES` থেকে Package আর তার সব Procedure/Function।
10. **নতুন Package `w19_hr_pkg`:** Spec-এ `emp_name(p_emp_id) RETURN VARCHAR2`, `gross(p_basic, p_medical DEFAULT 750, p_transport DEFAULT 450) RETURN NUMBER`, `show_emp(p_emp_id)`। Body লেখো। `SELECT emp_name, w19_hr_pkg.gross(basic_salary) FROM w16_emp`। (মোট `ACTIVE` ১৭৮৮০০)

IS
    FUNCTION emp_name (p_emp_id IN w16_emp.emp_id%TYPE) RETURN VARCHAR2
    IS
        v_name w16_emp.emp_name%TYPE;

        SELECT emp_name INTO v_name FROM w16_emp WHERE emp_id = p_emp_id;
        RETURN v_name;
    EXCEPTION
        WHEN NO_DATA_FOUND THEN

    END emp_name;

        p_basic     IN NUMBER,
        p_medical   IN NUMBER DEFAULT 750,
        p_transport IN NUMBER DEFAULT 450

    IS

        RETURN p_basic * 1.5 + p_medical + p_transport;
    END gross;

        DBMS_OUTPUT.PUT_LINE(p_emp_id || ': ' || emp_name(p_emp_id) || ' (' || v_dept || ')');

        WHEN NO_DATA_FOUND THEN

## ৬. হোমওয়ার্ক

## সারাংশ

- Package: সম্পর্কিত Procedure, Function আর অন্যান্য জিনিস এক বাক্সে
- Spec = কী ডাকা যায় (শুধু মাথা), Body = আসল কোড
- আলাদা আদেশ: `CREATE OR REPLACE PACKAGE` আর `CREATE OR REPLACE PACKAGE BODY`
- ডাকো `pkg.name`, ভেতরে নাম ছাড়াই
- Spec-এর মাথা আর Body-র মাথা হুবহু এক, না হলে `PLS-00323`
- এক `GRANT EXECUTE`-এ পুরো Package

**পরের ক্লাস (রবিবার):** Public আর Private: কী বাইরে দেখাবে, কী লুকিয়ে রাখবে।
