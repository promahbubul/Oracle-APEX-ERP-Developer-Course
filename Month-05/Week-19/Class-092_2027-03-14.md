# ক্লাস ৯২: Public ও Private Procedure/Function

**তারিখ:** ১৪ মার্চ ২০২৭, রবিবার
**সময়:** সন্ধ্যা ৭:০০ থেকে রাত ১০:০০
**সপ্তাহ:** ১৯ | **ধাপ:** ৩ (PL/SQL)

---

## আজকে কী শিখব

- Public (Spec-এ) আর Private (শুধু Body-তে)
- বড় Procedure ছোট Private টুকরায় ভাঙা
- Forward Declaration: আগে ডাকো, পরে লেখো
- Spec-এ এরর নম্বরের Constant
- Spec-এ Exception: কলকারী নাম ধরে ধরতে পারে

## ১. Public আর Private (৩৫ মিনিট)

| | কোথায় ঘোষণা | কে ডাকতে পারে |
|---|---|---|
| **Public** | Spec-এ (আর কোড Body-তে) | সবাই: অন্য Procedure, APEX, `store_user` |
| **Private** | শুধু Body-তে | শুধু একই Package-এর ভেতরের কোড |

কালকের `stock_issue` আর `stock_receive`-এ একই যাচাই দুইবার লেখা:

```sql
IF p_qty IS NULL OR p_qty <= 0 THEN
    RAISE_APPLICATION_ERROR(-20002, 'Quantity must be more than zero');
END IF;
```

আর দুইটাতেই `w14_txn`-এ `INSERT`। এগুলো আলাদা টুকরা হলে ভালো। কিন্তু APEX পেজ কি শুধু "`w14_txn`-এ রো ঢোকাও" ডাকতে পারবে? তাহলে স্টক না বদলিয়েই লেনদেনের রো! **না, এটা ভেতরের কাজ।**

### Private টুকরা

```sql
CREATE OR REPLACE PACKAGE BODY w19_stock_pkg
IS
    ---------------- Private ----------------

    PROCEDURE check_qty (p_qty IN NUMBER)
    IS
    BEGIN
        IF p_qty IS NULL OR p_qty <= 0 THEN
            RAISE_APPLICATION_ERROR(-20002, 'Quantity must be more than zero');
        END IF;
    END check_qty;

    FUNCTION add_txn (
        p_item_id  IN w14_txn.item_id%TYPE,
        p_txn_type IN w14_txn.txn_type%TYPE,
        p_qty      IN NUMBER
    ) RETURN w14_txn.txn_id%TYPE
    IS
        v_id w14_txn.txn_id%TYPE;
    BEGIN
        INSERT INTO w14_txn (item_id, txn_type, qty)
        VALUES (p_item_id, p_txn_type, p_qty)
        RETURNING txn_id INTO v_id;
        RETURN v_id;
    END add_txn;

    ---------------- Public ----------------

    FUNCTION stock_balance ( ... ) RETURN NUMBER   -- আগের মতো
    ...

    PROCEDURE stock_receive (
        p_item_id     IN  w14_stock.item_id%TYPE,
        p_qty         IN  NUMBER,
        p_max_receive IN  NUMBER DEFAULT 5000,
        p_txn_id      OUT w14_txn.txn_id%TYPE
    )
    IS
    BEGIN
        check_qty(p_qty);
        IF p_qty > p_max_receive THEN
            RAISE_APPLICATION_ERROR(-20005, 'Receive of ' || p_qty || ' looks wrong, check unit');
        END IF;

        UPDATE w14_stock SET balance_qty = balance_qty + p_qty WHERE item_id = p_item_id;
        IF SQL%NOTFOUND THEN
            RAISE_APPLICATION_ERROR(-20003, 'Item ' || p_item_id || ' not found');
        END IF;

        p_txn_id := add_txn(p_item_id, 'RECEIVE', p_qty);
    END stock_receive;

    ...
END w19_stock_pkg;
/
```

`add_txn` একটা Function যা `INSERT` করে, ক্লাস ৮৯-এর "Function পড়ে" নিয়মের ব্যতিক্রম। এটা Private আর শুধু PL/SQL থেকে ডাকা হয়, SQL থেকে কখনো না, তাই চলে। চাইলে `OUT` দিয়ে Procedure বানাতে পারো।

### বাইরে থেকে Private ডাকলে

```sql
EXEC w19_stock_pkg.check_qty(5);
-- PLS-00302: component 'CHECK_QTY' must be declared
```

Oracle-এর চোখে `check_qty` বাইরে থেকে নেই-ই।

### কেন এটা ভালো

| সুবিধা | মানে |
|---|---|
| ভুল ব্যবহার বন্ধ | `add_txn` একা কেউ ডাকতে পারে না, স্টক আর লেনদেন সবসময় একসাথে বদলায় |
| বদলানোর স্বাধীনতা | `check_qty`-এর Parameter বদলালে বাইরের কিছু ভাঙে না, কারণ বাইরের কেউ এটা জানেই না |
| Spec ছোট, পরিষ্কার | ডেভেলপার শুধু যা দরকার সেটা দেখে |

একে বলে **Encapsulation**: ভেতরের খুঁটিনাটি লুকানো, বাইরে শুধু কাজের দরজা।

**নিয়ম:** যা বাইরের কারো লাগবে না, Spec-এ দিও না। সন্দেহ হলে Private রাখো, পরে লাগলে Spec-এ যোগ করা সহজ। উল্টোটা (Spec থেকে সরানো) কঠিন, কারণ কেউ হয়তো ইতিমধ্যে ডাকছে।

## ২. Forward Declaration (২০ মিনিট)

Body-তে Private Procedure **ব্যবহারের আগে** লেখা থাকতে হয়।

```sql
CREATE OR REPLACE PACKAGE BODY w19_demo_pkg
IS
    PROCEDURE a
    IS
    BEGIN
        b;                     -- b এখনো জানা নেই
    END a;

    PROCEDURE b
    IS
    BEGIN
        DBMS_OUTPUT.PUT_LINE('b');
    END b;
END w19_demo_pkg;
/
-- PLS-00313: 'B' not declared in this scope
```

(ধরো Spec-এ শুধু `a` আছে, `b` Private।)

দুই সমাধান:

**ক.** `b`-কে `a`-এর উপরে সরাও। সবচেয়ে সহজ, তাই Private গুলো Body-র শুরুতে রাখি।

**খ.** উপরে শুধু মাথা লিখে দাও, যেমন Spec-এ লেখো:

```sql
CREATE OR REPLACE PACKAGE BODY w19_demo_pkg
IS
    PROCEDURE b;               -- Forward Declaration

    PROCEDURE a
    IS
    BEGIN
        b;
    END a;

    PROCEDURE b
    IS
    BEGIN
        DBMS_OUTPUT.PUT_LINE('b');
    END b;
END w19_demo_pkg;
/
```

Public Procedure-এর জন্য এটা লাগে না: Spec-এ ঘোষণা আছে, তাই Body-র যেকোনো জায়গা থেকে যেকোনো ক্রমে ডাকা যায়।

দুইটা Procedure যদি একে অপরকে ডাকে (`a` ডাকে `b`, `b` ডাকে `a`), তখন সরানোয় কাজ হয় না, Forward Declaration লাগবেই।

## ৩. Spec-এ Constant (৩০ মিনিট)

সপ্তাহ ১৭-এ এরর নম্বরের তালিকা ফাইলের কমেন্টে রেখেছিলে। কমেন্ট কেউ মানতে বাধ্য না। কেউ ভুলে `-20010` লিখল, অন্য কেউ `-20001`-কে "আইটেম নেই" ধরল।

**Package Spec-এ Constant:**

```sql
CREATE OR REPLACE PACKAGE w19_stock_pkg
IS
    -- এরর নম্বর
    c_err_low_stock     CONSTANT PLS_INTEGER := -20001;
    c_err_bad_qty       CONSTANT PLS_INTEGER := -20002;
    c_err_no_item       CONSTANT PLS_INTEGER := -20003;
    c_err_need_approval CONSTANT PLS_INTEGER := -20004;
    c_err_bad_receive   CONSTANT PLS_INTEGER := -20005;
    c_err_same_item     CONSTANT PLS_INTEGER := -20007;

    -- ব্যবসার সীমা
    c_default_min_stock CONSTANT NUMBER := 20;
    c_default_max_issue CONSTANT NUMBER := 500;

    FUNCTION stock_balance ( ... ) RETURN NUMBER;
    ...
END w19_stock_pkg;
/
```

Body-তে:

```sql
RAISE_APPLICATION_ERROR(c_err_low_stock,
    'Cannot issue ' || p_qty || ': only ' || v_balance || ' in stock');
```

বাইরে থেকে:

```sql
BEGIN
    DBMS_OUTPUT.PUT_LINE(w19_stock_pkg.c_err_low_stock);        -- -20001
END;
/
```

- `PLS_INTEGER`: পূর্ণসংখ্যার দ্রুত ধরন, শুধু PL/SQL-এ। এরর নম্বরের জন্য ঠিক
- Package-এর Constant বা Variable সরাসরি SQL-এ পড়া যায় না: `SELECT w19_stock_pkg.c_err_low_stock FROM dual` এরর দেয়। PL/SQL থেকে পড়ো, অথবা SQL-এ লাগলে একটা ছোট Function বানাও যা Constant-টা `RETURN` করে

### Default-এ Constant

Parameter-এর Default-এও Spec-এর Constant:

```sql
PROCEDURE stock_issue (
    p_item_id   IN  w14_stock.item_id%TYPE,
    p_qty       IN  NUMBER,
    p_min_stock IN  NUMBER DEFAULT c_default_min_stock,
    p_max_issue IN  NUMBER DEFAULT c_default_max_issue,
    p_txn_id    OUT w14_txn.txn_id%TYPE
);
```

সীমা বদলাতে (২০ থেকে ৫০) শুধু এক লাইন।

### কোনটা Public, কোনটা Private Constant

| Constant | কোথায় |
|---|---|
| এরর নম্বর | Spec, কলকারীর লাগে |
| Default সীমা যা কলকারী দেখতে চাইতে পারে | Spec |
| ভেতরের হিসাবের সংখ্যা (যেমন `c_month_days := 30`) | Body (Private) |

Body-র যেকোনো Procedure-এর বাইরে, শুরুতে লেখা Constant পুরো Body দেখে, বাইরে কেউ না।

## ৪. Spec-এ Exception (৩০ মিনিট)

কলকারী কীভাবে "স্টক কম" এরর ধরবে? সপ্তাহ ১৭-এ শিখেছ:

```sql
DECLARE
    e_low EXCEPTION;
    PRAGMA EXCEPTION_INIT(e_low, -20001);
BEGIN
    ...
EXCEPTION
    WHEN e_low THEN ...
```

প্রতিটা কলকারী নিজে ঘোষণা করছে, আর নম্বর মুখস্থ রাখছে। Package Spec-এ একবার:

```sql
CREATE OR REPLACE PACKAGE w19_stock_pkg
IS
    c_err_low_stock CONSTANT PLS_INTEGER := -20001;
    c_err_no_item   CONSTANT PLS_INTEGER := -20003;

    e_low_stock EXCEPTION;
    PRAGMA EXCEPTION_INIT(e_low_stock, -20001);

    e_no_item EXCEPTION;
    PRAGMA EXCEPTION_INIT(e_no_item, -20003);
    ...
```

`PRAGMA EXCEPTION_INIT`-এ সংখ্যা **সরাসরি** লিখতে হয়, Constant (`c_err_low_stock`) দেওয়া যায় না। তাই দুই জায়গায় একই সংখ্যা, পাশাপাশি রাখো যাতে মিলিয়ে দেখা যায়।

কলকারী এখন:

```sql
DECLARE
    v_txn NUMBER;
BEGIN
    w19_stock_pkg.stock_issue(2, 50, p_txn_id => v_txn);
EXCEPTION
    WHEN w19_stock_pkg.e_low_stock THEN
        DBMS_OUTPUT.PUT_LINE('Low stock, raise purchase requisition');
    WHEN w19_stock_pkg.e_no_item THEN
        DBMS_OUTPUT.PUT_LINE('Wrong item code');
END;
/
-- Low stock, raise purchase requisition
```

কোনো নম্বর মুখস্থ না। Package-ই বলে দেয় কোন কোন এরর আসতে পারে।

### Body থেকে RAISE

Body-তে দুইভাবেই ছোঁড়া যায়:

```sql
RAISE e_low_stock;                                          -- নম্বর -20001, কিন্তু বার্তা খালি
RAISE_APPLICATION_ERROR(c_err_low_stock, 'Only 60 in stock');   -- নম্বর + বার্তা
```

দ্বিতীয়টা ভালো: `PRAGMA` থাকায় কলকারী `WHEN e_low_stock`-এ ধরতে পারে, **আর** বার্তাও পায়, **আর** APEX বার্তা দেখায়।

-- ১ ও ৩: Body-র Private অংশ আর stock_issue
CREATE OR REPLACE PACKAGE BODY w19_stock_pkg
IS
    PROCEDURE check_qty (p_qty IN NUMBER)
    IS
    BEGIN
        IF p_qty IS NULL OR p_qty <= 0 THEN
            RAISE_APPLICATION_ERROR(c_err_bad_qty, 'Quantity must be more than zero');
        END IF;
    END check_qty;

    FUNCTION lock_balance (p_item_id IN w14_stock.item_id%TYPE) RETURN NUMBER
    IS
        v_bal w14_stock.balance_qty%TYPE;
    BEGIN
        SELECT balance_qty INTO v_bal FROM w14_stock WHERE item_id = p_item_id FOR UPDATE;
        RETURN v_bal;
    EXCEPTION
        WHEN NO_DATA_FOUND THEN
            RAISE_APPLICATION_ERROR(c_err_no_item, 'Item ' || p_item_id || ' not found');
    END lock_balance;

    FUNCTION add_txn (
        p_item_id  IN w14_txn.item_id%TYPE,
        p_txn_type IN w14_txn.txn_type%TYPE,
        p_qty      IN NUMBER
    ) RETURN w14_txn.txn_id%TYPE
    IS
        v_id w14_txn.txn_id%TYPE;
    BEGIN
        INSERT INTO w14_txn (item_id, txn_type, qty)
        VALUES (p_item_id, p_txn_type, p_qty)
        RETURNING txn_id INTO v_id;
        RETURN v_id;
    END add_txn;

    FUNCTION stock_balance (p_item_id IN w14_stock.item_id%TYPE) RETURN NUMBER
    IS
        v_bal w14_stock.balance_qty%TYPE;
    BEGIN
        SELECT balance_qty INTO v_bal FROM w14_stock WHERE item_id = p_item_id;
        RETURN v_bal;
    EXCEPTION
        WHEN NO_DATA_FOUND THEN
            RAISE_APPLICATION_ERROR(c_err_no_item, 'Item ' || p_item_id || ' not found');
    END stock_balance;

    FUNCTION item_exists (p_item_id IN w14_stock.item_id%TYPE) RETURN VARCHAR2
    IS
        v_cnt NUMBER;
    BEGIN
        SELECT COUNT(*) INTO v_cnt FROM w14_stock WHERE item_id = p_item_id;
        RETURN CASE WHEN v_cnt > 0 THEN 'Y' ELSE 'N' END;
    END item_exists;

    FUNCTION is_low_stock (
        p_item_id IN w14_stock.item_id%TYPE,
        p_min     IN NUMBER DEFAULT 100
    ) RETURN VARCHAR2
    IS
    BEGIN
        RETURN CASE WHEN stock_balance(p_item_id) < p_min THEN 'Y' ELSE 'N' END;
    END is_low_stock;

    PROCEDURE stock_receive (
        p_item_id     IN  w14_stock.item_id%TYPE,
        p_qty         IN  NUMBER,
        p_max_receive IN  NUMBER DEFAULT 5000,
        p_txn_id      OUT w14_txn.txn_id%TYPE
    )
    IS
    BEGIN
        check_qty(p_qty);
        IF p_qty > p_max_receive THEN
            RAISE_APPLICATION_ERROR(c_err_bad_receive, 'Receive of ' || p_qty || ' looks wrong, check unit');
        END IF;
        UPDATE w14_stock SET balance_qty = balance_qty + p_qty WHERE item_id = p_item_id;
        IF SQL%NOTFOUND THEN
            RAISE_APPLICATION_ERROR(c_err_no_item, 'Item ' || p_item_id || ' not found');
        END IF;
        p_txn_id := add_txn(p_item_id, 'RECEIVE', p_qty);
    END stock_receive;

    PROCEDURE stock_issue (
        p_item_id   IN  w14_stock.item_id%TYPE,
        p_qty       IN  NUMBER,
        p_min_stock IN  NUMBER DEFAULT c_default_min_stock,
        p_max_issue IN  NUMBER DEFAULT c_default_max_issue,
        p_txn_id    OUT w14_txn.txn_id%TYPE
    )
    IS
        v_balance w14_stock.balance_qty%TYPE;
    BEGIN
        check_qty(p_qty);
        IF p_qty > p_max_issue THEN
            RAISE_APPLICATION_ERROR(c_err_need_approval, 'Issue of ' || p_qty || ' needs manager approval');
        END IF;

        v_balance := lock_balance(p_item_id);

        IF v_balance - p_qty < p_min_stock THEN
            RAISE_APPLICATION_ERROR(c_err_low_stock,
                'Cannot issue ' || p_qty || ': only ' || v_balance || ' in stock, minimum ' || p_min_stock);
        END IF;

        UPDATE w14_stock SET balance_qty = balance_qty - p_qty WHERE item_id = p_item_id;
        p_txn_id := add_txn(p_item_id, 'ISSUE', p_qty);
    END stock_issue;

    PROCEDURE stock_transfer (
        p_from_item IN w14_stock.item_id%TYPE,
        p_to_item   IN w14_stock.item_id%TYPE,
        p_qty       IN NUMBER
    )
    IS
        v_txn w14_txn.txn_id%TYPE;
    BEGIN
        IF p_from_item = p_to_item THEN
            RAISE_APPLICATION_ERROR(c_err_same_item, 'Cannot transfer to the same item');
        END IF;
        stock_issue(p_from_item, p_qty, p_txn_id => v_txn);
        stock_receive(p_to_item, p_qty, p_txn_id => v_txn);
    END stock_transfer;
END w19_stock_pkg;

## সারাংশ

- Spec-এ থাকলে Public, শুধু Body-তে থাকলে Private
- Private দিয়ে বড় কাজ ছোট টুকরায়, আর ভেতরের কাজ বাইরের ভুল ব্যবহার থেকে নিরাপদ (Encapsulation)
- Private ব্যবহারের আগে লেখো, না হলে Forward Declaration
- এরর নম্বর আর সীমা Spec-এর Constant-এ, Default-এও ব্যবহার করা যায়
- Spec-এ Exception + `PRAGMA`: কলকারী `WHEN pkg.e_x` দিয়ে ধরে, নম্বর মুখস্থ লাগে না
- সন্দেহ হলে Private, পরে Public করা সহজ

**পরের ক্লাস (সোমবার):** Package Variable (Session জুড়ে মান) আর Overloading (একই নামে কয়েকটা Procedure)।
