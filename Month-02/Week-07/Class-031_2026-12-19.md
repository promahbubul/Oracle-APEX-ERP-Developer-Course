## ১. Function কী (২৫ মিনিট)

**Function** হলো তৈরি করা একটা কাজ: কিছু মান দাও, একটা ফল পাবে।

```
UPPER('garments')  →  'GARMENTS'
  │       │              │
 নাম   Argument         ফল
```

### দুই ধরন

| ধরন | কাজ | উদাহরণ | কবে |
|---|---|---|---|
| **Single Row** | প্রতিটা রো-র জন্য একটা ফল | `UPPER`, `ROUND`, `SYSDATE` | এই সপ্তাহে |
| **Multi Row (Aggregate)** | অনেক রো মিলে একটা ফল | `SUM`, `COUNT`, `AVG` | সপ্তাহ ৮ |

```sql
SELECT last_name, UPPER(last_name) AS upper_name   -- ১০৭টা রো, ১০৭টা ফল
FROM   employees;

SELECT COUNT(*) FROM employees;                    -- ১০৭টা রো, ১টা ফল
```

### Single Row Function-এর ধরন

| ধরন | উদাহরণ | ক্লাস |
|---|---|---|
| Character | `UPPER`, `SUBSTR` | ৩১, ৩২ |
| Number | `ROUND`, `MOD` | ৩৩ |
| Date | `ADD_MONTHS` | ৩৪ |
| Conversion | `TO_CHAR` | ৩৫ |
| General | `NVL`, `CASE` | ৩৬, ৩৭ |

### কোথায় ব্যবহার করা যায়

```sql
SELECT UPPER(last_name)            -- SELECT-এ
FROM   employees
WHERE  LENGTH(last_name) = 4       -- WHERE-এ
ORDER  BY LENGTH(last_name), last_name;    -- ORDER BY-তে
```

ফাংশন **ডাটা বদলায় না**, শুধু ফলাফলে বদলানো মান দেখায়। আসল ডাটা বদলাতে `UPDATE` লাগে।

## ২. UPPER, LOWER, INITCAP (৪০ মিনিট)

| ফাংশন | কাজ | উদাহরণ | ফল |
|---|---|---|---|
| `UPPER` | সব বড় হাতের | `UPPER('Denim Jeans')` | `DENIM JEANS` |
| `LOWER` | সব ছোট হাতের | `LOWER('Denim Jeans')` | `denim jeans` |
| `INITCAP` | প্রতিটা শব্দের প্রথম অক্ষর বড় | `INITCAP('DENIM JEANS')` | `Denim Jeans` |

```sql
SELECT last_name,
       UPPER(last_name)    AS upper_name,
       LOWER(last_name)    AS lower_name,
       email,
       INITCAP(email)      AS proper_email
FROM   employees;
```

### INITCAP-এর ফাঁদ

`INITCAP` অক্ষর ছাড়া যেকোনো চিহ্নের পরেও বড় হাতের অক্ষর দেয়:

```sql
SELECT INITCAP('basic t-shirt')  AS a,      -- Basic T-Shirt  (ঠিক আছে)
       INITCAP(q'[men's wear]')  AS b,      -- Men'S Wear     (ভুল!)
       INITCAP('H&M')            AS c       -- H&M
FROM   dual;
```

### ছোট-বড় না মেনে খোঁজা

সপ্তাহ ৬-এ দেখেছ, `last_name = 'king'` কিছু আনে না। ইউজার সার্চ বক্সে যেভাবেই লিখুক, পাওয়ার উপায়:

```sql
-- King (২ জন)
SELECT first_name, last_name
FROM   employees
WHERE  UPPER(last_name) = 'KING';

-- ইউজারের লেখাও বড় হাতে করে নাও
SELECT first_name, last_name
FROM   employees
WHERE  UPPER(last_name) = UPPER('kInG');

-- নামের যেকোনো জায়গায় (learn_freepdb1): Oracle SQL for Beginners, Oracle APEX in Practice
SELECT book_title
FROM   lib_book
WHERE  UPPER(book_title) LIKE '%ORACLE%';
```

**দুই পাশই একই রকম করো।** `UPPER(last_name) = 'King'` কখনোই মিলবে না।

> APEX-এ সার্চ পেজে ঠিক এই নিয়মই লাগবে: `WHERE UPPER(book_title) LIKE '%' || UPPER(:P1_SEARCH) || '%'`। `:P1_SEARCH` কী, সেটা সপ্তাহ ২৯-এ শিখবে।

### গতি নিয়ে একটা কথা

`WHERE UPPER(last_name) = 'KING'` কলামের উপর ফাংশন, তাই `last_name`-এর সাধারণ Index কাজ করে না। বড় টেবিলে এজন্য **Function-based Index** বানানো হয় (সপ্তাহ ১১)।

### ডাটা ঢোকানোর সময়েই ঠিক করা

ক্লাস ১১-এ দেখেছিলে, `'hm-ts-001'` আর `'HM-TS-001'` দুইটাই Unique পার হয়ে যায়। সমাধান: ঢোকানোর সময়েই বড় হাতে করো।

```sql
INSERT INTO w5_buyer (buyer_id, buyer_name, country_name)
VALUES (50, UPPER('test buyer'), INITCAP('bangladesh'));

SELECT buyer_name, country_name FROM w5_buyer WHERE buyer_id = 50;

ROLLBACK;
```

## ৩. LENGTH (২০ মিনিট)

লেখায় কয়টা অক্ষর আছে।

```sql
SELECT LENGTH('Garments')  AS a,    -- 8
       LENGTH('H&M')       AS b,    -- 3
       LENGTH(' A ')       AS c,    -- 3, স্পেসও গোনা হয়
       LENGTH(NULL)        AS d,    -- NULL
       LENGTH('')          AS e     -- NULL, 0 না
FROM   dual;
```

```sql
-- নাম আর তার দৈর্ঘ্য
SELECT last_name, LENGTH(last_name) AS name_length
FROM   employees
ORDER  BY name_length DESC, last_name;

-- ঠিক ৪ অক্ষরের নাম
SELECT last_name FROM employees WHERE LENGTH(last_name) = 4;
```

### বাংলায়

ক্লাস ৭-এ দেখেছিলে:

```sql
SELECT LENGTH('গার্মেন্টস') AS chars, LENGTHB('গার্মেন্টস') AS bytes FROM dual;   -- 10, 30
```

আমরা চোখে দেখি ৫–৬টা অক্ষর, কিন্তু Oracle গোনে **কোড পয়েন্ট**: `ার`, `্`, `ে`-ও আলাদা। তাই বাংলায় `LENGTH` চোখে দেখা অক্ষরের সংখ্যা দেয় না।

### কাজে লাগে যেখানে: ডাটা যাচাই

```sql
-- মোবাইল ১১ অঙ্কের নয় এমন মেম্বার (learn_freepdb1)। ভুল ডাটা খোঁজা
SELECT member_name, mobile_no
FROM   lib_member
WHERE  LENGTH(mobile_no) <> 11;
```

সপ্তাহ ৫-এর সমাধানের ডাটায় কোনো রো আসবে না। বাস্তব ডাটায় প্রায়ই আসে।

## ৪. CONCAT ও Nested Function (২৫ মিনিট)

### CONCAT

```sql
SELECT CONCAT('Hello ', 'Oracle') AS msg FROM dual;
```

**`CONCAT` শুধু ২টা মান নেয়।** ৩টা জুড়তে চাইলে এক `CONCAT`-এর ভেতরে আরেকটা লাগে, তাই `||` অনেক সহজ:

```sql
-- CONCAT দিয়ে
SELECT CONCAT(CONCAT(first_name, ' '), last_name) AS full_name FROM employees;

-- || দিয়ে: একই কাজ, পড়া সহজ
SELECT first_name || ' ' || last_name AS full_name FROM employees;
```

**বাস্তবে প্রায় সবসময় `||` ব্যবহার হয়।** `CONCAT` জেনে রাখো, পুরনো কোডে আর ইন্টারভিউতে আসে।

### Nested Function

ফাংশনের ভেতরে ফাংশন লেখা যায়। **ভেতর থেকে বাইরে চলে।**

```sql
SELECT UPPER(CONCAT(first_name, last_name)) AS a,
       LENGTH(first_name || last_name)      AS b,
       LOWER(first_name) || '.' || LOWER(last_name) || '@company.com' AS mail
FROM   employees;
```

```
LENGTH(UPPER('abc'))
         │
    ১. UPPER('abc') → 'ABC'
    ২. LENGTH('ABC') → 3
```

## ৫. হাতে-কলমে প্র্যাকটিস (৭০ মিনিট)

**HR (`hr_freepdb1`):**

1. `last_name` বড় হাতে, `first_name` ছোট হাতে দেখাও।
2. `email`-কে `INITCAP` করে দেখাও।
3. `last_name` `DE HAAN`, ছোট-বড় না মেনে খোঁজো। (১)
4. `first_name`-এ ছোট-বড় না মেনে `ALE` আছে, এমন কর্মী।
5. `last_name` আর তার অক্ষর সংখ্যা। সবচেয়ে লম্বা নাম আগে।
6. `last_name` ঠিক ৫ অক্ষরের।
7. পুরো নামের অক্ষর সংখ্যা ১৫-এর বেশি (নাম আর পদবির মাঝের স্পেসসহ)।
8. এই ঠিকানা বানাও: `steven.king@company.com`, শিরোনাম `office_email`।
9. `CONCAT` দিয়ে, আবার `||` দিয়ে: `King - AD_PRES`।
10. `job_title` (`jobs`) বড় হাতে, যেগুলোর নামে ছোট-বড় না মেনে `manager` আছে।

**লাইব্রেরি (`learn_freepdb1`):**

11. `book_title`-এ ছোট-বড় না মেনে `sql` আছে। (৩)
12. মেম্বারের `member_name` বড় হাতে, আর `email`।
13. `book_title` যাদের ১৫ অক্ষরের কম।
14. ক্যাটাগরির নাম আর দৈর্ঘ্য, দৈর্ঘ্যের ক্রমে।

**ফল আন্দাজ করো:**

```sql

SELECT CONCAT('A', NULL) FROM dual;               -- ১৮

```

## সারাংশ

- ফাংশন ডাটা বদলায় না, ফলাফলে বদলানো মান দেখায়
- `UPPER`, `LOWER`, `INITCAP`: অক্ষরের ধরন বদলায়
- ছোট-বড় না মেনে খুঁজতে দুই পাশে `UPPER`
- `LENGTH`: অক্ষর সংখ্যা, স্পেসসহ। `LENGTH(NULL)` NULL
- `CONCAT` ২টা মান নেয়, তাই বাস্তবে `||`
- Nested Function ভেতর থেকে বাইরে চলে

**পরের ক্লাস:** Character Function: SUBSTR, INSTR, TRIM, REPLACE, LPAD, RPAD।
