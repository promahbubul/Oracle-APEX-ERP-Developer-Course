# ক্লাস ৩৪: Date Function: SYSDATE, ADD_MONTHS, MONTHS_BETWEEN, LAST_DAY, NEXT_DAY

**তারিখ:** ২২ ডিসেম্বর ২০২৬, মঙ্গলবার
**সময়:** সন্ধ্যা ৭:০০ থেকে রাত ১০:০০
**সপ্তাহ:** ৭ | **ধাপ:** ২ (Oracle SQL)

---

## আজকে কী শিখব

- `SYSDATE` আর তারিখের হিসাব
- `ADD_MONTHS`, `MONTHS_BETWEEN`
- `LAST_DAY`, `NEXT_DAY`
- তারিখে `TRUNC`, `ROUND`
- `EXTRACT`

> তারিখ সময়সহ দেখতে আগে চালাও: `ALTER SESSION SET NLS_DATE_FORMAT = 'DD-MM-YYYY HH24:MI:SS';` (ক্লাস ৮)। কোডের কমেন্টে ফল `YYYY-MM-DD` আকারে লেখা, তোমার স্ক্রিনে সেশনের ফরম্যাটে দেখাবে।

## ১. তারিখের হিসাব: রিভিশন (২০ মিনিট)

```sql
SELECT SYSDATE              AS now_time,
       SYSDATE + 1          AS tomorrow,
       SYSDATE - 7          AS last_week,
       SYSDATE + 2/24       AS two_hours_later,
       SYSDATE + 30/1440    AS thirty_min_later
FROM   dual;
```

| হিসাব | ফল |
|---|---|
| তারিখ + সংখ্যা | তারিখ, দিন যোগ |
| তারিখ − সংখ্যা | তারিখ, দিন বিয়োগ |
| তারিখ − তারিখ | সংখ্যা, দিনের পার্থক্য |
| তারিখ + তারিখ | **এরর** `ORA-00975` |

### SYSDATE কার সময়?

`SYSDATE` দেয় **ডাটাবেস সার্ভারের** ঘড়ির সময়, তোমার কম্পিউটারের না।

```sql
SELECT SYSDATE, CURRENT_DATE, SYSTIMESTAMP FROM dual;
```

নিজের কম্পিউটারে দুইটাই একই। কিন্তু apex.oracle.com-এর সার্ভার বিদেশে, তাই সেখানে `SYSDATE` বাংলাদেশের সময়ের চেয়ে কয়েক ঘণ্টা আলাদা হতে পারে। APEX-এর অংশে এটা মনে রেখো।

### দিনের হিসাব (`learn_freepdb1`)

```sql
-- কত দিন দেরি: ইস্যু ২ → 4, ৫ → 8, ৯ → 8, ১২ → 7, ১৪ → 6
SELECT issue_id, return_date - due_date AS days_late
FROM   lib_book_issue
WHERE  return_date > due_date;

-- জরিমানা, দিনে ৫ টাকা
SELECT issue_id, (return_date - due_date) * 5 AS fine
FROM   lib_book_issue
WHERE  return_date > due_date;

-- আর কত দিন আগে ফেরত দেওয়ার কথা ছিল
SELECT issue_id, due_date, TRUNC(SYSDATE) - due_date AS days_overdue
FROM   lib_book_issue
WHERE  return_date IS NULL;
```

`SYSDATE`-এ সময় থাকে, তাই `SYSDATE - due_date`-এ দশমিক আসে। পূর্ণ দিন চাইলে `TRUNC(SYSDATE)`।

## ২. ADD_MONTHS (২৫ মিনিট)

`ADD_MONTHS(তারিখ, মাস)`

```sql
SELECT ADD_MONTHS(DATE '2026-12-22', 1)  AS a,    -- 2027-01-22
       ADD_MONTHS(DATE '2026-12-22', 6)  AS b,    -- 2027-06-22
       ADD_MONTHS(DATE '2026-12-22', -3) AS c     -- 2026-09-22
FROM   dual;
```

### মাসের শেষে

মাসের দিন সংখ্যা আলাদা, তাই `+ 30` দিয়ে "১ মাস পরে" পাওয়া যায় না।

```sql
SELECT ADD_MONTHS(DATE '2027-01-31', 1) AS a,    -- 2027-02-28
       ADD_MONTHS(DATE '2027-02-28', 1) AS b,    -- 2027-03-31
       DATE '2027-01-31' + 30           AS c     -- 2027-03-02
FROM   dual;
```

- **`a`:** ৩১ ফেব্রুয়ারি নেই, তাই মাসের শেষ দিন
- **`b`:** শুরুর তারিখ মাসের শেষ দিন হলে ফলও মাসের শেষ দিন
- **`c`:** `+ 30` একদম আলাদা মাসে চলে গেল

### কাজে লাগে যেখানে

```sql
-- ৬ মাস Probation শেষের তারিখ (hr_freepdb1)
SELECT last_name, hire_date, ADD_MONTHS(hire_date, 6) AS probation_end
FROM   employees;

-- গত ৩ মাসের ইস্যু (learn_freepdb1)
SELECT issue_id, issue_date
FROM   lib_book_issue
WHERE  issue_date >= ADD_MONTHS(TRUNC(SYSDATE), -3);
```

## ৩. MONTHS_BETWEEN (২৫ মিনিট)

`MONTHS_BETWEEN(পরের তারিখ, আগের তারিখ)`

```sql
SELECT MONTHS_BETWEEN(DATE '2026-12-22', DATE '2026-11-22') AS a,    -- 1
       MONTHS_BETWEEN(DATE '2026-11-22', DATE '2026-12-22') AS b,    -- -1
       MONTHS_BETWEEN(DATE '2026-12-31', DATE '2026-11-30') AS c,    -- 1, দুইটাই মাসের শেষ
       MONTHS_BETWEEN(DATE '2026-12-22', DATE '2026-11-07') AS d     -- 1.48...
FROM   dual;
```

- ক্রম উল্টো হলে ফল ঋণাত্মক
- দশমিক আসতে পারে, তাই সাধারণত `TRUNC` বা `ROUND` লাগে

### চাকরির বয়স

```sql
SELECT last_name,
       hire_date,
       TRUNC(MONTHS_BETWEEN(SYSDATE, hire_date))      AS service_months,
       TRUNC(MONTHS_BETWEEN(SYSDATE, hire_date) / 12) AS service_years
FROM   employees;
```

বছর পূর্ণ না হলে গোনা হয় না, তাই `TRUNC`, `ROUND` না।

### বছর আর বাকি মাস

```sql
SELECT last_name,
       TRUNC(MONTHS_BETWEEN(SYSDATE, hire_date) / 12)    AS years_part,
       TRUNC(MOD(MONTHS_BETWEEN(SYSDATE, hire_date), 12)) AS months_part
FROM   employees;
```

ফল যেমন: `৮ বছর ৫ মাস`। ক্লাস ৩৩-এর `MOD` এখানেও কাজে লাগল। HR রিপোর্ট আর গ্র্যাচুইটির হিসাবে এটা লাগে।

## ৪. LAST_DAY ও NEXT_DAY (২৫ মিনিট)

### LAST_DAY

মাসের শেষ তারিখ।

```sql
SELECT LAST_DAY(DATE '2026-12-22')     AS a,    -- 2026-12-31
       LAST_DAY(DATE '2028-02-10')     AS b,    -- 2028-02-29, অধিবর্ষ
       LAST_DAY(DATE '2026-12-22') + 1 AS c     -- 2027-01-01, পরের মাসের ১ তারিখ
FROM   dual;
```

```sql
-- মাসের আর কত দিন বাকি
SELECT LAST_DAY(TRUNC(SYSDATE)) - TRUNC(SYSDATE) AS days_left FROM dual;

-- এই মাসে কয় দিন
SELECT TO_NUMBER(TO_CHAR(LAST_DAY(SYSDATE), 'DD')) AS days_in_month FROM dual;
```

বেতন শীটের হিসাবে লাগে: "এই মাসে কয় দিন?" (`TO_CHAR` কাল শিখবে।)

### NEXT_DAY

তারিখের **পরের** নির্দিষ্ট বার।

```sql
-- ২২ ডিসেম্বর ২০২৬ মঙ্গলবার
SELECT NEXT_DAY(DATE '2026-12-22', 'FRIDAY')  AS a,    -- 2026-12-25
       NEXT_DAY(DATE '2026-12-22', 'TUESDAY') AS b     -- 2026-12-29, আজ না, পরের মঙ্গলবার
FROM   dual;
```

- আজ সেই বার হলেও **পরের সপ্তাহের** তারিখ দেয়
- বারের নাম ডাটাবেসের ভাষা (`NLS_DATE_LANGUAGE`) অনুযায়ী লিখতে হয়। ইংরেজি না হলে `ORA-01846: not a valid day of the week`

### মাসের শেষ শুক্রবার

```sql
SELECT NEXT_DAY(LAST_DAY(DATE '2026-12-22') - 7, 'FRIDAY') AS last_friday FROM dual;
-- 2026-12-25
```

ধাপে ধাপে: মাসের শেষ দিন ৩১ → ৭ দিন আগে ২৪ → তার পরের শুক্রবার ২৫।

## ৫. তারিখে TRUNC, ROUND ও EXTRACT (২০ মিনিট)

### TRUNC: তারিখের একক পর্যন্ত কেটে দেয়

```sql
SELECT TRUNC(SYSDATE)         AS today_start,     -- আজ রাত ১২:০০
       TRUNC(SYSDATE, 'MM')   AS month_start,     -- এই মাসের ১ তারিখ
       TRUNC(SYSDATE, 'YYYY') AS year_start,      -- এই বছরের ১ জানুয়ারি
       TRUNC(SYSDATE, 'Q')    AS quarter_start    -- এই ত্রৈমাসিকের ১ তারিখ
FROM   dual;
```

### এই মাসের সব রো

```sql
WHERE entry_date >= TRUNC(SYSDATE, 'MM')
AND   entry_date <  ADD_MONTHS(TRUNC(SYSDATE, 'MM'), 1)
```

ERP-র মাসিক রিপোর্টে এই শর্তটাই লাগে। মাস বদলালে কোড বদলাতে হয় না।

### ROUND: নিকটতম এককে

```sql
SELECT ROUND(DATE '2026-12-22', 'MM')   AS a,    -- 2027-01-01, ১৬ বা বেশি হলে পরের মাস
       ROUND(DATE '2026-12-10', 'MM')   AS b,    -- 2026-12-01
       ROUND(DATE '2026-12-22', 'YYYY') AS c     -- 2027-01-01, জুলাই বা পরে হলে পরের বছর
FROM   dual;
```

### EXTRACT

```sql
SELECT EXTRACT(YEAR FROM SYSDATE)  AS y,
       EXTRACT(MONTH FROM SYSDATE) AS m,
       EXTRACT(DAY FROM SYSDATE)   AS d
FROM   dual;

-- যেকোনো বছরের অক্টোবর মাসের ইস্যু (learn_freepdb1)
SELECT issue_id, issue_date
FROM   lib_book_issue
WHERE  EXTRACT(MONTH FROM issue_date) = 10;     -- অক্টোবর: ১২–১৫
```

ফল সংখ্যা, তাই হিসাব করা যায়।

## ৮. কুইজ

## সারাংশ

- তারিখ ± সংখ্যা = তারিখ, তারিখ − তারিখ = দিন
- `ADD_MONTHS`: মাস যোগ, মাসের শেষ ঠিক রাখে। `+ 30` এর বিকল্প না
- `MONTHS_BETWEEN`: দশমিকসহ মাস, পূর্ণ বছর পেতে `TRUNC(... / 12)`
- `LAST_DAY`: মাসের শেষ। `NEXT_DAY`: পরের সেই বার
- `TRUNC(d, 'MM')`: মাসের শুরু। `EXTRACT`: বছর, মাস, দিন সংখ্যায়

**পরের ক্লাস:** Conversion Function: TO_CHAR, TO_DATE, TO_NUMBER, Date Format।
