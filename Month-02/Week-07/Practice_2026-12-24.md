## ১. রিভিশন (২০ মিনিট)

খাতা না দেখে উত্তর দাও। না পারলে সেই ক্লাসের ফাইল আবার পড়ো।

**ক্লাস ৩১:** ছোট-বড় না মেনে কীভাবে খোঁজো? `CONCAT`-এর সীমাবদ্ধতা কী?

**ক্লাস ৩২:** `SUBSTR` আর `INSTR` দিয়ে `-`-এর আগের অংশ কীভাবে বের করো? `TRIM` আর `REPLACE`-এর পার্থক্য কী?

**ক্লাস ৩৩:** `ROUND`, `TRUNC`, `CEIL`, `FLOOR`-এর পার্থক্য কী? কার্টন গুনতে কোনটা? শেষ কার্টনের পিস কীভাবে বের করো?

**ক্লাস ৩৪:** `+ 30` আর `ADD_MONTHS(d, 1)`-এর পার্থক্য কী? এই মাসের ১ তারিখ কীভাবে পাও?

**ক্লাস ৩৫:** `fm` কেন লাগে? `TO_CHAR`-এর ফল কি হিসাব করা যায়? `TO_DATE`-এ `ORA-01843` কখন আসে?

## ২. মূল কাজ: ২৫টা কোয়েরি (১২০ মিনিট)

১–১৯ `hr_freepdb1`-এ, ২০–২৫ `learn_freepdb1`-এ। প্রতিটা কোয়েরি `week07.sql`-এ কমেন্টে নম্বর দিয়ে রাখো।

> `(n)` মানে প্রত্যাশিত রো সংখ্যা। HR-এর ভার্সনভেদে সামান্য আলাদা হতে পারে।

### অংশ ক: Character (৭টা)

1. পুরো নাম বড় হাতে, `full_name`।
2. `last_name`-এ ছোট-বড় না মেনে `king` খোঁজো। (২)
3. `S. King` আকারে নাম।
4. `office_email`: `steven.king@company.com`।
5. `job_id`-র `_`-এর আগের অংশ `dept_code`, আর পরের অংশ `role_code`।
6. `last_name`-এর `e` বদলে `3` করে দেখাও।
7. `'EMP-00100'` আকারে কোড, `first_name` ৫ অক্ষরের কর্মীদের।

### অংশ খ: Number (৪টা)

8. বেতনের ১২.৫% বোনাস, পুরো সংখ্যায়, `bonus`।
9. কমিশন পান এমন কর্মীদের মোট মাসিক আয় (`salary + salary * commission_pct`), ২ ঘরে। (৩৫)
10. বিজোড় `employee_id`-র কর্মী। (৫৩)
11. বেতন হাজারে কেটে `thousands`, আর হাজারের নিচের অংশ `remainder`। (`MOD`)

### অংশ গ: Date (৪টা)

12. চাকরির পূর্ণ বছর আর বাকি মাস। বেশি অভিজ্ঞ আগে।
13. যোগদানের ৬ মাস পরের তারিখ।
14. যোগদানের মাসের শেষ তারিখ আর পরের সোমবার।
15. ডিসেম্বরে যোগ দেওয়া কর্মী।

### অংশ ঘ: Conversion (৪টা)

16. `Wednesday, 23 December 2026` আকারে `hire_date`।
17. বেতন `$24,000.00` আকারে, ১০০০০-এর বেশি বেতনের কর্মীদের।
18. শুক্রবারে যোগ দেওয়া কর্মী।
19. এই বাক্য: `King (AD_PRES) joined in Jun 2003`।

### অংশ ঙ: লাইব্রেরি ও অর্ডার (৬টা)

20. ফেরত আসেনি এমন ইস্যুর `issue_id`, ফেরতের তারিখ `DD-Mon-YYYY` আকারে, আর কত দিন ওভারডিউ। (৫)
21. দেরিতে ফেরত দেওয়া ইস্যু, কত দিন দেরি, আর দিনে ৫ টাকা ধরে জরিমানা `Tk 20.00` আকারে। (৫)
22. মেম্বারের ইমেইলের `@`-এর আগের অংশ, বড় হাতে। (১২)
23. মোবাইল ঢেকে: `017*****001`। (২০)
24. `w5_order`-এর প্রতিটা অর্ডারে প্রতি কার্টন ১২ পিস ধরে মোট কার্টন আর শেষ কার্টনের পিস, পরিমাণ `5,000` আকারে।
25. `w5_order`-এর `ship_date`-এর ৪৫ দিন আগের তারিখ `fabric_in_house`, `DD-Mon-YYYY` আকারে, আর সেই বারের নাম। `ship_date` আছে এমন অর্ডারের।

```sql
-- অংশ ক
-- ১
SELECT UPPER(first_name || ' ' || last_name) AS full_name FROM employees;

-- ২

-- ৩
SELECT SUBSTR(first_name, 1, 1) || '. ' || last_name AS short_name FROM employees;

-- ৪
SELECT LOWER(first_name) || '.' || LOWER(last_name) || '@company.com' AS office_email
FROM   employees;

-- ৫
SELECT job_id,
       SUBSTR(job_id, 1, INSTR(job_id, '_') - 1) AS dept_code,
       SUBSTR(job_id, INSTR(job_id, '_') + 1)    AS role_code
FROM   employees;

-- ৬
SELECT last_name, REPLACE(last_name, 'e', '3') AS changed_name FROM employees;

-- ৭
SELECT 'EMP-' || LPAD(employee_id, 5, '0') AS emp_code, first_name
FROM   employees
WHERE  LENGTH(first_name) = 5;

-- অংশ খ
-- ৮
SELECT last_name, salary, ROUND(salary * 0.125) AS bonus FROM employees;

-- ৯
SELECT last_name, ROUND(salary + salary * commission_pct, 2) AS monthly_income
FROM   employees
WHERE  commission_pct IS NOT NULL;

-- ১০
SELECT employee_id, last_name FROM employees WHERE MOD(employee_id, 2) = 1;

-- ১১
SELECT last_name, salary,
       TRUNC(salary / 1000) AS thousands,
       MOD(salary, 1000)    AS remainder
FROM   employees;

-- অংশ গ
-- ১২
SELECT last_name,
       TRUNC(MONTHS_BETWEEN(SYSDATE, hire_date) / 12)     AS years_part,
       TRUNC(MOD(MONTHS_BETWEEN(SYSDATE, hire_date), 12)) AS months_part
FROM   employees
ORDER  BY hire_date;

-- ১৩
SELECT last_name, hire_date, ADD_MONTHS(hire_date, 6) AS after_six_months FROM employees;

-- ১৪
SELECT last_name, LAST_DAY(hire_date) AS month_end, NEXT_DAY(hire_date, 'MONDAY') AS next_monday
FROM   employees;

-- ১৫
SELECT last_name, hire_date FROM employees WHERE EXTRACT(MONTH FROM hire_date) = 12;

-- অংশ ঘ
-- ১৬
SELECT last_name, TO_CHAR(hire_date, 'fmDay, DD Month YYYY') AS hired FROM employees;

-- ১৭
SELECT last_name, TO_CHAR(salary, 'FM$99,999.00') AS salary_usd
FROM   employees
WHERE  salary > 10000;

-- ১৮
SELECT last_name, hire_date FROM employees WHERE TO_CHAR(hire_date, 'fmDay') = 'Friday';

-- ১৯
SELECT last_name || ' (' || job_id || ') joined in ' || TO_CHAR(hire_date, 'Mon YYYY') AS note
FROM   employees;

-- অংশ ঙ
-- ২০
SELECT issue_id,
       TO_CHAR(due_date, 'DD-Mon-YYYY') AS due_on,
       TRUNC(SYSDATE) - due_date AS days_overdue
FROM   lib_book_issue
WHERE  return_date IS NULL;

-- ২১
SELECT issue_id,
       return_date - due_date AS days_late,
       'Tk ' || TO_CHAR((return_date - due_date) * 5, 'FM9,990.00') AS fine_text
FROM   lib_book_issue
WHERE  return_date > due_date;

-- ২২
SELECT UPPER(SUBSTR(email, 1, INSTR(email, '@') - 1)) AS user_part
FROM   lib_member
WHERE  email IS NOT NULL;

-- ২৩
SELECT member_name,
       SUBSTR(mobile_no, 1, 3) || '*****' || SUBSTR(mobile_no, -3) AS masked_mobile
FROM   lib_member;

-- ২৪
SELECT order_no,
       TO_CHAR(order_qty, 'FM999,999') AS qty_text,
       CEIL(order_qty / 12)            AS total_cartons,
       MOD(order_qty, 12)              AS loose_pcs
FROM   w5_order;

-- ২৫
SELECT order_no,
       TO_CHAR(ship_date - 45, 'DD-Mon-YYYY') AS fabric_in_house,
       TO_CHAR(ship_date - 45, 'fmDay')       AS day_name

WHERE  ship_date IS NOT NULL;
```

- **২০:** এই সংখ্যা তোমার চালানোর দিনের উপর নির্ভর করে
- **২১:** সপ্তাহ ৫-এর `lib_fine`-এর টাকার সাথে মিলিয়ে দেখো: ২০, ৪০, ৪০, ৩৫, ৩০
- **২৪:** `MOD` শূন্য হলে শেষ কার্টনটা পুরো ভরা
