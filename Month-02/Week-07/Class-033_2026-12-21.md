## ১. ROUND (৩০ মিনিট)

`ROUND(সংখ্যা, দশমিকের ঘর)`

```sql
SELECT ROUND(45.926, 2)  AS a,    -- 45.93
       ROUND(45.926, 1)  AS b,    -- 45.9
       ROUND(45.926, 0)  AS c,    -- 46
       ROUND(45.926)     AS d,    -- 46, ঘর না দিলে 0
       ROUND(45.926, -1) AS e,    -- 50, দশকে
       ROUND(1450, -2)   AS f,    -- 1500, শতকে
       ROUND(2.5)        AS g,    -- 3
       ROUND(-2.5)       AS h     -- -3
FROM   dual;
```

**নিয়ম:** কাটার ঘরের পরের অঙ্ক ৫ বা বেশি হলে উপরে।

```
ঘর:   4  5 . 9  2  6
ঘর -1 ▲  ঘর 0▲  ▲ঘর 1 ▲ঘর 2
```

### টেবিলে

```sql
-- দৈনিক বেতন, ২ ঘর দশমিকে
SELECT last_name, salary, ROUND(salary / 30, 2) AS daily_salary
FROM   employees;

-- ১৫.৫% বাড়িয়ে পুরো সংখ্যায়
SELECT last_name, salary, ROUND(salary * 1.155) AS new_salary
FROM   employees;

-- নিকটতম ১০০০-এ
SELECT last_name, salary, ROUND(salary, -3) AS rounded_salary
FROM   employees;
```

**ক্লাস ৭-এর সাথে মিলিয়ে দেখো:** `NUMBER(10,2)` কলামে `3.999` রাখলে Oracle নিজে `ROUND` করে `4.00` রাখে। `ROUND` সেই কাজটাই তোমার হাতে দেয়।

### ROUND কোথায় করবে

```sql
-- ভুল ফল হতে পারে: আগে রাউন্ড, তারপর হিসাব
SELECT ROUND(2.345, 2) * 1000 AS a,     -- 2350
       ROUND(2.345 * 1000, 2) AS b      -- 2345
FROM   dual;
```

**হিসাব আগে, `ROUND` শেষে।** ইনভয়েসে প্রতি লাইনে রাউন্ড করলে মোট যোগফল সামান্য বদলে যেতে পারে। Buyer-এর হিসাবে এটা প্রায়ই প্রশ্নের কারণ হয়।

## ২. TRUNC (১৫ মিনিট)

`TRUNC(সংখ্যা, দশমিকের ঘর)`: বাড়তি অংশ **কেটে ফেলে**, রাউন্ড করে না।

```sql
SELECT TRUNC(45.926, 2)  AS a,    -- 45.92
       TRUNC(45.926, 1)  AS b,    -- 45.9
       TRUNC(45.926)     AS c,    -- 45
       TRUNC(45.926, -1) AS d,    -- 40
       TRUNC(-2.5)       AS e     -- -2
FROM   dual;
```

| মান | `ROUND` | `TRUNC` |
|---|---|---|
| 45.926 | 46 | 45 |
| 45.126 | 45 | 45 |
| 2.5 | 3 | 2 |
| -2.5 | -3 | -2 |

```sql
-- বেতনকে হাজারে: ৯ হাজার ...
SELECT last_name, salary, TRUNC(salary / 1000) AS thousands
FROM   employees;
```

> ক্লাস ৮-এ `TRUNC(SYSDATE)` দেখেছ। একই নাম, তারিখের জন্য আলাদা কাজ। কাল দেখবে।

## ৩. CEIL ও FLOOR (২০ মিনিট)

| ফাংশন | কাজ | `4.1` | `4.9` | `-4.1` |
|---|---|---|---|---|
| `CEIL` | উপরের পূর্ণ সংখ্যা | 5 | 5 | -4 |
| `FLOOR` | নিচের পূর্ণ সংখ্যা | 4 | 4 | -5 |
| `ROUND` | নিকটতম | 4 | 5 | -4 |
| `TRUNC` | দশমিক কেটে | 4 | 4 | -4 |

```sql
SELECT CEIL(4.1) AS a, CEIL(4.9) AS b, CEIL(-4.1) AS c,
       FLOOR(4.1) AS d, FLOOR(4.9) AS e, FLOOR(-4.1) AS f
FROM   dual;
```

- `CEIL`: এর **সংখ্যারেখায় ডান দিকে**, মানে বড়র দিকে
- `FLOOR`: **বাম দিকে**, মানে ছোটর দিকে
- ধনাত্মক সংখ্যায় `FLOOR` আর `TRUNC` একই, ঋণাত্মকে আলাদা

### কোনটা কখন

| প্রশ্ন | ফাংশন | কেন |
|---|---|---|
| ৫০০০ পিসে কয়টা কার্টন লাগবে? | `CEIL` | অর্ধেক কার্টনও একটা কার্টন |
| এই কাপড় দিয়ে কয়টা পুরো পোশাক হবে? | `FLOOR` | অর্ধেক পোশাক বিক্রি হয় না |
| Efficiency রিপোর্টে কত %? | `ROUND` | নিকটতম |
| কয় বছর চাকরি হলো? | `TRUNC` | পূর্ণ বছর |

### মাপে রাউন্ড

```sql
-- ৫০ টাকার গুণিতকে উপরে: 1234 → 1250
SELECT CEIL(1234 / 50) * 50 AS rounded_up FROM dual;
```

## ৪. MOD (২০ মিনিট)

`MOD(ভাজ্য, ভাজক)`: ভাগশেষ।

```sql
SELECT MOD(10, 3)   AS a,    -- 1
       MOD(10, 2)   AS b,    -- 0
       MOD(7, 10)   AS c,    -- 7
       MOD(-10, 3)  AS d,    -- -1
       MOD(10, 0)   AS e     -- 10, এরর না
FROM   dual;
```

`10 / 0` কিন্তু এরর দেয়:

```sql
SELECT 10 / 0 FROM dual;
```

```
ORA-01476: divisor is equal to zero
```

### কাজে লাগে

```sql
-- জোড় employee_id: ৫৪ জন
SELECT employee_id, last_name
FROM   employees
WHERE  MOD(employee_id, 2) = 0;

-- প্রতি ১০ নম্বর কর্মী (নমুনা নিতে)
SELECT employee_id, last_name
FROM   employees
WHERE  MOD(employee_id, 10) = 0;
```

## ৫. গার্মেন্টসের হিসাব (৩০ মিনিট)

### কার্টন

৫০০০ পিস, প্রতি কার্টনে ১২ পিস।

```sql
SELECT 5000 / 12         AS exact,            -- 416.666...
       CEIL(5000 / 12)   AS total_cartons,    -- 417
       FLOOR(5000 / 12)  AS full_cartons,     -- 416
       MOD(5000, 12)     AS loose_pcs         -- 8
FROM   dual;
```

৪১৬টা পুরো কার্টন, আর শেষ কার্টনে ৮ পিস।

### কাপড়ের প্রয়োজন

৫০০০ পিসে প্রতি পিসে ০.১৮ কেজি, ৫% অপচয়।

```sql
SELECT 5000 * 0.18              AS net_kg,     -- 900
       5000 * 0.18 * 1.05       AS gross_kg,   -- 945
       CEIL(5000 * 0.18 * 1.05) AS order_kg    -- 945
FROM   dual;
```

### Efficiency

একটা লাইনে আজ ১২০০ পিস, প্রতিটার SMV ১৫, ৪০ জন অপারেটর, ৮ ঘণ্টা।

```
Efficiency % = (উৎপাদিত পিস × SMV) ÷ (অপারেটর × মিনিট) × 100
```

```sql
SELECT ROUND(1200 * 15 / (40 * 8 * 60) * 100, 2) AS efficiency_pct FROM dual;
-- 18000 / 19200 * 100 = 93.75
```

### টেবিল থেকে (`learn_freepdb1`)

```sql
-- প্রতিটা অর্ডারের কার্টন (১২ পিসে)
SELECT order_no,
       order_qty,
       CEIL(order_qty / 12) AS total_cartons,
       MOD(order_qty, 12)   AS loose_pcs
FROM   w5_order;

-- প্রতিটা অর্ডারের মূল্য (FOB দাম এখানে হাতে দিয়েছি, JOIN শিখব সপ্তাহ ৯-এ)
SELECT order_no, order_qty, ROUND(order_qty * 2.35, 2) AS order_value_usd
FROM   w5_order
WHERE  style_id = 1;
```

### আরো কিছু ফাংশনের নাম

| ফাংশন | কাজ | উদাহরণ |
|---|---|---|
| `ABS` | ঋণাত্মক চিহ্ন বাদ | `ABS(-5)` = 5 |
| `POWER` | ঘাত | `POWER(2, 3)` = 8 |
| `SQRT` | বর্গমূল | `SQRT(16)` = 4 |

## সারাংশ

- `ROUND`: নিকটতম, `TRUNC`: কেটে ফেলে
- `CEIL`: উপরের দিকে, `FLOOR`: নিচের দিকে
- `MOD`: ভাগশেষ, জোড়-বিজোড় আর শেষ কার্টনের জন্য
- ঋণাত্মক ঘর দিলে দশক, শতকে রাউন্ড হয়
- হিসাব আগে, `ROUND` শেষে। `/ 0` দিলে `ORA-01476`

**পরের ক্লাস:** Date Function: SYSDATE, ADD_MONTHS, MONTHS_BETWEEN, LAST_DAY, NEXT_DAY।
