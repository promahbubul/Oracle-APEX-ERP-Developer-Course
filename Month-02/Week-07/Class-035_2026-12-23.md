# ক্লাস ৩৫: Conversion Function: TO_CHAR, TO_DATE, TO_NUMBER ও Date Format

**তারিখ:** ২৩ ডিসেম্বর ২০২৬, বুধবার
**সময়:** সন্ধ্যা ৭:০০ থেকে রাত ১০:০০
**সপ্তাহ:** ৭ | **ধাপ:** ২ (Oracle SQL)

---

## আজকে কী শিখব

- Implicit আর Explicit Conversion
- `TO_CHAR` দিয়ে তারিখ আর সংখ্যা সাজানো
- ফরম্যাট কোড, `fm`, `RR`
- `TO_DATE`, আর তার এরর
- `TO_NUMBER`, `DEFAULT ... ON CONVERSION ERROR`

---

## ১. Implicit আর Explicit (১৫ মিনিট)

```
          TO_CHAR                TO_DATE
DATE  ───────────►  VARCHAR2  ───────────►  DATE

          TO_CHAR                TO_NUMBER
NUMBER ──────────►  VARCHAR2  ───────────►  NUMBER
```

| ধরন | মানে | উদাহরণ |
|---|---|---|
| **Implicit** | Oracle নিজে বদলে নেয় | `salary = '24000'` |
| **Explicit** | তুমি ফাংশন দিয়ে বদলাও | `TO_NUMBER('24000')` |

**Implicit-এর উপর ভরসা করবে না:**
- তারিখে ফল সেশনের সেটিংয়ের উপর নির্ভর করে, এক কম্পিউটারে চলে, অন্যটায় এরর
- কলাম বদলে গেলে Index কাজ নাও করতে পারে
- ভুল ধরা কঠিন হয়

## ২. TO_CHAR: তারিখ (৩৫ মিনিট)

`TO_CHAR(তারিখ, 'ফরম্যাট')`

```sql
SELECT TO_CHAR(DATE '2026-12-23', 'DD-MM-YYYY')              AS a,  -- 23-12-2026
       TO_CHAR(DATE '2026-12-23', 'DD/MM/YY')                AS b,  -- 23/12/26
       TO_CHAR(DATE '2026-12-23', 'DD-Mon-YYYY')             AS c,  -- 23-Dec-2026
       TO_CHAR(DATE '2026-12-23', 'fmDay, DD Month YYYY')    AS d   -- Wednesday, 23 December 2026
FROM   dual;
```

### ফরম্যাট কোড

| কোড | মানে | ফল (২৩ ডিসেম্বর ২০২৬, রাত ৯:০৫) |
|---|---|---|
| `YYYY` / `YY` | বছর | 2026 / 26 |
| `MM` | মাস সংখ্যায় | 12 |
| `MON` / `Mon` | মাসের ছোট নাম | DEC / Dec |
| `MONTH` / `Month` | মাসের পুরো নাম | DECEMBER / December |
| `DD` | মাসের দিন | 23 |
| `DDD` | বছরের কত নম্বর দিন | 357 |
| `DY` / `Dy` | বারের ছোট নাম | WED / Wed |
| `DAY` / `Day` | বারের পুরো নাম | WEDNESDAY / Wednesday |
| `Q` | ত্রৈমাসিক | 4 |
| `HH24` | ঘণ্টা (০০–২৩) | 21 |
| `HH` / `HH12` | ঘণ্টা (০১–১২) | 09 |
| `MI` | মিনিট | 05 |
| `SS` | সেকেন্ড | 00 |
| `AM` / `PM` | সকাল বা বিকাল | PM |

**বড়-ছোট হাতের লেখা ফলে আসে:** `MON` → `DEC`, `Mon` → `Dec`।

### সময়সহ

```sql
SELECT TO_CHAR(SYSDATE, 'DD-Mon-YYYY HH24:MI:SS')    AS a,
       TO_CHAR(SYSDATE, 'DD-Mon-YYYY HH:MI AM')      AS b
FROM   dual;
```

### ফরম্যাটের ভেতরে লেখা

```sql
SELECT TO_CHAR(DATE '2026-12-23', '"Date: "DD/MM/YYYY') AS a,          -- Date: 23/12/2026
       TO_CHAR(DATE '2026-12-23', 'fmDD "of" Month, YYYY') AS b        -- 23 of December, 2026
FROM   dual;
```

### `fm` আর বারের নামের ফাঁদ

`Month` আর `Day` সবচেয়ে লম্বা নামের সমান জায়গা নেয়, বাড়তি স্পেস ভরে দেয়।

```sql
SELECT '[' || TO_CHAR(DATE '2026-12-25', 'Day') || ']'    AS a,   -- [Friday   ]
       '[' || TO_CHAR(DATE '2026-12-25', 'fmDay') || ']'  AS b    -- [Friday]
FROM   dual;
```

তাই এই শর্ত কখনো মেলে না:

```sql
WHERE TO_CHAR(hire_date, 'Day') = 'Friday'        -- ভুল, স্পেস আছে
WHERE TO_CHAR(hire_date, 'fmDay') = 'Friday'      -- ঠিক
WHERE TO_CHAR(hire_date, 'DY') = 'FRI'            -- ঠিক
```

`fm` সামনের `0`-ও বাদ দেয়: `fmDD/MM/YYYY` → `5/1/2027`।

### তারিখের ভাষা

বারের নাম ডাটাবেসের ভাষায় আসে। নিশ্চিত থাকতে ভাষা বলে দেওয়া যায়:

```sql
SELECT TO_CHAR(SYSDATE, 'fmDay', 'NLS_DATE_LANGUAGE=ENGLISH') AS day_name FROM dual;
```

### কাজে লাগে যেখানে

```sql
-- মাসভিত্তিক দেখা (learn_freepdb1)
SELECT issue_id, TO_CHAR(issue_date, 'Mon-YYYY') AS issue_month
FROM   lib_book_issue;

-- অক্টোবর ২০২৬-এর ইস্যু: ১২–১৫
SELECT issue_id, issue_date
FROM   lib_book_issue
WHERE  TO_CHAR(issue_date, 'YYYY-MM') = '2026-10';
```

শেষেরটা পড়তে সহজ। তবে বড় টেবিলে ক্লাস ৩৪-এর `>=`, `<` রেঞ্জ দ্রুত।

> **`TO_CHAR` দিয়ে সাজানোর ফাঁদ:** `ORDER BY TO_CHAR(d, 'Mon-YYYY')` তারিখের ক্রমে না, বর্ণক্রমে সাজায় (`Apr` আগে, `Jan` পরে)। সবসময় আসল তারিখ দিয়ে সাজাও।

## ৩. TO_CHAR: সংখ্যা (৩০ মিনিট)

`TO_CHAR(সংখ্যা, 'ফরম্যাট')`

| কোড | মানে | উদাহরণ | ফল |
|---|---|---|---|
| `9` | অঙ্ক, না থাকলে ফাঁকা | `TO_CHAR(45, '999')` | ` 45` |
| `0` | অঙ্ক, না থাকলে 0 | `TO_CHAR(45, '0000')` | ` 0045` |
| `,` | হাজারের কমা | `TO_CHAR(24000, '99,999')` | ` 24,000` |
| `.` | দশমিক | `TO_CHAR(4.5, '9.00')` | ` 4.50` |
| `$` | ডলার | `TO_CHAR(2.35, '$9.99')` | ` $2.35` |
| `FM` | ফাঁকা বাদ | `TO_CHAR(45, 'FM999')` | `45` |

```sql
SELECT last_name,
       salary,
       TO_CHAR(salary, 'FM99,999.00')  AS salary_text,
       TO_CHAR(salary, 'FM$99,999.00') AS salary_usd
FROM   employees
WHERE  department_id = 90;
```

ফল: `24,000.00`, `$24,000.00`। ফলটা এখন **লেখা**, হিসাব করা যাবে না।

### সামনে একটা স্পেস কেন?

Oracle চিহ্নের (`-`) জন্য একটা ঘর রাখে। তাই `FM` না দিলে সামনে স্পেস থাকে।

### ঘর কম হলে

```sql
SELECT TO_CHAR(123456, '999') AS a FROM dual;     -- ####
```

ঘরে না আঁটলে `#` দেখায়, এরর দেয় না। রিপোর্টে এটা দেখলে ফরম্যাট বড় করো।

### বাংলাদেশের নিয়মে কমা

```sql
SELECT TO_CHAR(1234567, 'FM99,99,999') AS taka FROM dual;     -- 12,34,567
```

### বেশি ব্যবহৃত ফরম্যাট

| কাজ | ফরম্যাট | উদাহরণ |
|---|---|---|
| পরিমাণ | `FM999,999,990` | `5,000` |
| টাকা | `FM99,99,99,990.00` | `12,34,567.00` |
| ডলারে দাম | `FM$9,990.0000` | `$2.3500` |
| শতকরা | `FM990.00` | `87.50` |

`0` না দিলে `0.50` হয়ে যায় `.50`। তাই শেষের ঘরে `0` রাখো।

## ৪. TO_DATE (২৫ মিনিট)

`TO_DATE('লেখা', 'ফরম্যাট')`: লেখা যেভাবে আছে, ফরম্যাট সেভাবে লিখতে হবে।

```sql
SELECT TO_DATE('23/12/2026', 'DD/MM/YYYY')              AS a,
       TO_DATE('23-Dec-2026', 'DD-Mon-YYYY')            AS b,
       TO_DATE('20261223', 'YYYYMMDD')                  AS c,
       TO_DATE('23/12/2026 21:05', 'DD/MM/YYYY HH24:MI') AS d
FROM   dual;
```

### DATE লিটারেল নাকি TO_DATE

| | `DATE '2026-12-23'` | `TO_DATE(...)` |
|---|---|---|
| ফরম্যাট | শুধু `YYYY-MM-DD` | যেকোনো |
| সময় | না | হ্যাঁ |
| কখন | কোডে সরাসরি তারিখ লিখতে | ইউজার বা ফাইল থেকে আসা লেখা বদলাতে |

### সাধারণ এরর

| কোড | এরর | কারণ |
|---|---|---|
| `TO_DATE('23/12/2026', 'DD-MM-YYYY')` | চলে | চিহ্নে Oracle সাধারণত ছাড় দেয় |
| `TO_DATE('2026/12/23', 'DD/MM/YYYY')` | `ORA-01861` বা অনুরূপ | ক্রম ভুল |
| `TO_DATE('23/13/2026', 'DD/MM/YYYY')` | `ORA-01843` | ১৩ নম্বর মাস নেই |
| `TO_DATE('32/12/2026', 'DD/MM/YYYY')` | `ORA-01847` | ৩২ তারিখ নেই |
| `TO_DATE('30/02/2027', 'DD/MM/YYYY')` | `ORA-01839` | ৩০ ফেব্রুয়ারি নেই |
| `TO_DATE('23/12/2026 10:30', 'DD/MM/YYYY')` | `ORA-01830` | ফরম্যাটের চেয়ে লেখা বড় |

### `YY` আর `RR`

দুই অঙ্কের বছরে কোন শতাব্দী?

```sql
SELECT TO_CHAR(TO_DATE('15-01-99', 'DD-MM-YY'), 'YYYY') AS with_yy,    -- 2099
       TO_CHAR(TO_DATE('15-01-99', 'DD-MM-RR'), 'YYYY') AS with_rr     -- 1999
FROM   dual;
```

| ফরম্যাট | নিয়ম |
|---|---|
| `YY` | সবসময় এই শতাব্দী |
| `RR` | ০০–৪৯ এই শতাব্দী, ৫০–৯৯ গত শতাব্দী |

**কোডে সবসময় `YYYY` লেখো,** আর ইউজারের কাছেও ৪ অঙ্কের বছর নাও। পুরনো ডাটা ইমপোর্টে `RR` কাজে লাগে।

## ৫. TO_NUMBER (১৫ মিনিট)

```sql
SELECT TO_NUMBER('5000')                  AS a,    -- 5000
       TO_NUMBER('1,234.50', '9,999.99')  AS b,    -- 1234.5
       TO_NUMBER('$2.35', '$9.99')        AS c     -- 2.35
FROM   dual;
```

কমা বা চিহ্ন থাকলে ফরম্যাট লাগে।

```sql
-- বারকোডের সংখ্যা অংশ (learn_freepdb1): ১৬–২০ নম্বর কপি
SELECT copy_id, barcode
FROM   lib_book_copy
WHERE  TO_NUMBER(SUBSTR(barcode, 4)) > 15;
```

### ভুল ডাটায় এরর

```sql
SELECT TO_NUMBER('abc') FROM dual;
```

```
ORA-01722: invalid number
```

Excel থেকে আসা ডাটায় হাজারে একটা `N/A` থাকলেই পুরো কোয়েরি থেমে যায়। সমাধান (12.2 থেকে):

```sql
SELECT TO_NUMBER('abc' DEFAULT 0 ON CONVERSION ERROR)      AS a,    -- 0
       TO_NUMBER('123' DEFAULT 0 ON CONVERSION ERROR)      AS b,    -- 123
       TO_DATE('32/12/2026' DEFAULT NULL ON CONVERSION ERROR, 'DD/MM/YYYY') AS c,   -- NULL
       VALIDATE_CONVERSION('abc' AS NUMBER)                AS d     -- 0, মানে বদলানো যাবে না
FROM   dual;
```

`VALIDATE_CONVERSION` দিয়ে ভুল রো খুঁজে বের করা যায়। Data Load-এর আগে পরিষ্কার করতে এটা খুব কাজের (সপ্তাহ ৩৪)।

## ৭. হোমওয়ার্ক

1. কাল ২৫টা কোয়েরির দিন। ক্লাস ৩১–৩৫-এর সারাংশ পড়ে আসো।
2. একটা ইনভয়েসের মতো একটা রো বানাও (`w5_order` থেকে): `Order: ORD-501 | Date: 01-Nov-2026 | Qty: 5,000 | Ship: Friday, 15 January 2027`
3. `DATE '2026-12-23'` আর `TO_DATE('23/12/2026', 'DD/MM/YYYY')`-এর পার্থক্য লেখো। কখন কোনটা?

<details>
<summary>হোমওয়ার্ক ২-এর সমাধান</summary>

```sql
SELECT 'Order: ' || order_no ||
       ' | Date: ' || TO_CHAR(order_date, 'DD-Mon-YYYY') ||
       ' | Qty: '  || TO_CHAR(order_qty, 'FM999,999') ||
       ' | Ship: ' || TO_CHAR(ship_date, 'fmDay, DD Month YYYY') AS order_line
FROM   w5_order;
```

</details>

## সারাংশ

- Explicit Conversion ব্যবহার করো, Implicit-এর উপর ভরসা না
- `TO_CHAR`: তারিখ বা সংখ্যা থেকে সাজানো লেখা। ফল লেখা, হিসাব বা সাজানো যায় না
- `fm`: বাড়তি স্পেস বাদ। `Day`, `Month` তুলনায় এটা লাগে
- `TO_DATE`: ফরম্যাট লেখার সাথে মিলতে হয়। কোডে `YYYY` লেখো
- `TO_NUMBER`: ভুল ডাটায় `ORA-01722`, `DEFAULT ... ON CONVERSION ERROR` বাঁচায়
