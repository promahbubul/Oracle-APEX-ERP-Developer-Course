## আজকে কী শিখব

- `NVL`: NULL হলে অন্য মান
- `NVL2`: NULL কি না দেখে দুই রকম মান
- `NULLIF`: দুই মান সমান হলে NULL
- `COALESCE`: প্রথম যে মান NULL না
- কোনটা কখন

## ১. NVL (৪৫ মিনিট)

সপ্তাহ ৬-এ দেখেছ: NULL-এর সাথে হিসাব করলে ফল NULL।

```sql
SELECT last_name, salary, commission_pct,
       salary * 12 + salary * 12 * commission_pct AS annual_income
FROM   employees
WHERE  department_id IN (80, 90);
```

বিভাগ ৯০-র King-এর আয় ফাঁকা! ২৮৮০০০ হওয়ার কথা। সমাধান **NVL**।

`NVL(মান, NULL হলে যা)`

```sql
SELECT last_name, salary, commission_pct,
       salary * 12 + salary * 12 * NVL(commission_pct, 0) AS annual_income
FROM   employees
WHERE  department_id IN (80, 90);
```

| `commission_pct` | `NVL(commission_pct, 0)` |
|---|---|
| 0.4 | 0.4 |
| NULL | 0 |

### লেখা আর তারিখে

```sql
-- learn_freepdb1
SELECT member_name,
       NVL(email, 'No email')          AS email_text,
       NVL(member_name_bn, member_name) AS display_name
FROM   lib_member;

-- ফেরত না এলে আজকের তারিখ ধরে কত দিন দেরি
SELECT issue_id,
       NVL(return_date, TRUNC(SYSDATE)) - due_date AS days_after_due
FROM   lib_book_issue;
```

`display_name`-এর কৌশলটা ERP-তে খুব কাজের: "বাংলা নাম থাকলে সেটা, নাহলে ইংরেজি।"

### Data Type-এর নিয়ম

দুইটা মান একই ধরনের হতে হবে।

```sql
-- এরর ORA-01722: 'No Commission'-কে সংখ্যায় বদলাতে পারে না
SELECT NVL(commission_pct, 'No Commission') FROM employees;

-- ঠিক: আগে সংখ্যাকে লেখা বানাও
SELECT last_name, NVL(TO_CHAR(commission_pct), 'No Commission') AS commission_text
FROM   employees;
```

### WHERE-এ

```sql
-- কমিশন ০.২-এর কম, যাদের কমিশনই নেই তারাও
SELECT last_name, commission_pct
FROM   employees
WHERE  NVL(commission_pct, 0) < 0.2;
```

ক্লাস ২৯-এ এটাই `OR commission_pct IS NULL` দিয়ে করেছিলে। `NVL` লেখা সহজ, তবে কলামের উপর ফাংশন থাকায় সাধারণ Index ব্যবহার হয় না। বড় টেবিলে `OR ... IS NULL` ভালো।

## ২. NVL2 (১৫ মিনিট)

`NVL2(মান, NULL না হলে এটা, NULL হলে এটা)`

```sql
SELECT last_name,
       commission_pct,
       NVL2(commission_pct, 'Yes', 'No') AS has_commission,
       NVL2(commission_pct, salary * 1.1, salary) AS new_salary
FROM   employees
WHERE  department_id IN (80, 90);
```

**ক্রমটা মনে রাখো:** দ্বিতীয় মান NULL **না** হলে, তৃতীয় মান NULL হলে। অনেকে উল্টো ভাবে।

```sql
-- learn_freepdb1
SELECT issue_id, NVL2(return_date, 'Returned', 'Not returned') AS issue_status
FROM   lib_book_issue;
```

## ৩. NULLIF (২০ মিনিট)

`NULLIF(ক, খ)`: ক আর খ সমান হলে NULL, না হলে ক।

```sql
SELECT NULLIF(10, 10) AS a,    -- NULL
       NULLIF(10, 20) AS b     -- 10
FROM   dual;
```

### সবচেয়ে বড় কাজ: শূন্য দিয়ে ভাগ আটকানো

```sql
SELECT 100 / 0 FROM dual;                -- এরর ORA-01476

SELECT 100 / NULLIF(0, 0) FROM dual;     -- NULL, এরর নেই
```

ধরো কোনো লাইনের আজকের টার্গেট `0`। রিপোর্টের একটা রো-র জন্য পুরো কোয়েরি থেমে যাবে। তাই:

```sql
-- নমুনা: এখানে দুইটা মান হাতে দিয়েছি
SELECT ROUND(950 / NULLIF(1000, 0) * 100, 2) AS achievement_pct,   -- 95
       ROUND(950 / NULLIF(0, 0) * 100, 2)    AS no_target          -- NULL
FROM   dual;
```

ফলটা `0` দেখাতে চাইলে বাইরে `NVL`: `NVL(ROUND(950 / NULLIF(target, 0) * 100, 2), 0)`।

### দুই কলাম মিলছে কি না

```sql
-- নাম আর পদবির দৈর্ঘ্য সমান হলে NULL
SELECT first_name, last_name,
       NULLIF(LENGTH(first_name), LENGTH(last_name)) AS length_check
FROM   employees;
```

## ৪. COALESCE (২৫ মিনিট)

`COALESCE(ক, খ, গ, ...)`: বাম থেকে প্রথম যে মান NULL না।

```sql
SELECT COALESCE(NULL, NULL, 'A', 'B') AS a,    -- A
       COALESCE('X', 'Y')             AS b,    -- X
       COALESCE(NULL, NULL)           AS c     -- NULL
FROM   dual;
```

```sql
-- যোগাযোগের জন্য: ইমেইল, না থাকলে মোবাইল, না থাকলে 'None'
SELECT member_name,
       COALESCE(email, mobile_no, 'None') AS contact
FROM   lib_member;
```

### NVL নাকি COALESCE

| | `NVL` | `COALESCE` |
|---|---|---|
| কয়টা মান | ২টা | যত খুশি |
| কোথায় চলে | শুধু Oracle | ANSI SQL, অন্য ডাটাবেসেও |
| Data Type | দ্বিতীয়টা নিজে থেকে বদলাতে চেষ্টা করে | সবগুলো একই ধরনের হতে হয়, নাহলে এরর |
| দ্বিতীয় মান কখন হিসাব হয় | সবসময় | দরকার হলেই |

```sql
SELECT COALESCE(commission_pct, 'None') FROM employees;
```

```
ORA-00932: inconsistent datatypes
```

**সুপারিশ:** ২টা মানে `NVL` ঠিক আছে, আর Oracle-এর কোডে এটাই বেশি দেখবে। ৩টা বা বেশি হলে `COALESCE`।

### চারটা একসাথে

| ফাংশন | প্রশ্ন | ফল |
|---|---|---|
| `NVL(a, b)` | a কি NULL? | হ্যাঁ: b। না: a |
| `NVL2(a, b, c)` | a কি NULL? | হ্যাঁ: c। না: b |
| `NULLIF(a, b)` | a আর b কি সমান? | হ্যাঁ: NULL। না: a |
| `COALESCE(a, b, c)` | প্রথম কোনটা NULL না? | সেই মান |

## ৫. হাতে-কলমে প্র্যাকটিস (৭৫ মিনিট)

## সারাংশ

- `NVL`: NULL হলে অন্য মান। হিসাবে NULL আটকাতে এটা প্রায় সবসময় লাগে
- `NVL2`: NULL না হলে দ্বিতীয়, NULL হলে তৃতীয়
- `NULLIF`: সমান হলে NULL, শূন্য দিয়ে ভাগ আটকায়
- `COALESCE`: প্রথম যে মান NULL না, সব মান একই ধরনের
- মানের ধরন মেলাও, দরকার হলে `TO_CHAR`

**পরের ক্লাস:** DECODE ও CASE Expression।
