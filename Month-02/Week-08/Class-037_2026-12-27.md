## ১. CASE Expression (৬০ মিনিট)

SQL-এর ভেতরে **"যদি এটা হয়, তাহলে ওটা"** লেখার উপায়।

### Simple CASE: একটা মানের সাথে তুলনা

```sql
SELECT last_name,
       department_id,
       CASE department_id
           WHEN 60 THEN 'IT'
           WHEN 90 THEN 'Executive'
           WHEN 50 THEN 'Shipping'
           ELSE 'Other'
       END AS dept_label
FROM   employees;
```

### Searched CASE: যেকোনো শর্ত

```sql
SELECT last_name,
       salary,
       CASE
           WHEN salary < 5000  THEN 'Low'
           WHEN salary < 10000 THEN 'Medium'
           WHEN salary < 15000 THEN 'High'
           ELSE 'Very High'
       END AS salary_grade
FROM   employees;
```

| অংশ | মানে |
|---|---|
| `CASE` | শুরু |
| `WHEN শর্ত THEN মান` | শর্ত সত্য হলে এই মান |
| `ELSE মান` | কোনোটাই সত্য না হলে, ঐচ্ছিক |
| `END` | শেষ, **ভুলে গেলে এরর** |

### ক্রমের নিয়ম: প্রথম সত্যটাই

Oracle উপর থেকে দেখে, **প্রথম সত্য শর্তে থেমে যায়।** তাই ক্রম জরুরি।

```sql
-- ভুল ক্রম: সবাই 'Medium' বা 'Very High', কেউ 'Low' পায় না
SELECT last_name, salary,
       CASE
           WHEN salary < 10000 THEN 'Medium'
           WHEN salary < 5000  THEN 'Low'
           ELSE 'Very High'
       END AS salary_grade
FROM   employees;
```

৩০০০ বেতন: প্রথম শর্তেই সত্য, তাই `Medium`। দ্বিতীয় শর্তে কখনো পৌঁছায় না।

### ELSE না দিলে

কোনো শর্ত না মিললে ফল **NULL**।

```sql
SELECT last_name,
       CASE WHEN salary > 20000 THEN 'CEO Level' END AS label
FROM   employees;     -- King বাদে সবার ফাঁকা
```

### সব মান একই ধরনের

```sql
SELECT CASE WHEN salary > 10000 THEN 'High' ELSE 0 END FROM employees;
```

```

```

### লাইব্রেরিতে (`learn_freepdb1`)

```sql
-- প্রতিটা ইস্যুর অবস্থা
SELECT issue_id,
       due_date,
       return_date,
       CASE
           WHEN return_date IS NULL      THEN 'Not returned'
           WHEN return_date > due_date   THEN 'Late'
           ELSE 'On time'
       END AS issue_status
FROM   lib_book_issue;
```

সপ্তাহ ৫-এর সমাধানের ডাটায়: `Not returned` ৫টা, `Late` ৫টা, বাকিগুলো `On time`।

### গার্মেন্টসের উদাহরণ

Efficiency-র মান অনুযায়ী লাইনের রেটিং (`w5_efficiency` ক্লাস ২২-এর হোমওয়ার্কের টেবিল):

```sql
SELECT line_id,
       ROUND(produced_minutes / available_minutes * 100, 2) AS efficiency_pct,
       CASE
           WHEN produced_minutes / available_minutes >= 0.70 THEN 'Excellent'
           WHEN produced_minutes / available_minutes >= 0.60 THEN 'Good'
           ELSE 'Needs Improvement'
       END AS rating
FROM   w5_efficiency;
```

> এটাই পরে APEX রিপোর্টে কালার দিয়ে দেখানো হবে: `DELAYED` লাল, `ON TIME` সবুজ। প্রজেক্ট ২-এর TNA ট্র্যাকিংয়ে লাগবে।

### WHERE-এ CASE

```sql
SELECT last_name, salary, department_id
FROM   employees
WHERE  salary > CASE department_id
                    WHEN 60 THEN 5000
                    WHEN 80 THEN 10000
                    ELSE 15000
                END;
```

প্রতিটা বিভাগের জন্য আলাদা সীমা।

### ORDER BY-তে CASE: নিজের ক্রম

স্ট্যাটাস বর্ণক্রমে সাজালে `CANCELLED`, `OPEN`, `SHIPPED` আসে। আমরা চাই আগে `OPEN`:

```sql
SELECT order_no, status
FROM   w5_order
ORDER  BY CASE status
              WHEN 'OPEN'      THEN 1
              WHEN 'SHIPPED'   THEN 2
              WHEN 'CANCELLED' THEN 3
          END;
```

## ২. DECODE (৩০ মিনিট)

Oracle-এর নিজস্ব, পুরনো ফাংশন। Simple `CASE`-এর মতো।

`DECODE(মান, মিললে১, ফল১, মিললে২, ফল২, ..., ডিফল্ট)`

```sql
SELECT last_name,
       department_id,
       DECODE(department_id,
              60, 'IT',
              90, 'Executive',
              50, 'Shipping',
              'Other') AS dept_label
FROM   employees;
```

শেষের একা মানটা ডিফল্ট। ডিফল্ট না দিলে NULL।

```sql
-- মেম্বারের ধরন (learn_freepdb1)
SELECT member_name,
       DECODE(member_type_id, 1, 'Student', 2, 'Teacher', 3, 'General') AS member_type
FROM   lib_member;

-- Y/N-কে পড়ার মতো করে
SELECT member_name,
       DECODE(is_active, 'Y', 'Active', 'N', 'Inactive') AS active_text
FROM   lib_member;
```

### DECODE-এর সীমাবদ্ধতা

শুধু **সমান কি না** দেখতে পারে। `<`, `>`, `BETWEEN`, `LIKE` সরাসরি হয় না।

### DECODE আর NULL: বড় পার্থক্য

```sql
SELECT DECODE(NULL, NULL, 'Match', 'No match') AS decode_result,          -- Match
       CASE NULL WHEN NULL THEN 'Match' ELSE 'No match' END AS case_result -- No match
FROM   dual;
```

`DECODE` দুইটা NULL-কে সমান ধরে। `CASE` ধরে না, কারণ `NULL = NULL` অজানা। Simple `CASE`-এ NULL ধরতে Searched `CASE` লাগে:

```sql
SELECT last_name,
       DECODE(department_id, NULL, 'No Dept', 'Has Dept') AS with_decode,
       CASE WHEN department_id IS NULL THEN 'No Dept' ELSE 'Has Dept' END AS with_case
FROM   employees
WHERE  last_name = 'Grant';
```

## ৩. CASE নাকি DECODE (২০ মিনিট)

| | `CASE` | `DECODE` |
|---|---|---|
| মান | ANSI SQL, সব ডাটাবেসে | শুধু Oracle |
| শর্ত | যেকোনো: `<`, `>`, `LIKE`, `IS NULL`, `AND` | শুধু সমান |
| NULL-এর তুলনা | `IS NULL` লাগে | `NULL` লিখলেই মেলে |
| পড়া | সহজ | বড় হলে কঠিন |
| PL/SQL-এ | চলে | SQL-এর ভেতরে ছাড়া চলে না |

**সুপারিশ:** নতুন কোডে **`CASE`**। `DECODE` জানতে হবে, কারণ পুরনো ERP কোডে প্রচুর দেখবে।

### সাধারণ ভুল

```sql
-- ১. END ভুলে যাওয়া: এরর
SELECT CASE WHEN salary > 1000 THEN 'A' ELSE 'B' FROM employees;

-- ২. Searched আর Simple মেশানো: এরর
SELECT CASE salary WHEN salary > 1000 THEN 'A' END FROM employees;

-- ৩. NULL-এর সাথে =: সবসময় মিথ্যার মতো, এরর আসে না
SELECT CASE WHEN commission_pct = NULL THEN 'None' ELSE 'Has' END FROM employees;
```

**৩ নম্বরটাই সবচেয়ে বিপজ্জনক:** এরর আসে না, সবার `Has` দেখায়। লিখতে হবে `commission_pct IS NULL`।

## ৪. হাতে-কলমে প্র্যাকটিস (৭০ মিনিট)

**HR (`hr_freepdb1`):**

1. `CASE` দিয়ে: বেতন ৩০০০-এর কম হলে `Junior`, ৮০০০-এর কম হলে `Mid`, বাকিরা `Senior`।
2. `job_id` `IT_PROG` হলে `Programmer`, `SA_REP` হলে `Sales`, বাকিরা `Staff`। `CASE` আর `DECODE` দুই উপায়ে।
3. পদের ধরন: `job_id` `MAN` বা `MGR` দিয়ে শেষ হলে `Manager`, নাহলে `Employee`। (`LIKE` ব্যবহার করো।)
4. কমিশন পান কি না: `CASE` দিয়ে `Yes`/`No`।
5. বেতন বৃদ্ধি: বিভাগ ৫০-এ ১০%, ৮০-তে ৫%, বাকিরা ২%। নতুন বেতন দেখাও।
6. চাকরির পূর্ণ বছর ১০ বা বেশি হলে `Veteran`, নাহলে `Regular`।
7. কর্মীদের এমনভাবে সাজাও, যাতে বিভাগ ৯০ আগে, তারপর ৬০, তারপর বাকিরা `department_id`-র ক্রমে।
8. যারা বিভাগ ৬০-এ ৫০০০-এর বেশি পান, অথবা অন্য বিভাগে ১৫০০০-এর বেশি (`WHERE`-এ `CASE`)।
9. `DECODE` দিয়ে: `manager_id` NULL হলে `Top`, নাহলে `Reports`।

**লাইব্রেরি ও অর্ডার (`learn_freepdb1`):**

10. প্রতিটা ইস্যুর অবস্থা: `Not returned`, `Late`, `On time`, ফেরতের তারিখের ক্রমে।
11. `DECODE` দিয়ে কপির স্ট্যাটাস বাংলায়: `AVAILABLE` → `আছে`, `ISSUED` → `ইস্যু করা`, `LOST` → `হারানো`, `DAMAGED` → `নষ্ট`।
12. জরিমানার মাত্রা: ৩৫ বা বেশি `High`, ২৫ বা বেশি `Medium`, বাকিটা `Low`।
13. বইয়ের বয়স: ২০২৪ বা পরে `New`, ২০১৮ বা পরে `Recent`, বাকিরা `Old`।
14. `w5_order`-এর অবস্থা: `ship_date` নেই `Not Scheduled`, আজকের আগে `Past`, ৬০ দিনের মধ্যে `Upcoming`, বাকিরা `Future`।
15. কার্টনের লেবেল: `w5_order`-এ `MOD(order_qty, 12) = 0` হলে `Full Cartons`, নাহলে `Has Loose`।

## ৫. হোমওয়ার্ক

1. গার্মেন্টসের একটা TNA কাজের জন্য স্ট্যাটাস বানাও: `actual_date` NULL আর `plan_date` পার হয়ে গেছে `DELAYED`, `actual_date` NULL আর সময় আছে `PENDING`, `actual_date > plan_date` `DONE LATE`, বাকিটা `DONE`। কোয়েরি না চালিয়ে শুধু `CASE` লেখো।
2. `CASE` আর `DECODE`-এর ৩টা পার্থক্য খাতায় লেখো।
3. আগের সপ্তাহের `SUBSTR` দিয়ে `w5_style`-এর `style_no` থেকে Buyer কোড নাও, আর `CASE` দিয়ে পুরো নাম দেখাও: `HM` → `H&M`, `ZR` → `Zara`, `PM` → `Primark`।

## সারাংশ

- `CASE`: SQL-এর "যদি-তাহলে"। `END` ভুলবে না
- প্রথম সত্য শর্তেই থামে, তাই ক্রম জরুরি। `ELSE` না থাকলে NULL
- সব ফল একই Data Type
- `SELECT`, `WHERE`, `ORDER BY` সব জায়গায় চলে
- `DECODE`: Oracle-এর, শুধু সমান, NULL-কে সমান ধরে। নতুন কোডে `CASE`

**পরের ক্লাস:** Aggregate Function: SUM, AVG, COUNT, MIN, MAX।
