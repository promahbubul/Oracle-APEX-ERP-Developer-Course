## ১. রিভিশন (২০ মিনিট)

খাতা না দেখে উত্তর দাও। না পারলে সেই ক্লাসের ফাইল আবার পড়ো।

**ক্লাস ৩৬:** `NVL` আর `COALESCE`-এর পার্থক্য কী? শূন্য দিয়ে ভাগ কীভাবে আটকাও?

**ক্লাস ৩৭:** `CASE` কখন থামে? `DECODE` আর `CASE`-এর NULL তুলনায় পার্থক্য কী?

**ক্লাস ৩৮:** `COUNT`-এর ৩ রকম ফর্ম কী কী? `AVG(x)` আর `AVG(NVL(x, 0))` আলাদা কেন?

**ক্লাস ৩৯:** `GROUP BY`-এর সবচেয়ে জরুরি নিয়ম কী? `SUM(CASE ...)` কী কাজে লাগে?

**ক্লাস ৪০:** `WHERE` আর `HAVING`-এর পার্থক্য কী? পুরো চলার ক্রম কী?

## ২. মূল কাজ: ২০টা রিপোর্ট (১১৫ মিনিট)

`hr_freepdb1`-এ করো। প্রতিটা কোয়েরি `week08.sql`-এ কমেন্টে নম্বর দিয়ে রাখো।

**নিয়ম:**
- প্রতিটা রিপোর্ট মিলিয়ে দেখো। ১২টা বিভাগ মিলে ১০৭ জন আর মোট বেতন ৬৯১৪১৬ হওয়ার কথা
- হিসাব করা কলামে Alias দাও
- টাকা বা গড়ে `ROUND` দাও

> `(n)` মানে প্রত্যাশিত রো সংখ্যা। ডাটা HR-এর ভার্সনভেদে সামান্য আলাদা হতে পারে।

> `employees`-এ বিভাগের নাম নেই, শুধু নম্বর। নাম দেখাতে JOIN লাগবে, সেটা আগামী সপ্তাহে। তখন এই রিপোর্টগুলোতেই নাম যোগ করবে, তাই `week08.sql` রেখে দিও।

### অংশ ক: পুরো কোম্পানি (৩টা)

1. মোট কর্মী, মোট মাসিক বেতন, গড় বেতন। (১০৭, ৬৯১৪১৬, ৬৪৬১.৮৩)
2. মোট বাৎসরিক খরচ, বেতন আর কমিশন মিলে (`NVL` লাগবে)।
3. কমিশন পান কতজন, পান না কতজন। (৩৫, ৭২)

### অংশ খ: বিভাগভিত্তিক (৭টা)

4. প্রতিটা বিভাগের কর্মী সংখ্যা, বেশি আগে। (১২)
5. প্রতিটা বিভাগের মোট বেতন, শুধু যাদের বিভাগ আছে। (১১)

7. প্রতিটা বিভাগের সর্বোচ্চ, সর্বনিম্ন বেতন, আর দুইয়ের পার্থক্য।
8. প্রতিটা বিভাগে কমিশন পান কতজন। (`COUNT(commission_pct)`)
9. `department_id` NULL হলে `No Department` লিখে কর্মী সংখ্যা। (১২)
10. প্রতিটা বিভাগের মোট বাৎসরিক বেতন, `12,34,567` আকারে।

### অংশ গ: বিভাগ ও পদ (৩টা)

12. বিভাগ আর পদ মিলে কর্মী সংখ্যা আর গড় বেতন।
13. বিভাগ ৫০-এর পদভিত্তিক হিসাব। (৩টা পদ: ST_MAN ৫, ST_CLERK ২০, SH_CLERK ২০)

### অংশ ঘ: HAVING (৩টা)

### অংশ ঙ: CASE দিয়ে রিপোর্ট (৪টা)

17. বেতনের স্তর (`Low`: ৫০০০-এর কম, `Medium`: ১০০০০-এর কম, `High`) ধরে কর্মী সংখ্যা। স্তরগুলোর যোগফল ১০৭ হওয়ার কথা।
18. প্রতিটা বিভাগে `Low`, `Medium`, `High` স্তরে কতজন, পাশাপাশি ৩ কলামে।
19. বিভাগ ৯০ বাদে, গড় বেতন ১০০০০-এর বেশি এমন বিভাগ। (১: বিভাগ ১১০)
20. চূড়ান্ত রিপোর্ট: বিভাগ, কর্মী সংখ্যা, মোট বেতন (কমাসহ), গড় বেতন (২ ঘরে), সর্বোচ্চ বেতন। শুধু বিভাগ আছে এমন, ২ জন বা বেশি কর্মী, মোট বেতনে শীর্ষ ৫টা। (প্রথম ৩টা: ৮০, ৫০, ৯০)

ORDER  BY department_id;

-- ৮
SELECT department_id, COUNT(commission_pct) AS with_commission
FROM   employees
GROUP  BY department_id
ORDER  BY department_id;

-- ৯
SELECT NVL(TO_CHAR(department_id), 'No Department') AS dept_text, COUNT(*) AS headcount
FROM   employees

-- ১০
SELECT department_id,
       TO_CHAR(SUM(salary * 12), 'FM99,99,99,999') AS yearly_salary
FROM   employees
GROUP  BY department_id
ORDER  BY department_id;

-- অংশ গ
-- ১১
SELECT job_id, COUNT(*) AS headcount
FROM   employees
GROUP  BY job_id
ORDER  BY headcount DESC, job_id;

SELECT department_id, job_id, COUNT(*) AS headcount, ROUND(AVG(salary), 2) AS avg_salary
FROM   employees
GROUP  BY department_id, job_id
ORDER  BY department_id, job_id;

-- ১৩
SELECT job_id, COUNT(*) AS headcount, SUM(salary) AS total_salary
FROM   employees
WHERE  department_id = 50
GROUP  BY job_id;

-- অংশ ঘ
-- ১৪
SELECT department_id, COUNT(*) AS headcount
FROM   employees
GROUP  BY department_id
HAVING COUNT(*) > 5;

-- ১৫
SELECT department_id, ROUND(AVG(salary), 2) AS avg_salary
FROM   employees
GROUP  BY department_id
HAVING AVG(salary) > 10000;

-- ১৬
SELECT department_id, SUM(salary) AS total_salary
FROM   employees
GROUP  BY department_id
HAVING SUM(salary) > 50000;

-- অংশ ঙ
-- ১৭
SELECT CASE WHEN salary < 5000  THEN 'Low'
            WHEN salary < 10000 THEN 'Medium'
            ELSE 'High'
       END AS salary_band,
       COUNT(*) AS headcount
FROM   employees
GROUP  BY CASE WHEN salary < 5000  THEN 'Low'
               WHEN salary < 10000 THEN 'Medium'
               ELSE 'High'
          END;

-- ১৮
SELECT department_id,
       COUNT(CASE WHEN salary < 5000 THEN 1 END) AS low_band,
       COUNT(CASE WHEN salary >= 5000 AND salary < 10000 THEN 1 END) AS medium_band,
       COUNT(CASE WHEN salary >= 10000 THEN 1 END) AS high_band
FROM   employees
GROUP  BY department_id
ORDER  BY department_id;

-- ১৯
SELECT department_id, ROUND(AVG(salary), 2) AS avg_salary
FROM   employees
WHERE  department_id <> 90
GROUP  BY department_id
HAVING AVG(salary) > 10000;

-- ২০
SELECT department_id,
       COUNT(*) AS headcount,
       TO_CHAR(SUM(salary), 'FM9,999,999') AS total_salary,
       ROUND(AVG(salary), 2) AS avg_salary,
       MAX(salary) AS max_salary
FROM   employees
WHERE  department_id IS NOT NULL
GROUP  BY department_id
HAVING COUNT(*) >= 2
ORDER  BY SUM(salary) DESC
FETCH  FIRST 5 ROWS ONLY;

- **১৫:** বিভাগ ৭০-এর গড় ঠিক ১০০০০। `>` তাই আসেনি, `>=` হলে আসত
- **২০:** `ORDER BY SUM(salary)`, `total_salary` না। `total_salary` এখন **লেখা**, তাই সেটা দিয়ে সাজালে বর্ণক্রমে সাজত, সংখ্যায় না। ক্লাস ৩৫-এর ফাঁদ

## ৪. মাস ২-এর হিসাব (১৫ মিনিট)

**এই মাসে যা পারা উচিত, টিক দাও:**

- [ ] Constraint সহ টেবিল বানাতে, `ALTER` দিয়ে বদলাতে পারি
- [ ] `INSERT`, `UPDATE`, `DELETE` নিরাপদে চালাতে পারি
- [ ] `COMMIT`, `ROLLBACK`, `SAVEPOINT` বুঝি, DDL-এর নিজে থেকে `COMMIT` জানি
- [ ] `WHERE`, `AND/OR`, `IN`, `BETWEEN`, `LIKE`, `IS NULL` দিয়ে খুঁজতে পারি
- [ ] `ORDER BY`, `FETCH FIRST` দিয়ে টপ N আনতে পারি
- [ ] লেখা, সংখ্যা, তারিখের ফাংশন ব্যবহার করতে পারি
- [ ] `NVL`, `CASE` দিয়ে রিপোর্ট বানাতে পারি
- [ ] `GROUP BY`, `HAVING` দিয়ে সারাংশ রিপোর্ট বানাতে পারি

যেটাতে টিক দিতে পারোনি, সেই ক্লাসটা শুক্রবার আবার দেখো। **রোডম্যাপ:** [Roadmap.md](../../Roadmap.md)-এ শেষ করা জিনিসগুলোতে টিক দাও।
