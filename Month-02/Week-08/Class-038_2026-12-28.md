## ১. Aggregate Function কী (২০ মিনিট)

ক্লাস ৩১-এ দেখেছিলে: **Single Row** ফাংশন প্রতিটা রো-র জন্য একটা ফল দেয়, আর **Aggregate (Multi Row)** ফাংশন **অনেক রো মিলে একটা ফল** দেয়।

```
    SALARY
    ┌───────┐
    │ 24000 │
    │ 17000 │   SUM(salary)
    │ 17000 │ ─────────────►  58000
    └───────┘
    (৩টা রো)              (১টা রো)
```

```sql
SELECT COUNT(*)     AS headcount,      -- 107
       SUM(salary)  AS total_salary,   -- 691416
       MIN(salary)  AS min_salary,     -- 2100
       MAX(salary)  AS max_salary,     -- 24000
       ROUND(AVG(salary), 2) AS avg_salary   -- 6461.83
FROM   employees;
```

| ফাংশন | কাজ | ডাটা | NULL |
|---|---|---|---|
| `SUM` | যোগফল | সংখ্যা | বাদ দেয় |
| `AVG` | গড় | সংখ্যা | বাদ দেয় |
| `MIN` | সবচেয়ে ছোট | সংখ্যা, লেখা, তারিখ | বাদ দেয় |
| `MAX` | সবচেয়ে বড় | সংখ্যা, লেখা, তারিখ | বাদ দেয় |
| `COUNT` | গোনা | সব | ধরন অনুযায়ী (নিচে) |

> ERP-র প্রায় সব রিপোর্ট আর ড্যাশবোর্ডের ভিত্তি এগুলো: মোট অর্ডার, মোট স্টক, গড় Efficiency।

## ২. SUM ও AVG (২৫ মিনিট)

```sql
-- বিভাগ ৬০: 28800, 5760
SELECT SUM(salary) AS total_salary,
       AVG(salary) AS avg_salary
FROM   employees
WHERE  department_id = 60;

-- লাইব্রেরির জরিমানা (learn_freepdb1): 165, 33
SELECT SUM(fine_amount) AS total_fine,
       AVG(fine_amount) AS avg_fine
FROM   lib_fine;

-- পরিশোধ হয়নি: 65
SELECT SUM(fine_amount) AS due_fine
FROM   lib_fine
WHERE  is_paid = 'N';
```

`WHERE` আগে চলে, তারপর Aggregate। অর্থাৎ শুধু বেছে নেওয়া রো-গুলোর উপর হিসাব হয়।

### হিসাব করা মানের উপর

```sql
-- মাসে মোট বেতন আর বছরে মোট বেতন
SELECT SUM(salary) AS monthly_total,
       SUM(salary * 12) AS yearly_total
FROM   employees;

-- সব অর্ডারের কার্টন, ১২ পিসে (learn_freepdb1)
SELECT SUM(CEIL(order_qty / 12)) AS total_cartons
FROM   w5_order;
```

Aggregate-এর ফলও সাজানো যায়:

```sql
SELECT ROUND(AVG(salary), 2) AS avg_salary,
       TO_CHAR(SUM(salary), 'FM9,999,999') AS total_text
FROM   employees;
```

## ৩. MIN ও MAX (১৫ মিনিট)

সংখ্যা ছাড়াও লেখা আর তারিখে চলে।

```sql
SELECT MIN(salary)    AS lowest_salary,    -- 2100
       MAX(salary)    AS highest_salary,   -- 24000
       MIN(last_name) AS first_name_az,    -- Abel
       MAX(last_name) AS last_name_az,     -- Zlotkey
       MIN(hire_date) AS oldest_hire,
       MAX(hire_date) AS newest_hire
FROM   employees;
```

```sql
-- learn_freepdb1: 2010, 2025
SELECT MIN(publish_year) AS oldest_year, MAX(publish_year) AS newest_year
FROM   lib_book;

-- পরবর্তী ID কত হবে (শুধু দেখার জন্য, প্রোগ্রামে এভাবে না)
SELECT MAX(book_id) + 1 AS next_id FROM lib_book;
```

> `MAX(id) + 1` দিয়ে নতুন ID বানালে দুইজন একসাথে একই ID পেতে পারে। ঠিক উপায় Sequence, সপ্তাহ ১১-এ।

## ৪. COUNT (৩০ মিনিট)

**তিন রকম `COUNT`, তিনটা আলাদা ফল।**

```sql
SELECT COUNT(*)                     AS all_rows,        -- 107
       COUNT(commission_pct)        AS with_commission, -- 35
       COUNT(department_id)         AS with_department, -- 106
       COUNT(DISTINCT department_id) AS distinct_depts, -- 11
       COUNT(DISTINCT job_id)       AS distinct_jobs    -- 19
FROM   employees;
```

| লেখা | কী গোনে | NULL |
|---|---|---|
| `COUNT(*)` | সব রো | গোনে |
| `COUNT(কলাম)` | যে রো-তে কলামে মান আছে | গোনে না |
| `COUNT(DISTINCT কলাম)` | ভিন্ন ভিন্ন মান | গোনে না |

> `COUNT(1)`-ও দেখবে অনেক কোডে। Oracle-এ এটা `COUNT(*)`-এর মতোই।

### বাস্তব প্রশ্ন

| প্রশ্ন | কোয়েরি |
|---|---|
| কতজন কর্মী? | `COUNT(*)` |
| কতজন কমিশন পান? | `COUNT(commission_pct)` |
| কতজনের কমিশন নেই? | `COUNT(*) - COUNT(commission_pct)` → ৭২ |
| কয়টা বিভাগে কর্মী আছে? | `COUNT(DISTINCT department_id)` |

```sql
-- learn_freepdb1
SELECT COUNT(*)              AS total_members,    -- 20
       COUNT(email)          AS with_email,       -- 12
       COUNT(member_name_bn) AS with_bangla_name  -- 3
FROM   lib_member;

-- কয়জন মেম্বার অন্তত একবার বই নিয়েছেন
SELECT COUNT(DISTINCT member_id) AS active_borrowers FROM lib_book_issue;   -- 20

-- এখন কয়টা বই বাইরে
SELECT COUNT(*) AS books_out FROM lib_book_issue WHERE return_date IS NULL; -- 5
```

### DISTINCT অন্য Aggregate-এও চলে

```sql
SELECT SUM(salary)          AS sum_all,
       SUM(DISTINCT salary) AS sum_unique
FROM   employees;
```

`SUM(DISTINCT ...)` একই মান একবারই যোগ করে। বেতনের যোগফলে এটা **ভুল** হবে, তাই বুঝে ব্যবহার করবে।

## ৫. NULL আর সাধারণ ভুল (২৫ মিনিট)

### ফাঁদ ১: AVG NULL-কে গোনে না

```sql
SELECT AVG(commission_pct)          AS avg_a,   -- 0.2229 (প্রায়), ৩৫ জনের গড়
       AVG(NVL(commission_pct, 0))  AS avg_b    -- 0.0729 (প্রায়), ১০৭ জনের গড়
FROM   employees;
```

দুইটাই ঠিক, কিন্তু আলাদা প্রশ্নের উত্তর। "যারা কমিশন পান, তাদের গড় কমিশন" নাকি "সব কর্মীর গড় কমিশন"? **আগে প্রশ্নটা পরিষ্কার করো।**

`SUM`-এ এই সমস্যা হয় না, কারণ NULL বাদ দিলেও যোগফল একই থাকে।

### ফাঁদ ২: কোনো রো না মিললে

```sql
SELECT COUNT(*)    AS a,    -- 0
       SUM(salary) AS b,    -- NULL
       AVG(salary) AS c     -- NULL
FROM   employees
WHERE  department_id = 9999;
```

`COUNT` শূন্য দেয়, বাকিরা **NULL**। রিপোর্টে `0` দেখাতে `NVL(SUM(salary), 0)`।

### ভুল ১: Aggregate আর সাধারণ কলাম একসাথে

```sql
SELECT last_name, MAX(salary) FROM employees;
```

```
ORA-00937: not a single-group group function
```

`MAX` একটা রো দেয়, `last_name` ১০৭টা। Oracle কোনটার পাশে কোনটা বসাবে? সমাধান: `GROUP BY` (কাল), অথবা Subquery (সপ্তাহ ১০)।

### ভুল ২: WHERE-এ Aggregate

```sql
SELECT last_name FROM employees WHERE salary = MAX(salary);
```

```
ORA-00934: group function is not allowed here
```

`WHERE` চলে Aggregate-এর আগে। সমাধান সপ্তাহ ১০-এ:

```sql
SELECT last_name, salary
FROM   employees
WHERE  salary = (SELECT MAX(salary) FROM employees);
```

### ভুল ৩: সংখ্যা ছাড়া অন্য ডাটায় SUM বা AVG

```sql
SELECT SUM(last_name) FROM employees;     -- এরর ORA-01722
SELECT AVG(hire_date) FROM employees;     -- এরর
```

`SUM` আর `AVG` শুধু সংখ্যায়।

## সারাংশ

- Aggregate অনেক রো মিলে একটা ফল দেয়
- `SUM`, `AVG` শুধু সংখ্যায়। `MIN`, `MAX` সংখ্যা, লেখা, তারিখে
- সবাই NULL বাদ দেয়, শুধু `COUNT(*)` ছাড়া
- `AVG(x)` আর `AVG(NVL(x, 0))` আলাদা প্রশ্নের উত্তর
