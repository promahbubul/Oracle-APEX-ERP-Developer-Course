## ২. মূল কাজ: ৩০টা কোয়েরি (১২০ মিনিট)

`hr_freepdb1` কানেকশনে করো। প্রতিটা কোয়েরি `week06.sql` ফাইলে কমেন্টে নম্বর দিয়ে রাখো।

**নিয়ম:**
- প্রশ্নে যা চাওয়া হয়েছে, তাই দেখাও। সব জায়গায় `SELECT *` না
- হিসাব করা কলামে Alias দাও
- ফলের রো মিলিয়ে নিজে যাচাই করো, শুধু এরর না আসা যথেষ্ট না
- আগে নিজে করো, আটকে গেলে সমাধান দেখো

> `(n)` মানে প্রত্যাশিত রো সংখ্যা। HR-এর ভার্সনভেদে সামান্য আলাদা হতে পারে।

### অংশ ক: SELECT, Alias, DISTINCT (৮টা)

1. `departments` টেবিলের সব তথ্য। (২৭)

4. `last_name`, মাসিক বেতন, আর `salary * 12`-কে `Annual Salary` শিরোনামে।
5. প্রতিটা পদের বেতনের পার্থক্য: `job_title`, `max_salary - min_salary` কে `salary_gap` নামে (`jobs`)।
6. এই বাক্য: `King earns 24000 per month`, শিরোনাম `salary_note`।
7. `employees`-এ যে যে `job_id` আছে, ডুপ্লিকেট ছাড়া। (১৯)

```sql

-- ২

-- ৫

-- ৬

-- ৭
SELECT DISTINCT job_id FROM employees;

-- ৮

-- অংশ খ
-- ৯
SELECT last_name, salary FROM employees WHERE salary > 15000;

-- ১০
SELECT last_name, department_id FROM employees WHERE department_id = 80;

-- ১১
SELECT last_name, job_id FROM employees WHERE job_id = 'IT_PROG';

-- ১২
SELECT first_name, last_name FROM employees WHERE last_name = 'Grant';

-- ১৩
SELECT last_name, job_id FROM employees WHERE job_id <> 'AD_PRES';

-- ১৪
SELECT last_name, salary * 12 AS annual_salary
FROM   employees
WHERE  salary * 12 > 200000;

-- অংশ গ
-- ১৫
SELECT last_name, salary
FROM   employees
WHERE  department_id = 60
AND    salary > 5000;

-- ১৬

FROM   employees
WHERE  department_id = 30
OR     department_id = 90;

-- ১৭
SELECT last_name, department_id
FROM   employees
WHERE  department_id IN (10, 20, 40);

-- ১৮
SELECT last_name, job_id
FROM   employees
WHERE  job_id NOT IN ('SA_REP', 'ST_CLERK');

-- ১৯
SELECT last_name, department_id, salary
FROM   employees
WHERE  (department_id = 60 OR department_id = 90)
AND    salary > 5000;

-- ২০
SELECT last_name, salary
FROM   employees
WHERE  salary BETWEEN 4000 AND 5000;

-- অংশ ঘ
-- ২১

-- ২২
SELECT first_name FROM employees WHERE first_name LIKE '%n';

-- ২৩
SELECT last_name FROM employees WHERE last_name LIKE '_a%';

-- ২৪
SELECT last_name, job_id FROM employees WHERE job_id LIKE 'SA\_%' ESCAPE '\';

SELECT last_name FROM employees WHERE commission_pct IS NULL;

-- ২৬
SELECT first_name, last_name FROM employees WHERE department_id IS NULL;

-- ২৯
SELECT last_name, salary
FROM   employees
ORDER  BY salary DESC
FETCH  FIRST 5 ROWS ONLY;

SELECT employee_id, last_name
FROM   employees
ORDER  BY employee_id
OFFSET 10 ROWS FETCH NEXT 10 ROWS ONLY;
```

- **১৩:** `job_id`-তে কোনো NULL নেই, তাই ১০৬ জন আসে
- **১৮:** ১০৭ − ৩০ (`SA_REP`) − ২০ (`ST_CLERK`) = ৫৭
- **১৯:** ব্র্যাকেট না দিলে ৮ জন আসে: বিভাগ ৬০-র ৫ জনের সবাই (বেতন যাই হোক), আর বিভাগ ৯০-র ৩ জন। নিজে ব্র্যাকেট সরিয়ে চালিয়ে দেখো
- **২৮:** ASC-এ NULL এমনিতেই শেষে যায়। তবু `NULLS LAST` লিখলে উদ্দেশ্য পরিষ্কার হয়
