# ক্লাস ২৭: WHERE ও Comparison Operator

**তারিখ:** ১৩ ডিসেম্বর ২০২৬, রবিবার
**সময়:** সন্ধ্যা ৭:০০ থেকে রাত ১০:০০
**সপ্তাহ:** ৬ | **ধাপ:** ২ (Oracle SQL)

---

## আজকে কী শিখব

- `WHERE` দিয়ে রো বাছাই
- Comparison Operator: `=`, `<>`, `<`, `>`, `<=`, `>=`
- সংখ্যা, লেখা আর তারিখ দিয়ে তুলনা
- দুই কলামের তুলনা
- `WHERE`-এর সাধারণ ফাঁদ

---

## ১. WHERE (২০ মিনিট)

কালকের `SELECT` সব রো আনে। ১০৭ জন কর্মীর মধ্যে শুধু IT বিভাগের কর্মীদের চাইলে?

```sql
SELECT employee_id, last_name, salary
FROM   employees
WHERE  department_id = 60;
```

ফল: ৫টা রো (Hunold, Ernst, Austin, Pataballa, Lorentz)।

| অংশ | কাজ | কী বাছাই করে |
|---|---|---|
| `SELECT` | কোন কলাম | কলাম |
| `FROM` | কোন টেবিল | টেবিল |
| `WHERE` | কোন রো | **রো** |

Oracle প্রতিটা রো-র জন্য শর্ত পরীক্ষা করে। শর্ত **সত্য** হলে রো আসে। মিথ্যা বা অজানা হলে আসে না।

`WHERE`-এর কলাম `SELECT`-এ থাকতে হয় না:

```sql
SELECT last_name FROM employees WHERE salary = 24000;    -- King
```

## ২. সংখ্যা দিয়ে তুলনা (২৫ মিনিট)

| চিহ্ন | মানে | উদাহরণ |
|---|---|---|
| `=` | সমান | `salary = 24000` |
| `<>` বা `!=` | সমান না | `department_id <> 50` |
| `>` | বড় | `salary > 15000` |
| `>=` | বড় বা সমান | `salary >= 17000` |
| `<` | ছোট | `salary < 2500` |
| `<=` | ছোট বা সমান | `salary <= 2200` |

```sql
-- ১৫০০০-এর বেশি বেতন: King, Kochhar, De Haan
SELECT last_name, salary
FROM   employees
WHERE  salary > 15000;

-- ১৭০০০ বা বেশি: একই ৩ জন
SELECT last_name, salary
FROM   employees
WHERE  salary >= 17000;

-- ১৭০০০-এর বেশি: শুধু King
SELECT last_name, salary
FROM   employees
WHERE  salary > 17000;
```

`>` আর `>=`-এর পার্থক্য ঠিক সীমার মানে। রিপোর্টে "১৭০০০ বা তার বেশি" নাকি "১৭০০০-এর বেশি", সেটা আগে পরিষ্কার করে জেনে নাও।

### হিসাব দিয়ে শর্ত

```sql
-- বছরে ২ লাখের বেশি
SELECT last_name, salary, salary * 12 AS annual_salary
FROM   employees
WHERE  salary * 12 > 200000;
```

## ৩. লেখা দিয়ে তুলনা (২৫ মিনিট)

```sql
SELECT employee_id, first_name, last_name
FROM   employees
WHERE  last_name = 'Grant';        -- Douglas, Kimberely
```

**নিয়ম:**
- লেখা সবসময় Single Quote-এ
- ছোট-বড় হাতের অক্ষর আলাদা

```sql
WHERE last_name = 'grant'          -- কেউ না
WHERE last_name = 'GRANT'          -- কেউ না
WHERE job_id    = 'IT_PROG'        -- ৫ জন
```

ছোট-বড় না মেনে খোঁজা শিখব সপ্তাহ ৭-এ (`UPPER`)।

### লেখায় বড়-ছোট তুলনা

লেখাও বর্ণক্রমে তুলনা করা যায়:

```sql
-- A দিয়ে শুরু নাম: Abel, Ande, Atkinson, Austin
SELECT last_name
FROM   employees
WHERE  last_name < 'B';
```

> সাধারণত বড় হাতের অক্ষর (`A–Z`) ছোট হাতের (`a–z`) আগে আসে। আর সংখ্যা লেখায় থাকলে তুলনাও লেখার মতো হয়: `'10'`, `'9'`-এর আগে আসে।

## ৪. তারিখ দিয়ে তুলনা (২৫ মিনিট)

**সবচেয়ে নিরাপদ:** `DATE 'YYYY-MM-DD'`

এবার `learn_freepdb1`-এ, লাইব্রেরির ডাটায়:

```sql
-- ১ নভেম্বর বা তার পরে ইস্যু: ১৬–২০ নম্বর (আর সপ্তাহ ৫-এর প্র্যাকটিসের ২১)
SELECT issue_id, member_id, issue_date
FROM   lib_book_issue
WHERE  issue_date >= DATE '2026-11-01';

-- ১ অক্টোবরের আগে ফেরতের তারিখ ছিল: ১–৮ নম্বর
SELECT issue_id, due_date
FROM   lib_book_issue
WHERE  due_date < DATE '2026-10-01';
```

তারিখে "ছোট" মানে **আগে**, "বড়" মানে **পরে**।

### আজকের সাথে তুলনা

```sql
-- যেগুলোর ফেরতের তারিখ পার হয়ে গেছে
SELECT issue_id, due_date, return_date
FROM   lib_book_issue
WHERE  due_date < TRUNC(SYSDATE);
```

HR-এ দেখো (`hr_freepdb1`):

```sql
SELECT last_name, hire_date
FROM   employees
WHERE  hire_date >= DATE '2015-01-01';
```

> HR-এর `hire_date` ভার্সনভেদে আলাদা। পুরনো ডাটায় এই কোয়েরিতে কোনো রো না-ও আসতে পারে। তখন আগে `SELECT hire_date FROM employees;` দেখে একটা তারিখ বেছে নাও।

### ক্লাস ৮-এর সতর্কতা আবার

`DATE`-এ সময়ও থাকে।

```sql
WHERE entry_date = DATE '2026-12-13'     -- শুধু রাত ১২:০০:০০-এর রো
```

একটা দিনের সব রো চাইলে এভাবে লেখো:

```sql
WHERE entry_date >= DATE '2026-12-13'
AND   entry_date <  DATE '2026-12-14'
```

`AND` কাল শিখব। ক্লাস ৮-এ `TRUNC(entry_date) = ...` শিখেছিলে, সেটাও ঠিক ফল দেয়। তবে কলামের উপর ফাংশন দিলে সাধারণ Index কাজ করে না (সপ্তাহ ৪০), তাই বড় টেবিলে এই উপায়টা ভালো।

## ৫. দুই কলাম তুলনা ও সাধারণ ফাঁদ (২৫ মিনিট)

### দুই কলামের তুলনা

```sql
-- দেরিতে ফেরত: ২, ৫, ৯, ১২, ১৪ নম্বর ইস্যু (learn_freepdb1)
SELECT issue_id, due_date, return_date
FROM   lib_book_issue
WHERE  return_date > due_date;
```

### ফাঁদ ১: WHERE-এ Alias চলে না

```sql
SELECT last_name, salary * 12 AS annual_salary
FROM   employees
WHERE  annual_salary > 200000;
```

```
ORA-00904: "ANNUAL_SALARY": invalid identifier
```

Oracle আগে `WHERE` দেখে, পরে `SELECT`। তখনো Alias তৈরি হয়নি। তাই হিসাবটাই লিখতে হয়: `WHERE salary * 12 > 200000`।

```
FROM → WHERE → SELECT
```

### ফাঁদ ২: NULL-এর সাথে তুলনা

```sql
SELECT last_name FROM employees WHERE commission_pct = NULL;     -- কোনো রো না
SELECT last_name FROM employees WHERE commission_pct <> NULL;    -- কোনো রো না
```

NULL-এর সাথে যেকোনো তুলনার ফল **অজানা**, আর অজানা হলে রো আসে না। `IS NULL` শিখব ক্লাস ২৯-এ।

### ফাঁদ ৩: `<>` NULL-কে বাদ দেয়

```sql
-- বিভাগ ৫০ বাদে সবাই?
SELECT last_name, department_id
FROM   employees
WHERE  department_id <> 50;
```

ফলে Kimberely Grant নেই! তাঁর `department_id` NULL। `NULL <> 50` অজানা, তাই রো বাদ। রিপোর্টে এই ভুল প্রায়ই হয়।

### ফাঁদ ৪: লেখা আর সংখ্যা মেশানো

```sql
SELECT last_name FROM employees WHERE salary = '24000';   -- চলে, Oracle নিজে বদলে নেয়
SELECT last_name FROM employees WHERE last_name = 100;    -- এরর ORA-01722
```

দ্বিতীয়টায় Oracle সব `last_name`-কে সংখ্যায় বদলাতে চেষ্টা করে, পারে না। কলামের ধরন অনুযায়ী মান লেখো: সংখ্যা Quote ছাড়া, লেখা Quote-সহ।

### ফাঁদ ৫: তারিখ লেখা হিসেবে

```sql
WHERE hire_date = '17-06-2003'      -- সেশনের সেটিংয়ের উপর নির্ভর, এরর আসতে পারে
```

সবসময় `DATE '2003-06-17'` বা `TO_DATE` ব্যবহার করবে।

## ৭. হোমওয়ার্ক

1. `locations` থেকে `country_id` `US` এমন শহরগুলো দেখাও।
2. `countries` থেকে `region_id` ৩-এর দেশগুলো দেখাও।
3. `jobs`-এ `min_salary` ১০০০০ বা বেশি, এমন পদের নাম আর `min_salary` দেখাও।
4. `<>` NULL রো বাদ দেয়, এটা নিজের ভাষায় ৩ লাইনে লেখো। গার্মেন্টসের একটা উদাহরণ দাও, যেখানে এই ভুল রিপোর্ট নষ্ট করতে পারে।

<details>
<summary>হোমওয়ার্ক ১–৩-এর সমাধান</summary>

```sql

SELECT country_name FROM countries WHERE region_id = 3;

SELECT job_title, min_salary FROM jobs WHERE min_salary >= 10000;
```

## সারাংশ

- `WHERE` রো বাছে, শর্ত সত্য হলেই রো আসে
- তুলনার চিহ্ন: `=`, `<>`, `<`, `>`, `<=`, `>=`
- সংখ্যা Quote ছাড়া, লেখা Single Quote-এ (ছোট-বড় আলাদা), তারিখ `DATE '...'`
- `WHERE`-এ Alias চলে না
- NULL-এর সাথে তুলনা সবসময় অজানা, তাই `<>`-ও NULL রো বাদ দেয়

**পরের ক্লাস:** AND, OR, NOT, IN, BETWEEN।
