# ক্লাস ২৯: LIKE, IS NULL ও IS NOT NULL

**তারিখ:** ১৫ ডিসেম্বর ২০২৬, মঙ্গলবার
**সময়:** সন্ধ্যা ৭:০০ থেকে রাত ১০:০০
**সপ্তাহ:** ৬ | **ধাপ:** ২ (Oracle SQL)

---

## আজকে কী শিখব

- `LIKE` দিয়ে লেখার অংশ খোঁজা: `%` আর `_`
- `ESCAPE` দিয়ে `%`, `_` নিজেই খোঁজা
- `IS NULL`, `IS NOT NULL`
- NULL-এর সব নিয়ম এক জায়গায়

---

## ১. LIKE (৪৫ মিনিট)

`=` পুরো মান মেলায়। আংশিক মেলাতে **LIKE**।

| চিহ্ন | মানে |
|---|---|
| `%` | যেকোনো সংখ্যক অক্ষর, শূন্যটাও |
| `_` | ঠিক একটা অক্ষর |

| শর্ত | মানে | মিলবে |
|---|---|---|
| `LIKE 'K%'` | `K` দিয়ে শুরু | King, Kochhar, Khoo |
| `LIKE '%son'` | `son` দিয়ে শেষ | Davidson |
| `LIKE '%ar%'` | ভেতরে কোথাও `ar` | Kochhar, Kumar |
| `LIKE '_a%'` | দ্বিতীয় অক্ষর `a` | Hartstein, Faviet |
| `LIKE 'K___'` | `K` দিয়ে শুরু, ঠিক ৪ অক্ষর | King, Khoo |

```sql
-- K দিয়ে শুরু: King (২ জন), Kochhar, Khoo, Kaufling, Kumar
SELECT first_name, last_name
FROM   employees
WHERE  last_name LIKE 'K%';

-- ঠিক ৪ অক্ষর, K দিয়ে শুরু: King (২ জন), Khoo
SELECT first_name, last_name
FROM   employees
WHERE  last_name LIKE 'K___';

-- শেষে son
SELECT last_name FROM employees WHERE last_name LIKE '%son';

-- দ্বিতীয় অক্ষর a
SELECT last_name FROM employees WHERE last_name LIKE '_a%';
```

### ছোট-বড় হাতের অক্ষর

`LIKE`-ও ছোট-বড় আলাদা ধরে:

```sql
SELECT last_name FROM employees WHERE last_name LIKE 'k%';    -- কেউ না
SELECT last_name FROM employees WHERE last_name LIKE '%k%';   -- শুধু ভেতরে ছোট k
```

`UPPER` দিয়ে সমাধান শিখব সামনের সপ্তাহে। এখন শুধু দেখো:

```sql
SELECT last_name FROM employees WHERE UPPER(last_name) LIKE 'K%';
```

### NOT LIKE

```sql
-- A দিয়ে শুরু নয়
SELECT last_name FROM employees WHERE last_name NOT LIKE 'A%';
```

### লাইব্রেরিতে (`learn_freepdb1`)

```sql
-- নামে SQL আছে: Oracle SQL for Beginners, PLSQL Step by Step, Advanced SQL Queries
SELECT book_title FROM lib_book WHERE book_title LIKE '%SQL%';

-- BC-001 দিয়ে শুরু বারকোড: BC-0010 থেকে BC-0019
SELECT barcode FROM lib_book_copy WHERE barcode LIKE 'BC-001%';
```

খেয়াল করো: `PLSQL Step by Step`-ও এসেছে, যদিও তুমি হয়তো "SQL" শব্দটাই খুঁজছিলে। ক্লাস ১৭-এর `Dark Red`-এর মতো ঘটনা।

### সংখ্যা আর তারিখে LIKE নয়

```sql
-- চলে, কিন্তু এভাবে লিখবে না
WHERE salary LIKE '17%'
WHERE hire_date LIKE '%2015%'
```

Oracle এগুলোকে লেখায় বদলে নেয়, আর তারিখের ক্ষেত্রে ফল সেশনের সেটিংয়ের উপর নির্ভর করে। সংখ্যা আর তারিখে `BETWEEN` বা `>=`, `<` ব্যবহার করো।

### গতি নিয়ে একটা কথা

| শর্ত | Index ব্যবহার হতে পারে? |
|---|---|
| `LIKE 'K%'` | হ্যাঁ |
| `LIKE '%K'`, `LIKE '%K%'` | সাধারণত না |

শুরুতে `%` থাকলে Oracle-কে প্রায় পুরো টেবিল পড়তে হয়। ছোট টেবিলে সমস্যা নেই, লাখ লাখ রো-তে ধীর হয়। বিস্তারিত সপ্তাহ ৪০-এ।

## ২. ESCAPE (১৫ মিনিট)

`job_id`-তে `_` আছে: `SA_REP`, `SA_MAN`। `_` নিজেই খুঁজতে চাইলে সমস্যা, কারণ `LIKE`-এ এর বিশেষ মানে আছে।

```sql
-- SA দিয়ে শুরু, তারপর যেকোনো একটা অক্ষর
WHERE job_id LIKE 'SA_%'
```

এখানে ফল ঠিক আসে কাকতালীয়ভাবে, কিন্তু `SAXREP` থাকলে সেটাও মিলত।

**ESCAPE** দিয়ে বলে দেওয়া হয়: এই চিহ্নের পরের অক্ষরটা সাধারণ অক্ষর।

```sql
-- SA_ দিয়ে শুরু: ৩৫ জন (SA_MAN ৫, SA_REP ৩০)
SELECT last_name, job_id
FROM   employees
WHERE  job_id LIKE 'SA\_%' ESCAPE '\';
```

`\` চিহ্নের বদলে অন্য চিহ্নও দেওয়া যায়, যেমন `ESCAPE '#'`।

`%` খুঁজতেও একই নিয়ম:

```sql
-- নামে % আছে (যেমন '100% Cotton')
WHERE composition LIKE '%100\%%' ESCAPE '\'
```

ডাটা শুধু নমুনা, কোনো টেবিলে না চালালেও চলবে। সপ্তাহ ৪-এর `SYS\_C` কোয়েরিতে এটা তুমি আগেই ব্যবহার করেছ।

## ৩. IS NULL ও IS NOT NULL (৩৫ মিনিট)

```sql
-- কমিশন পান না: ৭২ জন
SELECT last_name, commission_pct
FROM   employees
WHERE  commission_pct IS NULL;

-- কমিশন পান: ৩৫ জন
SELECT last_name, commission_pct
FROM   employees
WHERE  commission_pct IS NOT NULL;

-- ম্যানেজার নেই: King
SELECT last_name FROM employees WHERE manager_id IS NULL;

-- বিভাগ নেই: Kimberely Grant
SELECT first_name, last_name FROM employees WHERE department_id IS NULL;
```

### লাইব্রেরিতে (`learn_freepdb1`)

```sql
-- যে বই এখনো ফেরত আসেনি: ১৬–২০ নম্বর ইস্যু
SELECT issue_id, member_id, due_date
FROM   lib_book_issue
WHERE  return_date IS NULL;

-- ইমেইল নেই এমন মেম্বার: ৮ জন
SELECT member_name, mobile_no
FROM   lib_member
WHERE  email IS NULL;

-- ISBN নেই এমন বই: Advanced SQL Queries
SELECT book_title FROM lib_book WHERE isbn IS NULL;
```

বাস্তবে এগুলো সবচেয়ে কাজের রিপোর্টগুলোর মধ্যে: "কোন অর্ডারে শিপমেন্ট তারিখ দেওয়া হয়নি?", "কোন আইটেমের দাম নেই?"

### শর্ত জোড়া

```sql
-- যে বই ফেরত আসেনি, আর ফেরতের তারিখও পার হয়ে গেছে
SELECT issue_id, due_date
FROM   lib_book_issue
WHERE  return_date IS NULL
AND    due_date < TRUNC(SYSDATE);
```

```sql
-- কমিশন ০.৩-এর কম, অথবা কমিশনই নেই
SELECT last_name, commission_pct
FROM   employees
WHERE  commission_pct < 0.3
OR     commission_pct IS NULL;
```

দ্বিতীয় অংশ না লিখলে NULL-এর ৭২ জন বাদ পড়ত।

## ৪. NULL-এর সব নিয়ম (২৫ মিনিট)

NULL নিয়ে এই সপ্তাহে যা যা দেখলে, এক জায়গায়:

**NULL কী:** মান জানা নেই বা প্রযোজ্য নয়। এটা `0` না, ফাঁকা স্পেসও না।

| জায়গা | আচরণ | উদাহরণ |
|---|---|---|
| হিসাব | ফল NULL | `salary * NULL` = NULL |
| `||` | ফাঁকা লেখার মতো | `'A' || NULL` = `'A'` |
| `=`, `<>`, `<`, `>` | অজানা, রো আসে না | `col = NULL` → কোনো রো না |
| `<>` | NULL রো বাদ পড়ে | `dept <> 50`-এ Grant নেই |
| `LIKE`, `NOT LIKE` | NULL রো কোনোটাতেই আসে না | |
| `BETWEEN`, `NOT BETWEEN` | NULL রো কোনোটাতেই আসে না | |
| `IN` | NULL রো আসে না | |
| `NOT IN (.., NULL)` | **কোনো রোই আসে না** | |
| `DISTINCT` | NULL একবার | |
| Unique | একাধিক NULL চলে | ক্লাস ১১ |
| Check | NULL পার হয়ে যায় | ক্লাস ১২ |
| খালি লেখা `''` | Oracle-এ NULL | `col = ''` → কোনো রো না |

সহজ পরীক্ষা: **একটা শর্ত আর তার উল্টো শর্ত মিলে কি সব রো আসে?** NULL থাকলে আসে না।

```sql
SELECT last_name FROM employees WHERE commission_pct > 0.2;     -- ক
SELECT last_name FROM employees WHERE commission_pct <= 0.2;    -- খ
```

ক আর খ মিলে ১০৭ জন হয় না, ৩৫ জন হয়। বাকি ৭২ জন NULL, দুই দিকেই বাদ।

> NULL-এর মান বদলে হিসাব করার `NVL`, `COALESCE` শিখব সপ্তাহ ৮-এ।

## সারাংশ

- `LIKE`: `%` যেকোনো সংখ্যক অক্ষর, `_` ঠিক একটা। ছোট-বড় আলাদা
- `ESCAPE` দিয়ে `%`, `_` নিজে খোঁজা যায়
- NULL খোঁজো `IS NULL`, `IS NOT NULL` দিয়ে, `=` দিয়ে না
- `<>`, `NOT LIKE`, `NOT BETWEEN`, `NOT IN` কোনোটাই NULL রো আনে না
- NULL `0` না, ফাঁকা স্পেসও না

**পরের ক্লাস:** ORDER BY, FETCH FIRST।
