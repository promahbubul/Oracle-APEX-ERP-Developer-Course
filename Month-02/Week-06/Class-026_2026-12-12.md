## ১. SELECT (৩০ মিনিট)

```sql
SELECT কলাম১, কলাম২
FROM   টেবিল;
```

- `SELECT`: কোন কলাম চাই
- `FROM`: কোন টেবিল থেকে

### সব কলাম

```sql
SELECT * FROM departments;
```

`*` মানে সব কলাম। দ্রুত দেখার জন্য ঠিক আছে, কিন্তু **APEX পেজ বা প্রোগ্রামের কোডে `*` লিখবে না।** কারণ:
- যে কলাম লাগে না, সেটাও আসে, তাই ধীর হয়
- টেবিলে কলাম যোগ হলে কোড ভাঙতে পারে

### নির্দিষ্ট কলাম

```sql
SELECT employee_id, first_name, last_name, salary
FROM   employees;
```

কলাম যে ক্রমে লিখবে, সেই ক্রমেই দেখাবে। একই কলাম দুইবারও আনা যায়।

### HR-এর কলাম

`DESC employees` চালিয়ে দেখো। প্রধান কলাম:

| টেবিল | কলাম |
|---|---|
| `employees` | employee_id, first_name, last_name, email, phone_number, hire_date, job_id, salary, commission_pct, manager_id, department_id |
| `departments` | department_id, department_name, manager_id, location_id |
| `jobs` | job_id, job_title, min_salary, max_salary |
| `locations` | location_id, street_address, postal_code, city, state_province, country_id |

### কমার ফাঁদ

```sql
SELECT first_name last_name
FROM   employees;
```

এরর আসে না! একটাই কলাম আসে: `first_name`, আর তার শিরোনাম হয় `LAST_NAME`। Oracle ধরে নিয়েছে `last_name` হলো Alias। **কমা ভুলে গেলে এই ভুল ধরা কঠিন।**

## ২. কোয়েরিতে হিসাব (৩০ মিনিট)

```sql
SELECT last_name, salary, salary * 12, salary + 500
FROM   employees;
```

টেবিলে কিছু বদলায় না, শুধু **ফলাফলে** হিসাব দেখায়।

| চিহ্ন | কাজ |
|---|---|
| `+`, `-` | যোগ, বিয়োগ |
| `*`, `/` | গুণ, ভাগ |

ক্রম সাধারণ অঙ্কের মতো: আগে `*` আর `/`, তারপর `+` আর `-`। ব্র্যাকেট সবার আগে।

```sql
SELECT salary * 12 + 1000,     -- আগে গুণ
       salary * (12 + 1000)    -- আগে যোগ
FROM   employees;
```

### NULL-এর সাথে হিসাব: ফল NULL

```sql
SELECT last_name, salary, commission_pct,
       salary * 12 * commission_pct
FROM   employees;
```

`King`-এর `commission_pct` খালি, তাই ফলও খালি। `Russell`-এর `0.4`, তাই `14000 * 12 * 0.4 = 67200`।

**NULL মানে "জানা নেই"। অজানা কিছুর সাথে হিসাব করলে ফলও অজানা।** এটা `0` না। ঠিক করার উপায় `NVL`, শিখব সপ্তাহ ৮-এ।

## ৩. Column Alias ও লেখা জোড়া (৩০ মিনিট)

**Alias** মানে ফলাফলে কলামের অন্য নাম।

```sql
SELECT last_name AS name,
       salary * 12 AS annual_salary,
       salary * 12 yearly,                  -- AS না লিখলেও চলে
       salary * 12 AS "Annual Salary"       -- স্পেস থাকলে Double Quote
FROM   employees;
```

| লেখা | শিরোনাম |
|---|---|
| `AS annual_salary` | `ANNUAL_SALARY` (বড় হাতে) |
| `AS "Annual Salary"` | `Annual Salary` (হুবহু) |

**নিয়ম:**
- পরিষ্কার হওয়ার জন্য `AS` লিখবে
- হিসাব করা কলামে সবসময় Alias দেবে
- ক্লাস ৬-এ Double Quote নিষেধ করা হয়েছিল **টেবিল আর কলামের নামে।** শুধু দেখানোর Alias-এ এটা ঠিক আছে, তবে APEX-এ সাধারণ Alias রাখাই সহজ

### || দিয়ে লেখা জোড়া

```sql
SELECT first_name || ' ' || last_name AS full_name,
       last_name || ' earns ' || salary AS salary_note
FROM   employees;
```

- `' '` হলো একটা স্পেস
- `' earns '` একটা **Literal**: কোয়েরিতে সরাসরি লেখা মান
- সংখ্যা নিজে থেকেই লেখা হয়ে জোড়া লাগে
- `||`-এ NULL খালি লেখার মতো আচরণ করে, ফল NULL হয় না

### লেখার ভেতরে Single Quote

```sql
SELECT 'Men''s Wear' AS style_type FROM dual;      -- দুইবার ''

SELECT q'[Men's Wear]' AS style_type FROM dual;    -- q দিয়ে সহজ উপায়
```

`q'[...]'`-এর ভেতরে যা লিখবে, তা হুবহু লেখা হিসেবে ধরা হবে।

## ৪. DISTINCT (১৫ মিনিট)

```sql
SELECT department_id FROM employees;            -- ১০৭টা রো, অনেকগুলো একই

SELECT DISTINCT department_id FROM employees;   -- প্রতিটা মান একবার
```

- NULL-ও একবার আসে, তাই `department_id`-এ মোট ১২টা রো (১১টা বিভাগ + NULL)
- `DISTINCT` বসে `SELECT`-এর ঠিক পরে

### কয়েক কলামে

```sql
SELECT DISTINCT department_id, job_id
FROM   employees;
```

`DISTINCT` **পুরো রো-র উপর** কাজ করে: কলামগুলোর জোড়া একবার আসে। একটা কলামে আলাদাভাবে লেখা যায় না:

```sql
SELECT first_name, DISTINCT department_id FROM employees;
```

## ৫. DUAL (১৫ মিনিট)

**DUAL** হলো Oracle-এর একটা ছোট টেবিল: ১টা কলাম (`DUMMY`), ১টা রো (`X`)। কোনো টেবিল ছাড়া কিছু হিসাব বা দেখতে চাইলে এটা ব্যবহার হয়।

```sql
SELECT * FROM dual;

SELECT 150 * 12 AS result FROM dual;

SELECT SYSDATE AS today, USER AS who FROM dual;

SELECT 'Hello ' || 'Oracle' AS msg FROM dual;
```

কেন ১টা রো? টেবিলে যত রো, ফলও তত রো:

```sql
SELECT 150 * 12 FROM departments;      -- ২৭ বার একই ফল
```

> **নতুন ভার্সনে (23ai থেকে)** `FROM dual` ছাড়াও চলে: `SELECT 150 * 12;`। পুরনো ভার্সনে এরর আসে, আর কোম্পানিতে পুরনো ভার্সন অনেক আছে, তাই `FROM dual` লেখার অভ্যাস রাখো।

## সারাংশ

- `SELECT` কলাম, `FROM` টেবিল। কোডে `*` না, কলামের নাম লেখো
- কোয়েরিতে হিসাব টেবিল বদলায় না। NULL-এর সাথে হিসাবে ফল NULL
- `AS` দিয়ে Alias, `||` দিয়ে লেখা জোড়া
- `DISTINCT` পুরো রো-র ডুপ্লিকেট বাদ দেয়, NULL একবার রাখে
- `DUAL` টেবিল ছাড়া হিসাবের জন্য

**পরের ক্লাস:** WHERE, Comparison Operator।
