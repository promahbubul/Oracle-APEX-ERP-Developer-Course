# ক্লাস ২২: CREATE TABLE (Constraint সহ)

**তারিখ:** ৬ ডিসেম্বর ২০২৬, রবিবার
**সময়:** সন্ধ্যা ৭:০০ থেকে রাত ১০:০০
**সপ্তাহ:** ৫ | **ধাপ:** ২ (Oracle SQL)

---

## আজকে কী শিখব

- `CREATE TABLE`-এর পুরো গঠন
- Column Level আর Table Level Constraint
- `DEFAULT`, Virtual Column
- Parent-Child ক্রমে কয়েকটা টেবিল বানানো
- `CREATE TABLE AS SELECT` দিয়ে কপি বানানো
- বারবার চালানো যায় এমন স্ক্রিপ্ট লেখা

> আজ `w5_` প্রিফিক্সে যে টেবিলগুলো বানাবে, এই সপ্তাহের বাকি ক্লাসে সেগুলোই ব্যবহার হবে। মুছবে না।

## ১. পুরো গঠন (২৫ মিনিট)

```sql
CREATE TABLE টেবিলের_নাম (
    কলাম১  DataType  [DEFAULT মান]  [Column Constraint],
    কলাম২  DataType  [DEFAULT মান]  [Column Constraint],
    ...
    [CONSTRAINT নাম Table Constraint],
    [CONSTRAINT নাম Table Constraint]
);
```

`[ ]` মানে ঐচ্ছিক। একটা কলামের ভেতরে ক্রম হলো: **নাম, Data Type, DEFAULT, Constraint।**

সপ্তাহ ৩-৪-এ প্রতিটা অংশ আলাদা আলাদা শিখেছ। এখন সব একসাথে:

| অংশ | কী দেয় | কোথায় শিখেছ |
|---|---|---|
| Data Type | কী ধরনের ডাটা | ক্লাস ৭, ৮ |
| `PRIMARY KEY`, `UNIQUE` | রো চেনা, একই মান না | ক্লাস ১১ |
| `FOREIGN KEY` | সম্পর্ক | ক্লাস ১২ |
| `NOT NULL`, `CHECK` | মান বাধ্যতামূলক, শর্ত | ক্লাস ১২ |
| `DEFAULT` | স্বয়ংক্রিয় মান | ক্লাস ১২ |
| Naming Convention | নামের নিয়ম | ক্লাস ২০ |

## ২. Column Level আর Table Level (৩০ মিনিট)

Constraint দুই জায়গায় লেখা যায়।

```sql
-- Column Level: কলামের পাশে
CREATE TABLE w5_level_a (
    id    NUMBER(5)    CONSTRAINT w5_level_a_pk PRIMARY KEY,
    code  VARCHAR2(10) CONSTRAINT w5_level_a_code_uk UNIQUE
);

-- Table Level: সব কলামের পরে
CREATE TABLE w5_level_b (
    id    NUMBER(5),
    code  VARCHAR2(10),
    CONSTRAINT w5_level_b_pk PRIMARY KEY (id),
    CONSTRAINT w5_level_b_code_uk UNIQUE (code)
);

DROP TABLE w5_level_a;
DROP TABLE w5_level_b;
```

| Constraint | Column Level | Table Level |
|---|---|---|
| `NOT NULL` | হ্যাঁ | **না** |
| `PRIMARY KEY`, `UNIQUE`, `CHECK`, `FOREIGN KEY` | হ্যাঁ | হ্যাঁ |
| একাধিক কলাম নিয়ে Constraint | **না** | **হ্যাঁ** |

**সুপারিশ:** `NOT NULL` কলামের পাশে, বাকি সব নিচে Table Level-এ। তাহলে সব Constraint এক জায়গায় দেখা যায়।

### Constraint-এর নাম পুরো Schema-তে ইউনিক

দুই টেবিলে একই নাম দিলে এরর আসে:

```sql
CREATE TABLE w5_x (id NUMBER CONSTRAINT w5_same_pk PRIMARY KEY);
CREATE TABLE w5_y (id NUMBER CONSTRAINT w5_same_pk PRIMARY KEY);
```

```
ORA-02264: name already used by an existing constraint
```

```sql
DROP TABLE w5_x;
```

এই কারণেই Constraint-এর নামে টেবিলের নাম রাখা হয়।

### বানানো টেবিলের কোড দেখা

```sql
SELECT DBMS_METADATA.GET_DDL('TABLE', 'W5_ORDER') FROM dual;
```

Oracle নিজের দিক থেকে পুরো `CREATE TABLE` কোড দেখাবে, অনেক বাড়তি সেটিংসহ। SQL Developer-এ টেবিল খুলে **SQL** ট্যাবেও এটা দেখা যায়। অন্যের বানানো টেবিল বুঝতে কাজে লাগে।

### Virtual Column

ক্লাস ১৯-এ শিখেছ, হিসাব করা কলাম সাধারণত রাখা হয় না। **Virtual Column** এর একটা ভালো সমাধান: ডাটা জমা থাকে না, পড়ার সময় Oracle হিসাব করে দেয়।

```sql
CREATE TABLE w5_order_line (
    line_id     NUMBER(10),
    qty         NUMBER(12,3) NOT NULL,
    unit_price  NUMBER(10,4) NOT NULL,
    line_amount NUMBER GENERATED ALWAYS AS (qty * unit_price) VIRTUAL,
    CONSTRAINT w5_order_line_pk PRIMARY KEY (line_id)
);

INSERT INTO w5_order_line (line_id, qty, unit_price) VALUES (1, 100, 2.35);
COMMIT;

SELECT * FROM w5_order_line;

DROP TABLE w5_order_line;
```

`line_amount`-এ `235` দেখাবে। কখনোই পুরনো মান থাকবে না, কারণ জমাই থাকে না।

## ৪. CREATE TABLE AS SELECT (২০ মিনিট)

একটা কোয়েরির ফল থেকে নতুন টেবিল বানানো যায়। একে সংক্ষেপে **CTAS** বলে।

```sql
-- পুরো কপি
CREATE TABLE w5_buyer_copy AS
SELECT * FROM w5_buyer;

-- শুধু গঠন, ডাটা ছাড়া (শর্তটা কখনো সত্য হয় না)
CREATE TABLE w5_buyer_empty AS
SELECT * FROM w5_buyer WHERE 1 = 0;

SELECT * FROM w5_buyer_copy;
SELECT * FROM w5_buyer_empty;
```

### কী কী কপি হয়, কী হয় না

```sql
SELECT table_name, constraint_name, constraint_type
FROM   user_constraints
WHERE  table_name IN ('W5_BUYER', 'W5_BUYER_COPY');
```

| জিনিস | কপি হয়? |
|---|---|
| কলাম, Data Type, ডাটা | হ্যাঁ |
| `NOT NULL` | হ্যাঁ |
| `PRIMARY KEY`, `UNIQUE`, `FOREIGN KEY`, `CHECK` | **না** |
| `DEFAULT` | **না** |
| Index, Trigger | **না** |

**কোথায় কাজে লাগে:** জরুরি পরিবর্তনের আগে ব্যাকআপ, রিপোর্টের জন্য আলাদা টেবিল, পরীক্ষার ডাটা।

> `w5_buyer_copy` রেখে দাও, কাল লাগবে। `w5_buyer_empty` ক্লাস ২৪-এ লাগবে।

## ৫. বারবার চালানো যায় এমন স্ক্রিপ্ট (১৫ মিনিট)

টেবিল আগে থেকে থাকলে `CREATE TABLE` চালালে `ORA-00955` আসে। তাই স্ক্রিপ্টের শুরুতে পুরনোটা মুছে দেওয়া হয়, **উল্টো ক্রমে: আগে Child, তারপর Parent।**

```sql
-- নমুনা, এখন চালাবে না
DROP TABLE w5_order;
DROP TABLE w5_style;
DROP TABLE w5_buyer;

CREATE TABLE w5_buyer (...);
CREATE TABLE w5_style (...);
CREATE TABLE w5_order (...);
```

টেবিল না থাকলে `DROP`-এ `ORA-00942` আসবে, তবে `F5` দিয়ে চালালে পরের লাইনগুলো ঠিকই চলবে।

**নতুন ভার্সনে (23ai থেকে):**

```sql
DROP TABLE IF EXISTS w5_tmp;
CREATE TABLE IF NOT EXISTS w5_tmp (id NUMBER);
DROP TABLE IF EXISTS w5_tmp;
```

অনেক কোম্পানি এখনো পুরনো ভার্সন চালায়। সেখানে এটা চলে না, তাই আগের উপায়টাও জানতে হবে।

### সাধারণ এরর

| এরর | কারণ |
|---|---|
| `ORA-00955` | এই নামে অবজেক্ট আগেই আছে |
| `ORA-02264` | এই নামে Constraint আগেই আছে |
| `ORA-00902` | Data Type-এর নাম ভুল |
| `ORA-00904` | কলামের নাম ভুল বা Reserved word |
| `ORA-00907` | ব্র্যাকেট বা কমা ভুল |
| `ORA-00942` | FK-র Parent টেবিল এখনো বানানো হয়নি |
| `ORA-02270` | FK Parent-এর PK বা Unique-এর দিকে যাচ্ছে না |

## ৬. হাতে-কলমে প্র্যাকটিস (৫০ মিনিট)

**কাজ ১:** ভুল খুঁজে ঠিক করো। মোট ৫টা ভুল আছে। আগে পড়ে খোঁজো, তারপর চালিয়ে মিলাও।

```sql
CREATE TABLE w5_bad (
    id NUMBER(5) PRIMARY KEY,
    name VARCHAR(50) NOT NULL,
    date DATE,
    qty NUMBER(5) CHECK qty > 0,
    CONSTRAINT w5_bad_uk NOT NULL (name),
);
```

**কাজ ২:** নিচের প্রয়োজন থেকে ২টা টেবিল বানাও:

**`w5_supplier`:** ID, নাম (ইউনিক, আবশ্যক), বাংলা নাম, মোবাইল (ইউনিক), ঠিকানা, সক্রিয় কি না (Y/N, ডিফল্ট Y)।

**`w5_po`:** ID, PO নম্বর (ইউনিক, আবশ্যক), Supplier (আবশ্যক), PO তারিখ (আবশ্যক, ডিফল্ট আজ), Delivery তারিখ (PO তারিখের আগে হতে পারবে না), মোট টাকা (০-এর বেশি), স্ট্যাটাস (`DRAFT`, `APPROVED`, `CLOSED`, ডিফল্ট `DRAFT`)।

২টা Supplier আর ২টা PO ঢোকাও।

**কাজ ৩:** `w5_style` থেকে `w5_hm_style` নামে নতুন টেবিল বানাও, যাতে শুধু `buyer_id = 1`-এর স্টাইল থাকে। `DESC` আর Constraint দেখে কী কপি হয়েছে মিলাও। তারপর মুছে দাও।

## সারাংশ

- কলামের ক্রম: নাম, Data Type, `DEFAULT`, Constraint
- `NOT NULL` কলামের পাশে, বাকি Constraint নিচে নাম দিয়ে
- বানানোর ক্রম: Parent → Child। মোছার ক্রম: Child → Parent
- Virtual Column: জমা থাকে না, পড়ার সময় হিসাব হয়
- CTAS: কলাম, ডাটা আর `NOT NULL` কপি হয়, বাকিগুলো না

**পরের ক্লাস:** ALTER TABLE, DROP, TRUNCATE, RENAME।
