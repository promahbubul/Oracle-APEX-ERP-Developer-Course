# ক্লাস ২৪: INSERT, UPDATE ও DELETE

**তারিখ:** ৮ ডিসেম্বর ২০২৬, মঙ্গলবার
**সময়:** সন্ধ্যা ৭:০০ থেকে রাত ১০:০০
**সপ্তাহ:** ৫ | **ধাপ:** ২ (Oracle SQL)

## আজকে কী শিখব

- `INSERT`: এক রো, কয়েক রো, অন্য টেবিল থেকে
- `DEFAULT` আর `NULL` দিয়ে `INSERT`
- `UPDATE`: এক বা কয়েক কলাম, হিসাব করে
- `DELETE`
- ডাটা বদলানোর আগে নিরাপদ অভ্যাস

> এই ক্লাসে ক্লাস ২২-এর `w5_buyer`, `w5_style`, `w5_order` আর `w5_buyer_empty` লাগবে। ক্লাস ২৩-এ `w5_buyer`-এ `contact_email` কলাম যোগ হয়েছে।

## ১. INSERT (৫০ মিনিট)

### কলামের নাম দিয়ে (এটাই ব্যবহার করবে)

```sql
SET DEFINE OFF

INSERT INTO w5_buyer (buyer_id, buyer_name, country_name)
VALUES (4, 'Walmart', 'USA');

SELECT * FROM w5_buyer;
```

- ক্রম মেলাতে হয় কলামের তালিকার সাথে, টেবিলের সাথে না
- যে কলাম লেখোনি, সেখানে `DEFAULT` বসে, না থাকলে `NULL`
- পরে টেবিলে কলাম যোগ হলেও কোড ভাঙে না

### কলামের নাম ছাড়া

```sql
INSERT INTO w5_style VALUES (5, 'WM-TS-001', 'Walmart Tee', 4, 1.9500);
```

এতে **সব কলামের** মান, **টেবিলের ক্রমে** দিতে হয়। টেবিলে নতুন কলাম যোগ হলে এই কোড ভেঙে যায়। তাই শুধু দ্রুত পরীক্ষার জন্য এভাবে লেখো।

### NULL আর DEFAULT নিজে লেখা

```sql
INSERT INTO w5_buyer (buyer_id, buyer_name, country_name, is_active, contact_email)
VALUES (5, 'Next', NULL, DEFAULT, NULL);

SELECT buyer_id, buyer_name, country_name, is_active FROM w5_buyer;
```

- `NULL`: ঘর খালি
- `DEFAULT`: কলামের ডিফল্ট মান বসাও
- `''` Oracle-এ NULL-এর মতোই

### তারিখ দিয়ে

```sql
INSERT INTO w5_order (order_id, order_no, style_id, order_qty, order_date, ship_date, status)
VALUES (4, 'ORD-504', 2, 3000, DATE '2026-12-01', TO_DATE('15/03/2027', 'DD/MM/YYYY'), 'OPEN');
```

### এক কমান্ডে কয়েক রো

```sql
INSERT ALL
    INTO w5_style (style_id, style_no, style_name, buyer_id, fob_price)
         VALUES (6, 'PM-TS-002', 'Primark Tee', 3, 1.8000)
    INTO w5_style (style_id, style_no, style_name, buyer_id, fob_price)
         VALUES (7, 'ZR-PL-002', 'Zara Polo', 2, 5.2500)
SELECT * FROM dual;
```

শেষের `SELECT * FROM dual` Oracle-এর এই গঠনের অংশ, লাগেই।

**নতুন ভার্সনে (23ai থেকে):** একটা `INSERT`-এ কয়েক সেট মান দেওয়া যায়:

```sql
INSERT INTO w5_style (style_id, style_no, style_name, buyer_id, fob_price)
VALUES (8, 'NX-TS-001', 'Next Tee', 5, 2.1000),
       (9, 'NX-PL-002', 'Next Polo', 5, 3.9000);
```

পুরনো ভার্সনে এটা চলে না।

### অন্য টেবিল থেকে: INSERT ... SELECT

```sql
INSERT INTO w5_buyer_empty (buyer_id, buyer_name, country_name, is_active, created_on)
SELECT buyer_id, buyer_name, country_name, is_active, created_on
FROM   w5_buyer
WHERE  country_name = 'Spain';

SELECT * FROM w5_buyer_empty;
```

এখানে `VALUES` লেখা হয় না। অনেক ডাটা কপি করতে, বা হিসাব করা ফল জমা রাখতে এটা খুব কাজে লাগে।

```sql
COMMIT;
```

## ২. UPDATE (৩৫ মিনিট)

```sql
UPDATE টেবিল
SET    কলাম১ = মান১, কলাম২ = মান২
WHERE  শর্ত;
```

### এক কলাম

```sql
UPDATE w5_order
SET    status = 'SHIPPED'
WHERE  order_no = 'ORD-501';
```

নিচে দেখাবে: `1 row updated.` এই সংখ্যাটা **সবসময় দেখবে**। ১টা বদলানোর কথা, আর ৫০০ দেখাচ্ছে মানে ভুল হয়েছে।

### কয়েক কলাম

```sql
UPDATE w5_order
SET    ship_date = DATE '2027-03-01',
       order_qty = 4500
WHERE  order_no = 'ORD-502';
```

### হিসাব করে

```sql
-- ১০% পরিমাণ বাড়ানো
UPDATE w5_order
SET    order_qty = order_qty * 1.10
WHERE  order_no = 'ORD-503';

-- Primark-এর সব স্টাইলের দাম ০.২০ ডলার বাড়ানো
UPDATE w5_style
SET    fob_price = fob_price + 0.20
WHERE  buyer_id = 3;

-- শিপমেন্ট ৭ দিন পেছানো
UPDATE w5_order
SET    ship_date = ship_date + 7
WHERE  order_no = 'ORD-502';
```

### মান খালি করা

```sql
UPDATE w5_order
SET    ship_date = NULL
WHERE  order_no = 'ORD-504';
```

### NULL খোঁজার ফাঁদ

```sql
-- ভুল: কোনো রো মিলবে না
UPDATE w5_buyer SET country_name = 'UK' WHERE country_name = NULL;

-- ঠিক
UPDATE w5_buyer SET country_name = 'UK' WHERE country_name IS NULL;
```

`NULL`-এর সাথে `=` কখনো সত্য হয় না। `IS NULL` বিস্তারিত সপ্তাহ ৬-এ।

### অন্য টেবিলের মান দিয়ে (Subquery)

```sql
-- ORD-504-এর স্টাইল বদলে HM-TS-001 করা, কিন্তু style_id জানি না
UPDATE w5_order
SET    style_id = (SELECT style_id FROM w5_style WHERE style_no = 'HM-TS-001')
WHERE  order_no = 'ORD-504';
```

Subquery বিস্তারিত সপ্তাহ ১০-এ।

### সবচেয়ে বিপজ্জনক ভুল

**`WHERE` ভুলে গেলে সব রো বদলে যায়।**

```sql
UPDATE w5_order SET status = 'CANCELLED';

SELECT order_no, status FROM w5_order;    -- সব CANCELLED!

ROLLBACK;                                  -- বাঁচা গেল

SELECT order_no, status FROM w5_order;
```

Oracle কোনো সতর্কবার্তা দেয় না। `COMMIT` হয়ে গেলে আর এত সহজে ফেরানো যায় না।

> `ROLLBACK` ওই পর্যন্ত যায়, যেখানে শেষবার `COMMIT` হয়েছিল। তাই উপরের `UPDATE`-গুলোও বাতিল হলো। সেগুলো আবার চালিয়ে `COMMIT` দাও, অথবা এভাবেই এগোও।

## ৩. DELETE (২০ মিনিট)

```sql
DELETE FROM w5_order
WHERE  order_no = 'ORD-504';

ROLLBACK;
```

### FK থাকলে

একটা একটা করে চালাও:

```sql
-- স্টাইলের অর্ডার আছে, তাই এরর ORA-02292
DELETE FROM w5_style WHERE style_id = 1;

-- কোনো অর্ডার নেই এমন স্টাইল, তাই চলবে
DELETE FROM w5_style WHERE style_id = 6;

ROLLBACK;
```

মোছার ক্রম: আগে Child, তারপর Parent।

### সব রো মোছা

```sql
DELETE FROM w5_buyer_empty;

SELECT * FROM w5_buyer_empty;

ROLLBACK;
```

### ERP-তে মোছা

ক্লাস ২০-এ শিখেছ: মাস্টার ডাটা সাধারণত মোছা হয় না, Soft Delete হয়। লেনদেন বাতিল হলে স্ট্যাটাস বদলানো হয়।

```sql
UPDATE w5_buyer SET is_active = 'N' WHERE buyer_name = 'Next';
UPDATE w5_order SET status = 'CANCELLED' WHERE order_no = 'ORD-503';
ROLLBACK;
```

## ৪. নিরাপদ অভ্যাস (১৫ মিনিট)

বাস্তব কোম্পানির ডাটাবেসে একটা ভুল `UPDATE` অনেক ক্ষতি করে। এই অভ্যাসগুলো এখনই গড়ে তোলো।

**১. আগে একই `WHERE` দিয়ে `SELECT` চালাও।**

```sql
-- আগে দেখো কোন রো বদলাবে
SELECT * FROM w5_style WHERE buyer_id = 3;

-- ঠিক থাকলে তারপর
UPDATE w5_style SET fob_price = fob_price + 0.10 WHERE buyer_id = 3;

-- এটা শুধু উদাহরণ, তাই বাতিল
ROLLBACK;
```

**২. `n rows updated` সংখ্যাটা মিলিয়ে দেখো।**

**৩. PK দিয়ে `WHERE` দাও।** এক রো বদলাতে নাম নয়, ID ব্যবহার করো।

**৪. বদলানোর পরে `SELECT` দিয়ে মিলাও, তারপর `COMMIT`।**

**৫. বড় পরিবর্তনের আগে ব্যাকআপ নাও।**

```sql
CREATE TABLE w5_style_bak_20261208 AS SELECT * FROM w5_style;
```

**৬. Production-এ চালানোর আগে Test-এ চালাও।** কোন ডাটাবেসে আছ, SQL Developer-এর কানেকশনের নাম দেখে নিশ্চিত হও।

```sql
DROP TABLE w5_style_bak_20261208;
```

### এই ক্লাসের এরর

| এরর | কারণ |
|---|---|
| `ORA-00947` | মান কম দিয়েছ |
| `ORA-00913` | মান বেশি দিয়েছ |
| `ORA-00001` | PK বা Unique-এর মান আগে থেকেই আছে |
| `ORA-01400` | Not Null কলামে NULL |
| `ORA-02290` | Check মানেনি |
| `ORA-02291` | FK-র মান Parent-এ নেই |
| `ORA-02292` | Child আছে, মোছা যাচ্ছে না |
| `ORA-12899` | লেখা কলামের সাইজের চেয়ে বড় |
| `ORA-01438` | সংখ্যা কলামের অনুমতির চেয়ে বড় |
| `ORA-01722` | লেখাকে সংখ্যায় বদলানো যাচ্ছে না |

## ৫. হাতে-কলমে প্র্যাকটিস (৬০ মিনিট)

**কাজ ১:** ক্লাস ২২-এর `w5_supplier` আর `w5_po`-তে ডাটা ঢোকাও। প্রতিটা ভিন্ন উপায়ে:
1. কলামের নাম দিয়ে একটা Supplier (ID ৩)
2. `DEFAULT` লিখে আরেকটা Supplier (ID ৪), `is_active`-এ
3. `INSERT ALL` দিয়ে ২টা PO (ID ১১, ১২)

মনে রেখো: ক্লাস ২৩-এর কাজ ১-এ `mobile_no`-র নাম `contact_mobile` হয়েছে।

**কাজ ২:** এই `UPDATE`-গুলো লেখো। প্রতিটার আগে একই `WHERE`-এ `SELECT` চালাও।
1. `PO-501`-এর স্ট্যাটাস `APPROVED` করো
2. `supplier_id = 1`-এর সব PO-র মোট টাকা ৫% বাড়াও
3. `PO-502`-এর Delivery তারিখ `2027-01-10` করো, স্ট্যাটাস `CLOSED`
4. ৩ নম্বর Supplier-কে Soft Delete করো

**কাজ ৩:** ইচ্ছা করে প্রতিটা এরর আনো, আর কোডগুলো খাতায় লেখো:
1. একই PO নম্বর আবার
2. নেই এমন Supplier দিয়ে PO
3. `total_amount = -1`
4. PO আছে এমন Supplier মোছা
5. `status = 'DONE'`

**কাজ ৪:** `WHERE` ছাড়া `UPDATE` চালিয়ে সব PO-র স্ট্যাটাস `CLOSED` করো। `SELECT` দিয়ে দেখো। `ROLLBACK` দাও। আবার দেখো।

**কাজ ৫:** `w5_po_archive` নামে `w5_po`-এর খালি কপি বানাও (`WHERE 1 = 0`)। `INSERT ... SELECT` দিয়ে `CLOSED` স্ট্যাটাসের PO-গুলো সেখানে কপি করো।

## সারাংশ

- `INSERT`: কলামের নাম দিয়ে লেখো। `INSERT ALL` আর `INSERT ... SELECT` কয়েক রো-র জন্য
- `UPDATE`: `SET` আর `WHERE`। হিসাব করেও বদলানো যায়
- `DELETE`: `WHERE` দিয়ে, আগে Child, পরে Parent
- `WHERE` ভুললে সব রো বদলায়
- আগে `SELECT`, রো-র সংখ্যা মেলাও, তারপর `COMMIT`

**পরের ক্লাস:** COMMIT, ROLLBACK, SAVEPOINT।
