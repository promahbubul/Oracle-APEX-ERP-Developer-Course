## ১. রিভিশন (২০ মিনিট)

খাতা না দেখে উত্তর দাও। না পারলে সেই ক্লাসের ফাইল আবার পড়ো।

**ক্লাস ২১:** SQL-এর চার ভাগ কী? DDL আর DML-এর মূল পার্থক্য কী?

**ক্লাস ২২:** কলামের ভেতরে ক্রম কী? CTAS-এ কী কপি হয় না? Virtual Column কী?

**ক্লাস ২৩:** ডাটা আছে এমন টেবিলে `NOT NULL` কলাম কীভাবে যোগ করবে? `DELETE`, `TRUNCATE`, `DROP`-এর পার্থক্য কী?

**ক্লাস ২৪:** `INSERT ... SELECT` কী? `UPDATE`-এর আগে কী করবে?

**ক্লাস ২৫:** Transaction কী? DDL চালালে আগের পরিবর্তনের কী হয়? `ROLLBACK TO` কী করে?

## ২. মূল কাজ: লাইব্রেরি সিস্টেম (১৩০ মিনিট)

মাস ১ টেস্টে যে ডিজাইন করেছিলে, আজ সেটা SQL দিয়ে বানাবে। এই ডাটাবেসের উপরই সামনের SQL, PL/SQL আর APEX-এর লাইব্রেরি প্র্যাকটিস হবে, তাই যত্ন করে করো।

### ধাপ ১: স্ক্রিপ্ট ফাইল (৫ মিনিট)

SQL Developer-এ নতুন ফাইল বানাও: `D:\OracleLearning\library\01_create_tables.sql`। আরেকটা: `02_insert_data.sql`। কোড এই ফাইলে রাখলে যেকোনো সময় ডাটাবেস আবার বানানো যাবে।

### ধাপ ২: টেবিল বানানো (৪৫ মিনিট)

`learn_freepdb1`-এ ১২টা টেবিল বানাও। **আগে Parent, তারপর Child।** ক্রমটা নিজে ঠিক করো।

```
lib_category, lib_publisher, lib_author, lib_shelf, lib_member_type, lib_staff,
lib_book, lib_book_author, lib_book_copy, lib_member, lib_book_issue, lib_fine
```

সব Constraint-এর নিজের দেওয়া নাম থাকবে। শেষ করে যাচাই করো:

```sql
SELECT table_name FROM user_tables WHERE table_name LIKE 'LIB\_%' ESCAPE '\' ORDER BY table_name;
```

### ধাপ ৩: ডাটা ঢোকানো (৬০ মিনিট)

এই পরিমাণ ডাটা দাও:

| টেবিল | রো | কেন |
|---|---|---|
| `lib_book`, `lib_book_author`, `lib_book_copy`, `lib_member`, `lib_book_issue` | ২০টা বা বেশি | মূল ডাটা |
| `lib_category`, `lib_publisher`, `lib_shelf` | ৫টা করে | Lookup |
| `lib_author` | ১০টা | Lookup |
| `lib_member_type`, `lib_staff` | ৩টা করে | Lookup, এত কম মানই বাস্তবসম্মত |
| `lib_fine` | ৫টা | শুধু দেরিতে ফেরত হলে হয় |

> **টিপস:** প্রতিটা লাইন নতুন করে টাইপ কোরো না। একটা লাইন লিখে কপি করে মান বদলাও। প্রতি টেবিলের পরে `COMMIT` দাও।

**যুক্তি মেলাও:** যে কপি এখনো ফেরত আসেনি, তার `copy_status` হবে `ISSUED`। ইস্যুর তারিখ ফেরতের তারিখের পরে হতে পারবে না।

### ধাপ ৪: যাচাই ও পরিবর্তন (২০ মিনিট)

**১. রো গুনে দেখো** (`COUNT` বিস্তারিত সপ্তাহ ৮-এ):

```sql
SELECT COUNT(*) FROM lib_book;
SELECT COUNT(*) FROM lib_member;
SELECT COUNT(*) FROM lib_book_issue;
```

**২. Constraint কাজ করছে কি না দেখো।** প্রতিটা এরর কোড খাতায় লেখো:
1. একই `barcode` দিয়ে দ্বিতীয় কপি
2. যে বই নেই, তার কপি
3. `copy_status = 'MISSING'`
4. ইস্যু হয়েছে এমন মেম্বার মোছা
5. একই ইস্যুর দ্বিতীয় জরিমানা

**৩. Transaction হিসেবে করো:** ৩ নম্বর মেম্বার ১৬ নম্বর কপিটা নিলেন। `lib_book_issue`-তে রো ঢোকাও, আর `lib_book_copy`-তে স্ট্যাটাস `ISSUED` করো। দুইটা মিলে একটা Transaction।

**৪. আরেকটা Transaction:** ওই বই ফেরত এলো। `return_date` বসাও, আর কপি আবার `AVAILABLE` করো।

**৫. ALTER:** `lib_book`-এ `total_pages` কলাম যোগ করো (০-এর বেশি, Check সহ)। `lib_member`-এ `address` কলাম যোগ করো।

**৬. ব্যাকআপ:** `lib_book_bak` নামে `lib_book`-এর কপি বানাও। মূল টেবিলের সব `publish_year` `WHERE` ছাড়া `2000` করে `ROLLBACK` দাও। তারপর `lib_book_bak` মুছে দাও।

```sql
CREATE TABLE lib_category (
    category_id    NUMBER(5),
    category_name  VARCHAR2(100) NOT NULL,
    CONSTRAINT lib_category_pk PRIMARY KEY (category_id),
    CONSTRAINT lib_category_name_uk UNIQUE (category_name)
);

CREATE TABLE lib_publisher (
    publisher_id    NUMBER(5),
    publisher_name  VARCHAR2(150) NOT NULL,
    CONSTRAINT lib_publisher_pk PRIMARY KEY (publisher_id),
    CONSTRAINT lib_publisher_name_uk UNIQUE (publisher_name)
);

CREATE TABLE lib_author (
    author_id    NUMBER(10),
    author_name  VARCHAR2(150) NOT NULL,
    CONSTRAINT lib_author_pk PRIMARY KEY (author_id)
);

CREATE TABLE lib_shelf (
    shelf_id    NUMBER(5),
    shelf_code  VARCHAR2(20) NOT NULL,
    CONSTRAINT lib_shelf_pk PRIMARY KEY (shelf_id),
    CONSTRAINT lib_shelf_code_uk UNIQUE (shelf_code)
);

CREATE TABLE lib_member_type (
    member_type_id  NUMBER(3),
    type_name       VARCHAR2(30) NOT NULL,
    max_books       NUMBER(2)    NOT NULL,
    max_days        NUMBER(3)    NOT NULL,
    CONSTRAINT lib_member_type_pk PRIMARY KEY (member_type_id),
    CONSTRAINT lib_member_type_name_uk UNIQUE (type_name),
    CONSTRAINT lib_member_type_books_ck CHECK (max_books > 0),
    CONSTRAINT lib_member_type_days_ck CHECK (max_days > 0)
);

CREATE TABLE lib_staff (
    staff_id    NUMBER(5),
    staff_name  VARCHAR2(100) NOT NULL,
    username    VARCHAR2(50)  NOT NULL,
    CONSTRAINT lib_staff_pk PRIMARY KEY (staff_id),
    CONSTRAINT lib_staff_username_uk UNIQUE (username)
);

CREATE TABLE lib_book (
    book_id       NUMBER(10),
    book_title    VARCHAR2(300) NOT NULL,
    isbn          VARCHAR2(20),
    publish_year  NUMBER(4),
    category_id   NUMBER(5)     NOT NULL,
    publisher_id  NUMBER(5)     NOT NULL,
    CONSTRAINT lib_book_pk PRIMARY KEY (book_id),
    CONSTRAINT lib_book_isbn_uk UNIQUE (isbn),
    CONSTRAINT lib_book_category_fk FOREIGN KEY (category_id) REFERENCES lib_category (category_id),
    CONSTRAINT lib_book_publisher_fk FOREIGN KEY (publisher_id) REFERENCES lib_publisher (publisher_id)
);

CREATE TABLE lib_book_author (
    book_id       NUMBER(10),
    author_id     NUMBER(10),
    author_order  NUMBER(2) NOT NULL,
    CONSTRAINT lib_book_author_pk PRIMARY KEY (book_id, author_id),
    CONSTRAINT lib_book_author_order_uk UNIQUE (book_id, author_order),
    CONSTRAINT lib_book_author_book_fk FOREIGN KEY (book_id) REFERENCES lib_book (book_id),
    CONSTRAINT lib_book_author_author_fk FOREIGN KEY (author_id) REFERENCES lib_author (author_id),
    CONSTRAINT lib_book_author_order_ck CHECK (author_order > 0)
);

CREATE TABLE lib_book_copy (
    copy_id      NUMBER(10),
    book_id      NUMBER(10)   NOT NULL,
    shelf_id     NUMBER(5),
    barcode      VARCHAR2(30) NOT NULL,
    copy_status  VARCHAR2(20) DEFAULT 'AVAILABLE' NOT NULL,
    CONSTRAINT lib_book_copy_pk PRIMARY KEY (copy_id),
    CONSTRAINT lib_book_copy_barcode_uk UNIQUE (barcode),
    CONSTRAINT lib_book_copy_book_fk FOREIGN KEY (book_id) REFERENCES lib_book (book_id),
    CONSTRAINT lib_book_copy_shelf_fk FOREIGN KEY (shelf_id) REFERENCES lib_shelf (shelf_id),
    CONSTRAINT lib_book_copy_status_ck CHECK (copy_status IN ('AVAILABLE', 'ISSUED', 'LOST', 'DAMAGED'))
);

CREATE TABLE lib_member (
    member_id       NUMBER(10),
    member_name     VARCHAR2(100)      NOT NULL,
    member_name_bn  VARCHAR2(100 CHAR),
    mobile_no       VARCHAR2(20)       NOT NULL,
    email           VARCHAR2(100),
    join_date       DATE               DEFAULT TRUNC(SYSDATE) NOT NULL,
    is_active       CHAR(1)            DEFAULT 'Y' NOT NULL,
    member_type_id  NUMBER(3)          NOT NULL,
    CONSTRAINT lib_member_pk PRIMARY KEY (member_id),
    CONSTRAINT lib_member_mobile_uk UNIQUE (mobile_no),
    CONSTRAINT lib_member_email_uk UNIQUE (email),
    CONSTRAINT lib_member_type_fk FOREIGN KEY (member_type_id) REFERENCES lib_member_type (member_type_id),
    CONSTRAINT lib_member_is_active_ck CHECK (is_active IN ('Y', 'N'))
);

CREATE TABLE lib_book_issue (
    issue_id     NUMBER(10),
    copy_id      NUMBER(10) NOT NULL,
    member_id    NUMBER(10) NOT NULL,
    staff_id     NUMBER(5)  NOT NULL,
    issue_date   DATE       DEFAULT TRUNC(SYSDATE) NOT NULL,
    due_date     DATE       NOT NULL,
    return_date  DATE,
    CONSTRAINT lib_book_issue_pk PRIMARY KEY (issue_id),
    CONSTRAINT lib_book_issue_copy_fk FOREIGN KEY (copy_id) REFERENCES lib_book_copy (copy_id),
    CONSTRAINT lib_book_issue_member_fk FOREIGN KEY (member_id) REFERENCES lib_member (member_id),
    CONSTRAINT lib_book_issue_staff_fk FOREIGN KEY (staff_id) REFERENCES lib_staff (staff_id),
    CONSTRAINT lib_book_issue_due_ck CHECK (due_date >= issue_date),
    CONSTRAINT lib_book_issue_return_ck CHECK (return_date >= issue_date)
);

CREATE TABLE lib_fine (
    issue_id     NUMBER(10),
    fine_amount  NUMBER(8,2) NOT NULL,
    is_paid      CHAR(1)     DEFAULT 'N' NOT NULL,
    paid_date    DATE,
    CONSTRAINT lib_fine_pk PRIMARY KEY (issue_id),
    CONSTRAINT lib_fine_issue_fk FOREIGN KEY (issue_id) REFERENCES lib_book_issue (issue_id),
    CONSTRAINT lib_fine_amount_ck CHECK (fine_amount > 0),
    CONSTRAINT lib_fine_is_paid_ck CHECK (is_paid IN ('Y', 'N'))
);
```
