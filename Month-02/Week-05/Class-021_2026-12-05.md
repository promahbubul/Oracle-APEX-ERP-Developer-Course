## ১. SQL কী (২৫ মিনিট)

**SQL (Structured Query Language)** হলো রিলেশনাল ডাটাবেসের সাথে কথা বলার ভাষা।

এতে তুমি বলো **কী চাও**, **কীভাবে আনবে** সেটা Oracle নিজে ঠিক করে।

```sql
SELECT first_name, salary
FROM   hr.employees
WHERE  department_id = 90;
```

এখানে তুমি বলোনি কোন ফাইল খুলতে হবে, বা কীভাবে খুঁজতে হবে। শুধু বলেছ কী দরকার। একে বলে **Declarative** ভাষা।

| | SQL | PL/SQL (সপ্তাহ ১৪ থেকে) |
|---|---|---|
| ধরন | Declarative: কী চাই | Procedural: ধাপে ধাপে কীভাবে |
| কাজ | ডাটা আনা, রাখা, বদলানো | if-else, loop দিয়ে লজিক |
| উদাহরণ | `SELECT`, `INSERT` | `IF`, `LOOP` |

### সব ডাটাবেসে কি SQL একই?

SQL-এর একটা আন্তর্জাতিক মান (ANSI/ISO Standard) আছে। মূল অংশ প্রায় সব ডাটাবেসে একই, কিন্তু প্রতিটার নিজস্ব কিছু জিনিসও আছে।

| কাজ | Oracle | অন্য ডাটাবেসে (উদাহরণ) |
|---|---|---|
| বর্তমান তারিখ | `SYSDATE` | `NOW()` (MySQL) |
| লেখা জোড়া | `||` | `CONCAT()` (MySQL) |
| লেখার Data Type | `VARCHAR2` | `VARCHAR` |
| ডামি টেবিল | `FROM dual` | প্রায়ই লাগে না |

তাই আমরা **Oracle SQL** শিখব। এটা ভালো জানলে অন্য ডাটাবেসে যাওয়া কঠিন হয় না।

## ২. SQL লেখার নিয়ম (৩০ মিনিট)

### যা মানতেই হবে

**১. স্টেটমেন্টের শেষে সেমিকোলন `;`**

```sql
SELECT * FROM dual;
```

**২. SQL-এর শব্দ ছোট বা বড় হাতের যেকোনোভাবে লেখা যায়**

```sql
SELECT * FROM hr.departments;
select * from hr.departments;     -- একই কাজ
```

**৩. কিন্তু লেখার মান (Single Quote-এর ভেতরে) ছোট-বড় আলাদা**

```sql
SELECT first_name, last_name FROM hr.employees WHERE last_name = 'King';   -- ২ জন
SELECT first_name, last_name FROM hr.employees WHERE last_name = 'KING';   -- কেউ না
```

> `hr.employees` দেখার অনুমতি না থাকলে ক্লাস ৯-এর `GRANT` আবার চালাও, অথবা `hr_freepdb1` কানেকশনে চালাও।

**৪. লাইন বা স্পেসে কিছু যায় আসে না**

```sql
SELECT first_name FROM hr.employees WHERE employee_id = 100;

SELECT first_name
FROM   hr.employees
WHERE  employee_id = 100;
```

দুইটা একই। দ্বিতীয়টা পড়া সহজ, তাই এভাবে লিখবে।

### ভালো অভ্যাস

| অভ্যাস | উদাহরণ |
|---|---|
| SQL-এর শব্দ বড় হাতে, নাম ছোট হাতে | `SELECT first_name FROM employees` |
| প্রতিটা অংশ আলাদা লাইনে | `SELECT`, `FROM`, `WHERE` |
| কমেন্ট দিয়ে "কেন" লেখা | নিচে দেখো |

### কমেন্ট

```sql
-- এক লাইনের কমেন্ট

/* একাধিক লাইনের কমেন্ট
   এখানেও লেখা যায় */

SELECT 1 + 1 AS result FROM dual;   -- লাইনের শেষেও কমেন্ট দেওয়া যায়
```

### SQL আর টুলের কমান্ড আলাদা

কিছু কমান্ড আসলে SQL না। এগুলো চলে SQL*Plus বা SQL Developer-এর মতো টুলে।

| কমান্ড | কী | সেমিকোলন লাগে? |
|---|---|---|
| `SELECT`, `INSERT`, `CREATE` | SQL | হ্যাঁ |
| `DESC`, `SET DEFINE OFF`, `SHOW CON_NAME` | টুলের কমান্ড | না |

এজন্যই APEX-এর SQL Commands বা অন্য টুলে এদের কিছু কাজ না-ও করতে পারে।

## ৩. SQL-এর চার ভাগ (৪০ মিনিট)

| ভাগ | পূর্ণরূপ | কাজ | কমান্ড | কবে শিখব |
|---|---|---|---|---|
| **DDL** | Data Definition Language | গঠন তৈরি ও বদলানো | `CREATE`, `ALTER`, `DROP`, `TRUNCATE`, `RENAME`, `COMMENT` | ক্লাস ২২, ২৩ |
| **DML** | Data Manipulation Language | ডাটা আনা ও বদলানো | `SELECT`, `INSERT`, `UPDATE`, `DELETE`, `MERGE` | ক্লাস ২৪, সপ্তাহ ৬ থেকে |
| **DCL** | Data Control Language | অনুমতি | `GRANT`, `REVOKE` | ক্লাস ৯, সপ্তাহ ১৩ |
| **TCL** | Transaction Control Language | পরিবর্তন স্থায়ী বা বাতিল | `COMMIT`, `ROLLBACK`, `SAVEPOINT` | ক্লাস ২৫ |

> কিছু বইয়ে `SELECT`-কে আলাদা করে **DQL (Data Query Language)** বলে। Oracle-এর ডকুমেন্টে এটা DML-এর মধ্যে ধরা হয়। ইন্টারভিউতে দুইটাই জেনে রাখো।

### বাড়ির উদাহরণ

| ভাগ | বাড়ির সাথে তুলনা |
|---|---|
| **DDL** | বাড়ি বানানো, ঘর ভাঙা (গঠন) |
| **DML** | ঘরের ভেতর আসবাব রাখা, সরানো (জিনিসপত্র) |
| **DCL** | কাকে চাবি দেবে (অনুমতি) |
| **TCL** | সিদ্ধান্ত পাকা করা, বা বাতিল করা |

### সবচেয়ে জরুরি পার্থক্য

| | DDL | DML |
|---|---|---|
| কী বদলায় | টেবিলের গঠন | টেবিলের ডাটা |
| `ROLLBACK` দিয়ে ফেরানো যায়? | **না** | **হ্যাঁ**, `COMMIT`-এর আগে |
| নিজে নিজে `COMMIT` হয়? | **হ্যাঁ** | না |

**DDL চালালেই আগের সব না-COMMIT করা পরিবর্তন স্থায়ী হয়ে যায়।** ক্লাস ২৫-এ নিজে পরীক্ষা করে দেখবে।

## ৫. একটা টেবিলের জীবনচক্র (৩০ মিনিট)

চারটা ভাগ একসাথে দেখো। `learn_freepdb1`-এ `Ctrl + Enter` দিয়ে **একটা একটা করে** চালাও, আর প্রতিটার পরে ফল দেখো।

```sql
-- DDL: টেবিল বানানো
CREATE TABLE w5_demo (
    demo_id    NUMBER(5) CONSTRAINT w5_demo_pk PRIMARY KEY,
    item_name  VARCHAR2(50) NOT NULL,
    qty        NUMBER(8)
);

-- DML: ডাটা ঢোকানো
INSERT INTO w5_demo VALUES (1, 'Button 18L', 500);
INSERT INTO w5_demo VALUES (2, 'Zipper 7 inch', 200);

-- DML: ডাটা দেখা
SELECT * FROM w5_demo;

-- TCL: স্থায়ী করা
COMMIT;

-- DML: বদলানো
UPDATE w5_demo SET qty = 999 WHERE demo_id = 1;
SELECT * FROM w5_demo;

-- TCL: বাতিল করা
ROLLBACK;
SELECT * FROM w5_demo;       -- qty আবার 500

-- DCL: অনুমতি দেওয়া আর ফেরত নেওয়া
GRANT SELECT ON w5_demo TO store_user;
REVOKE SELECT ON w5_demo FROM store_user;

-- DDL: গঠন বদলানো
ALTER TABLE w5_demo ADD (remarks VARCHAR2(100));
DESC w5_demo

-- DDL: টেবিল মুছে ফেলা
DROP TABLE w5_demo;
```

> `store_user` ক্লাস ৯-এ বানিয়েছিলে। না থাকলে `GRANT`, `REVOKE` দুই লাইন বাদ দাও।
